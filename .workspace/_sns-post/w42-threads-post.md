## ポスト1: マンションで楽器は何時まで弾けるか

- タイプ: ②クエリ疑問オープナー型
- ソース: `mansion-instrument-practice-time-rules`／「マンション 楽器 何時まで」（`weekly-task.md` W-12）
- 切り口: 全国共通の時刻ルールはなく、管理規約・条例・受忍限度の3つで判断する
- フック型: 疑問（検索者の言葉＋本音の言語化）
- 続き誘導: 数の約束（3つの物差し）／情報ギャップ（物差しの中身と、決まっているかで変わる点を伏せる）／橋渡し（2/3末尾「規約に何も書いていなかったら？」→3/3で回収）
- 投稿予定: 2026-10-05（月）
- 投稿: [ ] 済（投稿日 / URL: ）
- 合計: 838字

### 1/3（198字）

```
「マンションで楽器、何時まで弾いていいの？」

本当に知りたいのは、時刻そのものより「ここまでなら苦情は来ない」という安心の線ではないでしょうか。

でも、全国共通の「何時まで」という答えは存在しません。検索しても、はっきりした答えが出てこないのはそのせいです。

では何を基準にすればいいのか。答えは3つの物差しにあり、そのうち1つが決まっているかどうかで話が大きく変わります。

（1/3）👇
```

### 2/3（281字）

```
その3つの物差しがこちらです。

① 管理規約・使用細則（物件ごとに内容が違う）
② 自治体の条例（多くは時刻ではなく、音量の目安を示すだけ）
③ 受忍限度（音量・時間帯・頻度・継続性から総合的に判断される、お互いの我慢の範囲）

使用細則では、こんな文言をよく見かけます。

「ピアノ等の演奏は、十分な防音措置を講じたうえで午前9時から午後8時までの間に行うこと」

時間帯が書いてあれば、それが最優先の基準です。まずは手元の規約や契約書類を確認するのが一番確実です。

では、規約に何も書いていなかったら？ 次で、その場合の目安をまとめます。

（2/3）👇
```

### 3/3（359字）

```
規約に何も書いていない物件も、珍しくありません。

その場合の一般的な目安は、平日9〜20時ごろ・休日10〜19時ごろ。日中に常識的な音量で短時間なら、受忍限度の範囲内とみなされやすい傾向があります。ただし、これは法的な保証ではなく「トラブルになりにくい範囲」の話です。

ピアノの音は90〜100dB。自治体の生活騒音の目安（地域により異なりますが、昼間55dB・夜間45dB程度の例があります）をはるかに超えるので、時間帯だけでなく防音対策もセットで考える必要があります。

あなたの物件の規約には、何時までと書いてありますか？

楽器別の注意点と判断手順はこちら
https://bouon-lab.com/ja/knowledge/mansion-instrument-practice-time-rules/
```

## ポスト2: 防音室の「-40dB」はどれくらい静かになるか

- タイプ: ①小ネタ型
- ソース: `db-reduction-familiar-sound-scale`
- 切り口: D-40で110dBの楽器音が隣室では掃除機レベル（約70dB）になる計算と、「10dBで半分」の体感換算。低音は別という注意つき
- フック型: 数値（楽器の音量＝救急車並み）
- 続き誘導: 情報ギャップ（体感に置き換えた答えを伏せる）／橋渡し（2/3末尾「計算どおりにはいかない音」→3/3の低音で回収）
- 投稿予定: 2026-10-08（木）
- 投稿: [ ] 済（投稿日 / URL: ）
- 合計: 537字

### 1/3（176字）

```
ピアノやサックスの音量は、90〜110dB。

救急車のサイレン（近距離で約90dB）と同じか、それ以上の大きさです。

カタログに並ぶ「-40dB」と言われても、ピンとこない方が多いはず。

防音室に入れると、この音はどこまで静かになるのでしょうか。「-dB」の数字は、体感に置き換えるとイメージしやすくなります。次で計算してみます。

（1/3）👇
```

### 2/3（172字）

```
「D-40」の防音室に入れると、理論上は約40dB下がります。110dBの音が、隣の部屋では掃除機くらい（約70dB）になる計算です。

耳には、10dB下がるごとに「半分の大きさ」に聞こえるのが目安。40dB下がれば、体感ではおよそ16分の1です。

ただし、この計算どおりにはいかない音があります。次で、その音を紹介します。

（2/3）👇
```

### 3/3（189字）

```
それは低音です。ドラムやベースの低い音は、カタログの数字ほど下がらないことが多いです。

「-dB」の数字は、楽器の音域で効き方が変わります。防音室を選ぶときは、自分の楽器でいくつ下げたいかから考えるのが近道です。

用途別の目安はこちら
https://bouon-lab.com/ja/knowledge/db-reduction-familiar-sound-scale/
```
