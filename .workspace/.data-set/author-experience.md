## 1. 体験（記事で使ってよい）

| テーマ | 体験（回答の要旨） | 使った記事 |
|---|---|---|
| ドア・隙間 | 音漏れが気になったことはない。冷暖房の効きのために部屋のドアの隙間は埋めている。ドアはごく普通の軽い木製で、防音素材ではない | `diy/door-soundproof` |
| 隙間テープ | 買ったことがある。100均とホームセンターで見た。ホームセンターは種類と厚みを選べるが、自宅のドアに貼れるかを売り場で考える必要があった。厚いテープで留め具が浮いたことがある | `diy/door-soundproof` |
| 耳栓 | 最初は耳に詰めるだけの安い耳栓だったが、横向きで寝ると邪魔になるので、寝転んでも邪魔にならない睡眠用を買って使っている（DJcong QuietFit 睡眠用耳栓、ASIN B0F1FYBV2G）。100均・ドラッグストアの耳栓は遮音性がそれほど高くないと感じている | `soundproof-rental/earplugs-for-sleep` |
| 寝るときの音 | BT イヤホンで ASMR や動画を聴きながら眠ることがある | `soundproof-rental/earplugs-for-sleep` |
| 耳栓の不安 | 耳が痛くなる・かゆくなるのが気になる | `soundproof-rental/earplugs-for-sleep` |
| 足音 | 住まいで困ったことはない。ホテルの廊下のスリッパ音や、かかとでドスドス歩く音は気になったことがある（その場ではどうしようもない） | `soundproof-rental/upstairs-footsteps-noise` |
| 苦情を伝える迷い | 関係が悪くならないか、気にしすぎか、どこに言うか、言っても変わらないか、の全部で迷う | `soundproof-rental/upstairs-footsteps-noise` |
| 室外機 | 戸建てなので気にしたことはない。ベランダに置くことを考えたが、うるさいだろうと思ってやめた | `knowledge/outdoor-ac-unit-noise` |
| 床・マット | 自宅のトレーニングでバーピーをするときヨガマットを敷いている。ないと響いていると感じた | `diy/floor-soundproof-underlay` |
| 床の張り替え | ためらうのは手間。戸建てなら考えるが、部屋の物を全部出す必要があり業者に頼みたいレベル。賃貸ならオーナーの許可で可否が決まるので、かえって決めやすいかもしれない | `diy/floor-soundproof-underlay` |
| 騒音で引っ越し | 考えたことはあるが、立地の利便性で引っ越す選択肢がない。費用を請求するならためらうのは 弁護士費用＞相手との関係＞時間 | `soundproof-rental/noise-moving-cost-claim` |
| 部屋の響き | ふだんはヘッドホンで収録もしないので気になったことはない。電話で相手側の響きが気になることはあるが、自分が指摘されたことはない | `diy/sound-absorbing-material-recommend` |
| 吸音材 | 買ったことはない。ためらうのは、効くか分からないことと、貼って剥がれないかの心配 | `diy/sound-absorbing-material-recommend` |
| 壁の DIY | 壁に棚を固定したことがある。突っ張り棒の経験もある。遮音シートは使ったことがない（全面か一部か、剥がすことを考えると踏み出せない）。自分で貼るなら、きれいに切れるかが不安 | `diy/sound-insulation-sheet-wall-install` |
| カーテン | 遮光目的で使っている。遮光90%の数字が想像しづらく、実店舗で触ってから買った。防音カーテンで迷うのは、効くか分からないことと見た目・色 | `diy/soundproof-curtain-recommend` |
| キーボード | メカニカルキーボードにフェルトマットを敷いて、幾分かマシになった（記憶の記録から。素材はフェルトをすすめ、控えめに書く） | 打鍵音の記事 |

## 2. 書き方の好み（アウトライン・指示書に反映する）

- **用語は正式名称から**: NRR・SNR などの略語は、何の頭文字かを書く。タッカーのような道具は「壁に布などを留める、壁用のホッチキスのようなもの」と形容する
- **数値は身近な比較で**: 「0.8なら8割」のように日常の割合へ。dB の差は、会話とささやき声の差（30dB）などの身近な差と比べる（6dB だけでは分からない）。重さは2Lペットボトル6本入りの箱・米袋など
- **専門用語より体感**: 「重量床衝撃音」より、ライブやフェスでバスドラムやベースを体で感じる、のたとえ
- **次にやることは、手に入る方法で**: 存在や入手先が分からないもの（試供パックなど）を次の行動にしない。環境ごとに分けてから1つに絞る
- **商品の紹介**: 安さ推しはしない。性能とレビューの評価、買って後悔しない選び方で。最強を選ぶなら数値（遮音性能と価格）で示す
- **店**: ドアの隙間の品は100均とホームセンター（ニトリには置いていない）
- **相手を悪く書かない**: 騒音の相手を責めず、協力してもらう方向で。同じ建物内の問題は、民事やオーナーを通した話し合いが中心。警察は緊急時だけ
- **弁護士**: 特定の事務所を指名せず、「近くで探す」という選択肢にする
- **生活保護の話**: 筆者自身の話として書くと「贅沢な悩み」に読まれるので避ける
- **賃貸の注意**: タッカーで壁に留めるのは契約上NGになりうると書く
- **読者の想定**: 簡易な対策を紹介するときは、賃貸の6畳で置くだけの前提が当てはめやすい
