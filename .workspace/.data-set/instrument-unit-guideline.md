# 楽器別の防音室（ユニット）の目安 — 記事で使う数字の正本

作成: 2026-11-25（hq、inbox I-30・I-35）／目的: 楽器ごとの Dr 値・広さ・簡易ブースの可否が記事でばらばらだったのを1つにする。反映先: `wind-string-instrument-booth-selection` ほか（指示書 `.workspace/codex/orders/2026-11-25-I-30.md`）

記事に楽器別の目安を書くときは、この表の値を使う。変えるときは、この表を直してから記事をそろえる（`grep` の語は末尾）。

- Dr値・広さは島村楽器グランフロント大阪店の区分が中心。「夜は Dr-40」は販売店の案内で、下限の数字。夜の練習の記事の表では「Dr-40以上」と書く。**建物の壁の条件つき**。木造・軽量鉄骨では Dr-40 でも隣に約40dBが届く計算（110dB−40−30、`wind-string-instrument-booth-selection` の表）なので、夜は消音器を併用するか避ける、と添える
- 「足りる・窮屈・厳しい」は、内寸と楽器の寸法からの当サイトの判定（販売店の案内は店で分かれる。市川コルトンプラザ店はトロンボーン1.5畳から、弦楽器0.8畳から）。**当サイトの目安と書く**
- レンタル会社の料金表にある用途（音レントの「1.2畳 管楽器・ギター用」「1.5畳 チェロ用」など）は会社の区分の可能性があるため、この表に合わせて書き換えない
- オーボエの音量・Dr・広さ、声楽の値、ホルンは販売店の区分にない

## 2. 簡易ブース（10万円台）

- だんぼっち: 公式は「声」の中〜高音向けで「完全防音の製品ではない」と案内。管楽器の案内は見つからない。→ 歌・声楽の昼の練習まで。**管楽器に「足りる」と書かない**
- OTODASU II: 公式 FAQ は「ギター、バイオリン、フルート、サックスなどの練習に多くご利用」「管楽器は音圧が高いため、最終的な防音性能は不十分な場合がある」。→ 練習はできるが、漏れは残る。昼〜夕方、鉄筋コンクリートの条件つきで書く

## 3. 物件（防音賃貸）の D値 は別の表

建物の壁の遮音で、防音室の Dr とは見方が違う。目安は `bouon-dchiseinou-meyasu` の「楽器別に、物件に求めたいD値の目安」（サックス・金管 D-55〜60 など）。**防音室の目安に物件の数字を当てない。** 地域の記事の「D-50：ピアノ・管楽器」などとの統一はまだ（T-68 で扱う）。
