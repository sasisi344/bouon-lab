## 1. エグゼクティブサマリー

| 仮説 | 検証結果 |
| :--- | :--- |
| 防音賃貸の平均家賃は8〜12万円前後 | **おおむね妥当**。MUSISION 1K下限の中央値は**約10.3万円**（n=26棟、2026-06-24時点） |
| 平均は都心・利便性物件に引っ張られている | **正しい**。都心クラスタ（下北沢・早稲田・世田谷等）の1K下限は**12.7〜16.3万円**、埼玉・西東京クラスタは**6.7〜9.1万円** |
| 郊外ならもっと安い選択肢がある | **正しいが条件付き**。絶対家賃は**3〜5万円安い**が、**空室待ち・通勤コスト・築年**のトレードオフが大きい |

**記事に使える結論（1文）**  
防音賃貸の「相場8〜12万」は首都圏ブランド物件の**中央帯**であり、利便性を下げれば**7万台前後**まで下がる一方、**一般賃貸との差（プレミアム率）は郊外でも30〜60%**と縮まらない。

## 5. 「8〜12万」仮説の精緻化

### 当てはまる条件

- MUSISION・Livlan等の**ブランド防音**で1Kを探す場合
- **首都圏（1都3県）**に限定した場合
- **掲載レンジの中央付近**（下限6.7万〜上限16.3万の中間）

### 当てはまらない／注意が必要な条件

| 条件 | 実態 |
| :--- | :--- |
| 都心・新築・駅近を希望 | **13〜20万**が現実的（下北沢・板橋駅前・世田谷新築） |
| 郊外最安を狙う | **7〜9万**まで下がるが、**築20年以上**の物件が中心（川越・志木旧棟） |
| 楽器相談可のみ | 一般相場+0〜10%。**8万以下**も存在するが遮音保証なし |
| 管理費・必須オプション込み | MUSISIONはポータル料等で**月+1,700円程度**（下記） |

### MUSISIONの実質コスト（記事用）

| 項目 | 金額 | 月額換算 |
| :--- | :--- | :---: |
| 入居者専用ポータル（2年） | 26,400円（税込） | 1,100円 |
| 24時間緊急対応（2年・必須） | 15,000円（税込） | 625円 |
| **合計** | — | **約1,725円/月** |

家賃比較時は「賃料+管理費+必須オプション」で揃える。

## 7. コスパ判断フレーム（記事構成用）

### 7-1. 実質コスト比較式

```
実質月額 = 家賃 + 管理費 + 必須オプション + 通勤交通費（都心勤務の場合）
```

| シナリオ | 住居エリア | 家賃目安 | 通勤（都心） | 実質目安 |
| :--- | :--- | :---: | :---: | :---: |
| A. 都心防音 | 下北沢 | 16.3万 | ほぼ0 | **16.5万** |
| B. 23区北部防音 | 野方 | 12.5万 | 月0.8〜1.0万 | **13.5〜13.8万** |
| C. 埼玉防音 | 志木 | 10.6万 | 月1.0〜1.2万 | **11.8〜12.0万** |
| D. 川越防音 | 川越 | 9.1万 | 月1.2〜1.5万 | **10.5〜10.8万** |
| E. 一般賃貸+スタジオ | 任意 | 8万+4万 | 任意 | **12万+** |

**示唆**: リモートワークなら **C・Dの実質コストが都心に近づく**。都心勤務なら **Bがバランス型**。

### 7-2. ペルソナ別・優先エリア早見

| ペルソナ | 最優先 | 家賃帯目安 | 妥協しやすい要素 | 妥協しにくい要素 |
| :--- | :--- | :--- | :--- | :--- |
| 音大・プロ奏者 | 国立・早稲田・下北沢 | 10〜16万 | 築年・面積 | D値・搬入動線 |
| VTuber・配信者 | 野方・西台・千葉 | 10〜13万 | 都心距離 | 深夜帯D-60以上・10G回線 |
| 会社員（週3出社） | 武蔵中原・登戸・下赤塚 | 10〜12万 | 築年 | 駅徒歩・通勤1本 |
| コスパ最優先 | 川越・小平・志木 | 7〜10万 | 利便性・築年 | 入居待ちの長さ |

### 7-3. 郊外選択の3つの注意（記事用チェックリスト）

1. **プレミアム率は下がらない** — 絶対家賃は安いが、地域相場比では+60%前後は珍しくない
2. **安い物件ほど築古** — 川越（2000年）・志木（2003年）など。遮音性能は維持されていても設備が古い
3. **「待機」が前提** — ウェイティング登録と審査書類の事前準備が必須（[`report-japan-soundproof-rental-market-needs`](../../../src/content/ja/soundproof-rental/report-japan-soundproof-rental-market-needs/index.mdx) 参照）
