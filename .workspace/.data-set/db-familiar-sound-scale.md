# dBの大きさを身近な空間で例える基準（正本）

記事で「◯dBは△△くらい」と書くときは、この表の言い方だけを使う。記事ごとに例えがずれると（図書館＝30dB／40dB、50dB＝静かな事務所／普通の会話など）、読者が数字を比べられなくなるため。2026-10-18に決定。

## 1. 下がったあとの音・周りの静かさを例える表（標準）

Dr値で下がったあとの音、夜の住宅地の静かさ、侵入音など「その場の音の大きさ」を例えるときに使う。

| dB | 身近な空間 | 体感の言い方 |
| :-- | :-- | :-- |
| 30 | ホテルの客室 | とても静か。小さな物音も目立つ |
| 40 | 図書館の館内、住宅地の夜 | 静か。ただし音楽が鳴っていれば分かる |
| 50 | 書店の店内、マンションが多い地域の昼 | 静かだが、人の気配や物音がある |
| 60 | 銀行の窓口、博物館の館内 | ふつうに話す声の大きさ |
| 70 | バスの車内、コーヒーショップ | 少し声を張らないと話しにくい |
| 80 | 地下鉄の車内、飛行機の機内 | 大きな声でないと話せない |
| 90 | パチンコ店の店内 | 長くいるとつらい |

出典: [環境省「騒音の目安」](https://www.env.go.jp/air/ippan/meyasu.pdf)（全国環境研協議会 騒音小委員会、図1 都心・近郊用）。実測の分布図を10dB刻みに丸めた目安。図の読み取り値（参考）: ホテルの室内30台前半、住宅地の夜30台後半、図書館40台前半、戸建住宅地の昼40台半ば、書店・高層住宅地域の昼50台前半、銀行の窓口・博物館60台前半、バス・コーヒーショップ70弱、地下鉄・在来線70台半ば、航空機の機内80前後、パチンコ店90。

## 2. 音を出す側の大きさ（音源）

楽器・声など「出す音」の大きさは、こちらを使う。

| dB | 音源 |
| :-- | :-- |
| 30 | ささやき声 |
| 60 | ふつうの会話 |
| 70 | 騒々しい街頭 |
| 80 | ピアノの演奏（前方1m） |
| 90 | 大声による独唱 |
| 100 | 電車が通るときのガード下 |
| 110 | 自動車の警笛（前方2m） |
| 120 | 飛行機のエンジンの近く |

出典: 日本環境協会「騒音の大きさの例」（[広島県の資料](https://www.pref.hiroshima.lg.jp/uploaded/attachment/577712.pdf)ほか、多くの自治体が引用）。

- ピアノは「正面1mで80〜90dB」と書く（表の80dBに、強く弾く曲の幅を足す）
- 叫び声・ゲーム実況の大声は「90dB前後（大声で歌うくらい）」
- 管楽器・ドラムなど、表にない楽器の値は記事ごとに出典を付ける

## 3. 書き方のルール

1. <strong>下がったあとの音は、その場の静かさと比べて書く</strong>。数字だけだと「聞こえない」と受け取られる
   - 例: 「外では図書館の館内くらい（40dB）。ただし夜の住宅地も40dB前後なので、曲が流れていることは分かる」
2. 音楽や声は、周りと同じくらいの大きさでも「何の音か」が分かりやすい。周りより十分に小さい場合だけ「気になりにくい」と書く
3. Dr値・D値の計算で例えるときは、<strong>低い音ほど下がりにくい</strong>ことを1文添える（Dr値は周波数ごとの等級で、低音側の基準が緩い）
4. 10dB下がると、耳にはおよそ半分の大きさに感じる（この言い方は使ってよい）
5. 環境基準・条例の数値（夜間45dBなど）を例えるときも表1を使う（45dB＝図書館の館内と書店の店内の間）

## 4. 使わない言い方

| 使わない | 理由 | 代わりに |
| :-- | :-- | :-- |
| 図書館＝30dB | 出典では40dB台 | 30dBはホテルの客室 |
| 40dB＝ささやき声 | ささやき声は30dB | 40dBは図書館の館内 |
| 50dB＝静かな事務所 | 読者が思い浮かべにくい | 書店の店内 |
| 50dB＝普通の会話 | 普通の会話は60dB | 60dBは銀行の窓口・ふつうの会話 |
| 外の風の音 | 風の強さで20〜60dB以上変わり、公的な目安にもない | 表1から選ぶ |
| 騒がしいオフィス、小さなテレビの音 | 人によって想像する大きさが違う | 表1から選ぶ |
| 掃除機 | 機種で大きく違う（60〜70dB台） | 表1から選ぶ |
