# 防音グッズ・設備データベース

防音室や防音DIYで使用される主要なグッズ・設備の情報を統合したデータベースです。
「電気・配線」「床・開口部」「照明・環境」の3カテゴリに分類しています。

---

## 1. 電気・配線まわり（遮音コンセント・スイッチ）

### 概要：なぜ対策が必要なのか？
**結論：壁の「穴」が最大の弱点だから**
壁の防音性能は「質量・多重構造・気密性」で決まりますが、コンセントやスイッチ部分は壁に穴を開けるため、そこが音の漏れる「最弱ポイント」になります。
- 通常の壁：D-50〜60の性能があっても、穴があるとD-20相当まで低下することもある。
- **気密性が命**：空気音は小さな隙間から漏れ出し、背中合わせの配置では「ダクト状態」となって音が直通します。

### 遮音コンセントBOXとスイッチBOXの違い
構造は似ていますが、役割と難易度が異なります。

| 項目 | 遮音コンセントボックス | 遮音スイッチボックス |
|------|-------------------------|------------------------|
| **役割** | 電源確保（配線多い） | 照明操作（配線少ない） |
| **奥行き** | 深い（機器が大きい） | 浅い（15〜25mm程度） |
| **音漏れリスク** | **極めて高い（空洞・穴が大きい）** | 中程度 |
| **必要な処理** | **パテ必須＋背面吸音・遮音** | パテ充填が中心 |
| **背中合わせリスク** | **ほぼ直通（絶対NG）** | 位置をずらすのが無難 |
| **優先度** | **最優先（ここを塞がないと意味がない）** | 推奨 |

### 遮音コンセントの仕組みと効果
**仕組み**
1.  **バックボックス化**：樹脂や金属製の密閉ボックスで覆う。
2.  **気密処理**：ボックスと壁の隙間、ケーブル貫通部を「防音パテ」で完全に埋める。
3.  **質量付加**：背面に遮音シートや吸音材を追加し、共振を防ぐ。

**改善効果**
-   **対策前**：壁本来の性能から10〜15dB低下（穴から音がダダ漏れ）。
-   **対策後**：低下幅を3〜5dB程度に抑制。特に400〜1,000Hz（人の声や楽器の中心帯域）の直通音が激減します。

### 施工タイプ別の対策法

#### A. 賃貸・DIY（壁の中にアクセスできない場合）
既存の設備を外さずに、室内側から蓋をするアプローチをとります。
-   **防音カバー**：コンセントの上から被せるタイプ。
-   **壁面密閉フォーム**：非破壊で隙間を埋める。
-   **吸音ボックス設置**：室内側に箱を設けて物理的に塞ぐ。

#### B. 持ち家・防音工事（壁の中を工事できる場合）
-   **ボックス内部のパテ埋め**：電線1本1本の隙間まで埋める。
-   **背面の補強**：コンセント裏の石膏ボードを2重にする、遮音シートを貼る。
-   **位置ずらし**：隣室と背中合わせにならないよう、設計段階で位置をズラす。

## 2. 床・開口部の防音（防振マット・隙間テープ）

### 防振マット（床の振動対策）
**選び方の鉄則**
「カーペットだけ」では低い音（足音・ドラム・ピアノ）は止まりません。
**「柔らかいクッション層（吸振）」＋「重いゴム層（遮音）」の多層構造**にすることが重要です。

**おすすめ製品**
1.  **P防振マット (ピアリビング)**
    -   素材：リサイクルゴム（高密度・高重量）
    -   用途：ピアノ、ドラム、重量機器の下。ベースとして最強。
    -   価格：2,000〜3,000円/枚
2.  **静床ライト**
    -   素材：パイル＋バッキング層
    -   特徴：JIS最高等級の防音タイルカーペット。
    -   **最強の組み合わせ**：「P防振マット」の上に「静床ライト」を重ね敷きする。

### 隙間テープ（ドア・窓の空気音対策）
**選び方の鉄則**
音は空気の漏れる場所（数ミリの隙間）から侵入します。場所に合わせて素材を選びます。

**おすすめ製品**
1.  **ゴム・スポンジタイプ (EPDM)**
    -   用途：**ドア（開き戸）の戸当たり**。密閉性が高い。
    -   製品：[トラスコ EPDMスポンジテープ](https://amzn.to/3K5wngX)、セメダイン。
    -   コツ：厚すぎるとドアが閉まらなくなるため、「閉まるギリギリの厚さ」を攻める。
2.  **モヘアタイプ（起毛）**
    -   用途：**引き戸、窓サッシ**。
    -   特徴：摩擦が少なく、スライドを阻害しない。

## 3. 防音室の照明（LED）

### 防音室ならではの選定基準
普通の部屋と違い、「狭い・密閉・録音/撮影環境」であることを考慮する必要があります。

1.  **発熱が少ない**：熱がこもると空調負荷が増え、楽器や機材にも悪影響。
2.  **静音性（ノイズレス）**：電源部の「ジジ…」というノイズや、冷却ファンの音は録音につきもの（NG）。
3.  **フリッカー（ちらつき）なし**：ウェブ会議や動画撮影で画面に縞模様が出ないこと。
4.  **調光・調色**：作業（白）とリラックス/撮影（暖色）を切り替えられること。

### おすすめの照明タイプ
| タイプ | おすすめ度 | 特徴・メリット |
|--------|------------|----------------|
| **シーリングライト** | **◎ 最適** | 発熱小、部屋全体が明るい、調光調色が豊富。 |
| **薄型パネルライト** | **◎ 優秀** | 天井が低い防音室でも圧迫感なし。拡散光で影が出にくい（配信向き）。 |
| **デスクライト** | 〇 補助 | 手元の明るさ確保。熱源を体に近づけないよう注意。 |
| **白熱灯・ハロゲン** | × NG | 発熱が凄まじく、防音室の温度を急上昇させる。 |
| **ファン付き照明** | × NG | ファンの回転音がノイズとして録音される。 |

### スペックの目安
-   **明るさ**：1畳あたり800〜1200lm、2畳なら1200〜2000lm。
-   **色温度**：
    -   3000K（電球色）：落ち着く、雑談配信。
    -   5000K（昼白色）：PC作業、譜面読み。
    -   **調色機能付きならシーンで使い分け可能（必須級）。**

**音響・配信視点でのポイント**
-   **拡散光を選ぶ**：直下型の硬い光は影を濃くし、映像のホワイトバランスも難しくなります。パネルライトなどの拡散光の方が肌写りが自然です。
