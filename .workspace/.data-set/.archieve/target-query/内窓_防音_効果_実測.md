## 2. 競合サイト分析

### A. 内窓・窓リフォーム専門店 (二重窓.jp, 内窓プラスト公式サイト等)
- **特徴**: メーカー（LIXIL, YKKAP, 大信工業）の公表データに基づいた、非常に精密な遮音性能グラフ（周波数別透過損失）を掲載。
- **強み**: 5mmガラス、6mmガラス、防音合わせガラス、真空ガラスそれぞれの「dB（デシベル）削減値」を具体的に提示。
- **弱み**: DIYに関する情報は皆無で、数万〜数十万円の工事が前提。

### B. YouTube (DIY系・住宅検証系チャンネル)
- **特徴**: 実際に騒音計を使って「設置前」と「設置後」の数値を動画で実測。
- **強み**: 救急車のサイレンやトラックの走行音が、内窓を閉めた瞬間にどれくらい下がるかを「音」と「数値」で直感的に理解できる。
- **弱み**: 体系的なデータのまとめが少なく、その時々の環境（隙間など）に左右されやすい。

### C. 住宅建材メーカー (LIXIL インプラス, YKKAP プラマードU)
- **特徴**: T-4（-40dB削減）といったJIS規格に基づく等級表示。
- **強み**: 圧倒的な製品信頼性と、断熱効果を含めたトータルなメリット提示。
- **弱み**: 防音「だけ」に特化した深い悩み（深夜の低周波振動など）への個別対策は薄い。

## 3. 防音Lab向けリファイン案

現状のDIY記事は「安さ」に特化していますが、検索意図である「実測（効果の裏付け）」を強化するために以下の要素を追加します。

### ① 「素材別・防音効果の実測値」比較表
DIYで使うポリカーボネートと、本格的な内窓ガラスの性能差を数値で明確にします。

| 対策の種類 | 予算 (窓1枚) | 防音効果 (実測目安) | 得意な音の周波数 |
| :--- | :--- | :--- | :--- |
| **DIY (ポリカ板)** | 約5,000円 | -10〜15dB | 話し声、虫の音 (高音) |
| **内窓 (単板5mm)** | 約40,000円 | -25〜30dB | 全般的な環境騒音 |
| **内窓 (6mm/合わせ)** | 約60,000円 | -35〜40dB | 楽器、交通振動 (低音) |

- **ポイント**: 「DIYでも効果はあるが、低音や楽器には本格的な内窓が必要」という使い分けを提示。

### ② 周波数別の「実測シミュレーション」
「-40dB」という数値が、実際の生活でどう聞こえるかを具体化します。
- 「幹線道路の騒音（80dB：地下鉄内レベル）が、内窓設置で40dB（図書館の静けさ）まで下がる」という対比。
- 6mmガラスがなぜ5mmより「低音（トラックの地響き）」に強いのかを、ガラスの「重さ（質量）」の観点から解説。

### ③ 2025年版「補助金活用」による実質コストの提示
「実測データを見て、本格的な内窓が欲しくなった」読者の背中を押します。
- **先進的窓リノベ2025事業**: 内窓設置で最大50%程度の補助が出ることを伝え、「DIYで1万円かけるなら、補助金を使って実質2万円で本物を付ける」という選択肢を提示。
