## 2. 競合サイト分析

### A. 家電・ガジェット系メディア (ITmedia, my-best)
- **特徴**: スポットクーラーの製品比較ランキングが充実。
- **強み**: 冷却能力、消費電力、ノンドレン方式の有無など、カタログスペックの比較が正確。
- **弱み**: 防音室特有の「音響的なノイズ」「ダクトによる音漏れ」という文脈での解説が不足。

### B. 個人ブログ・SNS (note.com等)
- **特徴**: 「実際にダクトをどう通したか」という自作ハックの画像が豊富。
- **強み**: ホームセンターで買える安価な材料を使った「ダクト消音ボックス」などの工夫が具体的。
- **弱み**: 科学的な裏付け（dB値の変化など）がなく、個別の事例に寄りすぎている。

### C. 防音・音響専門サイト (living-withsound.net等)
- **特徴**: 振動（低周波）対策にフォーカス。
- **強み**: 床に伝わるコンプレッサーの振動（ブーンという音）を止めるための「防振ゲル」などの専門的な提案。
- **弱み**: コンテンツが硬く、ライトな配信者層には少し敷居が高い。

## 3. 防音Lab向けリファイン案

### ① 「コンプレッサー振動」を止める専門的アプローチ
既存の記事は「空気伝播音（ダクト経由の音）」には強いですが、「固体伝播音（床を伝わる振動）」への言及を強化します。
- **改善案**: 一般的な防振ゴムよりも効果的な「耐震ゲル（ゲルダンパー）」の使用を提案。集合住宅で階下に響かないための「多層構造（本体→ゲル→厚手マット）」の図解を追加。

### ② 2025-2026年最新おすすめモデルの提示
単なる設置法だけでなく、現在市場で「防音室に最適」とされるモデルを具体名で挙げます。
- **アイリスオーヤマ IPK-2305S**: 排熱窓パネルが使いやすい。
- **JYWINA (2025新型)**: 2.7kWの高出力で急速冷却が可能。
- **ハイセンス HPAC-22H**: リモコン側に温度センサーがあるため、防音室内の温度を正確に制御できる（iFEEL機能）。

### ③ 「結露」と「音漏れ」のトレードオフ解消
ダクトを通す際に発生しやすいトラブルへの対策を追加します。
- **改善案**: 「ダクトの断熱」が結露防止だけでなく、実はダクト表面からの音漏れ防止にも寄与することを解説。グラスウール系ダクトカバーの推奨。
