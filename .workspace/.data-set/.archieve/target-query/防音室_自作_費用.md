## 2. 競合サイト分析

### A. note.com 等の個人体験記
- **特徴**: 「実際の領収書」や「失敗したポイント（隙間風、夏場の熱さ）」が非常に具体的。
- **強み**: 嘘偽りのない「リアルな苦労話」が読者の共感と信頼を得ている。
- **弱み**: 情報が断片的で、体系的な比較や最新の建材相場（2025年以降）に基づいた解説が少ない。

### B. DIY特化ブログ (sakumamatata.com等)
- **特徴**: 詳細な設計図と材料リストを公開。
- **強み**: 「何を買えばいいか」が具体的（商品名レベル）。
- **弱み**: プロ視点での「音響的な評価（Dr値の検証）」が不足している。

### C. リフォーム・不動産ポータル (SUUMO, リホームナビ)
- **特徴**: DIYとプロ施工の費用・性能差をマクロな視点で比較。
- **強み**: 資産価値や火災リスク、床荷重の法的制限など、コンプライアンス面での指摘が鋭い。
- **弱み**: DIYの具体的な手順や「安く済ませるハック」には詳しくない。
