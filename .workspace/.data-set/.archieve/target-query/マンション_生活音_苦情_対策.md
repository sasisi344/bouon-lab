## 2. 競合サイト分析

### A. 防音グッズ専門サイト (ピアリビング, 防音専門ピアリビング)
- **特徴**: 「床の足音」「壁の話し声」など、具体的な音の種類に対する物理的な対策グッズの紹介が極めて充実。
- **強み**: 静床ライト（マット）やワンタッチ防音壁など、工事不要で効果が高い製品の販売実績と紐づいた信頼性。
- **弱み**: 人間関係のトラブル解決や管理会社への交渉術といった「ソフト面」の解説は薄い。

### B. 大手生活情報メディア (All About, SUUMO, LIFULL HOME'S)
- **特徴**: 騒音トラブルの法的基準（受忍限度）や、一般的なマナーについての網羅的な解説。
- **強み**: 弁護士や一級建築士などの専門家監修による正確な法的・構造的知識。
- **弱み**: 「100均グッズで自作する」といった泥臭いDIYハックや、配信者などの特殊な層への配慮が少ない。

### C. 個人ブログ・DIYサイト (sakumamatata.com等)
- **特徴**: 賃貸でできる「原状回復可能な防音DIY」の実践記。
- **強み**: 遮音シートと吸音材をどう組み合わせるか、といった具体的な施工手順とコスト感。
- **弱み**: 法的な裏付けや、交渉が決裂した際のアドバイスが不足。

## 3. 防音Lab向けリファイン案

現状の「交渉ガイド」は非常に質が高いですが、「対策」という広い検索意図に応えるため、以下の物理的対策を統合します。

### ① 「物理的セルフディフェンス」と「ソフト交渉」のハイブリッド提示
交渉には時間がかかります。その間の精神的苦痛を和らげるための物理的対策を「応急処置」として追加します。
- **提案**: 交渉フェーズに合わせた対策チャートの作成。
  - **フェーズ1 (初期)**: 隙間テープ、耳栓、ホワイトノイズマシンで「音を入れない」自衛。
  - **フェーズ2 (証拠収集)**: 騒音計アプリでの記録と並行して、壁に吸音パネルを立てかける。
  - **フェーズ3 (交渉)**: 管理会社への連絡（既存記事の内容）。

### ② マンション特有の「音の侵入ルート」図解
生活音がどこから入ってくるかを可視化し、ピンポイントな対策を提示します。
- **床**: 厚手ラグ＋防音マット（階下への配慮）
- **壁**: 吸音パネル＋遮音シート（隣人の話し声）
- **窓**: 防音カーテン（外の騒音）
- **換気口**: 防音スリーブ（意外な盲点：2025年のトレンド）

### ③ 「受忍限度」を直感的に理解できる比較表
「どこまでが我慢すべき音で、どこからが苦情を言っていい音か」の基準を、具体的なdB値と日常の例で示します。
- **例**: 40dB（図書館の静けさ）→ **「我慢すべき」** / 55dB（掃除機の音）→ **「対策・苦情の検討ライン」**
