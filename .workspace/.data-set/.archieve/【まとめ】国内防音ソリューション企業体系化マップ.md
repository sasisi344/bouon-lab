# 国内防音ソリューション企業・業界体系化マップ

本ドキュメントは、日本国内における防音ソリューション提供企業を、その「強み」「ターゲット」「技術特性」に基づいて体系化した業界マップです。
ユーザーのニーズ（プロユース、簡易導入、特定の悩み解決など）に合わせて最適なプレイヤーを特定するために使用します。

---

## 1. 総合楽器・音響メーカー（高性能・信頼性）
**ターゲット:** 本格的な楽器奏者、プロフェッショナル、高性能を求めるテレワーカー

「音を止める（遮音）」だけでなく、「室内でどう響くか（音場制御）」を設計できる唯一のカテゴリです。製品の品質が安定しており、資産価値（リセールバリュー）が残るのが最大の特徴です。

### 主要プレイヤー
*   **ヤマハ (YAMAHA) ｜ アビテックス (Avitecs)**
    *   **特徴:** 業界トップシェア。独自技術「調音パネル」により、狭い空間でも音が詰まらない設計。
    *   **強み:** 0.8畳〜4.3畳の定型ユニット「セフィーネNS」は組立半日。エアコン設置やレンタル（音レント）のエコシステムが確立されています。
*   **カワイ音響システム (KAWAI) ｜ ナサール (Nasal)**
    *   **特徴:** ピアノメーカーのノウハウを凝縮。ユニット型から建築一体型の完全オーダーメイドまで対応。
    *   **強み:** すべての製品に「2年間の性能保証」が付帯。柱や梁に合わせたカスタム設計や、防音とインテリアの融合に長けています。

### 一般業者との違い
*   **音場設計:** 一般的な工務店が「音が漏れない」ことだけを目指すのに対し、メーカー系は「演奏していて気持ち良い音」を科学的に設計します。
*   **移設性:** ユニットタイプは「家具」扱いのため、引っ越しの際に分解・移設が可能であり、中古市場でも高値で取引されます。

## 2. 簡易・組立式防音室メーカー（低価格・DIY・配信）
**ターゲット:** YouTuber/ストリーマー、ライトなテレワーク、予算重視のホビー層

建築工事を行わず、数万円〜数十万円で導入できる「ブース」を提供するカテゴリです。軽量で賃貸でも導入しやすい反面、重低音やドラムなどの遮音には不向きです。

### 主要プレイヤー
*   **Coolish Music ｜ OTODASU（オトダス）**
    *   **特徴:** プラスチックダンボール等の軽量素材を使用し、9万円台からの圧倒的低価格を実現。
    *   **強み:** 工事不要・工具不要で組み立て可能。天井ファン標準装備などで「安価だが使える」バランスを追求し、配信者層に人気。
*   **VIBE ｜ だんぼっち**
    *   **特徴:** ダンボール製防音室のパイオニア。
    *   **強み:** 最も安価かつ軽量。ただし耐久性や湿度への弱さはあるため、入門機としての位置づけ。
*   **ピアリビング (Pia Living) ｜ おてがるーむ**
    *   **特徴:** 防音専門店が開発。フェノール樹脂吸音材を使用し、軽量さと遮音性能のバランスを設計。
    *   **強み:** LED照明や換気ファンなど、居住性を高めるオプションが豊富。

## 3. 防音材・建材・産業技術メーカー（素材・プロ仕様）
**ターゲット:** DIYユーザー、オーディオマニア、産業機器、特定環境（湿気等）

自社で特許技術や高性能素材を持ち、それを個人向けや特定用途向けに製品化しているカテゴリです。

### 主要プレイヤー
*   **株式会社静科 (Shizuka) ｜ 一人静シリーズ**
    *   **技術:** 元来は工場・発電機用の特許パネル技術。薄型・軽量のアルミ複合材。
    *   **強み:** **「タイプZ」**などの耐湿モデルがあり、湿気の多い場所や屋外でも性能が落ちない（グラスウールの弱点を克服）。
*   **東京防音**
    *   **技術:** **「ホワイトキューオン」**（高密度ポリエステル）。
    *   **強み:** ピアノやオーディオの「音質調整」に特化。チクチクしない安全な素材で、DIYユーザーやピアニストに支持される。
*   **ソノーラテクノロジー**
    *   **技術:** 無響室や産業用防音カバーの設計・製造。
    *   **強み:** **「音響性能保証」**を掲げ、契約通りの数値（dB低減）が出なければ無償対処する厳格な技術屋集団。

## 4. 防音工事・リフォーム専門業者（施工・カスタマイズ）
**ターゲット:** 自宅スタジオ、ドラム室、ライブハウス、居住環境の抜本改善

既製品の設置ではなく、部屋そのものを改造（リノベーション）する業者です。地域特性やニッチなニーズ（振動対策など）に特化した業者が存在します。

### 広域・全国対応メーカー
*   **リブテック:** 「他社施工のリカバリー（失敗補修）」を得意とし、換気口処理や振動対策のノウハウが深い。
*   **昭和クリエイト（昭和音響♪）:** 断熱リフォームと防音を組み合わせ、補助金を活用する提案に強み。

### 地域・特定ニーズ特化型
*   **【断熱×防音（寒冷地）】**
    *   **日昭 (Nissho) / 窓屋窓助:** 北海道・東北・北陸など。内窓（プラスト等）による「防音＋断熱」の同時施工で、結露と騒音を一挙解決。
*   **【基地・空港周辺（助成金）】**
    *   **アイグステック / 太陽ハウジング:** 神奈川（厚木基地）や沖縄など。国の「住宅防音工事」の手続き代行から施工、空調設備までを一貫対応。
*   **【振動対策（関西など）】**
    *   **関西防音:** ドラムやピアノの強力な「固体音（振動）」を止める浮き床工法に定評がある「駆け込み寺」。

## 5. オフィス・環境音響ソリューション（BtoB）
**ターゲット:** 企業の大会議室、オープンスペース、クリニック、コールセンター

「音を漏らさない」だけでなく、「集中できる環境を作る」「プライバシーを守る」ことに特化した法人向けソリューションです。

### サウンドマスキング（会話保護）
*   **コクヨ (KOKUYO):** 天井反射方式（間接音）により、違和感のないマスキング音で会話を聞こえにくくする。オフィスの意匠性を損なわない。
*   **グラムスラム:** 「リリーバー」等を提供。ホワイトノイズではなく環境音を用いた生理的に不快感のないマスキング。

### 会議室音響（Web会議最適化）
*   **ヤマハ (ADECIA):** 天井マイクとスピーカーシステムの統合ソリューション。Web会議の「聞こえにくい」「途切れる」を解消。
*   **東京通信電設:** 会議室の形状に合わせた最適な機材選定・施工。

---

## 6. ライフサイクル支援（買取・移設・メンテナンス）
**ターゲット:** 既存オーナー、引っ越し予定者、カビ・臭いに悩むユーザー

防音室は「設置して終わり」ではなく、維持管理や出口（売却）が重要です。これらを支える専門業者です。

### 買取・移設・リユース
*   **サウンドスペース / 東京サウンドボックス:** 防音室の解体・移設・買取を一貫して行う。中古防音室の販売も手掛け、安価に導入したい層の受け皿ともなる。
*   **おいくら / 出張買取のアシスト:** 大型防音室の運び出しに対応した総合買取サービス。

### クリーニング・環境維持
*   **純閃堂 / ブルークリーン:** 防音室特有の「カビ」「染み付いた臭い（タバコ等）」を除去する特殊清掃技術。

## 付録：業者選びのチェックリスト（ユーザー向け）

1.  **目的は何か？**
    *   楽器（ピアノ・ドラム） → **総合メーカー、防音工事専門**
    *   配信・テレワーク → **簡易メーカー、防音材（DIY）**
    *   生活騒音（電車・工事） → **窓リフォーム（一般・寒冷地系）**
2.  **将来動くか？**
    *   賃貸・転勤族 → **ユニット型（ヤマハ・カワイ・簡易系）**
    *   持ち家・永住 → **工事・リフォーム系**
3.  **地域の特性は？**
    *   湿気が多い → **調湿建材・カビ対策・静科（タイプZ）**
    *   寒い・雪国 → **断熱併用の窓屋**
    *   基地周辺 → **助成金対応業者**
