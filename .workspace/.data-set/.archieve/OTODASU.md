Coolish Music株式会社が製造・販売する簡易防音室「OTODASU（オトダス）」について、提供された資料に基づきその特徴、性能、ラインナップなどをまとめました。

### 1. OTODASUの概要
OTODASUは、**「誰もが手軽に使える」**ことをコンセプトに開発された、組み立て式の簡易防音室です。累計販売台数は4,500台を突破しており、楽器練習、テレワーク、ゲーム配信など幅広い用途で利用されています,,。

### 2. 主な特徴とメリット
*   **圧倒的な低価格**:
    *   本格的な防音室に比べて非常に安価で、モデルによっては**99,900円（税抜）**から購入可能です,。
*   **工具不要の簡単組み立て**:
    *   ドライバーなどの工具を使わず、パーツをはめ込むだけで組み立てが可能です。専用のロックパーツを使用し、大人2人で30分〜2時間程度で完成します,。
*   **軽量設計と賃貸適性**:
    *   壁材にプラスチックダンボール（プラパール）を採用しており、総重量は約30kg〜50kg程度と非常に軽量です,。
    *   床への負担が少なく、解体・移動も容易なため、賃貸住宅でも導入しやすいという特徴があります,。
*   **明るい室内**:
    *   天井や壁が半透明（モデルによる）で部屋の照明を透過するため、防音室内に専用照明が不要で明るさを確保できます,。

### 3. 防音性能と構造
*   **遮音性能**:
    *   平均して**約-20dB〜-25dB**の減音効果があります。これは、人の話し声やテレビの音などの「生活音レベル」まで音量を下げる性能です,。
    *   島村楽器の資料では「Dr-15程度」とされています。
*   **独自開発の吸音材**:
    *   「OTODASU MAGIC Ⅱ」という、吸音材の裏面に遮音シートをセットした素材を開発。音を吸収しつつ跳ね返すことで防音効果を高めています,。
*   **隙間対策（OTODASUⅡ）**:
    *   初期モデルからのアップデートにより、ロックパーツと壁の間の隙間を埋めるスペーサーが開発され、音漏れが減少しています。

### 4. 換気と空調
*   **換気システム**:
    *   天井に**4つの換気ファン**が標準搭載されており、室内の空気を循環させます,。
*   **暑さ対策**:
    *   密閉空間のため夏場は暑くなりやすいですが、部屋のエアコンを稼働させ、その冷気をファンで取り込むことで室温調整を行います,。

### 5. 製品ラインナップ
用途や広さに応じて複数のモデルが展開されています,,,。

| モデル名 | 特徴 | 用途・ターゲット |

| **OTODASU Ⅱ** | 吸音材が付属した標準モデル。 | 楽器練習、配信 |
| **OTODASU Ⅱ LIGHT** | 吸音材なしの軽量・廉価モデル。 | テレワーク、軽い防音 |

### 6. 注意点・デメリット
*   **完全防音ではない**: 簡易防音室であるため、ドラムやグランドピアノのような大音量・振動を伴う楽器には不向きです,。あくまで「生活音レベルへの減音」が目的です。
*   **質感**: 素材がプラスチックダンボール等のため、木製や金属製の防音室に比べると簡易的な質感です。
*   **キャンセル不可**: 受注生産のため、注文後のキャンセルはできません。
