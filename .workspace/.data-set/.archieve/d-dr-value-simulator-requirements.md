# 要件定義：防音ベストプラクティス診断（仮称：Bouon-Akinator 2025）

## 1. プロジェクト概要

ユーザーの「悩み」や「実現したいライフスタイル」をアキネイター形式の多肢選択でヒアリングし、蓄積された製品データベース（アビテックス、ナサール、オトダス等）から、そのユーザーにとっての「防音の正解（ベストプラクティス）」を逆算して提示するWebアプリ。

## 2. 診断コンセプト：悩みの逆算

従来のスペック比較ではなく、「今の不満」を解消するための最短ルートを提示します。

- **「スペック先行」から「悩み先行」へ**：Dr値を選ぶのではなく、解決したい事象（例：深夜に叫びたい）を選ぶ。
- **消去法と最適解の提示**：予算と性能のトレードオフを自動計算し、「これ以外は失敗する」という選択肢を絞り込む。

## 3. アプリケーション機能要件

### 3.1 診断フロー（質問ロジックの例）

1. **Q1. 解決したい一番の悩みは？**
   - [ ] 隣室からの苦情・壁ドンが怖い
   - [ ] 外部の騒音（身バレ、ノイズ）を遮断したい
   - [ ] 家族に気兼ねなく演奏・絶叫したい
2. **Q2. 何を「鳴らし」ますか？（音源の特定）**
   - 選択肢：配信、ピアノ、管楽器、ドラム、ASMR
3. **Q3. いつ「鳴らしたい」ですか？（時間帯・環境音）**
   - 深夜（30dB）、昼間（45dB）、24時間
4. **Q4. お住まいの「壁」の信頼度は？（建物の遮音性能）**
   - 木造、鉄骨、鉄筋(RC)
5. **Q5. 最大準備できる「覚悟（予算）」は？**
   - 15万以下、100万程度、300万以上（無制限）

### 3.2 演算・提案ロジック

- **Product Matcher**:
  - `音源dB - システム防音性能(製品Dr + 建物のD) < 許容漏出音量` を満たす製品群をフィルタリング。
- **Best Practice Ranking**:
  - 予算内で最も満足度（居住性、音質）が高いものを「第1候補」として選出。
  - 予算オーバーだが「これにしないと後悔する」ものを「推奨アップグレード」として提示。

### 3.3 アウトプット：診断レポート

- **あなたの「正解」はこれです**：特定の製品名（例：ヤマハ セフィーネNS Dr-40）を断定。
- **なぜこの製品なのか？**：消去法での理由解説（例：だんぼっちでは○○さんの叫び声は防げません）。
- **合わせて買うべき「周辺防音」**：吸音パテ、防音マット、エアコン設置の要否など。
- **アクションボタン**：製品詳細記事へ誘導、またはメーカーショールーム予約。

## 4. UI/UX設計

- **Interactive Diagnosis**: 一問一答形式で、回答するごとに「候補製品」が絞り込まれていく演出。
- **Visual Feedback**: 回答に合わせて「隣室に漏れる音」のイメージバーが変動。
- **Premium Design**: BouonLabのブランドに合わせた、信頼感のあるモダンなデザイン。

## 5. 技術・データ構成

- **Product DB**: `product_specifications.md` のデータをJSON化してマスタとして保持。
- **Diagnosis Engine**: 条件分岐ロジックによるスコアリングアルゴリズム。
