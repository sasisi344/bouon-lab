**Context**: Technical base for industrial and professional soundproofing solutions.

## 1. 産業用・建設用防音素材のメカニズム
防音は「遮音」「吸音」「防振・制振」の3要素の組み合わせで成立する。

### 1.1. 遮音（Sound Insulation）
- **原理**: 質量則（Mass Law）に基づき、音を反射させる。面密度が高いほど高性能（特に低周波）。
- **主要素材**: 鉛シート、高密度ゴム、アスファルト基材シート、コンクリート、鉄板。
- **指標**: 透過損失（Transmission Loss, TL値 [dB]）。

### 1.2. 吸音（Sound Absorption）
- **原理**: 音のエネルギーを摩擦熱に変換する。
- **多孔質材料**: グラスウール、ロックウール、ウレタンフォーム、ポリエステルウール。主に中〜高周波に有効。
- **共鳴構造**: 有孔ボード＋空気層。低周波の特定帯域に有効。
- **指標**: 吸音率（0.0〜1.0）、NRC（Noise Reduction Coefficient: 250/500/1k/2k Hzの平均）。0.7以上が高吸音。

### 1.3. 周波数帯別の有効素材
| 帯域 | 特徴 | 主な対策素材 |
| :--- | :--- | :--- |
| **低周波** (~200Hz) | 透過・回折しやすい | 高密度遮音材、厚い空気層、共鳴型構造 |
| **中周波** (500Hz~2kHz) | 人の声など | 一般的な吸音材（50mm厚以上）、遮音シート |
| **高周波** (2kHz~) | 直進性が高い | 薄手の吸音材、フェルト、隙間対策 |

## 2. 主要メーカーとブランド（国内・グローバル）

### 2.1. 国内主要プレイヤー
- **イノアックコーポレーション**: カームフレックス（ウレタン系吸音材）、バソテクト（メラミン系）。自動車・産業機器に強み。
- **日東電工**: エプトシーラー（シール・防音）、DBカバー。自動車・建築の気密・防音。
- **大建工業**: ダイロートン、オトカベ、防音ドア。住宅・公共建築の総合防音建材。
- **吉野石膏**: タイガーボード（耐火遮音システム）。石膏ボードの国内トップシェア。
- **ニチアス**: MGボード（ロックウール）。産業用の耐火・断熱・防音。
- **旭ファイバーグラス**: アクリア（グラスウール）。建築断熱・吸音の定番。

### 2.2. グローバルリーダー
- **Saint-Gobain (フランス)**: 世界最大級の建材メーカー。ISOVER、Ecophonブランドを展開。
- **ROCKWOOL (デンマーク)**: ロックウールの世界首位。不燃性とリサイクル性に優れる。
- **3M (米国)**: Thinsulate Acousticなど、自動車用の軽量・高性能吸音材。
- **Armacell (ドイツ)**: ゴム系発泡体（ArmaSound）。産業機器・HVACに強み。

## 3. BtoB選定の重要基準とトレンド

### 3.1. 認証・安全基準
- **防火認定**: 国土交通大臣認定（不燃・準不燃・難燃）。公共建築では必須。
- **環境規制**: RoHS指令（有害物質制限）、REACH規則（化学物質管理）、VOC排出（F☆☆☆☆）。
- **国際規格**: JIS（日本）、ASTM（米国）、EN（欧州）。測定方法の違いに注意。

### 3.2. 最新トレンド
- **サステナビリティ**: 再生ポリエステル（ペットボトル）、木質繊維、リサイクルゴムの採用。
- **LEED/WELL認証**: 建物全体の環境性能やウェルビーイング指標としての音響設計。
- **薄型・軽量化**: 空間効率を落とさずに透過損失を稼ぐ高性能パネル。
- **IoT連携**: センサーによる騒音モニタリングと動的遮音管理。
