## 1. 防音室との違い（記事の軸）

| 観点 | 個室ブース | 防音室（ヤマハ・カワイ等） |
|---|---|---|
| 目的 | 話し声・Web会議の音と視線を遮る「個室空間」 | 楽器・ドラム・歌などの大音量を外に漏らさない |
| 遮音の指標 | 話し声（スピーチ）の減衰量。メーカー公表値は約24〜42dB。測定条件は製品でばらばら | Dr値（Dr-30〜Dr-75以上）。JIS規格の等級 |
| 見た目 | アクリル・ガラスの透明ドアや窓があり、外から中が見える | 窓なし・密閉。無機質 |
| 設置 | 置くだけ・工事不要が多い。オフィスやコンビニ・駅に置く | 居住空間へ設置。床荷重・換気・工事の検討が必要 |
| 価格（1人用） | 購入30万〜150万円程度（2026年8月時点の二次情報）、サブスク月1.5万〜5万円台 | ヤマハ Cefine NS・カワイ Nassale で約90万〜150万円（`05_商品/product_specifications.md`、価格は要再確認） |
| 向かない用途 | 楽器・歌・ドラムなどの大音量 | 透明性や視線管理が目的の用途 |

**重要な注意**: ブースの「dB」と防音室の「Dr値」は別の指標で、直接比較できない。記事で「ブースは○dBカット＝Dr-○○相当」と書かない。

## 2. 遮音性能の実態

### 2-1. 測定規格（ISO 23351-1:2020）

- 電話ボックス・ワークポッド等の家具型エンクロージャーが、中で話す人の音声レベルをどれだけ下げるか（Speech Level Reduction）を、実験室で比較するための国際規格（二次情報: 規格販売サイト・解説）
- 125Hz〜8,000Hzのオクターブバンドで、2つのシナリオの音響パワーレベルの差から算出する
- 日本のメーカー公表値がこの規格で測られたものか、各社の独自条件かは**製品ごとに確認が必要**。同じ「dB」でも条件が違えば比べられない（`cocosy.jp` も「メーカー間で数値公表が異なり比較困難」と指摘）

## 4. 消防法（設置時の最大の落とし穴）

- 根拠は消防法施行令第32条の特例を、**「可動式ブース」の扱い**として自治体の消防が運用するもの。東京消防庁の別記「可動式ブースに係る消防用設備等の取扱いについて」（[PDF](https://www.tfd.metro.tokyo.lg.jp/content/000060364.pdf)、2026-10-07取得・原文確認）より
- 可動式ブースの定義: 天井と壁で囲われ、床や壁に固定されておらず、人が出入りして利用するもの
- **スプリンクラーヘッド・感知器の設置免除の主な要件**（火気使用・宿泊目的でないことが前提）:
  - 床面積**6㎡以下**
  - 天井・壁が不燃材料、ブース内に住宅用下方放出型自動消火装置を設置、点検・維持管理
  - ブース外から内部の火災を目視できること（または連動型住宅用火災警報器の設置）
  - 易燃性の可燃物（合成皮革・ウレタンのソファ等）がある場合は消火困難として認められないことがある
- **放送設備のスピーカー免除**: ブース外のスピーカーの放送が、ブース内で**65dB以上**になることが確認できること（など）。つまり**遮音が高すぎると非常放送が聞こえず、免除に不利**。メーカーが遮音を調整するスリットを設ける理由
- 注意: 古い解説記事には「床面積3㎡以下」とあるものがある（`shigyo.co.jp`など）。今回の東京消防庁の別記は「6㎡以下」。**改正または運用の見直しがあった可能性があり、記事の公開前に所轄の消防機関の最新基準で再確認する**（堺市の基準資料には「令和6年8月23日付」の通知を踏まえた旨の記載がある。通知番号は未確認）
- 自治体ごとに運用が異なる。**所轄消防署への事前相談が必要**とする記述に統一する（断定しない）
- 建築基準法: 設置方法・構造により建築設備・工作物扱いになる場合があるとされるが、個別案件の話として自治体確認を促す

## 5. 需要チャネル（誰が・どこで・何のために個室ブースを求めるか）

記事の主軸は「個室であること」の価値を、**検索する人の置かれた場面別**に届けること。以下は調査で確認できた実在の導入先・利用実態。

| チャネル | 具体的な事実（出典） | 読者像・本音 |
|---|---|---|
| 駅・外出先のWeb会議 | JR東日本「STATION BOOTH」。基本料金は1人用330円/15分、2人用385円/15分、4人用495円/15分（二次情報）。全ブースに電源とWi-Fi。利用者の約半数がWeb会議、平均利用60〜90分（[Impress Watch 2022-09-09](https://www.watch.impress.co.jp/docs/topic/1436187.html)）。拠点は2022年時点で約550、のち1,000超（STATION WORK） | 外回りの会社員・フリーランス。「会議の10分前に静かな場所がない」 |
| 社内（フリーアドレス・会議室不足） | オフィスで人事面談・Web会議用に導入。京王プラザホテルが6台導入（人事面談・Web会議のスペース不足解消） | 総務・情シス担当。「会議室が足りない」「面談の声を漏らしたくない」 |
| 大学の就活支援 | 成蹊大学・大妻女子大学・茨城大学・近畿大学などがキャリアセンターにオンライン面接用ブースを設置。東京しごとセンターにも面接練習用ブース | 就活生。「下宿やカフェで面接を受けられない」。大学職員が導入判断者 |
| 学生の自習・図書館 | 山口大学経済学部が自習室内に設置。東海大学医学部付属病院は病院のバックヤードと学生向け図書館に防音個室ブースを設置 | 大学職員・病院事務。「会話が漏れない環境」 |
| 公共施設・自治体 | 青梅市役所にテレキューブ設置（行政施設初とされる）。総務省が郵便局内の個室ブースでオンライン診療・服薬指導の実証（薬局空白地域） | 自治体職員。窓口・相談の個室需要 |
| 医療・オンライン診療 | 上記の郵便局での実証。広島県はオンライン服薬指導の導入手引きを公開（プライバシー確保をメリットに挙げる） | 薬局・クリニック経営者 |
| 集合住宅の共用部 | 横浜市内の特定共同住宅の共用部にテレキューブ設置（特定共同住宅の共用部では全国初とされる）。消防庁基準も「共同住宅等に設置される可動式ブース」の扱いを定めている | マンション管理組合・デベロッパー。在宅勤務住民の個室需要 |
| 駅構内・商業施設 | 富士フイルムビジネスイノベーションが東京メトロ駅構内等に「ココデスク」を設置（2024年時点で拡大計画）。STATION WORKは駅外（郵便局・コンビニ・カフェ）にも展開、「住宅地のブースの稼働が上がっている」（Impress Watch） | 運営事業者（貸す側）。`business/soundproof-space-business-guide`との役割分担に注意 |
| 家庭用 | 家庭用の防音個室ブースを扱う事業者もある（サウンドボックスポッド等）。在宅ワークの声漏れ対策は既存記事`remote-work-family-harmony-soundproof`が受け皿 | 在宅ワーカー本人。ただし個室ブースは「会社が置く」意思決定が多い |

- 市場規模（`05_商品/research-2026-06-10-supplementary.md` §1より）: 個室型ワークブース市場は2025年に約24億円（日本能率協会総合研究所）、出荷台数は2020年度約2,850台→2026年度約17,000台の予測
- **意思決定者が「使う人」と「買う人」で分かれる**のが個室ブースの特徴（総務・大学職員・自治体職員・管理組合が購入、会社員・学生・住民が利用）。記事の読者は両方ありうる

## 6. 記事化に向けた論点（調査から見えたこと）

1. 検索意図は「防音室を探す人」とはずれる。**「会議室が足りない」「面談の声が漏れる」「静かに電話したい」**が出発点で、防音性能は第2条件
2. 「個室であること」の訴求先は、**導入担当者（総務・大学職員）**と**一般利用者（駅で使う人）**の2種類に分けて書く
3. 防音室の記事を読んだ人への出口（「大音量でなければブースで足りる」「楽器は防音室」）を作る。逆にブース検討者に「防音性能が足りない用途」を伝える
4. 遮音数値の比較は、測定条件が揃っていない点を**正直に書く**ことが信頼につながる（E-E-A-T）
5. 消防法は読者の失敗を防ぐ最重要項目。ただし断定せず「所轄消防署に事前相談」に誘導
