## A-1 | 残響時間（RT60）の目安と可変調音

### 部屋の広さ別 推奨残響時間

| 部屋の広さ   | シアター推奨（デッド） | カラオケ推奨（ライブ） | 両立・推奨目安   |
| :----------- | :--------------------- | :--------------------- | :--------------- |
| **6畳**      | 0.20〜0.25秒           | 0.30〜0.40秒           | **0.25〜0.30秒** |
| **8畳**      | 0.25〜0.30秒           | 0.35〜0.45秒           | **0.30〜0.35秒** |
| **10畳**     | 0.30〜0.35秒           | 0.40〜0.50秒           | **0.35〜0.40秒** |
| **12畳以上** | 0.35〜0.45秒           | 0.50〜0.60秒           | **0.40〜0.50秒** |

### 可変調音の手法

- **可動式吸音パネル**（大建工業「サウンドデザイン」等）: 開閉で吸音↔反射を切り替え
- **厚手カーテン**: 壁一面をカーテン化し、開閉で大幅な残響調整
- **家具活用**: ソファ＝吸音体、乱雑な本棚＝拡散体

### フロントデッド・リアライブ設計

- フロント（画面側）: 吸音強化→映像音の定位明確化
- リア（背面側）: 拡散材配置→カラオケ時の包囲感・自然な響き

## A-2 | 低音処理・ルームインルーム工法・施工費用

### 対象周波数帯域

- **ホームシアター（重低音）**: 20Hz〜200Hz → 固体伝搬音対策（防振）が必須
- **カラオケ（声・音圧）**: 100Hz〜1kHz → 中低域吸音処理が必要

### 浮床・浮壁・浮天井構造（ルームインルーム工法）

- **浮床**: 防振ゴム・グラスウール等の上に床を組み上げる
- **浮壁・浮天井**: 防振吊木・防振ゴムで構造体と非接触
- **効果**: 振動の建物骨組みへの伝搬を防止
- **デメリット**: 各辺15〜20cm縮小、天井高も低下

### 施工費用目安（6畳・2024〜2025年）

| 用途・性能             | 推奨性能  | 6畳あたり費用目安 |
| :--------------------- | :-------- | :---------------- |
| **ホームシアター仕様** | Dr-50〜60 | 180万円〜300万円  |
| **カラオケ仕様**       | Dr-60〜70 | 200万円〜350万円  |
| **本格スタジオ仕様**   | Dr-65以上 | 300万円〜500万円  |

- 1畳単価: 40万〜60万円（現在の標準相場）
- 2025年傾向: 資材・物流費高騰により数年前比+10〜20%

### マンション特有の制約

- 重量衝撃音（LH値）はスラブ厚依存→専有部工事だけでは完全解決困難
- 積載荷重制限: 軽量高性能防振材の選択が必須
- 管理規約: リフォーム前に管理組合承認・床材遮音等級（L-45以上等）指定が一般的

## B-1 | 施工事例（業者別・場所別）

### 主要施工業者の特徴

**アバック（AVAC）**

- 防音設計〜機材インストールまでワンストップ
- 12〜15畳の多目的ルーム、5.1.2ch以上のサラウンド構築
- カラオケ伴奏はシアター用SP、マイク音声はPAスピーカー（JBL等）の「ハイブリッド構成」
- Dr-60〜Dr-70を実現

**ホームシアター工房**

- 照明・機器のiPad一括制御（ホームオートメーション）に強い
- 調音パネルで映画とカラオケの残響感を物理的に切り替える事例あり

**防音工事ウィズ（ウィズ・ワン）**

- 建築音響専門。ハウリング抑制＋ライブ感の精密設計

### 設置場所別 性能・特徴

| 設置場所       | 広さ     | 遮音性能  | 特徴                                     |
| :------------- | :------- | :-------- | :--------------------------------------- |
| **地下室**     | 10〜20畳 | Dr-65以上 | 最も防音に適す。深夜大音量カラオケに最適 |
| **戸建て1階**  | 6〜10畳  | Dr-55〜60 | 天井遮音・浮き床強化が重要               |
| **マンション** | 6〜8畳   | Dr-60以上 | ルーム・イン・ルーム工法必須             |

### ユーザーの後悔・注意点

- **換気・空調の音**: 高性能エアコン・防音換気扇の動作音が静かなシーンで気になる
- **調音のミスマッチ**: シアター用に吸音しすぎるとカラオケ時に声が響かず喉が疲れる
- **費用の妥協**: 遮音性能をケチると深夜に大声で歌えなくなる

## C-1 | ホームシアター防音要件定義

### 必要なD値（Dr値）の目安

- **一般マンション**: Dr-55〜60（深夜・大音量・階下振動防止はDr-65以上）
- **戸建て**: Dr-50〜55

### Dr値の体感差

| Dr値  | 聞こえ方                               |
| :---- | :------------------------------------- |
| Dr-30 | 隣室でテレビの音がはっきり聞こえる     |
| Dr-50 | 「何か鳴っているな」とかすかに聞こえる |
| Dr-60 | ほぼ何も聞こえない（深夜大音量も可能） |

### Dolby Atmos対応の天井スピーカー設置

- **弱点**: 埋め込み時に遮音層を切り欠く→音漏れの最大原因
- **対策1**: バックボックス（防音箱）でスピーカー背面を遮断
- **対策2**: 天吊り用防振金具で遮音層を破壊しない設置

### 室形状・広さの設計

- **形状**: 正方形は定在波が発生しやすい→長方形が理想
- **広さ**: 8〜12畳でスピーカーとの適切な離隔を確保
- **平均吸音率**: 0.20〜0.30を目標

## D-1 | カラオケ防音要件

### 音量と必要Dr値

- **平均音量**: 90〜100dB（騒々しい工場・ピアノ演奏相当）
- **戸建て**: Dr-65以上
- **マンション**: Dr-70以上（固体伝搬音対策が特に重要）

### 業務用カラオケ導入費用（2024〜2025年）

| 導入パターン | 初期費用       | 月額費用                         |
| :----------- | :------------- | :------------------------------- |
| **レンタル** | 0〜3万円       | 3.5万〜6万円（配信料・通信費込） |
| **機材購入** | 150万〜350万円 | 1.7万〜3万円（配信料のみ）       |

### 音響特性（ライブ感）

- **残響時間ターゲット**: 0.4〜0.6秒（6〜10畳）
- **拡散材の配置**: 壁面に凹凸拡散パネル
- **リバーブで補完**: 部屋が足りない場合はカラオケ機器側のリバーブ設定で調整

### スピーカー設置

- **PAスピーカー推奨**: 瞬発的大音量に対応する耐久性
- **天吊り防振設置**: 防振ゴムを介して上階への振動伝搬を防ぐ

## F-1 | 換気・空調設計

### 防音性能を損なわない換気工法

- **熱交換形換気扇（ロスナイ）**: 給排気同時・冷暖房を逃がさず空気入替。遮音性能30〜35dB
- **チャンバー方式（消音ダクト）**: ダクト途中の消音箱で音を減衰して外部排出
- **フレキサイレンサー**: 吸音機能を持つダクト部材

### エアコン設置

- **スリーブ穴が最大の弱点**: 遮音パテ・吸音材で高密度充填
- **配管ルートに消音処理**: 動作音・固体伝搬音を防止

### カラオケ利用時の健康管理目安

| 項目    | 目安値                                       |
| :------ | :------------------------------------------- |
| CO2濃度 | **1,000ppm以下**（超過で頭痛・眠気のリスク） |
| 室温    | 24〜26℃                                      |
| 湿度    | 40〜60%                                      |
| 換気量  | **1回/時以上**（複合用途の推奨）             |

### 換気・空調設備費用目安

- 防音換気扇（ロスナイ）設置: 5万〜15万円
- 消音チャンバー・ダクト施工: 10万〜30万円
- エアコン設置（防音処理込）: 10万〜20万円
