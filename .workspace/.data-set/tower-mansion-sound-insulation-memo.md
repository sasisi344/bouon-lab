# タワーマンションの防音性能：知見メモ

タワーマンションにおける防音性能と生活音、設備仕様に関するDeep Researchメモ。

- <strong>タワマンの床防音とジム（ランニングマシン）の騒音</strong>
    - 一般的なタワマンの床スラブ厚は <strong>250mm〜350mm</strong> と厚く、空気伝搬音（声やTV音）には強い耐性を持つ。
    - しかし、ランニングマシンの動作による <strong>重量床衝撃音（LH値）</strong> は、スラブそのものを振動させるため、階下や離れた住戸に <strong>低周波の振動音</strong> として伝わる。
    - 共用ジムには「浮き床構造」が必須だが、建物の構造（ラーメン構造の柱など）を伝って <strong>固体伝搬音</strong> が発生するリスクがあり、マシンの直上・直下住戸は注意が必要。

- <strong>防音重視ならタワマンがベストか？</strong>
    - 結論：<strong>「遮音」は高いが、特定用途（楽器・ホームシアター）の「防音」には不十分。</strong>
    - 外部騒音に対しては <strong>T-3（35等級）以上の高遮音サッシ</strong> や二重サッシによって国内最高レベルの性能を持つ。
    - 一方、住戸間の壁（戸境壁）は重量軽減のため <strong>乾式壁（石膏ボード＋グラスウール）</strong> が多く、低音域の遮音（TL値）においてRC壁（コンクリート壁）より劣る場合がある。
    - 究極の防音（24時間演奏など）を求めるなら、<strong>防音特化型マンション</strong> （ミュージション等）の方が <strong>D-70〜D-85</strong> クラスの圧倒的な性能を保証している。

- <strong>換気できない（FIX窓）タワマンの防音性能</strong>
    - 窓が完全に固定された <strong>FIX窓（嵌め殺し窓）</strong> は、サッシの隙間（音の漏れ道）が物理的に存在しないため、<strong>気密性＝遮音性能</strong> が極めて高い。
    - 24時間換気システムによって <strong>機械給排気</strong> を行うため、換気口には <strong>防音スリーブ</strong> や <strong>消音ユニット（サイレンサー）</strong> が組み込まれており、外音の侵入を徹底的に遮断する。
    - 「換気のために窓を開ける必要がない」設計は、隙間からの音漏れを最小化できるため、<strong>静寂環境の構築</strong> には最も有利な条件となる。
