# GSC 前期/後期比較 分析結果（2026-07-02）

## 最重要の発見: これは「ページ消失」ではなく「サイト全体のランキング崩壊」

- 前期→後期で **クリック数のあるページ73件のうち、URLごと完全に消えたのは2件のみ**（残り71件は現存するが失速）
  - 完全消滅の2件はどちらも `/en/` 配下（`building-code-reform-2025-soundproof`, `piano-proofroom-select-guide`）
- つまり「Hugo→Astro移行でリダイレクトが間に合わず記事URLが消えた」という当初仮説は、**日本語記事に関してはほぼ該当しない**。記事は現存するがGoogleでの評価が全体的に落ちている。

## 数字で見る規模

| 指標 | 前期 | 後期 | 変化 |
|---|---|---|---|
| 表示回数（インプレッション/日） | 348.8 | 89.5 | **-74%** |
| クリック数/日 | 4.52 | 2.02 | -55% |
| CTR | 1.30% | 2.25% | +73%（分母である表示回数が激減した結果の相対値） |
| インプレッション加重 平均掲載順位 | 21.1位 | 42.8位 | **順位がほぼ倍近く悪化** |
| クリックが発生したユニーククエリ数 | 920 | 470 | **-49%（ロングテール半減）** |

→ CTRはむしろ改善しているため、**タイトル/スニペット/CTR起因ではない**。表示回数そのもの＝掲載順位の全体崩壊が主因。QFO以前に「なぜ順位が全体的に落ちたか」の技術要因を潰す方が優先度が高い。

## `robots.txt` の `/en/` ブロックは意図的（要修正リスクではない）

- `public/robots.txt`（コミット `ce922a9` "taglist", 2026-06-01）の `Disallow: /en/` は**意図的な措置**（本人確認済み）
- 経緯: 前期（zenki）時点の `/en/` は日本語記事をそのまま翻訳しただけの記事が約100本あったが、実用的なアクセスがあったのは少数。Astro移行時にこの`/en/`をディレクトリごと排除し、現在は非公開（隠している）状態
- 将来方針: 単純翻訳ではなく、**各国の文化的側面を考慮した記事内容**へ作り直す（`CLAUDE.md` に既述の Japan lens 戦略＝`japan-noise-and-society` / `japan-soundproof-housing` / `japan-quiet-spaces` と一致）
- → 「完全消滅した2ページ」（`en/posts/building-code-reform-2025-soundproof`, `en/posts/piano-proofroom-select-guide`）はこの意図的な整理の一部であり、対応不要。**lost-pages分析からは`/en/`の2件を除外して考えてよい**（実質的な「消えた需要ページ」はゼロ件）
- 今後 `/en/` を作り直す際は、Japan lens戦略に沿って **新規カテゴリ・新規記事として再構築**する前提（旧`/en/posts/`のURL構造の復元は不要）

## 確認された実バグ: `/posts/` 旧URLのリダイレクト漏れ 32件

`astro.config.mjs` の `redirects` 設定と `lost-pages` を突き合わせたところ、旧Hugo URL（`/posts/xxx/`）のうち **32件がリダイレクト登録されておらず、現在404になっている**（`src/pages` にも `/posts/` 用のcatch-allルートは存在しない）。これは当初仮説どおりの**純粋な技術的リダイレクト漏れ**で、他の「ランキング崩壊」とは独立した実バグ。

- 前期の合計インプレッション約6,359（前期日次インプレッション全体348.8/日の一部を占める、無視できない規模）
- 32件中 **15件はコンテンツが同一スラッグのまま新カテゴリ配下に現存**（自動でリダイレクト先を特定可能 → `AUTO_MATCH`）
- 残り **17件は同一スラッグの記事が見つからず**、リネームされたか統合・削除された可能性（`NEEDS_MANUAL_REVIEW`）
- 成果物: `missing-redirects-20260702.csv`（列: `old_path` / `zenki_clicks` / `zenki_impressions` / `proposed_redirect_target` / `status`）

→ **これは判断不要ですぐ直せる技術負債**。`AUTO_MATCH`の15件は`astro.config.mjs`の`redirects`に追記するだけで良い。`NEEDS_MANUAL_REVIEW`の17件は、記事が統合先のどのページに吸収されたかを個別に確認する必要がある（`interlink-postlist.md`やタイトル類似で捜索）。

## 掲載順位の分布（後期・表示回数上位20クエリ）

上位インプレッションのクエリでも大半が **掲載順位30〜90位** に沈んでいる（`防音ラボ`＝指名検索の7.75位を除く）。従来のQFO戦略が前提とする「7〜20位のstriking distance」に該当するクエリは後期データにほぼ存在しない（3件のみ検出、うち2件はブランド/曖昧クエリ）。

→ **今の順位帯でコンテンツ追加・ファンアウトをしても、土台となる評価が戻らない限り効果が乗りにくい**。

## 成果物

- `lost-queries-20260702.csv` — 前期クリック2以上→後期に消滅/大幅減少したクエリ（10件、ブランドクエリなし）
- `lost-pages-20260702.csv` — 前期クリック2以上→後期に消滅/大幅減少したページ（73件、うち完全消滅2件）
- `striking-distance-kouki-20260702.csv` — 後期の掲載順位7〜20位×表示回数20以上のクエリ（3件のみ）
- `missing-redirects-20260702.csv` — `/posts/` 旧URLのリダイレクト漏れ32件（`AUTO_MATCH`15件 / `NEEDS_MANUAL_REVIEW`17件）

## 推奨: タスクの優先順位（更新版）

1. **即実行可能（技術負債の解消）**: `missing-redirects-20260702.csv` の `AUTO_MATCH` 15件を `astro.config.mjs` の `redirects` に追記する。判断不要・低リスク・すぐ効果測定できる
2. **要調査**: `NEEDS_MANUAL_REVIEW` 17件は統合先ページの特定（`interlink-postlist.md`・タイトル類似検索）→ 統合先へのリダイレクト、または統合先が無ければ復元要否を判断
3. **ランキング崩壊の根本原因調査**（1・2だけでは説明しきれない規模。表示回数-74%・平均掲載順位21→43位の崩壊は32件のリダイレクト漏れだけでは説明できない）:
    - GSC「ページのインデックス登録」レポートで`ja`ページの状態を確認
    - 手動対策（Manual Actions）の有無をGSCで確認
    - 移行前後のサイト構造変化を確認（canonical、内部リンク構造、パンくず、`src/pages/[lang]/[category]/[...slug].astro`への統一によるURL評価の分散など）
4. 上記3で技術的な問題が見つからない、または改善が反映されてもなお回復が遅い場合に限り、当初のQFO/コンテンツ拡充施策（`gsc-query-task.md` 内 2〜3）に進む
