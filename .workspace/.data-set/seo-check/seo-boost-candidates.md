## SEO改善アクション別マッピング

### 🔗 内部リンク強化（工数：低）
順位10〜15位の記事はコンテンツの質より「リンク評価不足」が主因の場合が多い。
同カテゴリの強い記事から内部リンクを集中させる。

| 対象記事 | リンク元候補 |
|---------|------------|
| diy-vocal-soundproof-mask | closet-diy-soundproof-room, diy-wall-soundproofing-room-guide |
| hsp-soundproof-room-guide | noise-canceling-headphones-sleep, soundproof-room-pollen-protection |
| bass-trap-installation-guide | rt60-reverberation-measurement-guide, acoustic-panel-placement |
| soundproof-room-cheapest | soundproof-room-rental-cost, budget-soundproof-booth-comparison |
| asmr-proofroom-guide | asmr-soundproof-environment-guide, diy-vocal-soundproof-mask |
| soundproof-room-loan | soundproof-room-tax-guide, soundproof-room-rental-cost |

### ✍️ コンテンツ強化（工数：中）
順位15〜25位の記事はコンテンツの網羅性・専門性が足りない場合が多い。

| 対象記事 | 強化ポイント |
|---------|------------|
| bass-trap-installation-guide（順位14.0） | 設置位置の図解、周波数帯別の効果データを追加 |
| soundproof-room-standard-size（順位15.0） | サイズ別価格・メーカー比較表を追加 |
| soundproof-room-loan（順位24.0） | 金融機関別の利用条件、申請フローを追加 |
| guitar-soundproof-room-selection-guide（順位15.9） | DR値別のギター対応表、メーカー別推奨モデルを追加 |
| saxophone-practice-apartment（順位20.8） | 時間帯別騒音データ、ミュート器具の比較を追加 |

### 🎯 タイトル最適化（工数：極小）
CTRが特に高い記事はタイトル変更不要。順位改善だけでクリック増を狙う。
ただし以下は現在のタイトルを検索クエリに近づけると表示回数も増やせる可能性あり。

| 対象記事 | 改善ポイント |
|---------|------------|
| rental-game-soundproof-booth-3man（順位20.6） | 「防音ブース 3人用」「配信スタジオ 賃貸」など複合キーワード強化 |
| soundproof-room-buyback-guide（順位16.9） | 「防音室 売却」「防音室 買取 相場」で検索ボリューム確認 |
