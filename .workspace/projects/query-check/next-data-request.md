## 2. Search Console（Google）

検索パフォーマンス → 検索結果。期間は**過去16か月**（データのある全期間）。

| 取り方 | 絞り込み | エクスポートするタブ |
|---|---|---|
| A. 配信系のクエリ（サイト全体） | クエリ → 正規表現に一致 → `(?i)配信\|ゲーム\|実況\|vtuber\|asmr\|歌\|宅録\|マイク` | クエリ、ページ |
| B. `creator/` 配下 | ページ → URLに含む → `/ja/creator/` | クエリ、ページ |

- Aは、配信者が `creator/` 以外のページ（賃貸・価格・DIYなど）に着地している場合を拾うために必要
- Search Consoleの正規表現（RE2）は大文字小文字を区別する。Aは先頭に `(?i)` を付ける：`(?i)配信|ゲーム|実況|vtuber|asmr|歌|宅録|マイク`
- 各タブは別々にCSVでエクスポートされる。ファイル名が重複するため、`gsc_A_クエリ.csv`、`gsc_A_ページ.csv`、`gsc_B_クエリ.csv`、`gsc_B_ページ.csv` のように、取り方を付けて保存する
