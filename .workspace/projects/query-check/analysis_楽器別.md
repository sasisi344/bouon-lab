## 1. 目的と、この分析でわかること・わからないこと

「楽器ごとにクラスタを作る」ために、「楽器名 防音」の周辺で実在する検索の言い回しを取り、読者の悩みの種類を分けて、楽器ごとの記事候補を出す。

| 項目 | 内容 |
|---|---|
| 取得方法 | Googleサジェスト（`楽器名 防音` ＋ 賃貸・マンション・夜・苦情・自作など15の足し語、主要10楽器は五十音とa〜zの展開）。31楽器、約1,100回 |
| わかること | 実在する言い回し、悩みの種類、楽器ごとの悩みの幅（言い回しの種類数） |
| わからないこと | **検索ボリューム**。サジェストの件数は、需要の大きさではなく「言い回しの種類の多さ」の目安にすぎない |
| 補助データ | GSC 16か月（上位1,000クエリ）とBing（2026-10-11）を、楽器名で絞った（§2） |
| 注意 | 「ドラム 防音」にはドラム式洗濯機の防音が混ざる。「キーボード 防音」はPCキーボードの打鍵音と電子キーボードが混ざる。どちらも楽器の需要としては数えない |

次の裏取りが必要（§7）: ボリューム（Googleキーワードプランナーなど）、上位表示されている記事の型（SERP確認）。

読み取れること:

- **厚い3楽器（ピアノ・ドラム・ギター）は悩みの型が全部そろう**。1楽器につき複数の記事を作る価値がある
- **薄い楽器は、単独の記事ではなく楽器群でまとめる**。木管、金管、和楽器・小型楽器など
- **チェロは言い回しの種類は少ないが、実データでは上位に出ている**。悩みが「エンドピン」「床の振動」と特定されていて、競合が少ない可能性がある
- **「防音マット」はピアノ・ドラム・チェロに共通の入口**。「マットで何が防げるか」を楽器別に書き分ける価値がある

## 6. クラスタ構成案と記事候補

### 6-1. 構成

```
楽器の防音 入口（楽器別ハブ）  ← 楽器名・悩みの型で入ってくる読者を各楽器へ分ける
├─ ピアノ         （入口＋悩み別の記事）
├─ ドラム         （生ドラム／電子ドラム）
├─ ギター・ベース
├─ 管楽器         （サックス／金管／木管）
├─ 弦楽器         （バイオリン・ビオラ／チェロ・コントラバス）
├─ ボーカル・声楽
└─ 和楽器・小型楽器
共通（既存）: D値の目安、時間帯・規約、夜間練習、防音室の価格
```

「ハブ」は、`bouon-hub-cards` skill のトップ入口カード（frontmatter `hub`）の使い方を、あとで検討する。

## 7. 次に必要な裏取り

1. **ボリューム**: P1・P2の狙いクエリを、Googleキーワードプランナー（またはサジェストツール）で月間検索数に当てる。ボリュームが小さい記事候補は統合する
2. **SERP確認**: 「ピアノ 防音マット」「電子ドラム 防音」「チェロ 防振」などの上位がどの型か（商品比較、メーカー、ブログ）を見て、勝てる型か確認する
3. **Bing側の取得**: 今回はGoogleサジェストのみ。Bingのサジェストと、Bing Webmaster Toolsの最新のキーワードを同じ手順で取る
4. **足し語の追加**: 「苦情」「近所迷惑」はサジェストに1件も出ず、「夜」は「ピアノ 防音室 夜中」の1件だけだった。悩みの深い言い回しは、「楽器名 うるさい」「楽器名 苦情」「楽器名 何時まで」などで別に取り直す
