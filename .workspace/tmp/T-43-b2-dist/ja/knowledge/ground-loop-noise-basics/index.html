アース線でノイズは減る？つなぐと増える場合とグランドループ対策の順番

アース線でノイズが減るのは、機器同士の基準の電位がそろう場合です。つないでかえってノイズが増える例、音の種類からアースが原因かを見分ける表、費用のかからない順の対策と、やってはいけない処置をまとめます。

アース線をつなげばノイズが消える、とは限りません。

アース線で減るのは、機器同士の基準の電位がずれて出る「ブーン」というハムノイズです。

一方で、アースの経路が2本以上できるとグランドループになり、つないだことでかえってノイズが増えることもあります。

この記事では、ノイズの音からアースが原因かを見分ける方法と、お金のかからない順の対策を整理します。

防音室や配信部屋の作り方を調べていると、「外の音は防げたのに、マイクに『ブーン』という音が乗る」という悩みによく行き当たります。

壁や吸音材では消えないこの音について調べていくと、多くの人が勘違いしているのが、アースのつなぎ方でした。

アース線でノイズが減る場合・増える場合

アース（接地）には、目的の違う2種類があります。

  • 安全用のアース : 洗濯機や電子レンジの緑の線、3Pプラグの丸いピン。漏電したときに電気を地面へ逃がし、感電を防ぐためのものです
  • オーディオのアース（信号のグラウンド） : 機器同士の基準の電位をそろえ、信号にノイズが乗らないようにするためのものです

ノイズ対策で効くのは、主に後者です。

壁のアース端子に何でもつなげば静かになる、という仕組みではありません。

状況アース線の効果理由
レコードプレーヤーのアース線を、アンプのGND（アース）端子につなぐ減るプレーヤーとアンプの基準の電位がそろい、ハムや静電気のノイズが逃げる
機器を別々のコンセントにつないでいて、電位に差がある電源をそろえると減るアースの電位差そのものが小さくなる
すでに信号ケーブルでつながっている機器同士を、さらにアース線でつなぐ・壁のアースにもつなぐ増えることがあるアースの経路が2本以上になり、ループができる
集合住宅で、壁のアース端子に機器のアースをつなぐ変わらない、または増えることがある建物のアースは他の家電も共用しており、そのノイズが流れ込むことがある
「サー」という一定の音が出ているほぼ変わらない原因はアースではなく、マイクの感度やゲインの上げすぎであることが多い

アース線は「つなぐ」「外す」の両方を試して、ノイズの変化で判断するのが基本です。

ただし、外してよいのはオーディオ用のアース線だけです。

安全用のアースを外す処置は危険なので、後の「やってはいけないアースの処置」で説明します。

ノイズの音でアースが原因かを見分ける

対策を買う前に、まずノイズの音を聞き分けます。

アースが原因のノイズには、はっきりした特徴があります。

聞こえ方主な原因最初に試すこと
「ブーン」という低い唸り電源の周波数（東日本50Hz・西日本60Hz）によるハムノイズ。グランドループの典型機器をすべて同じ電源タップにまとめる
「ジー」「ジジジ」という少し高い唸りハムの倍音や、電源ケーブルからの誘導信号ケーブルを電源ケーブルから離す
「サー」という一定の音マイクやアンプの自己雑音、ゲインの上げすぎゲインを下げて、マイクとの距離を近づける
「パチパチ」「ガリッ」という音静電気、端子の接触不良端子を挿し直す。レコードプレーヤーならアース線を確認
マウスを動かす・画面を変えると音が変わるPCのUSBや電源を経由して入るノイズノートPCなら充電器を外して変化を見る

「ブーン」「ジー」の2つは、アースの扱いで直る可能性が高い音です。

「サー」はアースを触っても変わらないことが多く、機材の設定から見直します。

グランドループの仕組み

グランドループは、次の流れで起きます。

  • 複数の機器（アンプ・オーディオインターフェース・PC・ミキサーなど）を、それぞれ異なるコンセントや電源タップにつなぐ
  • コンセントごとに、アースの電位（基準となる電圧）にわずかな差が出る
  • 機器同士を信号ケーブル（RCA・XLR・USBなど）でつなぐと、その差を埋めるようにケーブルのシールドへ電流が流れる
  • この電流が音声信号に混ざり、ハムノイズになる

つまり、アースが2つ以上の経路でつながっている状態がループを作ります。

1台の機器だけでは起きず、複数の機器をつないだときに初めて問題になるのが特徴です。

自分の環境がグランドループかを見分ける手順

原因を特定せずに対策すると、見当違いの買い物になりがちです。

次の順で切り分けます。

  1. 信号ケーブルを1本ずつ抜く : ノイズが消えるケーブルがあれば、その経路が原因の可能性が高いです
  2. 機器をすべて同じ電源タップ・同じコンセントにまとめる : これで軽くなれば、電源が分かれていることによるグランドループです
  3. 機器の電源を1台ずつ落とす : どの機器を止めるとノイズが変わるかで、発生源を絞れます
  4. ケーブルの種類を確認する : アンバランス接続（RCAなど）は影響を受けやすく、バランス接続（XLR・TRS）は受けにくい構造です

アースのノイズ対策は費用のかからない順に

切り分けができたら、お金のかからない対策から試します。

順対策費用向いている状況
1電源タップ・コンセントを1か所にまとめるなし機器の電源が別々のコンセントに分かれている
2信号ケーブルを電源ケーブルから離す・交差させるなし「ジー」という音で、配線が束ねてある
3バランス接続のケーブルに替えるケーブル代機器がXLR・TRSに対応している
4グラウンドループアイソレーターを入れる製品代電源をどうしても分けられない
5建物のアースを点検してもらう工事費1〜4で変わらず、コンセントのアース自体が疑わしい

私なら、お金をかける前に1と2を必ず試します。

どちらも元に戻せるので、効かなくても失うものがありません。

アイソレーターを買うのは、それでもノイズが消えなかったときで十分だと考えています。

電源タップ・コンセントを統一する（最も手軽）

すべての機器を同じ電源タップにまとめると、アースの電位差そのものが小さくなります。

工具も追加費用も要らないので、最初に試します。

信号ケーブルと電源ケーブルを離す

電源ケーブルと信号ケーブルを並べて束ねると、電源のノイズが信号側に移りやすくなります。

離せない場所では、平行に沿わせず直角に交差させます。

バランス接続に切り替える

アンバランス接続からバランス接続（XLR・TRS）に替えると、ノイズの混入経路そのものが減ります。

PA現場やオーディオインターフェースを使う環境では、できる限りバランス接続を選ぶのが基本です。

グラウンドループアイソレーターを使う

配線が離れている、業務用の電源が別系統になっているなど、電源を分けざるを得ない環境では、グラウンドループアイソレーターを信号経路に入れます。

アースの経路を信号ケーブルの途中で断ち切るので、ループができなくなります。

オーディオのRCA用、USB用、映像用など、扱う信号ごとに製品が分かれているため、つなぐ端子に合ったものを選びます。

アースの状態そのものを点検してもらう

コンセントのアース工事が不十分、またはアースが取られていない場合、上の対策だけでは直らないことがあります。

機器のアース線を、すでにあるコンセントのアース端子につなぐのは利用者でもできます。

一方で、壁の中のアース線の増設や配線の変更は、電気工事士の資格が必要な作業です。

疑わしい場合は、電気工事店か管理会社に相談してください。

やってはいけないアースの処置

アースを外すとノイズが消えることがあります。

ただし、安全用のアースを外したまま使うのは危険です。

  • 3Pプラグのアースピンを折る・浮かせる : ノイズは消えても、漏電したときの感電防止がなくなります。オーディオ用のアース線で調整し、安全用のアースは残します
  • ガス管にアース線をつなぐ : 引火のおそれがあり、アースとしても使えません
  • 水道管にアース線をつなぐ : 途中が樹脂の配管になっている建物では、地面とつながらずアースの役目を果たしません
  • 集合住宅で、アース線を勝手にベランダの手すりや地面へ引く : 共用部分の改変になるうえ、安全なアースになる保証がありません

アースの工事や電気設備の扱いは、感電や火災に関わります。

自己判断で分解・改造せず、電気工事士などの専門家に確認してください。

レコードプレーヤー・PA現場・電子工作の注意点

家庭のオーディオとは別に、次の場面にも注意点があります。

  • レコードプレーヤー : プレーヤーのアース線をアンプのGND端子につなぎます。外れていると「ブーン」というハムが出やすく、アナログ再生でアース線がもっとも効く場面です
  • PA現場 : 会場の電源が複数の系統に分かれていると、ミキサー・アンプ・照明がそれぞれ別のアースにつながり、グランドループが起きやすくなります。本番前のサウンドチェックで必ずノイズを確認します
  • 電子工作・自作オーディオ機器 : 回路のグラウンド（GND）の配線を1点に集める「スターグラウンド」を意識すると、ループを防ぎやすくなります

配信・宅録環境での見分け方と対策

マイク・オーディオインターフェース・PCの組み合わせでは、吸音パネルや機材の対策をしても消えない「ジー」という唸りが、グランドループ由来であることがよくあります。

私がノイズに困るのは、録音するときです。

ふだん部屋にある電磁ノイズは耳では聞こえませんが、録音して取り込むと目立つことがあります。

ほかにも、ケーブルがこすれたときや、電気・磁気を出す機器がマイクの近くにあるときにも、ノイズが入りやすくなります。

配信環境では、次の手順で切り分けます。

  • マイクケーブルを抜く : ノイズが消えれば、ケーブルや配線経路が原因の可能性が高いです
  • 機器をすべて同じ電源タップにつなぎ直す : これで軽くなれば、電源の分離が原因のグランドループです
  • ノートPCの充電器を外す : 外して静かになるなら、充電器とUSBを経由したループです。USB用のアイソレーターか、オーディオインターフェースとPCを同じタップにまとめる対策が効きます
  • PCの電源を落としてもノイズが残るか確認する : 残る場合は、PC本体ではなく配線・電源側の問題です

PC本体のファン音や振動によるノイズとの違いは、次の記事で解説しています。

よくある質問

アース端子のないコンセントでもノイズ対策はできる？

できます。

グランドループの多くは、壁のアースではなく機器同士のつなぎ方で起きています。

電源タップの統一、バランス接続、アイソレーターは、アース端子がなくても試せます。

アースを外したらノイズが消えた。そのままでいい？

外したのがオーディオ用のアース線なら、そのままで構いません。

3Pプラグのアースピンを浮かせて消えた場合は、安全用のアースを失った状態なので、元に戻してアイソレーターなど別の方法で対策します。

グラウンドループアイソレーターで音質は落ちる？

トランス式の製品は、機種によって低音や高音の出方が変わることがあります。

購入前に、仕様に書かれた周波数特性が自分の用途の帯域をカバーしているかを確認します。

まずは電源タップの統一など、無料の対策で直るかを先に確かめるのがおすすめです。

まとめ

アース線でノイズが減るのは、機器同士の基準の電位がそろう場合です。

アースの経路が2本以上できるとグランドループになり、つないでかえって増えることもあります。

「ブーン」「ジー」という音ならアースが原因の可能性が高く、電源タップの統一→配線の分離→バランス接続→アイソレーター→建物のアース点検の順に試します。

安全用のアースは外さず、壁の中の工事は電気工事士に任せてください。

ノイズが消えるとしても、3Pプラグのアースピンを浮かせる方法だけは、私は選びません。

音の悩みが解決する代わりに、感電の危険を抱えることになるからです。
