吸音材か遮音材か迷う人へ｜あなたの環境で“必要なのはどっち？”徹底ガイド

吸音材と遮音材はどちらがいいのか。結論は「悩みが音漏れなら遮音、響きやこもりなら吸音」です。違いを表で比べ、3つの質問で判断できる簡易チェックと、施工の順番、よくある失敗を解説します。

防音対策で失敗する人の多くは、「音漏れ」と「響き・こもり」を区別せずに対策を選んでいます。「吸音パネルをたくさん貼ったのに隣室への音漏れが変わらない」という相談は非常に多く、その原因のほとんどは素材選びの根本的な勘違いにあります。

この記事では、吸音材と遮音材それぞれの仕組みを物理的に解説したうえで、あなたの状況でどちらを優先すべきかを判断できるようにします。

先に結論です。

「吸音材と遮音材はどちらがいいですか？」という疑問への答えは、悩みが音漏れなら遮音、室内の響き・こもりなら吸音です。

吸音と遮音の違いを表で比べる

項目遮音吸音
目的音を壁・床の向こうに通さない室内の反射・響きを減らす
仕組み重さ（質量）で音を跳ね返す多孔質の隙間で音のエネルギーを熱に変える
代表的な素材石膏ボード、遮音シート、防音ドア・窓グラスウール、ウレタンフォーム、吸音パネル
向いている悩み隣の部屋に聞こえる、外の音が入る声がこもる、反響する、録音が聞き取りにくい
効かない悩み室内の響き壁の向こうへの音漏れ

どちらか一方だけでは、悩みが片方しか解決しません。

3つの質問で判断する簡易チェック

次の順に、当てはまるものを選んでください。

  1. 音が壁や床を通って、隣や外に伝わっていますか？ : はい → 遮音（と隙間対策）を先に
  2. 部屋の中で声が反響したり、録音がこもったりしますか？ : はい → 吸音を足す
  3. 足音や低音が「ドン」と下の階に響きますか？ : はい → 遮音・吸音ではなく防振。低周波・振動対策の基礎を参照

1と2の両方に当てはまる場合は、遮音で音の出入りを止めてから、吸音で室内を整える順番で進めます。

「漏れている音」と「響いている音」は別の問題

まず最初に切り分けるべきは、自分が困っているのが遮音の問題なのか吸音の問題なのかです。

  • 遮音の問題 : 「隣の部屋の話し声が聞こえる」「外の車の音が気になる」「自分の声が外に漏れていないか心配」など、音が壁・床・天井を通り抜けて移動することが原因
  • 吸音の問題 : 「録音した自分の声がこもって聞こえる」「部屋で話すと反響して聞き取りにくい」など、音が室内で反射・滞留することが原因

この2つは発生するメカニズムが全く違うため、対策に使う素材も別物です。「漏れ」を解決したいのに「響き」用の素材を選んでしまうのが、防音対策で最も多い失敗パターンです。

遮音材とは：「質量則」で音を跳ね返す仕組み

遮音材は、音を跳ね返して通さないための素材です。その効果の根拠になっているのが「質量則」という物理法則で、簡単に言うと「壁の面密度（1m²あたりの重さ）が高いほど、音は透過しにくくなる」という原則です。

理論上は、壁の面密度が2倍になると遮音性能（透過損失）が約6dB向上するとされています（質量則）。重く・密度が高い素材ほど、音のエネルギーをその場でせき止める力が強くなります。

代表的な遮音材・遮音方法には以下があります。

  • 石膏ボードの重ね張り : 壁の面密度を上げて透過損失を稼ぐ最も基本的な方法
  • 遮音シート（鉛・高比重ゴム系など） : 薄くても比重が大きく、限られたスペースで遮音性能を上げられる
  • 制振材 : 板の振動を抑える素材。遮音シートとは別物で、組み合わせて使うことが多い
  • 防音ドア・防音窓 : ゴムパッキンによる気密性確保が遮音性能の大部分を左右する

遮音性能の指標である「D値」については、遮音性能の基準「D値」とは？楽器・用途別の目安で詳しく解説しています。

吸音材とは：音エネルギーを「熱」に変える仕組み

吸音材は、グラスウールやウレタンフォームのような多孔質構造（小さな穴や繊維が無数にある構造）の素材です。音波がこの細かい隙間に入り込むと、空気とのわずかな摩擦によって音のエネルギーが熱エネルギーに変換され、音が減衰します。

ここで重要なのは、吸音材は「音を消す」のではなく「室内の反射を抑える」素材だという点です。多孔質で軽量な構造であるため、質量則の観点ではほとんど効果がなく、壁の外に漏れる音量自体はほぼ変わりません。

見た目のデザイン性も重視したい場合は、苔を使った吸音パネルという選択肢もあります。苔の吸音効果はどのくらい？研究データで見る防音との違いと壁への取り入れ方で、研究データと貼る場所を紹介しています。

最大の誤解：「吸音材を貼れば防音できる」は誤り

防音対策で最も多い失敗が、壁一面に吸音パネル（ウレタンフォームなど）を貼ったのに、隣室への音漏れが全く改善しないケースです。

理由は単純で、吸音材はスカスカで軽い構造のため、質量則の観点でほとんど遮音効果を持たないからです。室内の反響音（こもり感）は確実に減りますが、壁を通り抜けていく音のエネルギーそのものは、吸音材を貼る前とほとんど変わりません。

逆に、遮音材だけを使った場合も問題が起きます。重い遮音シートで壁を覆って音漏れを止めても、室内の反響は変わらないため「声が部屋の中で響いて聞き取りにくい」状態は解消されません。

つまり、「防音」とは遮音と吸音の役割分担であり、どちらか一方だけでは目的を達成できません。DIY防音グッズの効果を見極める考え方は、防音パネルの罠｜DIY失敗例から学ぶ『遮音と吸音』の物理学的黄金比も参考にしてください。

ケース別：あなたに必要なのはどっち？

自分の状況がどのパターンに近いかを確認してください。

状況主な悩み優先すべき対策
在宅ワーク（オンライン会議の声漏れ）漏れが中心遮音（ドア・壁・窓の隙間対策）
楽器の演奏練習漏れが中心、響きも一部関係遮音を優先しつつ、室内の反響も吸音で調整
ゲーム配信・宅録（声の録音品質）響き・こもりが中心吸音を優先（マイク周辺の反射対策）
録音スタジオ・本格的な防音室漏れ・響きの両方遮音で音の出入りを止めたうえで、吸音で音場を整える

楽器演奏のように音量が大きく近隣への影響が出やすい用途では、まず遮音を確保してから吸音で室内環境を整えるのが基本です。一方、配信・宅録のように自分のマイクで拾う音質が課題の場合は、吸音材から着手しても効果を実感しやすいです。

自宅で映画とカラオケを両立させたい場合も、遮音と音響を目的別に切り分ける発想が欠かせません。

具体的な費用や設計の進め方は、防音室サイズ別価格相場2026（ホームシアターとカラオケを兼用する場合の予算の考え方も掲載）で解説しています。

正しい施工順序：遮音が先、吸音は後

防音対策には正しい順序があります。

  1. 遮音で音の出入りを最小化する : 壁・ドア・窓・隙間など、音が通り抜けるルートを物理的にふさぐ
  2. 吸音で室内の音場を整える : 反響・こもりを抑え、聞き取りやすい・録音しやすい空間にする
  3. 隙間を再点検する : ドア下のすき間、配線用の貫通穴などは、どれだけ遮音材を増やしても遮音性能を一気に下げる弱点になる

特に隙間は見落とされがちですが、わずか数mmの隙間があるだけで、壁全体の遮音性能が大幅に低下します。遮音材を選ぶ前に、まず隙間の有無を確認することが費用対効果の高い第一歩です。

予算別の防音対策の進め方は、予算別防音室選び方ガイド｜50万円・100万円・200万円で選ぶ方法も参照してください。

よくある質問

吸音材を貼れば、隣の部屋への音漏れは減りますか？

ほとんど変わりません。

吸音材は軽くて空隙が多く、質量則の面では遮音の効果が小さいためです。減るのは、室内の反響やこもりです。

遮音シートを貼るだけで防音できますか？

シートだけでは足りないことが多いです。

壁の面密度が十分に上がらない場合や、ドア・窓・コンセントまわりに隙間がある場合は、そこから音が抜けます。先に隙間を塞ぐのが費用対効果の高い第一歩です。

吸音パネルは、どこに貼ればいいですか？

用途で変わります。配信や宅録なら、マイクの周囲やモニター・スピーカーの背面など、反射が気になる位置です。

まとめ

  • 「漏れ」と「響き」は別の問題 : まず自分の悩みがどちらに当たるかを切り分ける
  • 遮音は質量則 : 重く・密度が高い素材ほど音を通しにくい
  • 吸音は摩擦による熱変換 : 多孔質素材が室内の反響を減らすが、音漏れには効果が薄い
  • 「吸音材だけ貼る」は音漏れ対策にならない : 防音は遮音と吸音の組み合わせで成立する
  • 施工順序は遮音→吸音→隙間処理 : 順序を間違えると効果を実感しにくい

吸音材と遮音材は、競合する選択肢ではなく役割が異なる道具です。自分の悩みが「漏れ」なのか「響き」なのかを正しく切り分けることが、無駄な出費を避けるための最短ルートになります。

各素材の面密度・透過損失（TL値）・NRC値を具体的な数値で確認したい方は、防音材スペック早見表もあわせてご覧ください。
