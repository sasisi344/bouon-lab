暗騒音の目安はNC値で決める｜ASMR・歌枠・ゲーム実況の録音に必要な静けさ

録音や配信で部屋をどこまで静かにすべきかは、暗騒音のNC値で決めます。録音スタジオの目安はNC-15〜20（約25〜30dB(A)）、寝室はNC-25〜35。ASMR・歌枠・ゲーム実況ごとの目標値、暗騒音を上げる室内の音源、測り方と下げる順番を表で整理します。

暗騒音（何も鳴らしていないときの部屋の音）の目安は、NC値という指標で決めるのが一般的です。

録音スタジオや放送スタジオの推奨はNC-15〜20で、騒音計の値にするとおよそ25〜30dB(A)、ホテルの客室くらいの静けさです。

ASMRのように小さな音を録るほど低いNC値が必要で、ゲーム実況なら寝室並みのNC-30前後でも困らないことが多くなります。

この記事では、NC値の読み方、コンテンツ別の目標値、暗騒音を上げる室内の音源、測り方と下げる順番を整理します。

暗騒音とは｜録音の「底」にある音

暗騒音は、声も楽器も鳴らしていないときに、部屋に残っている音です。

エアコンの送風、PCのファン、冷蔵庫の唸り、外の車の音などが重なってできています。

マイクは、声と一緒にこの暗騒音も拾います。

声に対して暗騒音が大きいほど、編集で消そうとしたときに声まで削れ、音が不自然になります。

防音（外へ漏らさない）と、暗騒音を下げること（中を静かにする）は、別の課題です。

外への音漏れの基準は、遮音性能の基準「D値」とは？楽器・用途別の目安のようにD値・Dr値で見ます。

NC値とは｜周波数ごとの許容値で決める静けさ

NC値（Noise Criteria）は、1957年にレオ・ベラネクが提案した、室内の騒音を評価する指標です。

低い音から高い音まで、オクターブごとに「ここまでなら許容できる」という上限の線（NC曲線）が決まっています。

測った騒音が、すべての周波数で下回っている一番低い線の番号が、その部屋のNC値です。

（単位はdB。出典: The Engineering ToolBox「NC - Noise Criterion」）

低い音ほど許容値が大きいのは、人の耳が低い音に鈍いためです。

騒音計のdB(A)とは、おおよそdB(A) ≒ NC値＋10の関係で読み替えられます。

ただし音の成分によってずれるため、あくまで目安として使ってください。

ふつうの住宅の寝室は、静かな時間帯でもスタジオの基準より10dBほど騒がしいことになります。

コンテンツ別の暗騒音の目標

録音・配信の内容によって、必要な静けさは変わります。

次の表は、上の推奨値をもとに、本サイトが用途ごとに当てはめた目安です。

コンテンツ目標のNC値理由
ASMR・囁き声・バイノーラル収録NC-20以下声そのものが30dB前後と小さく、マイクの感度を上げて録るため、暗騒音がそのまま聞こえる
歌枠・弾き語り・朗読NC-25前後声や楽器は大きいが、曲の静かな部分や息づかいで暗騒音が目立つ
雑談・ゲーム実況NC-30前後声が大きく、ゲーム音も重なるため、寝室並みの静けさで足りることが多い

ささやき声は約30dB、ふつうの会話は約60dBです。

ささやき声を録るASMRでは、暗騒音が30dB(A)あると声と同じ大きさになり、録音の背景に常に「サー」という音が残ります。

複数のジャンルを配信するなら、一番静けさが必要なコンテンツに合わせて部屋を作るのが安全です。

暗騒音を上げる室内の音源

外の音を防音で止めても、部屋の中に音源があれば暗騒音は下がりません。

音源音の特徴下げ方
エアコンの送風「サー」という広い帯域の音録音中だけ止める、風量を最小にする、吹き出し口とマイクを離す
PCのファン負荷で回転数が上がり、音が大きくなるPCを室外や机の下に置く、マイクの背中側に向ける
冷蔵庫低い唸りと、床を伝わる振動録音する部屋から離す、脚の下を防振する
換気扇・換気ファン気流の音消音型のダクト・ファンに替える、録音中は弱運転
外の車・人の声窓から入る窓の隙間をふさぐ、二重窓、防音室

ファン音・反響・外の音のどれが原因かを切り分ける手順は、配信のマイクノイズはPC本体が原因？ファン音・反響・外音の切り分けと直し方で解説しています。

冷蔵庫の唸りや振動を床に伝えない置き方は、冷蔵庫のブーンという振動音の対策｜防振マットの選び方と床に響かせない置き方にまとめています。

防音室では「静けさ」と「暑さ」がぶつかる

防音室は外の音を止めるため、暗騒音を下げるのに有利です。

一方で、気密が高いため、PCや人の熱がこもって室温が上がりやすくなります。

暑さ対策でエアコンや換気ファンを強く回すと、今度はその音が暗騒音を押し上げます。

録音の目標が厳しいほど、PCを室外に出す、録音中は空調を弱める、録音の合間に冷やすといった運用で両立させます。

小型の防音室で熱がこもる仕組みと対策は、格安防音室は夏に地獄化する？だんぼっち・OTODASU排熱リスクと中古購入の注意点と、防音室の温湿度管理ガイド2026｜暑さ・結露・乾燥を物理的に防ぐ改善術で解説しています。

暗騒音の測り方と、下げる順番

NC値を正確に出すには、オクターブごとに測れる騒音計が必要です。

家庭では、騒音計やスマホアプリのdB(A)の値から、上の「dB(A) ≒ NC値＋10」でおおよその見当をつけます。

  1. 何も鳴らさずに測る : 録音する時間帯に、マイクの位置で測る
  2. 音源を1つずつ止めて測る : エアコン、PC、冷蔵庫を順に止め、どれで一番下がるかを見る
  3. 一番効いた音源から対策する : 止められるものは録音中だけ止め、止められないものは離す・防振する
  4. 外の音が残るなら防音へ : 室内の音源を止めても目標に届かないときは、窓や防音室で外の音を止める

スマホアプリでどこまで測れるかは、防音性能を測るスマホアプリ比較2026｜無料アプリでどこまで分かる？で比べています。

ASMRで外の音を消す部屋づくりと、防音ブースの選び方は、ASMR収録の部屋づくり｜外音の消し方と防音ブースの選び方で解説しています。

よくある質問

NC値とdB(A)はどう違いますか？

dB(A)は、騒音全体を1つの数字にした値です。

NC値は、低い音から高い音まで周波数ごとに許容値を決めた指標で、どの高さの音がうるさいかまで評価できます。

ふつうの部屋でASMRは録れますか？

録れますが、夜の住宅地でも暗騒音は40dB(A)前後になることがあり、スタジオの目安より10dBほど騒がしくなります。

エアコンやPCを止め、外の音が少ない深夜に録るなど、運用で下げる工夫が必要です。

防音室に入れば、暗騒音は必ず下がりますか？

外から入る音は下がりますが、中に持ち込んだPCやエアコンの音は下がりません。

防音室の中では、室内の音源の対策がより重要になります。

まとめ｜録るものに合わせて静けさを決める

  • 暗騒音の目安 : 録音スタジオはNC-15〜20（約25〜30dB(A)）、寝室はNC-25〜35
  • コンテンツ別 : ASMRはNC-20以下、歌枠はNC-25前後、ゲーム実況はNC-30前後
  • 下げる順番 : 室内の音源を1つずつ止めて測り、効いた順に対策。足りなければ防音で外の音を止める
  • 防音室の注意 : 静けさと暑さがぶつかる。PCを外に出し、録音中は空調を弱める運用で両立する
