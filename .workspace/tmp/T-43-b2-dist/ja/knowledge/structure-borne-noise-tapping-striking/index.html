叩く音・押す音が下の階に響くのはなぜ？ヘッドホンでも消えない振動の止め方

叩く音・押す音が下の階に響くのは、衝撃が机や脚から床へ振動（固体伝搬音）として伝わり、ヘッドホンでは消えないからです。キーボード・電子ピアノ・電子ドラム・台パンに共通する仕組みと、発生源・置き台・脚・床の4か所で効く対策を表で整理します。

叩く音・押す音が下の階に響くのは、衝撃が空気ではなく、机や脚から床へ「振動」として伝わるからです。

この振動は、ヘッドホンで演奏の音を消しても、吸音パネルやカーテンを付けても止まりません。

止めるには、叩いた場所から床までの通り道のどこかで、振動を受け止める必要があります。

この記事では、キーボード・電子ピアノ・電子ドラム・台パンに共通する仕組みと、4か所の対策の順番を整理します。

自分の音源が決まっている人は、途中の表から音源別の記事へ進んでください。

足音は同じ仕組みでも対策が違うため、別の記事で扱います（よくある質問を参照）。

下の階に響くのはなぜ？空気ではなく、机や床を伝わる「固体伝搬音」

音は、伝わり方で2つに分けられます。

種類伝わり方主に聞こえる場所効く対策
空気伝搬音音が空気を振るわせて広がる同じ部屋、隣の部屋、マイク遮音・吸音、静かな機器を選ぶ
固体伝搬音叩いた衝撃が、机・脚・床・壁を振動として伝わり、離れた場所で音になる下の階、壁を隔てた部屋防振（振動の通り道を切る）

固体伝搬音のやっかいな点は、出ている場所と聞こえる場所がずれることです。

叩いている本人には「カチャカチャ」「パタパタ」と軽く聞こえていても、下の階では天井から「コトコト」「ドンドン」という低い音になって届きます。

床のコンクリートや梁が振動し、下の階の天井や壁が、スピーカーの膜のように音を出すためです。

ヘッドホンで演奏の音を消しても、この振動は消えません。

キーボード・電子ピアノ・電子ドラム・台パンは同じ仕組み

指や足、道具で「押す・叩く」音は、どれも同じ道筋で下の階に届きます。

叩く → 底や面に当たる → 置き台・スタンド・机 → 脚 → 床 → 下の階の天井

違うのは、衝撃の重さと、通り道の形です。

音源衝撃の出どころ通り道衝撃の性質詳しい対策
キーボード（PC）キーの底打ち机 → 机の脚 → 床軽く、硬いキーボードの打鍵音対策
電子ピアノ鍵盤の底打ち、ペダルの踏み込みスタンドの脚・ペダル → 床軽い〜中くらい電子ピアノの打鍵音対策
電子ドラムキックペダル、パッドペダル・ラックの脚 → 床重く、低い電子ドラムの振動対策
台パン机を手で叩く机 → 机の脚 → 床重く、低い台パンの衝撃吸収・防振対策

キーボードの記事で「鍵盤の底に当たる衝撃が脚から床へ伝わる」と書いた仕組みは、電子ピアノでもそのまま当てはまります。

電子ドラムのキックと台パンは、1回の衝撃が重いぶん、下の階で低い「ドン」という音になりやすいです。

軽い衝撃と重い衝撃で、効く対策が変わる

床に伝わる衝撃音は、建築の分野では2種類に分けて考えます。

種類例下の階での聞こえ方柔らかいマットの効き方
軽量床衝撃音スプーンを落とす、硬い物で床を打つ「コツコツ」「カチャ」という高めの音効きやすい
重量床衝撃音子どもが飛び跳ねる、重い物を落とす「ドスン」「ドン」という低い音効きにくい

打鍵音の多くは、軽い衝撃の側に近い音です。

底打ちの硬い衝撃は、柔らかい層を1枚はさむだけで、かなり丸くなります。

電子ドラムのキックや台パンは、重い衝撃の側に近い音です。

重く低い衝撃は、薄いマットではほとんど止まらず、重い板と柔らかい層を組み合わせるような対策が必要になります。

床衝撃音の2種類と、L等級（LH・LL）の読み方は、階下から足音の苦情が来たら？ジョイントマットで防げない理由と正しい対策で解説しています。

固体伝搬音の対策は「通り道の4か所」で考える

対策は、衝撃が通る順に4か所あります。

音源に近いほど、安く、よく効くのが基本です。

場所やること費用の目安向いている音源
発生源底打ちしない打ち方、静音スイッチ・静音キックなど静かな機器0円〜機器の買い替えすべて
叩く物の下キーボードの下のマット、ペダルの下の防振ボード数千円〜1万円台キーボード、電子ドラム
脚机・スタンドの脚の下に防振ゴムやインシュレーター数千円キーボード、電子ピアノ、台パン
床防音マット・遮音カーペットを敷く。重い衝撃は「ふにゃふにゃシステム」のような浮かせる台数千円〜数万円電子ピアノ、電子ドラム

発生源：叩く力と、当たる面を変える

いちばん効くのは、衝撃そのものを小さくすることです。

  • キーボード : 底まで押し切らない打ち方、Oリング、静音スイッチ
  • 電子ピアノ : 鍵盤とペダルを踏み切る強さ。ペダルは底に当てない踏み方
  • 電子ドラム : ビーターのないキックや、静音タイプのパッド

たとえばローランドは、ビーターをなくしたキック「KT-9」について、階下への打撃音を63％削減するとしています（同社独自の測定方法による）。

叩く物の下と脚：振動の通り道を切る

衝撃を、机やスタンドに渡る前に受け止めます。

ローランドのペダル用防振ボード「NE-10」は、階下への騒音を約75％軽減するとしています（同社の測定結果）。

脚の下のゴムは、机やスタンドから床へ渡る振動を減らします。

床：重い衝撃は「重さ＋柔らかさ」で受ける

床に敷く対策は、軽い衝撃には薄いマットでも効きます。

重い衝撃には、柔らかい層の上に、重い板を載せる組み合わせが効きます。

重さで揺れにくくし、柔らかい層で床へ渡る振動を減らす考え方です。

ただし、柔らかすぎる材料や、重さとの組み合わせを外すと、かえって揺れが増えることがあります。

共振が起きる仕組みと、質量・ばね・固有振動数の基本は、低周波・振動対策の基礎｜防振床・浮き床構造の仕組みと選び方にまとめています。

自分の音が下の階に届いているかを確かめる

対策を買う前と後に、同じ方法で確かめると、効いたかどうかが分かります。

  • 家族に聞いてもらう : いつもの強さで1分ほど鳴らし、別の部屋や下の階（戸建ての場合）で聞いてもらいます
  • 床に置いたスマホで録音する : 机や楽器から少し離れた床で録り、「コトコト」「ドン」が残っているかを聞きます
  • 水を入れたコップを置く : 机やスタンドの上の水面が揺れるなら、置き台ごと揺れています

いずれも目安で、騒音計での測定ではありません。

「気にしていたら練習できない」への考え方

固体伝搬音は、本人には聞こえにくい音です。

だからこそ、下の階の人との受け取り方の差が大きくなります。

裁判例では、音の大きさだけでなく、時間帯と、生活音か演奏の音かが判断に入っています。

深夜は小さな音でも受忍限度を超えるとされた例がある一方、昼間の音は受忍限度の内とされた例もあります。

練習をやめるのではなく、時間で線を引き、できる対策をしておくのが現実的な落としどころです。

判例の中身は、電子ピアノの打鍵音対策と騒音苦情への正しい対応｜解決事例と判例から学ぶ受忍限度の境界線で紹介しています。

個別の事例が法的にどう判断されるかは、事情によって変わります。

実際にトラブルになっている場合は、弁護士や自治体の相談窓口に確認してください。

マットや防振で足りないとき

生ドラムや、深夜の練習が欠かせない場合は、置き台や床の対策だけでは足りません。

部屋の中に、床から浮かせた部屋を作る防音室や防振工事が必要になります。

ドラムに必要な性能の目安は、自宅でドラムを叩いても許されるDr値は？住む環境別に見る防音の必要性で解説しています。

夜間の練習と防音室の振動の注意点は、夜間練習はどこまで許される？深夜でも楽器を弾くための防音室選びと「振動」の罠にまとめています。

よくある質問

固体伝搬音は吸音材で防げますか？

ほとんど防げません。

吸音材は、空気中の音の反射を減らす材料です。

机や床を伝わる振動には、防振ゴムやマットなど、通り道を切る対策が必要です。

足音も同じ対策でよいですか？

仕組みは同じですが、足音は部屋じゅうで出るため、置き台や脚の対策が使えません。

床全体の対策が中心になるので、階下から足音の苦情が来たら？ジョイントマットで防げない理由と正しい対策を参照してください。

防振ゴムは厚いほど効きますか？

厚さだけでは決まりません。

載せる物の重さに対して柔らかすぎたり硬すぎたりすると、効きが落ちたり、揺れが増えたりします。

製品ごとの「耐荷重」を、載せる物の重さに合わせて選んでください。

戸建てなら気にしなくてよいですか？

下の階が家族の部屋なら、同じように響きます。

木造は、コンクリートの建物より床が揺れやすく、振動が伝わりやすい傾向があります。

まとめ

  • 固体伝搬音は、叩いた衝撃が机・脚・床を振動として伝わり、下の階で音になるもの
  • キーボード・電子ピアノ・電子ドラム・台パンは、同じ道筋で届く
  • 対策は、発生源・叩く物の下・脚・床の4か所。音源に近いほど安く効く
  • 軽い衝撃はマットで効きやすく、重い衝撃は「重さ＋柔らかさ」の組み合わせが必要
  • 深夜は、ヘッドホンをしていても振動は届く前提で、時間で線を引く
