無声音声インターフェース（SSI）とは？声を出さずに話す技術の現在地と防音への影響

無声音声インターフェース（SSI）は、声を出さずに口や喉の筋肉の信号から言葉を読み取る技術です。2026年の研究では限られた文なら認識率90%台に届く一方、誰でも自由に話せる製品はまだありません。主な研究の数値、実用化の壁、防音室が不要になるかを用途別に整理します。

無声音声インターフェース（Silent Speech Interface：SSI）は、声を出さずに、口や喉の筋肉の信号や動きから言葉を読み取る技術です。

2026年の研究では、決まった短い文なら認識率90%台に届く例が出ていますが、自由な会話を誰でも使える製品はまだ発売されていません。

防音の面では、防音室を置き換えるより先に、音声入力やWeb会議など「声を出す用途」の一部を静かにする技術として見るのが現実的です。

この記事では、SSIの仕組み、2026年時点の研究の数値、実用化の壁、防音への影響を順に整理します。

無声音声インターフェース（SSI）とは

人が話そうとするとき、脳からの指令で、喉・あご・舌・唇の筋肉が動きます。

SSIは、この「話そうとした動き」をセンサーで読み取り、AIで言葉やテキストに戻す技術です。

声帯を震わせなくても、言葉にしようとする筋肉の動きは起きているため、音を出さずに入力できます。

何を読み取るのか｜4つの読み取り方

2026年3月に公開されたSSIの総説（Xuほか）は、読み取る場所を4つに分けています。

読み取る場所主な方法装着の形の例
脳の活動脳波など頭に付ける電極
筋肉の電気信号筋電（EMG）首・あご・耳の周りに貼るセンサー
舌や唇の動き超音波、磁気センサー、カメラあごの下の超音波、口元を写すカメラ
外から当てて測る音波や電波を当てて、反射の変化を見るイヤホン型、メガネ型

いま実用に近いのは、皮膚の上から筋肉の信号を読む筋電（EMG）型です。

体に穴を開けず、首やあごに貼るだけで測れるためです。

2026年時点の研究の到達点

SSIの主な研究と製品の発表を、数値つきで並べます。

発表読み取り方対象の言葉結果
AlterEgo（MIT Media Lab、2018年）首・あごの筋電数字など限られた語彙認識率 約92%
AlterEgo社の発表（2025年9月）顔と喉の筋肉の信号非公表応答は骨伝導で本人だけに返す。発売時期・価格は未公表
SilentWear（2026年3月）首に巻く布製の筋電センサー（14チャンネル）8つの操作コマンド声を出さない場合 77.5%、付け直した後は59.3%
Revoice（ケンブリッジ大学ほか、2026年）首に巻くチョーカー型で、喉の振動と脈を読む脳卒中後の発話障害のある患者5人単語の誤り率 4.2%
AESSI（2026年9月）耳の周りの電極中国語の日常文25文当日の調整なしで92.24%、21日以上あとのオンライン試験で98.0%

出典は記事末の参考文献にまとめています。

表から読み取れることは、次の3つです。

  • 決まった言葉なら精度は高い : 数字・コマンド・決まった文の中から当てる形なら、90%台が出ている
  • 自由な会話はまだ遠い : 好きな言葉を何でも話せる形での、日常利用の実績はまだない
  • 医療から先に進んでいる : 発話障害のある人の会話を助ける用途で、具体的な成果が出始めている

SilentWearは、全体の消費電力が20.5mWで、27時間以上動き続けられると報告しています。

1日身に着けたまま使える電池の持ちには、すでに届きつつあります。

実用化の壁｜なぜまだ誰でも使えないのか

SSIが日常の道具になるまでには、まだ壁があります。

  • 人によって信号が違う : 筋肉の付き方や話し方が人ごとに違い、本人のデータで調整しないと精度が出にくい。2026年の総説は、これを最大の課題に挙げている
  • 付け直すと精度が落ちる : SilentWearでは、センサーを付け直した後に無声の認識率が77.5%から59.3%に下がった
  • 話せる言葉が限られる : 多くの研究は、決まったコマンドや文の中から当てる形で評価している
  • 心の中の言葉を扱う不安 : AlterEgo社は脳のデータは読まないと説明しているが、総説は「考えていること」の保護を倫理上の課題に挙げている

AESSIのように、当日の調整なしで高い精度を出した研究も出てきています。

調整の手間をなくす研究が進めば、製品化は一気に近づきます。

防音への影響｜防音室はいらなくなるのか

SSIが減らせるのは、人の声という音源だけです。

防音が扱う音のうち、どれが置き換わり、どれが残るかを用途別に見ます。

用途SSIで置き換えられる可能性防音が残る理由
深夜の音声入力・AIへの指示高い短い指示はSSIが得意な形に近い
Web会議・通話中くらい相手に届くのは合成された声になる。自然さと遅れが課題
ゲーム実況・配信の声低い叫び声や笑い声の生々しさが、配信の価値そのもの
歌・楽器の練習ほぼない音そのものを出すことが目的
足音・生活音ない声ではないため、防振や遮音が必要

ふつうの会話の声は約60dBで、ささやき声でも約30dBあります。

SSIはこの音源をほぼゼロにできる可能性がありますが、楽器や足音のように声以外の音には何の効果もありません。

防音は「出た音を通さない」技術で、SSIは「音を出さずに伝える」技術です。

2つは競合するというより、声の音源をSSIで減らし、残った音を防音で閉じ込めるという組み合わせで使われていくと考えられます。

配信者が防音室を選ぶときの考え方は、配信者・VTuberのための防音環境完全ガイド｜ワンルームから防音室まで全解説で整理しています。

SSIが届く前に、今できる声の対策

SSIの製品が手に入るまでは、声の音源を小さくし、漏れる音を減らす方法を組み合わせます。

  • マイクを口に近づける : ヘッドセットや口元のマイクにすると、小さな声でも拾えるため、声量を下げられる
  • AIのノイズ除去を使う : NVIDIA Broadcastなどのノイズ除去で、周りの音を相手に届けない
  • 声が漏れる経路をふさぐ : ドアの隙間や窓から声は漏れやすい。隙間対策が一番安く効く

家族がいる家でWeb会議の声を漏らさない工夫は、在宅ワークの音の悩みと防音｜家族の声・Web会議の声漏れ・寝室仕事の対策を整理にまとめています。

叫び声や楽器のように、声量そのものを下げられない場合は、防音室で閉じ込めるのが確実です。

防音室の性能と価格は、防音室おすすめ比較｜失敗しない選び方とROI（投資対効果）を分析で比べています。

よくある質問

無声音声インターフェースは、いつ買えますか？

2026年10月時点で、一般向けに発売された製品は確認できません。

AlterEgo社は2025年9月にデバイスを発表しましたが、発売時期と価格は公表していません。

SSIは頭の中の考えを読み取るのですか？

いま実用に近いSSIの多くは、脳ではなく、話そうとしたときの筋肉の信号を読んでいます。

AlterEgo社も、脳のデータには触れないと説明しています。

SSIが普及するなら、防音室の購入は待ったほうがいいですか？

楽器・歌・配信の叫び声・足音が悩みなら、待つ理由はありません。

SSIが減らせるのは話し声だけで、それも決まった言葉の入力から先に実用化が進むと考えられます。

まとめ｜SSIは「声の音源」を減らす技術

  • 無声音声インターフェース（SSI） : 声を出さずに、筋肉の信号や口の動きから言葉を読み取る技術
  • 2026年の到達点 : 決まった言葉なら認識率90%台。自由な会話の製品はまだない
  • 実用化の壁 : 人ごとの調整、付け直しでの精度低下、話せる言葉の少なさ
  • 防音への影響 : 音声入力やWeb会議の一部は静かにできるが、楽器・歌・足音には効かない
