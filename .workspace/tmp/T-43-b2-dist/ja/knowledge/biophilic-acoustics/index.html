苔の吸音効果はどのくらい？研究データで見る防音との違いと壁への取り入れ方

苔の吸音効果は、厚い種類で1kHzの吸音率0.62ほど（2026年の音響管試験）。響きは減らせますが、音漏れを止める防音にはなりません。研究データ、音を吸う構造、本物の苔と苔パネルの違い、壁のどこに貼れば効くかを表で整理します。

苔の吸音効果は、部屋の響きを減らすには役立ちますが、隣や外への音漏れを止める「防音」にはなりません。

2026年に発表された音響管での試験では、厚く育つ苔で1kHzの吸音率が0.62ほどでした。

一般的な吸音パネル（0.7〜0.9程度）より少し低く、苔は「見た目の良い吸音の補助材」として使うのが現実的です。

この記事では、苔の吸音を測った研究、音を吸う仕組み、壁に取り入れるときの配置を順に説明します。

苔の吸音効果とは｜「吸音」と「防音」は別の話

苔の吸音効果という話で気になったのは、専用の吸音パネルとどこが違うのかでした。

最初に、言葉の違いを押さえておきます。

  • 吸音 : 室内で跳ね返る音を吸い取り、響きやエコーを減らすこと
  • 遮音 : 壁や窓で音を跳ね返し、反対側へ通さないこと
  • 防音 : 遮音と吸音を組み合わせ、音漏れと響きの両方を抑えること

苔は、細かい茎や葉のすき間に音が入り込んで弱まる吸音の素材です。

軽く、すき間の多い素材なので、音を跳ね返す重さ（遮音）はほとんどありません。

そのため、苔を壁一面に貼っても、隣の部屋への話し声や楽器の音はほぼ同じように漏れます。

吸音と遮音のどちらが自分に必要かは、吸音材か遮音材か迷う人へ｜あなたの環境で“必要なのはどっち？”徹底ガイドで判定できます。

苔の吸音を測った研究｜吸音率はどのくらいか

吸音率は、当たった音のうち吸い取られた割合です。

0なら全部跳ね返し、1なら全部吸い取ります。

苔の吸音を数字で確かめた研究は、まだ多くありません。

その中で、条件と数値が公開されているのが次の研究です。

ラトビアの研究（2026年）｜4種類の苔を音響管で測定

ラトビア生命科学技術大学の研究チームは、身近な4種類の苔を、音響管（ISO 10534-2）で測りました。

この研究からわかることは、次の3つです。

  • コンクリートの壁よりは、はるかに音を吸う : 薄い苔でも、むき出しの壁の数倍の値が出ている
  • 吸音パネルの代わりにはなりにくい : 一番よい苔でも、一般的な吸音パネルの下限あたり
  • 低い音はほとんど吸わない : 500Hzでは多くの苔が0.1前後で、足音や重低音には効かない

研究チーム自身も、試料の数が少ない探索的な結果だとしたうえで、苔だけを主な吸音材にするのは難しいと結論づけています。

オランダ・デルフト工科大学の研究｜苔で覆ったコンクリート

同じ論文の中で紹介されているデルフト工科大学の研究では、6種類の苔をコンクリートの表面に育てて測っています。

苔で覆うと、特に1,000Hzより高い音で吸音が増え、最もよい種類で吸音率のピークが0.86、50〜6,400Hzの平均で0.48でした。

人の声の響きや、食器・キーボードの高い音には効きやすい、という傾向は2つの研究で共通しています。

製品の「吸音率0.95」は条件を確認する

苔パネルの販売資料には「吸音率0.95」といった高い数字が載っていることがあります。

ニュージーランドの販売会社の資料では、この値は5,000Hzという高い音の1点だけの値でした。

声の中心（数百Hz〜2kHz程度）の値ではないため、数字が高くても、そのまま声の響きに効くとは限りません。

製品を比べるときは、何Hzの値か、どの試験方法（残響室法・音響管法）かを確認してください。

なぜ苔は音を吸うのか｜吸音する構造

苔が音を吸う仕組みは、グラスウールやフェルトと同じ多孔質吸音です。

  • すき間に入った音が弱まる : 細い茎や葉のすき間で空気が揺れ、こすれ合うことで音のエネルギーが熱に変わる
  • 厚いほど低い音まで吸う : ラトビアの研究では、8cmの厚さに育つタチハイゴケが最もよく、薄く広がる種類は低かった
  • 縦に立つ形が効く : 茎が縦に密集する種類ほど、音が入り込むすき間が多くなる
  • 下地を足すと上がる : 麻の下地を足すと、4種類すべてで吸音率が上がった

壁に取り入れるときは、苔の厚みに加えて、苔の裏にフェルトや空気層を足すと吸音の幅が広がります。

本物の苔・保存加工の苔パネル・フェイクの違い

室内の壁に使う「苔」には、3つの種類があります。

種類手入れ吸音室内の壁に向くか
生きた苔水やり・光・湿度管理が必要厚く育てば効く向かない（湿気・カビの管理が難しい）
保存加工の苔パネル（トナカイゴケなど）水やり・日光は不要中〜高音の響きに効く向く
フェイクの苔（樹脂製）不要ほとんど期待できない見た目だけ

室内の吸音で使われるのは、北欧のトナカイゴケ（Cladonia stellaris）を保存加工したパネルが中心です。

販売元の資料では、次の扱い方が案内されています。

  • 水をやらない : 水をかけると、空気中の湿気を吸ったり出したりする性質が損なわれる
  • 湿度を保つ : 相対湿度40〜80%程度で、乾燥しすぎると硬くなり、ぽろぽろ崩れやすい
  • 直射日光を避ける : 色あせの原因になる。屋外では使わない

触れると欠片が落ちることがあるため、人がよく通る場所や、手が当たる高さは避けたほうが無難です。

苔パネルの実用例｜壁のどこに貼れば効くか

苔パネルは、吸う面積が小さいと効果を感じにくい素材です。

響きを減らしたい場所に、まとめて置くのが基本です。

目的貼る場所ポイント
Web会議・配信の声の響きを減らす机の正面の壁、顔の高さ声が最初に跳ね返る面を優先する
楽器練習の響きを和らげる楽器と向き合う壁、左右の壁低音は吸わないので、ベーストラップと併用する
リビング・寝室の反響を減らす平行に向き合う壁の片側向き合う壁の間で音が往復する「鳴き」を抑える

吸音材をどこに貼ると効くかの考え方は、吸音材はどこに貼る？モニター裏・スピーカー裏など5つの正解ポイントで場所ごとに解説しています。

苔だけで足りないと感じたら、見える面を苔、裏や見えない面を一般的な吸音パネルにして、見た目と吸音量を分担させる方法もあります。

音漏れを止めたいなら、苔の前にやること

苔を検討している理由が「隣や家族に音が聞こえるのを防ぎたい」なら、先に遮音と隙間対策が必要です。

  • 隙間をふさぐ : ドア下・窓のすき間からの漏れが一番大きい
  • 重さを足す : 遮音シートや石膏ボードなど、重い層で音を跳ね返す
  • 響きを整える : 苔や吸音パネルは、この後の仕上げとして使う

DIYで遮音と吸音を組み合わせるときの失敗例は、防音パネルの罠｜DIY失敗例から学ぶ『遮音と吸音』の物理学的黄金比にまとめています。

楽器や配信で確実に音漏れを抑えたい場合は、遮音性能が公表されているユニット型防音室の中を、苔や木で仕上げるという考え方もあります。

防音室の性能と価格は、防音室おすすめ比較｜失敗しない選び方とROI（投資対効果）を分析で比べています。

よくある質問

苔で防音室は作れますか？

作れません。

苔は軽く、音を跳ね返す重さがないため、音漏れを止める遮音の役割は果たせません。

苔の吸音効果は、吸音ウレタンより高いですか？

研究で測られた値を見る限り、一般的な吸音パネルと同じか、それより低い程度です。

苔を選ぶ理由は、吸音量よりも見た目と、緑のある空間の心地よさにあります。

苔パネルは足音や重低音に効きますか？

ほとんど効きません。

500Hz以下の低い音の吸音率は小さく、床を伝わる足音は吸音ではなく防振の問題です。

まとめ｜苔は「響きを整える、見た目の良い補助材」

  • 苔の吸音効果 : 厚い種類で1kHzの吸音率0.62ほど。中〜高音の響きを減らす
  • 防音にはならない : 重さがないので、音漏れは止まらない
  • 選ぶなら保存加工のパネル : 水やり不要。湿度40〜80%を保ち、直射日光を避ける
  • 貼る場所 : 声や音が最初に跳ね返る壁に、まとめて置く

緑と静けさが気持ちに与える効果については、静寂の力：なぜ防音室はメンタルケアに役立つのかで解説しています。

私なら、隣からの音が悩みなら先に遮音を考え、苔は響きと見た目の補助として選びます。

苔を増やしても、音漏れを止める重さは補えないからです。
