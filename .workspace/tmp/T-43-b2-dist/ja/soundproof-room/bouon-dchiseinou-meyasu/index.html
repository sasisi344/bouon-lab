遮音性能の基準「D値」とは？楽器・用途別の目安

防音性能の最重要指標「D値（Dr値）」の見方を解説。ピアノ・ドラム・配信など用途別の遮音目安から、防音室ユニットと防音賃貸物件でD値の見方が違う理由、内見チェックまで、失敗しない選び方をまとめました。

自宅に防音室を導入する際、カタログで必ず目にするのが 「D値（またはDr値）」 という指標です。これは「どれだけ音を遮ることができるか」を表す遮音性能の等級ですが、単に数字が大きいものを選べば良いというわけではありません。

2026年現在の住宅事情や最新の防音ユニットの性能を調べた結果をもとに、 「後悔しないD値の選び方」 をまとめました。

本記事では、防音室（防音ユニット）のD値と、防音賃貸（物件）のD値を、別々に解説します。

同じ「D値」という言葉でも、何の遮音性能を指すかで、必要な数字が変わるためです。

賃貸物件を探している方は、目次の「防音賃貸（物件）のD値」からお読みください。

防音性能の要「D値（Dr値）」の基礎知識

D値（遮音等級） とは、日本産業規格（JIS）で定められた、建物の部屋と部屋の間の遮音性能を表す基準です。一方、ヤマハやカワイなどの防音ユニット（組立型防音室）のカタログでは、日本建築学会の基準に基づいた 「Dr値」 という表記が一般的に使われます。

厳密には測定条件が異なりますが、一般ユーザーが防音性能を比較する上では 「D値（Dr値）＝遮音の強力さ」 と考えて差し支えありません。

D値と音の減衰（聞こえ方）の目安

D値の数字は、遮断できる音の大きさ（デシベル数）と概ねリンクしています。

  • D-30 : 普通の話し声（60dB）が約30dB、ホテルの客室くらいまで下がる。隣の部屋で「何か話しているな」と微かにわかる程度。
  • D-35 : ピアノの音（正面1mで80〜90dB）が約45〜55dB、書店の店内くらいまで下がる。
  • D-40 : ピアノの音が約40〜50dB、図書館の館内から書店の店内くらいまで下がる。夜の住宅地（40dB前後）では、曲が流れていることは分かる。
  • D-50以上 : ピアノの音が約30〜40dB、ホテルの客室から図書館の館内くらいまで下がる。プロのスタジオで使われる水準。

身近な場所の例は環境省「騒音の目安」をもとにしています。

D値は低い音ほど下がりにくい等級のため、ピアノの低音やドラムはこの目安より大きく聞こえることがあります。

防音賃貸（物件）のD値は、防音室ユニットと見方が違う

賃貸の募集図面にある「D-50」などの数字は、建物の壁や床そのものの遮音性能を指します。

一方、ヤマハやカワイのカタログにあるDr値は、部屋に置く防音室ユニットの性能です。

両者は測定する対象も、前提となる建物条件も違います。

そのため、同じ楽器でも必要な数字が変わります。

楽器防音室ユニットの目安防音賃貸（物件）の目安
サックスD-40〜45D-55〜60
ピアノ（アップライト）D-35〜40D-50〜55

物件の目安は、物件の壁だけで隣戸に配慮するための数字です。

ユニットの目安は、居室の中にもう一つ防音の箱を置く前提の数字です。

一方の数字を、もう一方にそのまま当てはめないようにしてください。

物件選びでD値以外に確認したいこと

D値だけを見ても、トラブルは防げません。

  • 振動対策 : 浮き床構造か、防振ゴムが使われているか。ドラムやチェロは特に重要
  • 低音対策 : 壁の厚み、二重壁、空気層の有無。D値が同じでも低音の漏れ方は変わる
  • 窓・ドア・換気口 : 二重サッシ、防音ドア、消音ダクトの有無。ここが弱いと音が漏れる
  • 間取り : 角部屋、隣室との間に収納があるか、真下に寝室がないか

契約前と内見でのチェックリスト

契約前に確認すること:

  • D値の数値が書面にあるか : 「防音仕様」とだけ書かれているのは不十分
  • 測定方法 : 実験室の数値か、現場での実測値か。測定時期も確認する
  • 楽器の種類・時間帯の制限 : 「楽器可」でも種類や音量、時間が決まっていることが多い

内見で確認すること:

  • 許可を得て、実際に音を出す : 隣室や廊下、可能なら外でも聞こえ方を確認する
  • 壁を軽く叩く : 軽い音なら壁が薄い可能性がある
  • 隣室や共用部の生活音 : 隣の音が聞こえる部屋は、こちらの音も漏れやすい

内見時の調べ方は、楽器可賃貸の正しい探し方も参考にしてください。

物件のD値でよくある誤解

  • 「D-50なら絶対に漏れない」 : D値は音を完全に遮断する指標ではありません。大音量なら隣室にわずかに聞こえます。低音と振動はD値だけでは判断できません
  • 「カタログ値がD-60だから安心」 : 実験室のデータは、現場の実測より良い数字になる傾向があります。契約前に測定条件を確認してください
  • 「D値が高ければ音質も良い」 : 遮音と、部屋の中の響き（音響）は別物です
  • 「防音賃貸ならドラムもOK」 : D値が高くても、振動対策がなくドラムNGの物件は多くあります

失敗しないための「暗騒音（L50）」という考え方

「D-35の防音室を買ったのに、夜中にピアノを弾いたら文句を言われた」というケースがあります。これは 「暗騒音（あんそうおん）」 を考慮していないことが原因です。

暗騒音 とは、周囲に何もない時に聞こえる微かな音（環境音）のことです。

  • 昼間 : 外が騒がしいため（暗騒音が大きいため）、多少の音漏れはかき消されます。
  • 深夜 : 外が非常に静かなため（暗騒音が小さいため）、漏れた音が非常に目立ちます。

深夜にしっかり活動したい場合は、カタログスペックに プラス5〜10 の余裕を持った設計（例：D-45など）をおすすめします。

遮音性能だけで決めてはいけない「構造伝搬音」の罠

D値が指標としているのは「空気中を伝わる音（空気音）」です。しかし、集合住宅で最もトラブルになりやすいのは 「構造伝搬音（振動）」 です。

  • 例 : ドラムのキック、ピアノのペダル、ベースの重低音、椅子の移動音。

これらは壁の厚さ（D値）を上げても防ぎきれません。床に 「浮き床構造」 を採用したり、高硬度のゴムマットを敷くなどの 「防振対策」 をセットで行うことが、防音ライフ成功の鍵となります。

まとめ：あなたの「ライフスタイル」に最適なD値を選ぼう

防音性能は「高ければ高いほど良い」ですが、性能に比例して価格も跳ね上がります（Dr-35からDr-40にするだけで、数十万円のコストアップも珍しくありません）。

  1. 何を鳴らすか （ピアノか、声か、ベースか）
  2. いつ鳴らすか （昼間だけか、深夜もか）
  3. どこで鳴らすか （一軒家か、木造アパートか、RC造マンションか）

この3点を整理し、オーバースペックにならず、かつ不足のない 「ちょうど良いD値」 を見極めてください。不安な場合は、専門業者に「深夜にピアノを弾きたい。D値でいくつを目指せば良いか？」と具体的に相談することをおすすめします。

D値についてさらに深く知りたい方は、以下もあわせてご覧ください。

  • D値の嘘と本当｜カタログスペックだけで選ぶと失敗する理由（カタログ値と実際の体感差、測定環境の落とし穴）
  • D値とRw値は換算できない｜日本と海外の遮音等級を混同すると失敗する理由（海外製防音建材を検討する際の注意点）
  • 防音室の-dB軽減効果とは？楽器・交通音・空港・配信音で分かる体感早見表（図書館・電車内など身近な音でD値の軽減効果をイメージする）
