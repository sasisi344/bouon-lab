防音室で耳鳴り・耳が詰まる原因｜気圧と静けさの違いと受診の目安

防音室で耳鳴りがするのは、静けさで体の中の音が聞こえやすくなるためで、耳が詰まる感じはドアの開閉時の気圧や反響の少なさで起きます。めまい・頭痛は換気不足も疑います。原因の切り分け表、防音室は酸欠になるかを示すCO2濃度の計算表、換気の工夫、受診の目安をまとめました。

防音室で耳鳴りがするのは、多くの場合、周りの音がなくなって体の中の音が聞こえやすくなるためです。

耳が詰まる感じはドアを閉める瞬間の気圧の変化や反響の少なさ、めまい・頭痛は換気不足やCO2の上昇が重なって起きることがあります。

本記事では、症状ごとの原因の切り分け表と、防音室は酸欠になるかを確かめるCO2濃度の計算、音を漏らさない換気の工夫、耳鼻科を受診する目安を順に示します。

本記事は一般的な情報で、診断の代わりにはなりません。

症状が続く・強くなる場合は、自己判断で使い続けず、医療機関を受診してください。

防音室で起きやすい症状と原因の切り分け表

症状起きやすい場面考えられる原因まず試すこと
耳が詰まる・痛いドアを閉めた直後閉める瞬間の気圧の変化ドアをゆっくり閉める。つばを飲み込む
耳が詰まる感じが続く入ってしばらく反響と周りの音が少ない環境小さな音でBGMを流す
耳鳴り（キーン・ジー）静かにしているとき静けさで体の中の音が聞こえる小さな音を流す。外に出て消えるか確かめる
頭痛・眠気・だるさ30分〜1時間以上いたとき換気不足によるCO2の上昇、熱換気扇を確認し、ドアを開けて空気を入れ替える
めまい・息苦しさ・不安入ってすぐ、またはドアを閉めたとき狭さ・閉じ込められる感覚ドアを少し開けて座る。広いサイズで試す
防音室の外でも続く場所を問わない耳や体の病気の可能性耳鼻科・内科を受診する

大切なのは、防音室の外に出ると消えるかどうかです。

外に出て数分で消えるなら、防音室の環境が関係している可能性が高くなります。

外でも続くなら、防音室とは別の原因を疑い、受診を考えてください。

防音室で耳が詰まる｜ドアの開閉と気圧

防音室のドアは、四周のパッキンで隙間をふさぎます。

閉める最後の瞬間に、ドアが押し込んだ空気の逃げ場が少なくなり、室内の気圧がわずかに上がります。

どのくらい気圧が変わるか

1.2畳のユニット防音室（内容積 約3.45㎥）で、閉める瞬間に押し込まれる空気の量を仮に置いて計算しました。

押し込まれる空気気圧の上がり方（計算値）近い体験
1リットル約40Paエレベーターで約3m移動
5リットル約200Paエレベーターで約17m移動
10リットル約400Paエレベーターで約35m移動

計算は、空気が急に押し縮められるとして、気圧の上がり方を「押し込んだ量÷内容積×大気圧×1.4」とした単純化です（当サイトの試算）。

地上近くでは、高さが1m変わると気圧は約12Pa変わります。

実際は換気口や小さな隙間からすぐに空気が抜けるため、気圧の差は一瞬で小さくなります。

それでも、勢いよく閉めるほど一瞬の差は大きくなります。

鼻づまりや風邪で耳の空気の通り道（耳管）の調子が悪いときは、小さな気圧の差でも耳が詰まった感じや痛みが出やすくなります。

気圧が変わらなくても「詰まった感じ」がすることがある

防音室は、外の音が入らないうえ、吸音材で反響も少なくなっています。

反響がほとんどない部屋では、気圧が変わっていなくても耳が詰まったように感じる人がいます。

ふだん耳に入っている周りの音や反響がなくなり、その違いを「圧迫感」として受け取るためと考えられています。

この感覚は、少し音を流したり、ドアを開けたりすると軽くなるのが特徴です。

防音室で耳鳴りが気になる｜静けさで聞こえる体内音

防音室で「キーン」「ジー」という音が聞こえて、不安になる人は少なくありません。

1953年にHellerとBergmanが行った実験では、耳鳴りのない聴力が正常な若者を防音された部屋に数分入れたところ、約9割の人が何らかの音を聞いたと報告されています（Annals of Otology, Rhinology & Laryngology, 1953）。

ふだんは周りの音に紛れている、耳や体の中の音が、静けさで聞こえやすくなるためです。

防音室で耳鳴りが聞こえること自体は、珍しいことではありません。

気にしたほうがよい耳鳴り

  • 防音室の外でも聞こえる : 静かな場所に限らず続く
  • 片耳だけ : 片方の耳だけで、聞こえにくさを伴う
  • 急に始まった : 大きな音を聞いたあとや、ある日突然
  • めまいを伴う : 耳鳴りと同時に、ぐるぐる回るめまいがある

このような場合は、防音室のせいと決めつけず、耳鼻科を受診してください。

静けさが体と心に与える影響は、静寂の力｜防音室がメンタルケアになる理由でも扱っています。

防音室でめまい・頭痛がする｜換気・温度・姿勢

めまい・頭痛・眠気は、防音室の空気と温度が関係していることが多い症状です。

めまいや頭痛が、入って30分〜1時間ほどたってから出るなら、まずCO2の上昇を疑います。

酸欠との違いとCO2の上がり方は、次の「防音室は酸欠になる？」で計算しています。

熱と姿勢

小さな防音室では、人とパソコンの熱がこもり、室温が上がりやすくなります。

暑さと脱水は、頭痛やめまいの原因になります。

低い椅子での前かがみや、モニターを見続ける姿勢も、首や肩のこりから頭痛につながります。

狭さ・閉じ込められる感覚

ドアを閉めた瞬間にめまいや息苦しさ、不安を感じる場合は、狭い空間が苦手なことが関係しているかもしれません。

ある配信者は、防音室に入ると落ち着かなくなり、長く使えなかったと話していました。

これは購入してから気づいても取り返しにくい問題です。

  • 展示品で座ってみる : 楽器店やショールームの展示品で、ドアを閉めて10分以上座ってみる
  • 広いサイズを選ぶ : 0.8畳より1.2畳、1.2畳より1.5畳以上のほうが圧迫感は小さくなる
  • 窓付きを選ぶ : 外が見える小窓があると、閉じ込められた感じが和らぐことがある
  • レンタルで試す : 購入の前に、レンタルで一定期間使ってみる

防音室は酸欠になる？二酸化炭素濃度の上がり方

防音室が酸欠になることは、換気扇が回っていれば通常は考えにくいといえます。

現実に起きやすいのは、酸素が減るより先に吐く息のCO2が増えて、眠気・頭痛・集中力の低下が出ることです。

酸欠より先にCO2が上がる

人は酸素を吸った分に近い量のCO2を吐くため、酸素が21％から20％へ1％下がるころには、CO2は約1％（約10,000ppm）近くまで上がっています。

そのため、家庭の防音室で測るなら、酸素濃度計よりCO2モニターが役に立ちます。

CO2濃度目安出典
約400〜420ppm外気—
1,000ppmビルや事務所の空気の基準（これを超えたら換気不足のサイン）建築物衛生法の管理基準、事務所衛生基準規則5条
2,000〜5,000ppm換気の悪い室内。頭痛・眠気などが出ることがある東京消防庁などの解説
5,000ppm事務所の室内で超えてはいけない上限事務所衛生基準規則3条
30,000ppm（3％）以上めまい・頭痛・呼吸の乱れなど中毒の症状が出始める高圧ガスの安全データシート、経済産業省の資料

酸素については、18％未満が「酸素欠乏」とされています（酸素欠乏症等防止規則）。

CO2が3％まで上がるころには、酸素も18％前後まで下がっている計算で、ここまで来ると酸欠とCO2中毒が同時に起きます。

防音室の二酸化炭素濃度を計算する｜容積・人数・時間

座って作業する大人1人が吐くCO2は、1時間に約0.02㎥です。

防音室の広さと人数ごとに、換気扇を止めて、隙間からの空気の出入りもないとした場合の濃度を計算しました。

広さ（内容積）人数30分後1時間後2時間後
自作ブース（約1.4㎥）1人約7,400ppm約14,300ppm約28,200ppm
0.8畳（約2.25㎥）1人約4,900ppm約9,300ppm約18,200ppm
0.8畳（約2.25㎥）2人約9,300ppm約18,200ppm約36,000ppm
1.2畳（約3.45㎥）1人約3,300ppm約6,200ppm約12,000ppm
1.2畳（約3.45㎥）2人約6,200ppm約12,000ppm約23,600ppm
6畳の部屋（約24㎥）1人約840ppm約1,300ppm約2,100ppm

換気扇（有効換気量23㎥/h）を回している場合は、広さにかかわらず1人で約1,300ppm、2人で約2,200ppmで頭打ちになります。

計算は、外気を約420ppm、空気が均一に混ざるとした単純化です（当サイトの試算）。

自作ブースは幅90cm×奥行き80cm×高さ2mを想定し、6畳は天井高2.4mとしています。

表から分かることは3つです。

  • 換気扇を止めると、小さな防音室ほど急に上がる : 0.8畳では30分で5,000ppm近くになる
  • 2人で入ると倍の速さで上がる : 0.8畳に2人なら、2時間で3％を超える計算になる
  • 換気扇を回していても1,000ppmは超える : 1時間に1回はドアを開けて入れ替えるのが安全

歌や管楽器では呼吸が増えるため、表より早く上がります。

実際の防音室は、換気口やドアの隙間から少しずつ空気が出入りするため、換気扇を止めても表ほどは上がらないことが多いものの、隙間の量は製品ごとに違います。

一酸化炭素は「火を使わない」で防ぐ

一酸化炭素は、ものが燃えるときに出るガスで、人の呼吸からは出ません。

防音室の中で石油ストーブ・ガスストーブなど火を使う暖房器具を使わなければ、通常は問題になりません。

事務所の空気の基準では、一酸化炭素は50ppm以下とされています（事務所衛生基準規則3条）。

防音室の換気｜換気扇・吸気口・消音ダクトの基本

防音室の換気では、「空気を入れ替えたい」と「音を漏らしたくない」がぶつかります。

空気の通り道は、そのまま音の通り道にもなるためです。

吸気と排気をセットで考える

  • 排気（換気扇） : 室内の空気を外へ出す。ユニット防音室には、消音の工夫をした換気扇が付いている
  • 吸気口 : 出した分の空気を取り込む口。これがないと換気扇が回っても空気が入れ替わりにくい
  • 位置 : 吸気口と排気口を離して、できれば対角に置くと、部屋全体の空気が入れ替わる

ユニット防音室の換気扇は、運転音が気になって止めてしまう人が少なくありません。

録音のときだけ止める場合は、録り終えたらすぐに回し直し、ドアを開けて空気を入れ替えてください。

音を漏らさない換気の工夫

音は、まっすぐな穴ほどよく抜け、曲がった通り道や吸音材のある通り道では弱まります。

  • 曲がったダクト : S字やクランク状に曲げると、音がダクトの壁に当たって弱まる
  • 消音ボックス : 内側に吸音材を貼った箱をダクトの途中に入れる
  • 吸音材入りのダクト : ダクトそのものに吸音材が入った部材を使う

ダクトの配管と消音ボックスの仕組みは、防音室のエアコン選びと静音化の極意で図とともに解説しています。

ロスナイ（熱交換換気）は有効か

ロスナイは三菱電機の熱交換形換気扇で、排気と吸気を同時に行い、出ていく空気の熱を入ってくる空気に移します。

冬や夏でも、冷暖房の効きを落とさずに換気できるのが長所です。

ただし、ロスナイそのものは防音のための機器ではありません。

防音室に付けるなら、ダクトの途中に消音の工夫を足すことが前提になります。

工事で作る防音室では、熱交換換気と消音ダクトを組み合わせる設計がよく使われます。

自作防音室・防音室で寝るときの酸欠の注意

自作防音室は換気口を必ず作る

自作の防音室は、すき間をふさぐほど防音は良くなりますが、そのぶん空気が入れ替わらなくなります。

上の表のとおり、約1.4㎥の自作ブースで換気がまったくないと、1時間でCO2は約14,000ppmに達する計算です。

  • 吸気口と排気口を付ける : 曲がったダクトや消音ボックスで音の漏れを抑える
  • 小型のファンを付ける : 静かなPC用ファンなどで、空気を動かす
  • 30分〜1時間ごとに外に出る : ドアを開けて空気を入れ替える

頭を囲うだけの防音マスクは、さらに容積が小さく、短い時間でCO2が上がります。

防音マスクの使い方と危険は、防音マスク自作は息苦しい？で検証しています。

自作で起きやすい失敗は、防音パネルの罠｜DIY失敗例から学ぶ遮音と吸音にまとめています。

防音室で寝るのはおすすめしない

防音室の中で眠ることは、当サイトではおすすめしません。

眠っている間は、CO2が上がっても気づいて外に出ることができないためです。

眠っている人が吐くCO2は起きているときより少なめですが、1.2畳で換気扇を止めて8時間眠ると、計算上はCO2が3％前後まで上がります。

どうしても防音室で仮眠をとるなら、次の条件を守ってください。

  • 換気扇は必ず回す : 換気扇が回っていれば、1人の睡眠なら1,000ppm前後で頭打ちになる計算
  • ドアを少し開ける : 防音より空気を優先する
  • CO2モニターの警告を使う : 濃度が上がったら音で知らせる機能があるものを選ぶ
  • 1人で使う : 2人で眠ると上がる速さが倍になる

静かな環境で眠りたい理由と、防音室以外の方法は、防音室で眠ると睡眠の質が変わる理由で解説しています。

CO2モニターで簡易モニタリング

  • 測定方式 : NDIR（非分散型赤外線）方式のセンサーを選ぶ。安価な製品には、CO2を直接測らない方式もある
  • 温度・湿度も表示 : 熱がこもったか、乾燥しているかも同時に分かる
  • 警告の表示 : 1,000ppmを超えたら色や音で知らせる機能があると気づきやすい

温度と湿度の管理は、防音室の温湿度管理ガイドで解説しています。

今日からできる対処法

症状対処
耳が詰まる・痛いドアを最後まで勢いよく閉めず、ゆっくり押し込む。つばを飲む・あくびをする
詰まった感じ・耳鳴り雨音や環境音などのBGMを小さく流し、完全な無音を避ける
頭痛・眠気換気扇を回し、1時間に1回はドアを開けて空気を入れ替える。CO2モニターで確かめる
熱室温を確認し、エアコンのない防音室は使う時間を短くする
息苦しさ・不安ドアを少し開けて使う時間をつくり、少しずつ慣らす。窓付き・広いサイズを検討する

換気扇が止まっていないか、フィルターが詰まっていないかも、定期的に確認してください。

防音性能を落とさずに換気と空調を整える方法は、防音室のエアコン選びと静音化の極意にまとめています。

耳鼻科を受診する目安

次のような場合は、防音室の使い方の問題と決めつけず、早めに耳鼻科を受診してください。

  • 防音室を出て、時間がたっても耳の詰まり・耳鳴りが消えない
  • 片耳だけ聞こえにくい、または急に聞こえが悪くなった
  • 耳鳴りと一緒に、ぐるぐる回るめまいや吐き気がある
  • 耳の痛みが強い、耳だれが出る
  • 頭痛がひどく、手足のしびれやろれつが回らないなどの症状を伴う（この場合は救急を含めて受診を急ぐ）

急に聞こえが悪くなった場合は、日にちがたつと治りにくくなる病気もあります。

様子を見すぎず、早めに相談してください。

HSP・音過敏との関係

音に敏感な人は、防音室の静けさで楽になる一方、体の中の音や小さな機械音が気になることもあります。

音過敏の人に向く防音室の選び方は、HSP・音過敏のための防音室の選び方で解説しています。

音への敏感さと環境の整え方は、聴覚過敏・ミソフォニアの環境調整ガイドも参考になります。

防音室で眠る場合の注意点は、防音室で眠ると睡眠の質が変わる理由にまとめています。

よくある質問

防音室で耳鳴りがするのは異常ですか？

静かな場所で耳鳴りに気づくこと自体は、聴力が正常な人にも起きます。

防音室を出て消えるなら、静けさで体の中の音が聞こえやすくなっている可能性が高いと考えられます。

外でも続く、片耳だけ、急に始まった場合は耳鼻科を受診してください。

防音室で耳が痛いときはどうすればいいですか？

ドアをゆっくり閉め、つばを飲み込んだりあくびをしたりして、耳の中と外の気圧をそろえます。

痛みが強い、または続く場合は受診してください。

防音室で頭痛がするのは酸欠ですか？

酸素が大きく減るより先に、CO2が上がって頭痛や眠気が出ることが多くなります。

CO2モニターで1,000ppmを超えていないか確かめ、1時間に1回は換気してください。

防音室は酸欠になりますか？

換気扇が回っていれば、酸欠になることは通常は考えにくいといえます。

ただし、換気扇を止めた小さな防音室や、換気口のない自作ブースでは、CO2が短い時間で上がります。

0.8畳に1人で換気がまったくないと、1時間でCO2は約9,300ppmに達する計算です。

防音室で寝ても大丈夫ですか？

おすすめしません。

眠っている間はCO2の上昇に気づけないため、仮眠をとるなら換気扇を回し、ドアを少し開け、CO2モニターの警告を使ってください。

まとめ｜まず「外に出ると消えるか」で切り分ける

  • 耳が詰まる・痛い : ドアを閉める瞬間の気圧と、反響の少なさ。ドアはゆっくり閉める
  • 耳鳴り : 静けさで体の中の音が聞こえる。小さなBGMで和らぐことが多い
  • 頭痛・眠気・めまい : CO2の上昇と熱を疑う。CO2モニターで確かめ、1時間に1回換気する
  • 酸欠 : 換気扇が回っていれば通常は考えにくい。換気扇を止めた小さな防音室・自作ブース・睡眠は要注意
  • 狭さが苦手 : 購入前に展示品で座る。広いサイズや窓付きを選ぶ
  • 外でも続く・片耳・急な変化 : 防音室のせいと決めつけず、早めに受診する

次の一手として、防音室の換気と空調を見直したい方は、防音室のエアコン選びと静音化の極意をご覧ください。
