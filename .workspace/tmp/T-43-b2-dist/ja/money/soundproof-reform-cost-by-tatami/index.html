防音室リフォームの費用相場｜6畳・8畳・10畳の総額とユニットとの分かれ目

防音室リフォームの費用は、ピアノ向けの6畳で約160万〜460万円が施工会社の公表価格の幅です。6社の価格を畳数別・用途別の表にまとめ、差が出る3つの条件と、ユニット防音室との分かれ目を整理します。

今ある部屋を防音室にリフォームする費用は、ピアノ・声楽向けの6畳で約160万〜460万円が、施工会社6社の公表価格の幅です。

8畳では約200万〜490万円、ドラム向けの8畳では約420万〜760万円まで上がります。

幅が広いのは、費用が畳数ではなく「目標の遮音性能」「建物の構造」「どこまで工事するか」で決まるためで、本記事ではその見分け方とユニット防音室との分かれ目まで整理します。

見積もりを受け取って「この金額は高すぎるのでは」と感じている方は、まず下の早見表で自分の条件の位置を確かめてください。

防音室リフォームの費用早見表（畳数別・用途別）

公表価格を並べてみると、同じ畳数でも幅が広く、何の条件が違うのかを先に知りたくなりました。

私が以下で整理したのは、各社の公式サイトにある開始価格で、個別の見積もりではありません。

下の表は、防音工事の専門会社6社が公式サイトで公表している「〜万円から」の価格を、元の部屋の広さと用途で並べたものです。

元の部屋の広さピアノ・声楽・シアター管楽器・エレキギタードラム・打楽器
4.5畳約240万〜420万円（2社）約380万〜420万円（1社）公表例なし
6畳約160万〜460万円（6社）約420万〜455万円（1社）約380万〜680万円（2社）
8畳約200万〜490万円（4社）約460万〜515万円（1社）約420万〜760万円（4社）
10畳約380万〜455万円（1社）約490万〜540万円（1社）約835万円〜（1社）

括弧内は、その欄の数字を公表している会社の数です。

1社だけの欄は、その会社の価格であり、一般的な相場として扱わないでください。

性能の等級が低いプランでは、6畳で150万円〜という公表例もあります（次の章の表）。

この表の読み方と注意点

  • 開始価格である : どの会社も「〜万円から」の表記です。窓・ドアの仕様、空調、内装で上がります
  • 税込・税別が会社で異なる : 税込を併記している会社は税抜の数字で揃えました。表記がない会社は公表どおりの数字です
  • 別途費用がある : 既存内装の解体費（6畳で15万〜20万円程度と公表している会社があります）、エアコン本体、照明器具は別になることが多いです
  • 完成後は狭くなる : 部屋の中にもう一つ部屋を作るため、6畳が約5.2畳（ピアノ用）、ドラム用では約3.7畳になる例があります

表の元にした各社の公表価格は、記事の最後にまとめています。

防音室リフォームの費用を決める3要素（Dr値・工事範囲・建物構造）

同じ6畳で160万円と460万円の差が出るのは、次の3つが会社ごと・物件ごとに違うためです。

目標の遮音性能（Dr値・D値）

遮音性能を一段上げるごとに、費用は階段状に上がります。

D.S.Pコーポレーションが公表している室内約6畳の参考価格では、スタンダード以上では、性能の等級が1段上がるごとに約50万〜100万円ずつ上がっています。

プランRC造の性能（屋外・隣戸）RC造の価格木造の性能木造の価格
ベーシックD-40150万円〜D-40180万円〜
スタンダードD-60250万円〜D-50280万円〜
ハイクオリティD-65300万円〜D-55330万円〜
プレミアムD-65350万円〜D-60380万円〜
プロフェッショナルD-70430万円〜D-65〜480万円〜

※解体費は別途（RC造で6畳15万円程度、木造で20万円程度）。木造のリフォームでは構造補強が別途必要になる場合があると明記されています。

性能を上げると費用が跳ねる理由は、壁の重さだけで遮音しようとすると限界があるからです。

一重の壁の遮音量は、おおむね「重さが2倍で約6dB増える」という質量則に従います。

12.5mmの石膏ボード2枚（約17kg/m²）の壁は、500Hzで約36dBの計算です。

これを一重の壁だけで50dBにするには、約84kg/m²、石膏ボード約10枚分の重さが必要になります。

現実的ではないため、Dr-50を超える防音室は壁・天井・床を既存の部屋から浮かせた二重構造（ボックスインボックス）にします。

この二重構造の部材と手間が、価格の階段の正体です。

工事範囲（壁・天井・床・開口部）

部屋まるごとの防音室は、壁だけでなく天井・床・ドア・窓・換気口まで一体で作ります。

音は一番弱いところから漏れるため、どこか1か所だけ省くと、ほかにかけた費用が性能に結びつきません。

一方で、壁だけ・窓だけの部分的な防音工事なら数十万円で収まることもあります。

部分工事の工法別の価格は防音工事の種類と価格比較｜壁・床・開口部、業者の選び方までで比較しています。

建物の構造（木造・鉄骨造・RC造）

木造の戸建ては壁自体が軽いため、同じ性能を出すのにRC造より費用がかかる傾向があります。

上のD.S.Pコーポレーションの表でも、同じプラン名で木造がRC造より30万〜50万円高くなっています。

木造の1階では床下の束（つか）の補強、2階以上では構造の確認が必要になると公表している会社もあります。

6畳・8畳・10畳の防音室リフォームの考え方

畳数が増えても、総額は面積に比例して増えません。

ドア・窓・換気・電気・設計といった費用は、部屋の広さにかかわらずほぼ一定でかかるためです。

公表例6畳8畳10畳6畳からの増え方
バドシーン（ピアノ用・戸建・レギュラー）350万円〜390万円〜420万円〜面積1.67倍で約1.2倍
環境スペース（RC造・ベーシック）310万円〜340万円〜公表なし面積1.33倍で約1.1倍

1畳あたりに直すと、広い部屋ほど割安になります。

6畳の防音室リフォーム

6畳は、アップライトピアノと譜面台、椅子を置いて余裕がある広さです。

公表価格の幅は約160万〜460万円と最も広く、選ぶ会社と目標性能で総額が大きく変わります。

防音工事の匠は、ピアノを昼間から夕方まで弾く想定で160万円〜、24時間弾く想定で180万円〜としています。

使う時間帯を夜まで延ばすと、必要な性能が上がり、費用も上がります。

完成後は約5.2畳になる例があるため、グランドピアノを置く場合は配置図を先に描いてもらってください。

8畳の防音室リフォーム

8畳は、グランドピアノでのレッスン、ホームシアター、個人用のドラム室で多い広さです。

ピアノ・シアター用で約200万〜490万円、ドラム用で約420万〜760万円が公表価格の幅です。

リブテックは、8畳のシアター・リスニングルーム（Dr-60）を400万〜450万円、ドラム・バンドスタジオ（Dr-60）を550万〜600万円としています。

ドラム用は低音と床に伝わる振動を止めるために浮き床が必要で、完成後の広さも約5.4畳まで縮む例があります。

10畳の防音室リフォーム

10畳の価格を公表している会社は、今回確認した範囲では1社でした。

バドシーンの公表価格は、ピアノ用で戸建380万〜420万円、マンション455万円〜です。

6畳の同じプランとの差は70万円前後で、広さのわりに増え方は小さくなっています。

10畳以上は個別設計になることが多いため、2〜3社から現地調査つきの見積もりを取って比べるのが確実です。

マンションと戸建てで防音室リフォームはどう変わるか

同じ「D-70」でも測る場所が違う

マンションの公表性能は、戸建てより大きな数字が並びます。

たとえばバドシーンのピアノ用は、戸建がD-55〜D-60、マンションがD-70〜D-75です。

これは性能を測る場所が違うためで、戸建ては「外壁から1m離れた屋外」、マンションは「隣の住戸」までの遮音量として示されることが多いです。

マンションの数字には、建物のコンクリートの壁・床がもともと持つ遮音量が含まれています。

戸建てのD-50とマンションのD-70は、どちらが上という比較ができません。

見積もりを比べるときは、数字と一緒に「どこで測った値か」を必ず確認してください。

マンションで先に確認すること

  • 管理規約 : 国土交通省のマンション標準管理規約では、専有部分の模様替えなどには理事長への事前申請と書面の承認が必要とされています。自分のマンションの規約と、申請から承認までの期間を最初に確認してください
  • 床の重さ : 防音室は壁・床に重い材料を使います。床にかかる重さの確認や、構造補強が必要になる場合があります
  • 工事の時間帯と搬入 : 工事できる曜日・時間、エレベーターの養生など、規約で決まっていることがあります
  • ドラムは対応外のことが多い : 今回確認した会社のうち2社は、マンションでのドラム室を価格表に載せていないか、施工不可としています

管理規約で工事ができないと分かってから他の方法を探すと、数か月を失うことがあります。

業者に見積もりを頼む前に、管理会社へ「防音室の工事は申請すれば可能か」を一言聞いておくのが近道です。

戸建てで先に確認すること

  • 床の補強 : 木造の1階は床下の束の補強、2階以上は梁の確認が必要になる場合があります
  • 窓の扱い : 既存の窓を残すか塞ぐかで費用が変わります。窓を残したい場合に上位プランになる会社もあります
  • 近隣との距離 : 戸建ては隣家までの距離で必要な性能が変わります。夜に弾くなら、近隣側の壁を重点的に強化する提案になることがあります

工事費の内訳（壁・天井・床・ドア・窓・換気・電気）

見積書には、おおむね次の項目が並びます。

公表価格にエアコン本体・照明器具・空調・防災設備が含まれないと明記している会社が複数あります。

最初の見積もりでは、本体価格とは別に何がいくら加わるかを一覧で出してもらってください。

換気と結露を削ってはいけない理由

防音室は気密性が高いため、換気が足りないと息苦しさや結露・カビの原因になります。

換気口は音が漏れやすい場所でもあるため、消音ダクトなどの対策が費用に含まれているかを確認してください。

見積もりを下げるために換気の仕様を落とすと、完成後に「暑くて長く入っていられない」部屋になりがちです。

ユニット防音室との分かれ目（総額比較表）

部屋まるごとのリフォームと、部屋の中に置くユニット防音室は、必要な広さで分かれます。

必要な広さユニット防音室の目安防音室リフォームの目安向いている選択
1.5畳以下（アップライトピアノ・声楽・配信）約90万〜130万円＋設置費20万円前後6畳で約160万円〜ユニット
2〜2.5畳（グランドピアノ・弦楽器）約140万〜190万円＋設置費6畳で約160万円〜部屋の使い方で選ぶ
3〜4.5畳（アンサンブル・レッスン）約200万〜350万円＋設置費6畳で約250万〜350万円が中心リフォームが有力
ドラム（4.3〜6畳）約450万〜600万円8畳で約420万〜760万円構造と住まい方で選ぶ

ユニット防音室の価格は、防音室の値段・価格相場2026｜サイズ別の実勢価格と隠れコスト完全比較の相場表と、島村楽器が公表しているドラム向けの目安をもとにしています。

分かれ目は「3畳」と「住み続けるか」

  • 1.5畳以下で足りる : ユニット防音室の方が総額は安くなります。部屋の残りも普段どおり使えます
  • 3畳以上が必要 : ユニットの総額がリフォームに近づきます。リフォームなら6畳の部屋のほぼ全体を防音室として使えます
  • 引っ越す可能性がある : ユニットは移設・売却ができます。リフォームは家に残り、持っていけません
  • 賃貸に住んでいる : 原状回復の義務があるため、壁・床に手を入れるリフォームは基本的にできません

「ユニットで十分なのに部屋ごと工事して高くつく」失敗と、「ユニットを並べて結局狭い」失敗は、どちらも必要な広さを先に決めていないことから起きます。

予算から逆算して選ぶ方法は予算別防音室選び方ガイド｜50万円・100万円・200万円で選ぶ方法で整理しています。

ユニットを将来手放すときの考え方は防音室の買取で損しない方法｜買取できない条件・査定を下げない準備・個人売買の注意点【2026年版】を参考にしてください。

見積もりで必ず確認する項目（相見積もりの取り方）

高額を払って「思ったほど静かにならない」事態を避けるには、金額より先に次の5点を揃えて比べます。

  • 性能の保証値と測定場所 : 「D-50保証」なら、どこで測った値か（外壁から1m・隣戸・室内の隣室）
  • 完成後の実測 : 工事後に遮音性能を測り、結果を書面で出すか
  • 完成後の広さと天井高 : 6畳が何畳になり、天井が何cm下がるか
  • 含まれない費用 : 解体・補強・エアコン・照明・申請手続きの扱い
  • 保証期間と不具合時の対応 : 性能が出なかったときにどう直すか

相見積もりは、同じ「用途・使う時間帯・目標性能」を伝えて2〜3社に依頼すると比べやすくなります。

条件をそろえずに金額だけ並べると、性能の低いプランが安く見えるだけになります。

本記事の早見表から大きく外れた見積もりが出たら、上の5点のどこが他社と違うのかを聞いてください。

業者の選び方と契約前のチェックリストは防音リフォーム業者の選び方｜失敗しない相見積もりと契約前チェックで詳しく解説しています。

補助金・ローン・税の確認先

楽器演奏のための防音室リフォームは、補助金の対象にならないことが多いです。

補助が出るのは、空港・基地・幹線道路の周辺など、騒音対策の区域に指定された住宅の防音工事が中心です。

自宅が対象区域かどうかはうちの家は対象？防音工事の補助金エリアの調べ方【空港・基地・道路／東京・大阪の例つき】で確認できます。

窓の断熱改修として内窓を追加する場合は、省エネ目的の補助制度が使える年度があります。

窓の防音と費用は賃貸と戸建てで変わる窓の防音対策｜遮音窓・防音窓の違いと費用完全ガイドで比較しています。

支払い方法は、リフォームローンや住宅ローンへの組み込みが選択肢になります。

防音室ローン・分割払い完全ガイド2026｜月々いくら？審査・無金利・節税を解説と、ピアノと住宅ローン｜防音室・ピアノ室は組み込める、ピアノ本体は別が基本を参考にしてください。

税金の扱い（ローン控除・固定資産税・事業用の経費）は条件で変わるため、税理士や税務署に確認してから判断してください。

よくある質問

防音室の値段は8畳だといくらですか？

施工会社の公表価格では、部屋をリフォームする場合、ピアノ・シアター用で約200万〜490万円、ドラム用で約420万〜760万円です。

ユニット防音室で8畳相当を置く製品は一般的ではないため、8畳はリフォームを前提に考えるのが現実的です。

6畳の防音室リフォームを200万円以下でできますか？

ピアノを昼間〜夕方に弾く用途なら、160万〜180万円からと公表している会社があります。

ただし性能の等級や窓・ドアの仕様で上がるため、24時間使う、管楽器やドラムを使う場合は200万円以下に収まりにくいです。

マンションでも防音室リフォームはできますか？

管理規約で承認を得られれば可能です。

ピアノ・声楽・管楽器は対応している会社が多い一方、ドラムは対応外としている会社が目立ちます。

防音室リフォームの工期はどのくらいですか？

防音工事の匠は、6畳のピアノ室で7〜14日、ホームシアター・カラオケで14日以上としています。

マンションは管理組合への申請期間が工期の前に加わります。

まとめ／次のステップ

私なら、必要な広さと住み続ける予定を決めてから、ユニットとリフォームの総額を比べます。

畳数だけでは、目標性能や工事範囲の違いによる価格差を判断できないからです。

防音室リフォームの費用は、畳数よりも「目標の遮音性能」「建物の構造」「工事範囲」で決まります。

6畳のピアノ用で約160万〜460万円、8畳で約200万〜490万円、ドラム用の8畳で約420万〜760万円が、施工会社の公表価格の幅です。

1.5畳以下のスペースで足りるならユニット防音室、3畳以上が必要で住み続ける家ならリフォームが有力です。

見積もりは金額だけでなく、性能の保証値と測定場所、完成後の実測、含まれない費用をそろえて比べてください。

まずは自分の用途と使う時間帯を決め、マンションなら管理会社に工事の可否を確認するところから始めましょう。
