賃貸に防音室を置くと退去時いくらかかる？撤去費用・原状回復・売却の考え方（アビテックス・ナサール）

賃貸にヤマハ アビテックスやカワイ ナサールなどのユニット防音室を置いた場合の退去時費用を整理。撤去費用の目安、国交省ガイドラインにおける原状回復の考え方、事前に取る承諾、売却で費用を抑える条件を解説します。

「賃貸で防音室を置きたいけど、退去時の修繕費が怖い……」 「大家さんに無断で置いたらどうなる？」

設置許可の取り方や交渉術は、賃貸でユニット型防音室を置く方法は？大家交渉と許可取得の完全ガイドで解説しています。

本記事は、その先の「退去するときに、いくらかかるのか」に絞って整理します。

結論から言うと、防音室そのものの撤去費用は自己負担で、サイズに応じて5万〜12万円が目安です。 一方、床のへこみや壁の日焼けのような「置いたこと自体による跡」は、国土交通省のガイドラインでは貸主負担（通常損耗）とされています。

ただし、事前の承諾がない場合や、契約書に特約がある場合は、この原則どおりにならないことがあります。

退去時にかかる費用は3種類に分けて考える

退去費用を調べる中で、防音室の撤去と床の設置跡は別に考えると知ったのが最初の発見でした。

費用誰が負担するか目安
防音室の解体・撤去借主（自分の所有物のため）5万〜12万円（サイズ・階数で変動）
設置による跡（床のへこみ、壁の日焼け）原則は貸主（通常損耗）原則なし。ただし例外あり
借主が加えた工事の撤去（コンセント増設など）借主工事内容による

売却できる場合は、買取価格から解体・搬出費が差し引かれる形が一般的です。 防音室のサイズや条件によって、実質の持ち出しがゼロに近づくこともあります。

解体・撤去の費用目安

解体・廃棄を専門業者に依頼する場合の費用は、サイズでほぼ決まります。

サイズ目安解体・処分費用の目安
0.8畳〜1.2畳5万〜8万円
1.5畳〜2.0畳8万〜12万円
2.5畳以上12万円〜

エレベーターの有無、階数、搬出経路、クレーン作業の有無で変動します。 エレベーターのない上階の物件では、上限に近い金額になりやすい点に注意してください。

費用の内訳と、自分で解体するリスクは、防音室の解体・処分完全ガイド｜自分でやるリスクと業者費用の相場で解説しています。

国交省ガイドラインでの原状回復の考え方

賃貸の原状回復は、国土交通省の「原状回復をめぐるトラブルとガイドライン（再改訂版、平成23年8月）」が目安になります。

私が以下の負担区分の手がかりにしているのは、国土交通省のガイドラインです。

ガイドラインでは、借主の故意・過失による損耗は借主負担、通常の使用による損耗は貸主負担と整理されています。

防音室に関わる項目は、次のとおりです。

項目ガイドラインの考え方
家具の設置による床・カーペットのへこみ、設置跡通常の使用による損耗（貸主負担）。家具の設置は必然的なものと考えられるため
日照などによる壁クロスの変色自然現象によるもので、通常の損耗の範囲（貸主負担）
壁の画鋲・ピン穴（下地ボードの張替えが不要な程度）通常の損耗（貸主負担）

つまり、防音室を置いたことだけを理由に、フローリングやクロスの張り替え費用を請求されるのは、原則としておかしいという扱いです。

ただし、ユニット防音室は一般的な家具より重く、次のような場合は話が変わります。

  • 重量による床の損傷 : たわみ・破損など、単なる「設置跡」を超える損傷
  • 無断での設置 : 賃貸借の標準契約書には、「大型の金庫その他の重量の大きな物品等を搬入し、又は備え付けること」を、貸主の書面による承諾なしに行わない旨の条項がある
  • 特約の存在 : 契約書に原状回復の特約がある場合

特約が借主に有効に負担を課すには、ガイドラインでは次の3つの要件が必要とされています。

  1. 特約の必要性があり、暴利的でないなど、客観的・合理的な理由がある
  2. 借主が、通常の原状回復義務を超える負担を負うことを認識している
  3. 借主が、特約による義務負担の意思表示をしている

契約書に防音室や楽器に関する記載がある場合は、設置前に必ず確認してください。

ガイドラインはあくまで考え方で、個別の紛争は契約内容や状況によって結論が変わります。 トラブルになった場合は、消費生活センターや弁護士などの専門家に相談してください。

設置前にやっておくと退去時に困らない5つのこと

退去時のトラブルを減らすために、事前に次の準備をしておきます。

  1. 書面で承諾を取る : 口頭ではなく、メールや承諾書で、防音室の設置と撤去時の取り決めを残す
  2. 設置前の写真を撮る : 床・壁・天井・コンセント周りを、日付がわかる形で記録する
  3. 荷重を分散させる : 床に直接置かず、荷重分散のための板やプレートを敷く
  4. 壁から少し離す : 壁に密着させると、クロスの変色や湿気のこもりが起こりやすい
  5. 配線・増設を最小限にする : 増設したコンセントや配線は、撤去時に原状へ戻す前提で、事前に工事内容を合意しておく

重量と床への影響は、築20年のマンションに重さ500kgの防音室を置ける？床補強なしで設置するための安全基準と計算術で、計算方法を解説しています。

撤去か売却か：判断の目安

退去時の選択肢は、解体して処分するか、売却するかです。

状況方針
人気メーカーで年式が新しく、状態が良いまず買取の査定を取る
製造から長く経っている、喫煙・ペット使用がある買取不可になる可能性が高い。解体業者に複数見積もりを取る
引越し先でも使いたい売らずに移設（解体・運搬・再組立が必要）

買取の条件は業者によって異なります。 島村楽器の案内を例にすると、製造から11年以上経過した場合、喫煙・ペット使用・カビがある場合、解体済みの場合は、買取できないとされています。 そのため、売却を考える場合は、解体する前に査定を受けることが大切です。

買取の条件と手取りの考え方は、防音室の買取で損しない方法｜買取できない条件・査定を下げない準備・個人売買の注意点で詳しく解説しています。 引越し先に持っていく場合の費用は、引越しで防音室を移設する費用は？専門業者の選び方と失敗しない手順で確認できます。

まとめ：退去費用は「承諾・記録・年式」で先読みできる

私なら、購入前に設置の承諾と撤去時の取り決めを書面に残し、退去費用も予算に入れます。

通常損耗の考え方だけでは、重量による損傷や特約まで判断できないからです。

判断軸要点
撤去費用自己負担で5万〜12万円が目安。売却できれば差し引きで相殺されることがある
設置跡の原状回復家具の設置による跡や日焼けは、原則として貸主負担（通常損耗）
例外無断設置、重量による損傷、契約書の特約がある場合
事前対策書面承諾、設置前の写真、荷重分散、壁から離す

退去費用は、導入後に慌てて調べるものではありません。 購入・設置の段階で「何年後に、撤去か売却か」まで見込んでおくと、想定外の出費を避けられます。

契約や法的な判断に迷う場合は、契約書の内容を確認したうえで、管理会社や専門家に相談してください。
