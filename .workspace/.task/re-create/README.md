6. 本フォルダは作業用の派生ファイル。マスターは`task-list.md`（T-NN）・`weekly-task.md`（W-NN）。バッチの作業をT-NNとして起票する場合も、詳細は本フォルダに書いて、T-NN側はID参照のみにする
