## 優先度 D — 1件のみ使用・ニッチすぎるタグの整理

使用数1件で、他記事への横展開が見込めない超ニッチタグ。将来の記事追加がなければ削除を検討。

**地名系（1件ずつ）:**
`川崎` / `川口` / `松戸` / `船橋` / `豊中` / `日本橋` / `渋谷` / `新宿` / `神戸市` / `京都市` / `横浜`
→ 地域ガイドカテゴリで都市記事が増えれば統合先が生まれる。今は放置でOK

**製品固有（1件）:**
`S-OTODASU` / `ISOVOX` / `Anker` / `Sony` / `Bose` / `Quintet神戸` / `エリザベト音楽大学`
→ 超ニッチ。汎用タグとの組み合わせで記事は見つかる。削除推奨

**特殊素材・技法（1件）:**
`バイオフィリック` / `スカンディアモス` / `Japandi` / `音響短絡`
→ ニッチすぎる。`吸音材` 等に統合推奨
