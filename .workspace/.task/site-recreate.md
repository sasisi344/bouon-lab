# サイト構成SEO診断メモ（2026-04-13）

## 目的
- 現在のサイト構成を分析し、SEOとインデックス促進の改善ポイントを優先度順に整理する。

## 現状サマリ
- 強み: `/ja/`・`/en/` の言語導線、静的生成、カテゴリ導線、パンくずがありクロールしやすい構造はある。
- 課題: `sitemap` / `robots` / `canonical` / `hreflang` が未整備で、インデックス最適化が弱い。
- URL課題: frontmatter の `slug` がURL生成に使われておらず、ファイル名依存URLになっている。

## 実装時の注意
- 既存URLを変更する場合は、必ずリダイレクトマップを用意して評価損失を防ぐ。
- `canonical` と `hreflang` はURL正規化（末尾スラッシュ、言語パス）を厳密に統一する。
- 大量記事運用のため、メタ生成は「共通デフォルト + 記事個別上書き」の設計にする。
