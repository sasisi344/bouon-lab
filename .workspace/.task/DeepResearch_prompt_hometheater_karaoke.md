## 【カテゴリA】音響設計の専門知識
> ナレッジ不足度：★★★★★（最優先）
> 理由：遮音・吸音の基礎はあるが、ホームシアターとカラオケで"残響時間が異なる"という核心的な差異の具体的数値・設計手法が不足

### プロンプトA-1｜残響時間の違いと両立設計

```
以下のテーマについて、専門的かつ実用的な情報を調査してください。

【調査テーマ】
ホームシアターとカラオケを同じ防音室で両立する際の「残響時間（RT60）」の設計アプローチ

【具体的に知りたいこと】
1. ホームシアターに最適な残響時間の数値目安（部屋の広さ別）
2. カラオケ・歌声に最適な残響時間の数値目安
3. 両用途で残響時間を切り替える・調整する具体的な方法
   - 可動式吸音パネルの使い方
   - 吸音材の配置パターンによる調整方法
4. 「調音設計」と「防音設計」の違いと、両方が必要な理由
5. 国内外の施工業者・メーカーが推奨している具体的な設計手法

【出力形式】
- 各項目について数値データを含めて説明
- 素人にも分かる言葉で補足説明を加える
- 参考にした情報源（サイト名・記事名）を明記
```

> ナレッジ不足度：★★☆☆☆
> 理由：ナレッジに換気の重要性は記載あり。ただしホームシアター＋カラオケという複合用途での具体的な換気設計が不足

### プロンプトF-1｜防音室の換気・空調設計

```
以下のテーマについて調査してください。

【調査テーマ】
ホームシアター＋カラオケ用途の防音室における換気・空調設計の具体的な方法
```

## 利用上の注意

- 各プロンプトは**1つずつ独立して実行**してください（まとめて投げると情報が混在しやすい）
- 取得した情報は「数値・事例・費用」を優先的に抜き出してメモしておくと記事執筆時に使いやすいです
- カテゴリA（音響設計）とカテゴリB（施工事例）が記事の核になる部分なので**優先度高め**で実行を推奨します
