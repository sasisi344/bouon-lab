# Role: Real Estate Investment Consultant (Acoustic Renovation Specialist)
## Task: 賃貸オーナー向け「防音リノベーション」の投資対効果と施工原価分析

# 📍 調査テーマ: 建設コスト高騰下における防音賃貸への転換戦略と収益性

## 🎯 リサーチ・オブジェクト（深掘り項目）:

### 1. 【原価高騰のリアル】防音資材と施工費の最新動向
- 2024年〜2026年にかけての主要防音資材（石膏ボード、遮音シート、吸音ウール、防音ドア）の価格上昇率を特定せよ。
- 職人の人件費（大工、電気工、内装工）の上昇分を含めた「平米あたりの防音施工単価（Dr-30〜50）」の直近の市場相場を算出せよ。

### 2. 【収益性の分岐点】家賃上昇額 vs 建築コスト
- 普通リフォーム（原状回復＋α）と防音リノベーション（完全防音）のコスト差を、3年・5年・10年の家賃収入プレミアム（増額分）で回収できるか、損益分岐点を特定せよ。
- 「一般募集」と「防音特化募集」における、空室期間（ダウンタイム）の短縮効果をデータ（不動産市場レポート等）から抽出せよ。

### 3. 【施工・技術の最適化】コストを抑える賢い設計
- 「部屋ごと防音」ではなく、大手メーカーの「防音ユニット（アビテックス等）を室内に設置して貸し出す」モデルのメリット・デメリットを比較せよ。
- 施工時の「防音欠損（コンセント、配管）」を安価に防ぐための、建築現場での代替部材や工夫（コストカット手法）を調査せよ。

### 4. 【出口・税制】物件価値の向上と補助金
- 防音リノベーションが「住宅性能向上」として認められ、固定資産税の減免や省エネ・リフォーム補助金の対象となるケース（2026年最新制度）を特定せよ。
- 防音賃貸化による「売却価格（キャップレート）」への影響を、過去の取引事例から類推せよ。

## 📊 出力フォーマット
- **【Investment Logic Table】**: 通常リノベ vs 防音リノベのROI（投資収益率）比較表。
- **【Cost Analysis Chart】**: 施工費の内訳（材料 vs 手間）と、コストを削っても「性能」を維持できる急所の特定。
- **【Strategic Advice】**: 低コストで「防音賃貸」を成立させるためのオーナー向けアクションプラン。

- 「24時間演奏可」という唯一無二のフラグを立てることで、エリア内での「選ばれ続ける理由（客付け力）」を作る。
