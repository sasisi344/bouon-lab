# ブランドクエリ・ファンアウト戦略：実装プラン (2026-03)

「指名検索（ブランドクエリ）」を起点としたコンテンツの多角化（ファンアウト）を行い、一般層をファン化・成約へ導くための戦略的実装プラン。

## 🎯 目的

- 既存記事のKWから「ブランド（独自性・専門性）」の種を特定する。
- 特定した種を多角的な意図（Fan-out）で深掘りし、競合が追従できない専門層向けコンテンツを拡充する。
- 一般クエリからの流入ユーザーを、これら深化コンテンツ（書庫/データセット）へフレキシブルに誘導する。

---

## 🏗️ 実装ステップ

### 1. 既存記事からの「ブランド・グラニュール（種）」抽出

防音Labの既存記事（特に防音室、遮音材、リフォーム関連）から、以下の要素を抽出します。

- **メーカー/商品名**: ヤマハ、カワイ、大建工業、ピアリビング等の指名KW。
- **独自分析テーマ**: 「防音室の資産価値」「防音室をローンで買う方法」等の独自視点。

### 2. ファンアウト・マトリクスによる記事生成（展開案）

抽出した「種」に対し、以下の4つの切り口でサブトピックを生成します。

| カテゴリ                    | 展開例：防音ユニット（アビテックス等）   | 展開例：防音技術（遮音・吸音）           |
| :-------------------------- | :--------------------------------------- | :--------------------------------------- |
| **How-to（深化）**          | 失敗しない搬入経路の確認手順             | 測定アプリを使ったDIY防音の効果検証法    |
| **Data（証跡）**            | メーカー別の中古市場残価率データ         | 特定遮音材の周波数別透過損失の理論値     |
| **Integration（連携）**     | 防音ユニット内のインテリア・レイアウト術 | 防音 × 空調（ロスナイ）の静音性最大化    |
| **Troubleshooting（解決）** | 防音室設置後の「こもり」問題の解消法     | マンション管理組合への防音工事申請のコツ |

### 3. フレキシブルな誘導（Internal Linking & Hubs）

- **一般記事（獲得層）向け**: 「防音室 おすすめ」などの記事から、「専門的な検証データはこちら」と各種レポートへ誘導。
- **ハブ記事の作成**: `column` や `company` カテゴリを、各ファンアウト記事を束ねる階層構造の受け皿として機能させる。
