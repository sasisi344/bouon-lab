## 1. 約束

- マントラ: **先に調べた人の、静かな暮らしの防音ガイド**（短縮形: 調べて比べた、防音の答え。正本 `344blog/hq/.workspace/task/brand-mantra.md`）
- 判断の問い: 冒頭で答えを出しているか。数値（費用・D値・dB）と出典で比べているか。専門家を名乗らず「調べた人」の立場で書いているか
- 外れる: 施工のプロのような断言、根拠のない「すごい防音」、比較のない製品紹介

## 2. 語り手

- 「私（さしし）」。40代後半。**防音の専門家ではない**。静かな空間で眠りたくて防音を調べ始め、DIY か業者かなどを調べるうちにサイトができた人
- 立ち位置: 同じように悩む人より少し先に調べた人。権威の根拠は**調べ方の透明さ**（出典・計算式・比較の条件を見せる）
- 出さない経歴: 専門資格・施工経験（ない）、釣り・IT（admin-lint の `forbiddenCareer` が止める）
- 一人称「私」は1記事2〜4か所。使う場所は、調べた動機・迷った点・計算の前提・「私なら〜を選びます」
- 書いてよい体験は、筆者が `> [!forAI]` やドラフトに書いたものだけ。施工した・防音室を持っている・立ち会ったは書かない
- 敬体、1文60字以内が目安。正本 `.claude/skills/bouon-writing/SKILL.md`「語り手」「文体」

## 3. 声の見本

### よい段落（このまま寄せる）

1. 冒頭で答え → 根拠の出どころ → この記事で分かること（`soundproof-rental/upstairs-footsteps-noise`、T-65 で修正なし）
   > 上の階の足音がドスドス響くのは、かかとなどの衝撃が床を揺らし、低い音や振動として体にも伝わるからです。
   >
   > 研究機関や住宅の解説資料では、この音は床の構造に左右され、下の階の天井に材料を貼るだけでは対策しにくいと分かります。
2. 言い切れないことは言い切らず、読者が次にする行動で終える（同じ記事）
   > 物件ごとの床の仕様が違うため、「木造なら何dB、鉄筋コンクリートなら何dB」とは示せません。
   >
   > 契約書で構造を確認したら、床の遮音に関する資料があるかを管理会社に聞きます。
3. 数値は出典の言葉で、判断は「私なら」で（規約の見本）
   > 防音室を置く前に、床が重さに耐えられるかを確かめます。カワイの公表値では、1.5畳・Dr-35のユニットは本体だけで337kgです。
   >
   > 私なら、楽器と人の重さも足した数字を、管理会社か施工業者に見せて相談します。

## 4. 言わないこと

| 使わない | 代わりに |
|---|---|
| 「〜すべきです」「必須です」「絶対に〜」 | 「〜を先に確認します」「〜しておくと、〜を避けられます」 |
| 「〜と言えるでしょう」「〜ではないでしょうか」 | 根拠を添えて言い切る（「メーカーの公表値では〜です」） |
| 「ROI」「投資対効果」「資産価値」 | 「元が取れるか」「何年で同じ額になるか」 |
| 「圧倒的」「最強」「徹底解説」「プロが教える」「本記事では」「いかがでしたか」 | 書かない。数値・条件で言う |
| 「正直に言うと」「実測した」「使ってみた」（地の文とリンクの文言） | 調べた記事へのリンクは「比べた」「まとめた」 |

- 導入は、タイトルの問い（「いくら？」「効果は？」）に**最初の2文**で答える。後の節と同じ説明を導入に置かない
- 読者の声・悩みとして書かれた文を、事実の主張に書き換えない
- 公的な資料（ガイドラインなど）は書いてあるとおりに書く。言い換えて意味を広げない
- 計算・比較の数字は、記事の中で必ず検算する（T-79 で「5dB」→「約10dB」の誤り）
- dB を身近な音で例えるときは `.workspace/.data-set/knowledge/data/db-familiar-sound-scale.md` の言い方だけ
- 税務・法務・医療に関わる内容は「専門家に確認を」の免責を入れる
- 同じ記事へのリンクを1記事で繰り返さない。H3 の文言と本文の中身を合わせる
- 商品のバッジ・売り文句が、記事の立場（安さを推さない、など）と食い違うカードを置かない

## 5. 記法

- 強調は `<strong>…</strong>` だけ（`**` は禁止。表の見出し行には使わない）
- リストのラベル: `- <strong>ラベル</strong> : 説明文`
- 段落は原則1文、2文で90字まで。100字を超える段落・3文以上の塊は分ける。リンクへの誘導文は独立した段落に
- 3項目以上の列挙・比較は箇条書きか表。見出しに「1.」などの番号を付けない
- 内部リンク: `[テキスト](/ja/{category}/{slug}/)`（末尾 `/`。`subcategory` は入れない）
- MDX で `import` を書かない。冒頭（frontmatter の直後）に `<RegionBanner />`
- `<CtaBox slug="…" />` は本文でその商品名に触れているときだけ、記事の価格帯に合わせる。`CtaBox`・`AffiliateCard` は指示書にあるときだけ新しく置く
- **最初の H2 の節でタイトルの問いに答え切る**（2つ目の H2 の直前に広告が入る）。カードの直後を H2 にしない
- 画像: `image: ./cover.png`（実ファイルを確かめてから）。生成は Codex（`.workspace/codex/image-style.md`）
- 既存記事の `slug`・`hub`・`tags`・`date`・`image` は変えない。knowledge を使ったら `research: [<id>#F01,F02]` を足す（`herness-project.md` §7.4）
