# 防音Lab：Astro移行・コンテンツ再構築ロードマップ

GSC（Google Search Console）のアクセスデータ分析に基づき、記事の「選択と集中」を行いながら、Astroへのモダンな移行を実現するためのロードマップです。

## 🎯 戦略目標：350記事を「100記事の精鋭」へ
現状の350記事（JA/EN合計）には、アクセスの全くない「幽霊記事」が約150件含まれています。これらをバッサリ削り、高パフォーマンス記事にエネルギーを集中させることで、サイト全体のドメインパワーを最大化します。

---

## 📅 ロードマップ概要

### Phase 1: コンテンツ・オーディット（完了）
GSCデータに基づき、全記事を4つのバケットに分類し、移行の優先順位を確定しました。
- **Keep (>=20 Imp):** 45記事（最優先・完全リライト）
- **Review (1-19 Imp):** 91記事（統合してハブ記事化）
- **Legacy Ghost (0 Imp, 2025以前):** 147記事（原則削除・非公開）
- **New Ghost (0 Imp, 2026以降):** 69記事（移行後のインデックス待ち）

### Phase 2: 選別とカテゴリ再編（現在のタスク）
Hugoの古い5カテゴリから、Astro向けの新しい **「5大コレクション」** へ記事を再配置します。

| 新コレクション | 旧カテゴリからの移行対象 | 役割 |
| :--- | :--- | :--- |
| **`booth`** | `room`（防音室単体・メーカー比較） | 防音室購入のコンバージョン窓口 |
| **`rental`** | `rent`（防音賃貸・MS・内見） | 賃貸契約のリード獲得 |
| **`diy-guide`** | `diy`（吸音材・自作・100均） | ボトムアップのSEO集客 |
| **`creator`** | `streaming`（配信環境・機材・暑さ対策） | クリエイター特化の技術紹介 |
| **`news`** | `news`, `reform`（法改正・補助金・新製品） | 最新トレンドと公共情報 |

### Phase 3: コンテンツの「ハブ＆スポーク」統合
インプレッションの低い「Review」記事（91記事）を、強力な「Keep」記事（45記事）に統合します。
- **例:** 各都市別の防音賃貸ガイド（インプレッション1桁）を、一つの『全国・防音賃貸選びの完全版（Keep記事）』のサブセクションに集約。
- **メリット:** ページの「薄さ（Thin Content）」を解消し、検索意図を満たす「包括的なページ」として上位表示を狙う。

### Phase 4: Astro Technical Migration
`astro-migration-spec.md` に基づき、テクニカルな移行を実施。
1.  **Page Bundle化:** `index.mdx` と `cover.jpg` を同じフォルダに配置し、画像を最適化。
2.  **i18nの実装:** `src/content/posts/ja/` と `src/content/posts/en/` に物理分割。
3.  **Frontmatterの浄化:** Hugo依存のパラメータを削除し、Astro Schemaに適合。

### Phase 5: リダイレクト設定と監視
1.  削除・統合した150記事以上のURLから、移行後の新しいURL（ハブ記事など）へ **301リダイレクト** を設定。
2.  Search Consoleでのインデックス再登録状況を監視。
