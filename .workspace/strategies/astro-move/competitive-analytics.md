# 競合分析・コンテンツ強化リサーチタスク (Competitive Analytics & Content Refinement)

このドキュメントは、Gemini CLIやDeep Researchツールを使用して、主要キーワードにおける競合サイトの分析を行い、防音Labの記事を「10x Content（競合の10倍価値のあるコンテンツ）」へと磨き上げるための指示書です。

---

## 1. 競合分析実行プロンプト (Master Prompt for Gemini)

以下のプロンプトをGeminiに投入し、特定のクエリにおける上位サイトの傾向を抽出します。

### Gemini CLI用リサーチ命令

```text
あなたはSEOとUXのスペシャリストです。
以下の[ターゲットクエリ]において、Google検索順位1位〜5位にランクインしているウェブサイトをDeep Researchしてください。

## ターゲットクエリ
- {{TARGET_QUERY}}

## 分析項目
1. **コンテンツの種類と構造**:
   - 記事の主な目的（比較、選び方、DIY手順、ニュース、事例紹介など）
   - 文中の見出し構成（H2, H3）の傾向
2. **競合の「強み（差別化ポイント）」**:
   - 独自の図解、表、チェックリスト、計算ツールの有無
   - 専門家（一級建築士等）の監修や実測データの有無
   - ユーザーの口コミや体験談の量と質
3. **コンテンツの「欠損（弱み）」**:
   - 最新の情報（2025-2026年の法改正や新製品）が反映されているか
   - ユーザーが次に知りたい「二次的な悩み」への言及はあるか
   - Q&Aセクションの充実度

## 防音Lab向けリファイン案の作成
上記分析に基づき、防音Labの記事（{{TARGET_URL}}）をリッチにするための、以下の要素を含む具体的な改善案を提案してください。
- 競合が持っていない「独自の比較軸」を盛り込んだ比較表案
- 読者の信頼を勝ち取るための「実測データの見せ方」
- コンバージョンを促すための「ベネフィットの再定義」
```

## 2. ターゲットクエリ・分析リスト

アクセスデータ（GSC）に基づき、リライト優先度の高いクエリを選定しています。

### クラスターA: 防音室・ブース (`/room/`)
| ターゲットクエリ | 競合タイプ | 分析のポイント |
| :--- | :--- | :--- |
| `防音室 おすすめ 比較` | メーカー、大手比較サイト | ヤマハ・カワイ以外の「新興メーカー(OTODASU等)」や「中古」の扱い。 |
| `防音室 自作 費用` | 個人ブログ、YouTube | 材料費だけでなく、2025年時点の「入手可能な材料」による最新コスト。 |
| `防音室 暑さ対策 スポットクーラー` | 家電サイト、配送者ブログ | 防音性能を落とさずに冷やす「物理的な設置事例」の豊富さ。 |

### クラスターB: 防音賃貸・暮らし (`/rent/`)
| ターゲットクエリ | 競合タイプ | 分析のポイント |
| :--- | :--- | :--- |
| `防音賃貸 大阪 相場` | 大手不動産ポータル | ポータルにはない「地域特有の遮音性能の傾向」や「内見時のチェックリスト」。 |
| `マンション 生活音 苦情 対策` | 法律相談、主婦向けサイト | 感情論ではなく「騒音計による測定」や「受忍限度」の具体的な基準。 |

### クラスターC: リフォーム・補助金 (`/reform/`)
| ターゲットクエリ | 競合タイプ | 分析のポイント |
| :--- | :--- | :--- |
| `内窓 防音 効果 実測` | リフォーム業者 | 「断熱」メインの競合に対し、「防音」に特化したガラス厚とエアギャップのデータ。 |
| `防音室 補助金 2025` | 行政、ニュースサイト | 申請時の「理由書」の書き方や、採択されやすい具体的な事例。 |

## 3. リッチコンテンツ（10x Content）の構成要素チェックリスト

分析後、記事に以下の要素が一つ以上含まれているか確認します。

- [ ] **Interactive**: 防音性能シミュレーターや予算計算機
- [ ] **Visual**: 独自の断面図、レイアウト図解、または実写写真
- [ ] **Professional**: 建築基準法やD値の計算式に基づく技術的裏付け
- [ ] **Personal**: 実際の導入者による「後悔したポイント」と「解決策」
- [ ] **Comparison**: 3社以上の製品を同じ条件下で比較したスペック・価格表
