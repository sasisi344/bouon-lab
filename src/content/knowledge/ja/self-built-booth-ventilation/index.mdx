自作防音室を作ったものの、暑すぎて5分も入っていられない……。
そんな「熱中症予備軍」の皆さんのために、格安でできる強力な換気システム改造術を伝授します。

## 【悲報】自作防音室で熱中症？PC排熱と換気の重要性

防音室が完成した時の達成感は、室温の上昇とともに絶望に変わります。

### なぜ自作防音室は「サウナ化」しやすいのか

防音性能を高めるために「隙間」を埋めると、同時に空気の通り道もなくなります。
さらに、ハイスペックPCが放出する排熱が加わると、内部は短時間で40度を超えます。

### 1,000円で導入する「強制換気」の仕組み

単に扇風機を回すだけでは、室内の熱気は滞留します。  
外気を入れて、内部の熱気を押し出す  
<strong>給気と排気の2系統</strong> が重要です。

## 消音ダクトの寸法と材料費の目安

換気を強くすると音漏れも増えます。  
そこで、空気は通して音を曲げる  
迷路型ダクトを作ります。

### 段ボール試作とMDF本設の使い分け

- <strong>段ボール</strong> : 試作向けです。軽くて加工が簡単です。
- <strong>MDF 9mm前後</strong> : 本設向けです。気密と耐久が安定します。
- <strong>判断基準</strong> : 毎日使うならMDF移行を推奨します。

### 参考寸法

- <strong>ダクト内径</strong> : 100mm前後
- <strong>曲げ回数</strong> : 2〜3回
- <strong>全長</strong> : 80〜120cm

### 材料費の目安

| 材料 | 価格目安 |
| :-- | :-- |
| USBファン2台 | 1,000〜2,000円 |
| 段ボールまたはMDF | 500〜3,000円 |
| 吸音材・気密テープ | 1,000〜2,000円 |
| 合計 | <strong>2,500〜7,000円</strong> |

## CO2濃度リスクは必ず管理する

防音は「密閉」に寄るため、  
換気を軽視すると集中力低下と頭痛を招きます。  
目安として、室内CO2は  
<strong>1,000ppm以下</strong> を維持してください。

- <strong>開始前</strong> : CO2計で基準値を確認します。
- <strong>配信中</strong> : 1,000ppmを超えたら換気量を増やします。
- <strong>終了後</strong> : 5〜10分の強制排気でリセットします。

CO2と作業効率の関係は  
[CO2濃度とロスナイで生産性を守る方法](/ja/knowledge/co2-concentration-lossnay-productivity/)  
を参照してください。

## 夏冬で変える運用ルール

季節で最適解は変わります。  
同じ設定を通年で使うと、  
暑さや結露で失敗しやすくなります。

### 夏の運用

- <strong>給気側を冷気に寄せる</strong> : スポットクーラーの冷風を給気側へ当てます。
- <strong>排気優先</strong> : 内部熱源（PC）を先に抜く設計にします。

### 冬の運用

- <strong>急激な温度差を避ける</strong> : 暖気と外気の差で結露が起きます。
- <strong>吸音材の湿気管理</strong> : 乾燥運転と定期点検でカビを防ぎます。

## まとめ

自作防音室の換気は、  
「安いファンを置く」では足りません。  
給排気の設計、消音ダクト、CO2管理まで揃えると、  
安全に長時間運用しやすくなります。

換気は快適性だけでなく、  
体調と配信品質を守る基礎設備です。
