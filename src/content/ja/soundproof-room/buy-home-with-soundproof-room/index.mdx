防音室付きマンションは、分譲でも中古でも買えます。

ただし売りに出る数は少なく、「防音室付き」と書かれていても、<strong>どのくらい音を止められるかは物件ごとにまちまち</strong>です。

<strong>探し方を3つ使い分けること</strong>と、<strong>内見・契約前に5項目を確かめること</strong>で、買った後に「思ったより音が漏れる」という後悔は減らせます。

この記事は、防音室のある家を<strong>買う</strong>人向けです。

防音室のある賃貸を探している場合は、[防音賃貸・防音マンションの選び方](/ja/soundproof-rental/bouon-rental-market-guide/)を参考にしてください。

賃貸のように、音の心配があるたびに引っ越すのはもう終わりにしたい。

防音室付きの家を探す人の多くは、そう考えています。

だからこそ、売主や仲介会社の「防音室あり」という一言を、そのまま信じていいのかが気になるはずです。

この記事では、その一言を自分で確かめる方法を中心に整理します。

## 防音室付き物件の種類｜分譲マンション・中古マンション・中古戸建て

「防音室付き」と呼ばれる物件には、大きく5つの種類があります。

種類によって、防音室の作り方と、性能を確かめる方法が違います。

| 種類 | 防音室の作り方 | 性能を確かめる手がかり | 見つけやすさ |
| :-- | :-- | :-- | :-- |
| <strong>新築分譲マンション</strong> | メーカーのユニット防音室をオプションで設置 | メーカーの性能表示（Dr値） | 対応する物件が少ない |
| <strong>中古マンション</strong> | 前の住人がユニットを置いた、または部屋を防音リフォームした | 機種名・施工記録 | 少ない |
| <strong>中古戸建て</strong> | 新築時に組み込んだ、またはリフォームで作った | 設計図・施工会社の記録 | 中古マンションより多い |
| <strong>建売住宅</strong> | 防音室付きで売り出す例はまれ | 売主の仕様書 | ほとんど無い |
| <strong>注文住宅</strong> | 自分で依頼して作る | 自分で性能を指定できる | 探すのではなく作る |

### 新築分譲マンションのオプション

新築分譲マンションでは、ヤマハのユニット防音室をオプションで選べる物件が出てきています。

たとえば京急グループが分譲した「プライムパークス横浜並木 ザ・レジデンス」（横浜市金沢区、全509戸）は、ヤマハの「アビテックス」をオプション工事として選べる形で発表されました。

推奨されたのは<strong>セフィーネNSのDr-40タイプ</strong>で、基本の広さは0.8畳・1.2畳・1.5畳です（[2024年11月7日のリリース](https://digitalpr.jp/r/98555)）。

オプションなので、すべての住戸に防音室が付いているわけではありません。

販売状況やオプション価格は、販売元に確認してください。

### 中古マンション・中古戸建て

中古の防音室付き物件は、前の持ち主が自分のために作った防音室が残っているものです。

楽器の種類も、かけた費用も、持ち主ごとに違います。

<strong>同じ「防音室付き」でも、ピアノ用のDr-40の部屋と、配信用の簡易ブースが同じ言葉で並んでいる</strong>と考えてください。

中古戸建ては、新築時にピアノ室を組み込んだ家が売りに出ることがあり、中古マンションより見つかりやすい傾向があります。

注文住宅で一から作る方法は、[注文住宅で防音室を作る依頼先の選び方](/ja/soundproof-room/custom-home-soundproof-builder-selection/)で整理しています。

## 防音室付きマンションの探し方

防音室付きマンションは、ポータルサイトで条件を絞るだけでは、ほとんど見つかりません。

たとえば東急リバブルの購入物件をフリーワード「防音室」で検索すると、全国で321件が表示されました。

ところが「平塚市 防音室」に絞ると<strong>0件</strong>でした（2026年10月18日確認。件数には、防音室の記載がない物件や建物情報も含まれます）。

地域を絞った途端に候補が消えるのが、防音室付き物件の探しにくさです。

次の3つの探し方を並行して使ってください。

### ポータルはフリーワードで探し、地域を広げる

防音室は、間取り図や検索条件の項目に出ないことが多い設備です。

物件ページの「特徴」「設備」「備考」の欄に書かれているため、<strong>フリーワード検索</strong>で拾います。

検索に使う語は、次のように変えて試します。

- <strong>防音室</strong> : いちばん多く使われる表記
- <strong>防音</strong> : 「防音仕様」「防音工事済み」も拾える
- <strong>楽器</strong> : 「楽器演奏可」「楽器相談」の物件
- <strong>ピアノ室・音楽室・スタジオ</strong> : 戸建てで使われやすい表記
- <strong>アビテックス・ナサール</strong> : ユニット防音室の製品名

最初は市区町村ではなく、<strong>通える範囲の沿線や都道府県</strong>で検索します。

候補が見つからない地域でも、新着の通知を設定しておくと、売り出された物件を逃しにくくなります。

### 防音リノベ済み物件を探す

リノベーション会社が買い取り、防音工事をしてから売り出す物件もあります。

「防音リノベ」「楽器演奏可リノベーション」の語で探すと、ポータルとは別の物件が見つかります。

施工した会社がはっきりしているため、<strong>遮音性能の説明や測定結果を出してもらいやすい</strong>のが利点です。

### 仲介会社と楽器店に「探してほしい」と伝える

防音室付きの物件は数が少ないため、ポータルに載る前に話がまとまることもあります。

仲介会社に、楽器の種類・演奏する時間帯・必要な広さを伝え、条件に合う物件が出たら連絡をもらうよう頼んでおきます。

島村楽器などの楽器店は、防音室の販売・移設の相談を受けています。

物件探しそのものは仲介会社の仕事ですが、<strong>見つけた物件の防音室の機種や状態を相談する先</strong>として楽器店も役立ちます。

## 内見で確認する5項目

内見では、防音室の中で楽器を鳴らせないことがほとんどです。

そのため、<strong>書類と目で確かめられる5項目</strong>を順に確認します。

| 確認項目 | 見るもの・聞くこと | 注意したい答え |
| :-- | :-- | :-- |
| <strong>Dr値の根拠</strong> | 製品名と型番、または施工会社の測定結果 | 「防音なので大丈夫」だけで数値がない |
| <strong>建物の構造</strong> | RC造か木造か、床の厚さ、隣の住戸との壁 | 防音室が隣の住戸側の壁に接している |
| <strong>換気・空調</strong> | 換気扇の有無、エアコンの配管、電源 | 換気扇がない、エアコンが付けられない |
| <strong>床荷重・搬入</strong> | 防音室の重さ、床の補強、交換時の搬入経路 | ユニットの重さが分からない |
| <strong>管理規約</strong> | 楽器演奏の時間・種類の制限 | 「楽器は○時まで」など防音室でも制限がある |

### Dr値の根拠

Dr値（ディーアール値）は、部屋の中と外で音がどれだけ小さくなるかを表す等級です。

<strong>Dr-40なら、中で鳴らした音が外ではおよそ40dB小さくなる</strong>目安になります。

ピアノの音は正面1mで80〜90dBほどあるため、Dr-40の部屋なら、外では40〜50dB、<strong>図書館の館内から書店の店内くらいの大きさ</strong>まで下がる計算です（[環境省「騒音の目安」](https://www.env.go.jp/air/ippan/meyasu.pdf)）。

ただし、夜の住宅地はそれより静かな40dB前後のため、この大きさでも曲が流れていることは分かります。

また、Dr値は低い音ほど下がりにくい等級なので、ピアノの低音はこの計算より大きく聞こえることがあります。

ユニット防音室なら、扉や本体に貼られたラベルで製品名と型番が分かり、メーカーの性能表示（Dr-35・Dr-40など）を調べられます。

部屋を防音リフォームした場合は、<strong>施工会社名と、完成時の遮音測定の結果</strong>が残っているかを聞きます。

### 建物の構造

防音室の性能は、防音室だけでなく建物でも変わります。

マンションなら、床のコンクリート（スラブ）の厚さと、隣の住戸との壁がコンクリートか乾式壁（石膏ボード）かを確認します。

<strong>乾式壁は、同じ厚さのコンクリート壁より低い音が抜けやすい</strong>傾向があります。

木造の戸建ては、防音室の外側に音が回り込みやすいため、防音室の位置と隣家までの距離も見ておきます。

### 換気・空調

防音室は密閉されているため、換気扇とエアコンがないと夏は長く使えません。

換気扇の有無、エアコンが付いているか（付けられる配管穴があるか）、専用の電源があるかを確認します。

### 床荷重・搬入

ユニット防音室はかなり重く、ヤマハのセフィーネNSは1.2畳タイプでも約320kgあります。

前の住人が置いたユニットなら、床の補強をしたかどうかを聞いてください。

床の安全の考え方は、[マンションに重さ500kgの防音室を置けるかの計算方法](/ja/soundproof-rental/apartment-weight-limit-500kg/)で解説しています。

また、将来ユニットを大きいものに替える場合に、エレベーターや廊下を部品が通るかも見ておきます。

### 管理規約

マンションでは、防音室があっても<strong>管理規約や使用細則で楽器の演奏時間が決められている</strong>ことがあります。

仲介会社を通して、規約と使用細則の原本、過去の音の苦情の有無を確認してもらいます。

規約で演奏できる時間が短ければ、防音室があっても夜に練習することはできません。

## 「防音室付き」を信用していい根拠と疑うべきサイン

「防音室付き」の言葉を信用していいかは、<strong>後から確かめられる記録があるか</strong>で判断します。

| 信用していい根拠 | 疑うべきサイン |
| :-- | :-- |
| ユニットの製品名・型番が分かる | 「防音仕様」「防音対策済み」だけで中身の説明がない |
| 施工会社と工事の時期が分かる | 前の持ち主が自分でDIYした |
| 完成時の遮音測定の結果がある | 売主も仲介会社も「詳しいことは分からない」 |
| 付帯設備表に防音室が載っている | 防音室が引き渡しの対象か決まっていない |
| 前の持ち主が実際に何の楽器を使っていたか分かる | 楽器ではなくオーディオや配信用だった |

### 付帯設備表で防音室の扱いを確認する

中古物件を買うときは、売主が「付帯設備表」で、引き渡す設備とその状態を伝えます。

<strong>ユニット防音室は、組み立て式で取り外せるため、売主が持って行くこともあります</strong>。

付帯設備表に防音室が載っているか、扉や換気扇に不具合がないかを確認してください。

個人が売主の中古物件では、設備の不具合について売主が責任を負う期間を短くしたり、責任を負わないとしたりする契約もよくあります。

気になる不具合は、契約の前に見つけておく必要があります。

### 建物状況調査（インスペクション）を使う

中古物件では、建物の劣化を専門家が調べる「建物状況調査（インスペクション）」を頼めます。

仲介会社は、この調査をあっせんできるかを伝えることになっています。

調査で分かるのは主に建物の劣化で、<strong>防音室の遮音性能を測るものではありません</strong>。

遮音性能まで確かめたい場合は、防音工事の会社に測定を頼めるか相談してください。

## 防音室付き中古マンションと、中古＋防音工事の総額比較

防音室付きの中古マンションが見つからないなら、<strong>ふつうの中古マンションを買って防音室を作る</strong>方法もあります。

防音室にかかる費用を比べると、次のようになります。

| 方法 | 防音室にかかる費用の目安 | 向いている人 |
| :-- | :-- | :-- |
| <strong>防音室付き中古を買う</strong> | 物件価格に含まれる。点検・修理費は別 | 条件の合う物件が見つかった人 |
| <strong>中古を買ってユニットを置く</strong> | 1.5畳以下で約90万〜130万円＋設置費20万円前後 | ピアノ・声楽・配信を1人で使う人 |
| <strong>中古を買って部屋を防音リフォーム</strong> | 6畳で約160万〜460万円。解体費は別 | グランドピアノ・レッスン・アンサンブル |
| <strong>注文住宅に組み込む</strong> | ピアノ・声楽向け（Dr-40〜50）で坪単価約70万〜120万円 | 土地から探して家を建てる人 |

※費用は当サイトの関連記事で整理した公表価格・目安です。実際の金額は見積もりで確認してください。

この表から分かるのは、<strong>1.5畳以下で足りる用途なら、防音室付きにこだわらなくても100万円台前半で作れる</strong>ということです。

防音室付きの物件だけに絞ると、駅・広さ・価格の条件をすべて譲ることになりかねません。

住みたい場所と広さを先に決め、防音室は後から作る前提で探すほうが、候補は大きく増えます。

一方で、6畳の部屋を防音室にするなら数百万円かかるため、<strong>条件の合う防音室付き物件が見つかれば、その分を節約できる</strong>可能性があります。

部屋を防音リフォームする費用の内訳は、[防音室リフォームの費用相場](/ja/money/soundproof-reform-cost-by-tatami/)で畳数別に比べています。

ユニット防音室の価格は、[防音室の値段・価格相場](/ja/money/soundproof-room-price-market/)を参考にしてください。

## 将来の売却・資産価値はどう考える？

防音室付きの家は、楽器を弾かない人には「使い道の少ない部屋」に見えることがあります。

そのため、<strong>防音室があるから高く売れる、とは考えないほうが安全</strong>です。

ただし、ユニット防音室は取り外して売ったり、次の家に移したりできます。

部屋を防音リフォームした場合も、書斎や在宅ワークの部屋、シアタールームとして使える形にしておけば、買い手の幅は狭まりにくくなります。

防音室の価値は、売るときの値段よりも、<strong>住んでいる間、音の心配をせずに弾ける時間</strong>にあります。

ユニット防音室の中古価格の残り方は、[防音室の資産価値分析](/ja/money/bouon-asset-value-analysis/)で詳しく扱っています。

## 住宅ローン・税金の確認先

防音室付きの物件を買う場合、防音室の分も物件価格として住宅ローンの対象になります。

中古物件を買って防音工事をする場合は、<strong>購入とリフォームを1本で借りられる「リフォーム一体型」の住宅ローン</strong>があるか、金融機関に確認してください。

購入後に別でリフォームローンを組むと、金利が高くなりやすいためです。

住宅ローン控除（住宅ローン減税）は、令和8年度の税制改正で適用期限が延長され、中古住宅の床面積や控除期間の要件も見直されています。

最新の要件は、[国土交通省の住宅税制のページ](https://www.mlit.go.jp/jutakukentiku/house/zeisei_index2.html)と国税庁で確認してください。

防音室が固定資産税の評価にどう影響するかは、自治体の評価によって変わります。

新築時の資金計画と固定資産税の考え方は、[防音室・ピアノ室を住宅ローンに組み込む方法](/ja/money/piano-soundproof-mortgage-tax-guide/)で整理しています。

<strong>ローンと税金の扱いは個別の条件で変わるため、金融機関・税理士・自治体の窓口に確認してください</strong>。

## よくある質問

### 防音室付きの中古戸建ては見つかる？

中古マンションより見つかりやすい傾向があります。

新築時にピアノ室を組み込んだ家が売りに出ることがあるためです。

ポータルのフリーワード検索で「ピアノ室」「音楽室」も試してください。

### 東京で防音室付きの分譲マンションを探すには？

都内で地域を絞ると、候補がほとんど残らないことがあります。

通勤できる沿線や近隣の県まで広げて探し、新築分譲はモデルルームで防音室のオプションがあるかを確認してください。

### 防音室付きの賃貸を探している場合は？

賃貸には、防音マンションの専門ブランドなど、購入とは別の探し方があります。

[防音賃貸・防音マンションの選び方](/ja/soundproof-rental/bouon-rental-market-guide/)で、相場とブランドを整理しています。

## まとめ

- <strong>防音室付きマンションは買える</strong> : 新築分譲のオプション、中古マンション、中古戸建てがある。ただし数は少ない
- <strong>探し方</strong> : ポータルのフリーワード検索で地域を広げる、防音リノベ済み物件を探す、仲介会社に条件を伝えておく
- <strong>内見で確認する5項目</strong> : Dr値の根拠、建物の構造、換気・空調、床荷重・搬入、管理規約
- <strong>信用していい根拠</strong> : 製品名・施工会社・測定結果など、後から確かめられる記録がある
- <strong>見つからないとき</strong> : 1.5畳以下で足りるなら、中古を買ってユニットを置けば100万円台前半で作れる

防音室付きかどうかより先に、<strong>どの楽器を、何時まで、どの広さで弾きたいか</strong>を決めておくと、物件を見る目がぶれません。
