防音室でトランペットは吹けます。

目安は<strong>Dr-35〜40・1.5畳以上</strong>で、夜も吹くならDr-40を選ぶのが販売店の一般的な案内です。

本記事では、楽器可の物件なのに苦情が来た人に向けて、隣に届く音の計算表と、10万円台の組み立て式（OTODASU・だんぼっち）で足りる条件、トロンボーン・ホルン・フルート・バイオリンに必要な広さを順に示します。

## 楽器可の物件でも苦情が来るのはなぜか

楽器可の物件を選んで、時間帯も守っていたのに、隣から苦情が来た。

このページにたどり着く人の多くは、そうした状況にいるのではないでしょうか。

楽器可は「楽器を弾くことを契約で禁止しない」という意味で、<strong>建物の壁が楽器の音を止められることまでは約束していません</strong>。

隣の部屋に届く音は、おおまかに次の引き算で考えられます。

<strong>隣に届く音 ≒ 楽器の音 − 防音室で下がる分 − 建物の壁で下がる分</strong>

トランペットの音は、販売店の目安で100〜110dB以上です。

壁で下がる分が足りなければ、どれだけ時間帯を守っても、隣にははっきり聞こえます。

楽器可の物件の探し方そのものは、[楽器可物件の調べ方](/ja/soundproof-rental/instrument-allowed-rental-research-method/)で解説しています。

苦情が来たあとの話し合いの進め方は、[騒音の苦情を管理会社と相談する方法](/ja/soundproof-rental/noise-complaint-landlord-negotiation-guide/)にまとめています。

## 楽器別の必要Dr値・広さの早見表

| 楽器 | 音量の目安 | 必要なDr値の目安 | 広さの目安 | 広さで注意すること |
| :--- | :--- | :--- | :--- | :--- |
| <strong>トランペット</strong> | 100〜110dB以上 | Dr-35〜40（夜はDr-40） | 1.5〜2.0畳 | 立奏で、ベルの先に余白がほしい |
| <strong>トロンボーン</strong> | 100〜110dB以上 | Dr-35〜40 | <strong>2.0畳以上</strong> | スライドを伸ばす前方の長さ |
| ホルン | 100dB以上を想定 | Dr-35〜40 | 1.5畳前後 | ベルが右後ろを向く。背中側の壁との距離 |
| フルート | 80〜90dB | Dr-35 | 1.2〜1.5畳 | 楽器が横に伸びる。右側の余白 |
| クラリネット | 80〜90dB | Dr-35 | 1.2畳 | 立奏なら0.8畳でも入る |
| <strong>バイオリン・ヴィオラ</strong> | 80〜90dB | Dr-35 | 1.5〜2.0畳 | 弓を引く右側の余白 |
| 声楽 | 90dB前後（大声の独唱） | Dr-35〜40 | 0.8〜1.2畳 | 狭いと声がこもる |

音量・Dr値・広さの目安は、[島村楽器 グランフロント大阪店の解説](https://www.shimamura.co.jp/shop/osaka-classic/product/20240125/7274)の区分を中心に、ヤマハの案内と当サイトの判定で補ったものです。

楽器の音量は測る距離と吹き方で大きく変わり、販売店の区分にも測定条件は書かれていません。

ホルンはこの区分に載っていないため、同じ金管として100dB以上を想定しています。

声楽の90dBは、日本環境協会の「大声による独唱」の目安です。

サックス・チェロ・ピアノ・ギター・ドラムは、それぞれ専用の記事で扱っています（後述）。

## 防音室でトランペットを吹くには

### Dr-40なら外は60dB前後

島村楽器の別の店舗の解説では、100dBの音をDr-40の防音室で鳴らすと、外では60dB程度になると試算しています。

60dBは、銀行の窓口や、ふつうに話す声くらいの大きさです。

防音室の外にいる家族には聞こえますが、さらに建物の壁を通ったあとの隣の部屋では、ずっと小さくなります。

### 隣に届く音を計算する

トランペット（110dB）を、建物の壁の性能と防音室の組み合わせごとに計算しました。

| 防音室 | 鉄筋コンクリートの壁（D-45と仮定） | 木造・軽量鉄骨の壁（D-30と仮定） |
| :--- | :--- | :--- |
| なし | 約65dB（ふつうの会話くらい） | 約80dB（地下鉄の車内くらい） |
| OTODASU II（平均-25dBと仮定） | 約40dB（図書館の館内くらい） | 約55dB（書店の店内より大きい） |
| ユニット防音室 Dr-35 | 約30dB（ホテルの客室くらい） | 約45dB |
| ユニット防音室 Dr-40 | 約25dB | 約40dB（図書館の館内くらい） |

計算は「楽器の音−防音室−建物の壁」の単純な引き算です（当サイトの試算）。

建物の壁の性能は物件で大きく違うため、仮の値を置いています。

低い音ほど壁でも防音室でも下がりにくく、実際には表より大きく聞こえる音域があります。

鉄筋コンクリートの物件で「防音室なし・約65dB」は、隣の人がはっきり気づく大きさです。

楽器可の物件で苦情が来るのは、この段にいることが多いと考えられます。

### トランペットは何畳あればいいか

販売店の目安は1.5〜2.0畳ですが、店舗によっては0.8畳を勧めている例もあり、案内は分かれています。

0.8畳でも吹くことはできますが、立って構えたときにベルの先が壁に近く、音が自分に跳ね返って耳が疲れやすくなります。

長い時間練習するなら、<strong>ベルの先に1m前後の余白が取れる1.5畳以上</strong>のほうが楽です。

ヤマハのアビテックス セフィーネNSの内寸は、0.8畳が884×1,325mm、1.5畳が1,325×1,766mmです。

各サイズの内寸は、[防音室0.8畳で足りる？](/ja/soundproof-room/compact-booth-under-1-5-tatami/)で表にしています。

## 予算別に見る｜OTODASU・だんぼっちで足りるか

ヤマハやカワイのユニット防音室は、楽器練習ではいちばん確実な選択肢です。

ただし、セフィーネNSは0.8畳のDr-35で77万円、Dr-40で107万8千円（希望小売価格）と、すぐには手が出ない価格です。

そこで、10万円台の組み立て式で足りる条件を整理しました。

| 製品 | 価格の目安 | 遮音の公式表記 | 足りる楽器と条件 |
| :--- | :--- | :--- | :--- |
| だんぼっち | 8.4万〜12.8万円（ベーシック〜グランデ） | 声と中高音向けの設計と案内 | 声楽・フルート・クラリネットの昼の練習。楽器を持ち込むならワイドかグランデ |
| OTODASU II | 14.4万円（吸音材なし）〜20.7万円（吸音材あり） | 平均-20dB（吸音材なし）、平均-30dB（吸音材あり） | フルート・バイオリンの昼〜夕方。トランペットは<strong>鉄筋コンクリートの物件の昼間</strong>なら候補 |
| ユニット防音室（Dr-35〜40） | 77万〜110万円前後 | Dr-35・Dr-40 | トランペット・トロンボーンの夜を含む練習 |

価格は各社の公式サイト・販売店の表示（2026年10月時点）で、時期とセールで変わります。

OTODASUの公式のよくある質問でも、<strong>管楽器は音圧が高いため、最終的な防音性能は不十分な場合がある</strong>と案内されています。

### OTODASUで「足りる」と判断しやすい条件

- <strong>建物</strong> : 鉄筋コンクリートで、隣との壁が厚い
- <strong>時間帯</strong> : 昼〜夕方に限る
- <strong>苦情の内容</strong> : 「うるさい」ではなく「毎日長く聞こえて気になる」程度
- <strong>楽器</strong> : フルート・クラリネット・バイオリンなど80〜90dBの楽器。トランペットは消音器（ミュート）と組み合わせる

### 消音器（ミュート）と組み合わせる

ヤマハの消音器「サイレントブラス」は、トロンボーン用・チューバ用のピックアップミュートで、公式の消音程度を-25〜-35dBとしています。

消音器だけでは吹き心地と音色が変わるため、本番に近い音で練習する時間は防音室で、それ以外は消音器、と分けると練習量を確保しやすくなります。

### 実際に使っている人の声

OTODASUを2年半使ったボカロPの方は、使い心地を次のように書いています（[りきやのボカロP日和](https://rikiya-ieshima.com/otodasu-review-2years/)）。

> 「音を出す不安」はかなり減りました。

同じ記事では、限界についても率直に書かれています。

> 音は小さくなるけどゼロにはならない

別の方のレビューでは、外で音を確かめたところ「完全に上から聞こえてきます」と、天井が弱点だったことが書かれています（[Likelyレビュー](https://www.likely.jp/entry/2023/11/12/140355)）。

10万円台の防音室は、<strong>苦情の原因になっている音を「気にならない大きさ」まで下げる道具</strong>で、音を消す道具ではないと考えるのが現実的です。

だんぼっちとOTODASUの違い、夏の暑さの注意点は、[格安防音室の比較](/ja/soundproof-room/budget-soundproof-booth-comparison/)で解説しています。

## トロンボーン・ホルンを防音室で吹くには

### トロンボーンは前方の長さで決まる

トロンボーンは、スライドを一番遠い7番ポジションまで伸ばすと、口元から先に1m以上の長さが必要です（目安）。

壁にスライドが当たると、楽器を傷めるうえ、遠いポジションの練習ができません。

販売店の目安は1.5畳から2.0畳以上と分かれますが、<strong>スライドを伸ばす方向に内寸1.7m以上</strong>取れるかで確かめてください（立ち位置の奥行きを含めた当サイトの目安）。

セフィーネNSの1.5畳（内寸1,325×1,766mm）なら、長い辺の方向に向けて構えることになります。

バストロンボーンや、座って吹く練習が中心なら2.0畳以上が安心です。

### ホルンは背中側の壁との距離に注意

ホルンはベルが右後ろを向き、奏者の後ろの壁で音が跳ね返って聞こえます。

背中側の壁が近すぎると、音がこもって自分の音を判断しにくくなります。

狭い防音室では、ベルが向く壁に吸音パネルを足すと、聞こえ方を整えやすくなります。

## フルート・クラリネットの防音室選び

フルートとクラリネットは80〜90dBで、トランペットより音が小さい楽器です。

Dr-35の防音室なら、夜の練習も現実的な範囲に入ります。

- <strong>フルート</strong> : 楽器が右に70cm前後伸びるため、横幅が必要。1.2畳から、余裕を見るなら1.5畳
- <strong>クラリネット</strong> : ヤマハは0.8畳を「クラリネット、オーボエなど管楽器の立奏」に適したサイズと案内している
- <strong>ピッコロ</strong> : 音域が高く耳に刺さりやすい。狭い防音室では吸音を足す

サックスは音量が大きく、別の記事で扱っています。

サックスの練習環境は、[サックスを自宅で練習する方法](/ja/soundproof-rental/saxophone-apartment-practice-guide/)をご覧ください。

## バイオリン・ヴィオラの防音室選び

バイオリンの音量は80〜90dBで、Dr-35が目安です。

広さで困るのは、音量より<strong>弓を引く右側の余白</strong>です。

バイオリンの弓は長さ約75cmで、弓を引ききったときに右手が体の横に大きく出ます。

ヤマハは、1.5畳を「弓を使う弦楽器にも最適」なサイズと案内しています。

- <strong>0.8畳</strong> : 弓が壁に当たりやすく、長い時間の練習には向かない
- <strong>1.2畳</strong> : 構える向きを工夫すれば弾ける
- <strong>1.5〜2.0畳</strong> : 弓と譜面台を置いても余裕がある

バイオリンは弱音器を付けると音が小さくなるため、OTODASUなど10万円台の防音室と組み合わせやすい楽器です。

チェロは音量も楽器も大きいため、[チェロを賃貸で弾くときの注意点](/ja/soundproof-rental/rental-caution-cello/)で別に扱っています。

## 声楽・ボーカルの防音室

大声の独唱は90dB前後で、Dr-35〜40が目安です。

声楽は体を楽器にするため、0.8畳でも練習できますが、狭いと響きが少なく、自分の声を判断しにくくなります。

声の響きを重視するなら1.2畳以上、配信やボイスチャットが中心なら0.8畳でも足ります。

## 熱・湿度・換気の注意｜管楽器は呼気が多い

管楽器と声楽は、ふつうに座って作業するより呼吸の量が増えます。

そのため、防音室の中のCO2と湿気が早く上がります。

- <strong>CO2</strong> : 1.2畳の防音室では、換気扇を回していても1人でCO2が1,000ppmを超える計算になる。1時間に1回はドアを開ける
- <strong>湿気</strong> : 吐く息の水分で湿度が上がり、楽器と吸音材に結露が出やすい
- <strong>熱</strong> : 夏はエアコンのない防音室が暑くなりやすい

防音室のCO2の上がり方は、[防音室は酸欠になる？CO2の上がり方](/ja/soundproof-room/ear-pressure-tinnitus-dizziness/)で試算しています。

温度と湿度の管理は、[防音室の温湿度管理ガイド](/ja/soundproof-room/proofroom-humidity-airconditionlist/)をご覧ください。

## よくある質問

### 防音室でトランペットを夜に吹いても大丈夫ですか？

Dr-40のユニット防音室なら、鉄筋コンクリートの物件で夜の練習も現実的な範囲です。

木造・軽量鉄骨の物件では、Dr-40でも隣に図書館の館内くらいの音が届く計算になるため、夜は消音器との併用をおすすめします。

### 防音室でフルートを吹くには何畳必要ですか？

1.2畳から吹けますが、楽器が右に伸びるため、余裕を見るなら1.5畳が目安です。

### 防音室でバイオリンを弾くには何畳必要ですか？

弓を引く余白が必要なため、1.5〜2.0畳が目安です。

0.8畳では弓が壁に当たりやすくなります。

### トロンボーンは防音室に入りますか？

スライドを伸ばす方向に内寸1.7m以上あれば入ります。

ホルンは1.5畳前後、トロンボーンは2.0畳以上を目安にしてください。

## まとめ｜楽器・時間帯・建物の3つで決まる

- <strong>トランペット</strong> : Dr-35〜40・1.5畳以上。夜も吹くならDr-40
- <strong>トロンボーン</strong> : 2.0畳以上。スライドを伸ばす方向に内寸1.7m以上
- <strong>フルート・クラリネット・バイオリン</strong> : Dr-35。バイオリンは弓の余白で1.5畳以上
- <strong>楽器可でも苦情が来る</strong> : 建物の壁だけでは足りていない。「楽器の音−防音室−壁」で隣に届く音を見積もる
- <strong>10万円台</strong> : OTODASUは鉄筋コンクリートの物件の昼間、80〜90dBの楽器なら候補。トランペットは消音器と組み合わせる

次の一手として、防音室を置く前に床の重さや部屋の条件を確かめたい方は、[防音室の設置チェックポイント](/ja/soundproof-room/bouon-setti-checkpoint/)をご覧ください。
