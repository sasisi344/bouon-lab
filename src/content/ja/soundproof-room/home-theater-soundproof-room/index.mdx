防音室でホームシアターを楽しむとき、いちばんの難所は<strong>サブウーファーの重低音</strong>です。

夜に映画の迫力を落とさず鳴らすなら、目安はDr-60前後に浮き床を組み合わせた工事で、6畳の費用は約250万〜450万円（当サイトの概算）になります。

昼間や中音量で楽しむならDr-50前後で足り、費用も下がるため、本記事では時間帯・音量別の必要Dr値と、3〜6畳の書斎サイズで計算した費用の目安を順に示します。

## ホームシアターの防音で難しいのは低音

人の声やピアノの中高音は、壁を重くすれば比較的よく止まります。

一方で、映画の爆発音や効果音を受け持つサブウーファーの音は、<strong>壁を重くしても止まりにくい</strong>のが特徴です。

### 低い音ほど壁を通り抜ける（質量則の限界）

一重の壁が音を止める量は、壁の重さと音の高さで決まります（質量則）。

重さが同じなら、音が1オクターブ低くなるたびに、止まる量はおよそ6dBずつ減ります。

| 音の高さ | 主な音 | 石膏ボード2枚（約21kg/㎡）で止まる量（計算値） |
| :--- | :--- | :--- |
| 500Hz | 人の声、セリフ | 約33dB |
| 125Hz | 低めの男声、ベース | 約21dB |
| 63Hz | 爆発音、サブウーファーの音 | 約15dB |

計算は、一重の壁の透過損失を「20×log（面密度×周波数）−47」とした概算です（当サイトの試算）。

セリフより、サブウーファーの音のほうが<strong>約18dBも多く漏れる</strong>計算になります。

10dB下がると耳にはおよそ半分の大きさに感じるので、この差はとても大きいといえます。

材料ごとの面密度と透過損失は、[防音材のスペック一覧](/ja/knowledge/soundproof-material-spec-chart/)にまとめています。

### Dr値は重低音を評価していない

防音室の性能を表すDr値は、主に125Hz〜4kHzの音で評価する等級です。

サブウーファーが受け持つ20〜80Hz付近の音は、等級の範囲に入っていません。

さらにDr値の基準は、低い音ほど緩く決められています。

つまり、<strong>同じDr-50でも、重低音がどこまで止まるかはカタログから読み取れない</strong>ということです。

Dr値の見方そのものは、[D値の嘘と本当](/ja/knowledge/d-value-truth-and-myths/)で解説しています。

### 低音は「振動」として床から伝わる

サブウーファーの音は、空気だけでなく床や壁の振動として建物に伝わります。

マンションでは、上下階や隣の部屋に「ドン」という響きとして届きやすくなります。

この振動を止めるには、壁を重くするのではなく、<strong>部屋を建物から浮かせる構造</strong>が必要です。

振動の伝わり方は、[建物を伝わる音（固体伝搬音）の基本](/ja/knowledge/structure-borne-noise-tapping-striking/)で詳しく扱っています。

## ホームシアター用防音室に必要なDr値｜時間帯・音量別

必要な性能は、<strong>何時に、どのくらいの音量で観るか</strong>で決まります。

外に漏れてよい音の上限を、昼は50dB（書店の店内くらい）、夜は40dB（図書館の館内や住宅地の夜くらい）として、当サイトで目安を出しました。

| 観る時間と音量 | 室内の音量の目安 | 必要なDr値の目安 | 床の対策 |
| :--- | :--- | :--- | :--- |
| 昼・控えめな音量 | 平均70dB、爆発音で85dB前後 | Dr-40〜45 | 防振マット |
| 昼・映画館に近い迫力 | 平均75dB、爆発音で95dB前後 | Dr-50 | 浮き床が望ましい |
| 夜・控えめな音量 | 平均70dB、爆発音で85dB前後 | Dr-50 | 浮き床が望ましい |
| 夜・映画館に近い迫力 | 平均75dB、爆発音で95dB以上 | <strong>Dr-60以上</strong> | <strong>浮き床が必須</strong> |

目安は、爆発音などの大きな音から、外に漏れてよい上限を差し引き、重低音が止まりにくい分の余裕を足したものです。

Dr値の数字が上の表を満たしても、上で見たとおり重低音は数字より多く漏れます。

施工会社の公表例でも、8畳のシアター・リスニングルームをDr-60で案内している例があります。

### 戸建てとマンションの違い

| 住まい | 目安 | 理由 |
| :--- | :--- | :--- |
| 戸建て | 表の目安どおり | 隣家まで距離があり、外に出た音もさらに小さくなる |
| マンション | 表より一段上（Dr-55〜65） | 壁・床を共有し、重低音の振動が直接伝わる |

マンションでは、管理規約で床材の遮音等級が決められていることが多いため、工事の前に管理組合への確認が必要です。

Dr値ごとの聞こえ方は、[防音室のD値・Dr値の目安](/ja/soundproof-room/bouon-dchiseinou-meyasu/)で一覧にしています。

## 床・壁・天井の構造｜浮き床と二重壁

Dr-50を超える防音室は、既存の部屋の中に、もう一つの部屋を浮かせて作ります。

この工法をボックスインボックス（ルームインルーム）と呼びます。

- <strong>浮き床</strong> : 防振ゴムやグラスウールの上に床を組み、建物の床と縁を切る。重低音の振動を止める中心になる
- <strong>二重壁</strong> : 既存の壁から離して、もう一枚の壁を立てる。間の空気層と吸音材で音を止める
- <strong>浮き天井</strong> : 防振吊り具で天井を吊り、上の階や屋根への伝わりを抑える
- <strong>防音ドア</strong> : 重く、四周をパッキンでふさいだ専用の扉。ここが弱いと全体の性能が落ちる

デメリットは、<strong>部屋が一回り狭くなる</strong>ことです。

壁・床・天井の厚みで、内側は各辺15〜20cm前後小さくなり、天井も低くなります。

6畳を工事すると、完成後は5畳台になると考えておいてください。

防振の素材と工法の流れは、[防振技術のトレンド](/ja/knowledge/vibration-isolation-technology-trend/)で紹介しています。

ドアと窓が音漏れの弱点になる理由は、[防音室の窓とドアは音漏れの弱点](/ja/soundproof-room/door-window-weak-points/)で解説しています。

## 室内の響きを整える｜吸音・残響・低音のこもり

防音と、部屋の中の音の良さは別の問題です。

音を外に出さない部屋は、そのままだと響きすぎたり、低音がこもったりします。

### 残響時間の目安

映画は、響きを少なめにした部屋のほうがセリフが聞き取りやすくなります。

| 部屋の広さ | シアター向けの残響時間の目安 |
| :--- | :--- |
| 6畳 | 0.20〜0.25秒 |
| 8畳 | 0.25〜0.30秒 |
| 10畳 | 0.30〜0.35秒 |

カラオケも兼ねる場合は、これより少し長め（0.3〜0.4秒前後）にしないと、声が響かず歌いにくくなります。

### 小さな部屋ほど低音にムラが出る

向かい合う壁の間では、特定の低い音が強まったり弱まったりします（定在波）。

壁の間隔が2.7m（3畳の長辺くらい）なら約64Hz、1.8mなら約95Hzで起きやすく、どちらもサブウーファーの音域です。

座る場所によって低音が大きすぎたり、ほとんど聞こえなかったりするのはこのためです。

- <strong>部屋の形</strong> : 正方形は定在波が重なりやすい。長方形のほうが整えやすい
- <strong>座る位置</strong> : 部屋のちょうど真ん中や壁際は避ける
- <strong>部屋の角</strong> : 低音がたまりやすい角に、厚い吸音材（ベーストラップ）を置く

ベーストラップの置き方は、[ベーストラップの設置ガイド](/ja/diy/bass-trap-installation-guide/)で解説しています。

## 防音室にプロジェクター・5chを置くときの配置

### スクリーンの大きさは「完成後の内寸」で決める

| スクリーン（16:9） | 幅×高さ | 置ける広さの目安（完成後） |
| :--- | :--- | :--- |
| 80インチ | 約177×100cm | 3畳（短辺の壁に置ける） |
| 100インチ | 約221×125cm | 4.5〜6畳 |
| 120インチ | 約266×149cm | 8畳以上 |

3畳の部屋は、工事後の短辺が1.4m台になることがあり、100インチは入りません。

スクリーンの幅だけでなく、左右のスピーカーを置く余白も残してください。

### 5ch・天井スピーカーは遮音層に穴を開けない

5.1chは、前の3本・後ろの2本・サブウーファーの構成です。

天井にスピーカーを足す配置（ドルビーアトモスなど）では、<strong>天井に埋め込む工事が音漏れの最大の原因</strong>になります。

- <strong>埋め込むなら</strong> : スピーカーの背面を防音の箱（バックボックス）で覆う
- <strong>吊るすなら</strong> : 防振金具で吊り、遮音層を壊さない
- <strong>サブウーファー</strong> : 床に直置きせず、防振台に載せる

### プロジェクターの固定と配線

プロジェクターを天井から吊る場合も、天井の遮音層を貫通させない吊り方を選びます。

配線は、壁に穴を開けて通すと音の抜け道になります。

工事の段階で、防音処理をした配線用の管（スリーブ）を入れておくのが確実です。

## 換気・空調・排熱

防音室は気密が高く、プロジェクターやAVアンプの熱がこもりやすい部屋です。

2時間の映画を見る間に、室温が上がり、CO2も増えます。

- <strong>換気</strong> : 消音ボックスや曲がったダクトを通し、換気口から音が漏れないようにする
- <strong>エアコン</strong> : 配管の穴（スリーブ）を遮音パテで埋め、運転音の小さい機種を選ぶ
- <strong>静かな場面の音</strong> : 換気扇とエアコンの音は、映画の静かな場面で意外に目立つ

2人以上で長く観るなら、CO2が上がりやすくなります。

防音室のCO2の上がり方と換気の目安は、[防音室は酸欠になる？CO2の上がり方](/ja/soundproof-room/ear-pressure-tinnitus-dizziness/)で試算しています。

空調と換気の選び方は、[防音室のエアコン選びと静音化の極意](/ja/soundproof-room/proofroom-aircondition-select/)にまとめています。

## ホームシアター用防音室の費用｜3〜6畳の書斎サイズで試算

注文住宅では、書斎や趣味の部屋を防音のホームシアターにする人が少なくありません。

ここでは、書斎によくある3〜6畳を、<strong>建てたあとにリフォームで防音室にする</strong>場合で費用を試算しました。

| 広さ | 昼〜夜の中音量（Dr-50前後） | 夜も重低音（Dr-60以上＋浮き床） |
| :--- | :--- | :--- |
| 3畳 | 約120万〜200万円 | 約200万〜300万円 |
| 4.5畳 | 約150万〜250万円 | 約230万〜370万円 |
| 6畳 | 約180万〜300万円 | <strong>約250万〜450万円</strong> |

金額は、施工会社が公表している6〜8畳の価格をもとに、ドア・換気・電気など広さにかかわらずかかる費用を残して、当サイトで小さい部屋に割り戻した概算です。

実際の金額は建物の構造と工事範囲で大きく変わるため、必ず複数社の見積もりで確かめてください。

### 坪単価に直すと

防音工事は、1畳あたり40万〜60万円前後で語られることが多く、1坪（2畳）に直すと80万〜120万円前後です。

ただし、ドアや換気の費用は部屋が小さくても減らないため、<strong>3畳のような小さな部屋ほど1畳あたりは割高</strong>になります。

畳数別の公表価格は、[防音室リフォームの費用相場](/ja/money/soundproof-reform-cost-by-tatami/)で6社分を比べています。

### 機材の費用は別にかかる

| 機材 | 価格の目安 |
| :--- | :--- |
| AVアンプ（7ch以上） | 7万〜15万円 |
| スピーカー一式（5.1ch〜） | 10万〜30万円 |
| 4Kプロジェクター | 15万〜35万円 |
| スクリーン（100〜120インチ） | 5万〜15万円 |
| 合計 | 約37万〜95万円 |

機材は選ぶ製品で何倍も変わるため、ここでは入門〜中級の目安として示しています。

### 新築時に組み込むと割安になりやすい

リフォームでは、今ある内装を壊す費用と、部屋が狭くなる分の損が出ます。

注文住宅の設計段階で組み込めば、壁や床の下地を最初から防音用に作れるため、同じ性能でも割安になりやすくなります。

間取りの段階で決めておきたいことは、[注文住宅で防音室を作る間取りのポイント](/ja/soundproof-room/custom-home-soundproof-room-layout/)にまとめています。

注文住宅で防音室にかかる費用の全体は、[注文住宅の防音室の費用](/ja/money/custom-home-soundproof-price-guide/)で解説しています。

### 予算別の割り切り方

| 予算 | できること | 割り切るところ |
| :--- | :--- | :--- |
| 100万円前後 | ユニット防音室（Dr-35〜40）で中音量の映画 | 夜の重低音、大きなスクリーン |
| 200万円前後 | 3〜4.5畳のDr-50工事 | 夜の大音量。サブウーファーは控えめに |
| 300万〜450万円 | 6畳のDr-60＋浮き床 | ほぼなし。換気と響きの調整まで任せられる |

「思ったほど低音が消えない」という後悔は、たいてい予算の段で浮き床を削ったときに起きます。

夜に重低音を鳴らすつもりなら、スクリーンを一回り小さくしてでも、床の工事を残すほうが満足しやすいといえます。

## ユニット防音室で足りる場合・足りない場合

ヤマハやカワイのユニット防音室は、Dr-35〜40が中心です。

販売店では、カワイの「ナサール」をシアター用途で紹介している例もあります。

| ユニット防音室で足りる | 工事が必要 |
| :--- | :--- |
| 昼〜夕方に中音量で観る | 夜に重低音を鳴らしたい |
| サブウーファーを使わない、または小さく鳴らす | 5.1ch以上で迫力を出したい |
| 2畳前後の部屋で一人で観る | 100インチ以上のスクリーンを使いたい |
| 賃貸で、引っ越しのときに持っていきたい | 持ち家で、部屋ごと作り替えられる |

ユニット防音室は床に置くだけなので、重低音の振動は床から伝わります。

サブウーファーを使うなら、防振台と床の防振マットは欠かせません。

## 地下室シアターは防音に向くが、浸水には弱い

筆者は子どものころから地下室にあこがれがあり、そこを防音室にして、好きなだけ映画を観て大声を出すのが夢でした。

今でも地下室にひかれるのは、防音のためだけではありません。

台風の風の音や雷の音が苦手で、そんな夜に逃げ込める場所がほしいと思っているからです。

### 地下室は防音にいちばん向いている

地下室は周りを土に囲まれているため、外に漏れる音も、外から入る音も少なくなります。

施工会社の事例でも、地下室はDr-65以上を出しやすい場所として紹介されています。

住宅の地下室は、条件を満たせば延べ床面積の3分の1まで容積率に算入されない緩和もあります（建築基準法52条3項）。

一方で、ある住宅情報サイトは、注文住宅の地下室の坪単価を100万〜150万円程度と案内しており、地上の部屋よりかなり割高です。

### 大雨のときは、地下がいちばん危ない

台風や雷の「音」から逃げる場所として、地下室は理想的です。

ただし、<strong>大雨で地上が浸水したときは、地下室がいちばん危険な場所</strong>になります。

- <strong>水は一気に入る</strong> : 地上の浸水が浅くても、出入口の高さを超えると一気に流れ込み、短時間で水位が上がる（練馬区・新宿区などの注意喚起）
- <strong>ドアが開かなくなる</strong> : 京都大学防災研究所の実物大の実験では、ドアの前の水深が約40cmで、ドアを開けて逃げるのが難しくなると報告されている
- <strong>階段も危ない</strong> : 同じ研究グループの実験では、地上の水深が約30cmで、階段を上って逃げるのが難しくなるとされている
- <strong>外の様子が分からない</strong> : 防音が効いているほど、雨の音や外の騒ぎに気づきにくい

防音室の中は、外の音が聞こえないことそのものが弱点になります。

### 地下室シアターを作るなら確かめること

- <strong>ハザードマップ</strong> : 自治体の洪水・内水のハザードマップで、浸水が想定される場所でないかを確かめる
- <strong>出入口の高さ</strong> : 地下への入口を道路より高くし、止水板を付けられるようにする
- <strong>排水ポンプ</strong> : 雨水が入ったときに排水できるポンプと、停電への備えを用意する
- <strong>大雨のときは使わない</strong> : 大雨・洪水の警報が出たら、地下には入らず上の階へ移る
- <strong>外の情報を受け取る</strong> : スマホの通知や、外の音を知らせる仕組みを用意する

防音室の中で外の警報やインターホンに気づく方法は、[防音室でインターホンが聞こえない時の対策](/ja/soundproof-room/notice-outside-sounds-in-booth/)で紹介しています。

地下室は、雷や風の音から逃げる「静かな部屋」にはなりますが、水害の避難所にはなりません。

建物の安全に関わる設計は、建築士や施工会社と必ず相談してください。

## よくある質問

### 防音室でホームシアターを作るとき、何畳あればいいですか？

100インチのスクリーンと5.1chを置くなら、完成後で4.5〜6畳あると無理がありません。

工事で内側が狭くなるため、元の部屋は6畳以上あると安心です。

### ホームシアターの防音はDr-50で足りますか？

昼間や夜でも控えめな音量なら、Dr-50で足りることが多いと考えられます。

夜に重低音まで鳴らすなら、Dr-60以上と浮き床を目安にしてください。

### 防音室にプロジェクターは置けますか？

置けます。

天井から吊る場合は、遮音層を貫通しない防振金具を使い、配線は工事の段階で防音処理をした管を通します。

## まとめ｜重低音を鳴らす時間帯で性能と予算が決まる

- <strong>難所は重低音</strong> : 63Hzの音は500Hzより約18dB多く漏れる。Dr値の数字だけでは判断できない
- <strong>必要なDr値</strong> : 昼・控えめならDr-40〜45、夜も重低音を鳴らすならDr-60以上＋浮き床
- <strong>費用の目安</strong> : 6畳でDr-50前後なら約180万〜300万円、Dr-60以上＋浮き床なら約250万〜450万円（概算）。機材は別に約37万〜95万円
- <strong>小さな部屋</strong> : 3畳は1畳あたり割高。スクリーンは80インチ前後が限界
- <strong>地下室</strong> : 防音には最適だが、大雨の浸水ではいちばん危ない。ハザードマップを先に確かめる
