島村楽器の防音室は、ヤマハ・カワイなどの取扱製品を、展示のある店舗で体験して選べます。

まず公式の展示店舗一覧と在庫情報で候補を探し、希望機種・楽器持込み・試奏の可否を店舗に確認してください。

<strong>S-OTODASUのような専売の簡易型もありますが、展示機種と購入・配送条件は店舗や販売窓口で異なります。</strong>

製品のタイプから選びたい方は、[防音室おすすめ比較と用途・予算別の入口](/ja/soundproof-room/bouon-osusume-hikaku/)を先に確認できます。

## 島村楽器で防音室を見る・買うと何が違うか

島村楽器は防音室メーカーではなく、複数メーカーの製品や工事を相談できる販売窓口です。

防音室を調べてきたさししです。

私が公式サイトで確かめたかったのは、「近くのお店で相談できること」と「実物が置いてあること」が同じなのか、という点でした。

[公式の防音室紹介サイト](https://info.shimamura.co.jp/soundproof/)は、取扱製品と展示・在庫をまとめて案内しています。

| 公式に案内される取扱い | 見る・相談する内容 | 注意点 |
| :--- | :--- | :--- |
| ヤマハ | アビテックスのユニット、防音ドア、調音パネル | 希望の畳数・Dr値の展示があるか確認 |
| カワイ | ナサールのユニット、オーダータイプなど | 定型と自由設計で見積もり範囲が違う |
| 簡易防音室 | OTODASU、YAMAHA DIY.M、ライトルームなど | 本格ユニットと同じ遮音性能とは限らない |
| 中古防音室 | ヤマハ・カワイのユニット | カワイ中古は公式案内で関東のみ。最新の対応地域を確認 |
| 部屋全体の防音 | カワイの自由設計、在来工事など | 自宅の条件を伝えて個別に相談 |

複数メーカーを同じ窓口に相談できることが、比較のしやすさにつながります。

ただし、全店舗に両メーカーの実物が並んでいるわけではありません。

ナサールの種類を先に知るなら、[カワイ防音室の価格・構造・ヤマハ比較](/ja/soundproof-room/kawai-nasal-soundproof-room-guide/)を確認してください。

## 島村楽器の防音室店舗は展示一覧と在庫で探す

[防音室展示店舗の公式一覧](https://info.shimamura.co.jp/soundproof/shoplist)には、「防音ショールーム」と「防音室展示店舗」が載っています。

公式案内では、防音ショールームは複数モデルを比較体感できる場所とされています。

| 探す順番 | 確認する場所 | 確かめること |
| :--- | :--- | :--- |
| 行ける店舗を選ぶ | 展示店舗一覧 | 所在地、営業時間、予約方法 |
| 希望機種を絞る | 店舗の防音室在庫情報 | メーカー、型番、畳数、Dr値、新品・中古 |
| 実物を見られるか確認 | 個別の商品ページと店舗 | 「展示」か「倉庫保管」か、現在も見られるか |
| 試奏を相談する | 店舗への連絡 | 楽器持込み、音出し、同伴者、所要時間の条件 |

一覧には、たとえば立川店、ミーナ町田店、イオンモール名古屋茶屋店、ららぽーとEXPOCITY店などがあります（2026年11月6日確認）。

展示機種や台数は変動するため、店舗名だけで目的の製品を試せるとは判断できません。

<strong>「在庫がある」と「来店時に組み立てた実物に入れる」は別です。</strong>

予約前には、次のように具体的に伝えると確認が進めやすくなります。

> 防音室の購入を検討しています。〇〇という楽器で、△△畳・Dr-□□の機種を比較したいです。現在の展示と、楽器持込みで試奏できる日時・条件を教えてください。

## 防音室の試奏では中の響きと外への音を分けて確認

公式サイトは、展示店で楽器を持ち込んだ試奏も可能と案内しています。

実際の受付条件や対応できる楽器は、訪問する店舗に確認してください。

| 試すこと | 確認する理由 | 自宅との違い |
| :--- | :--- | :--- |
| 同じ楽器・同じ曲や声量で比較 | 室内の反響、こもり、演奏のしやすさを見る | 展示品の吸音材配置が購入品と同じか確認 |
| 同伴者に外で聞いてもらう | 室内の感想と音漏れを分ける | 店内の音が漏れ音を目立たなくすることがある |
| 椅子に座る・楽器を構える | 肘、弓、ギターのネック、扉との距離を見る | 自宅の机・椅子の寸法も持参する |
| 換気設備を動かしてもらう | 風の音や収録への影響を見る | 自宅の空調・排気条件は別に計画する |
| 配線穴と扉を確かめる | ケーブル経路、ドアの重さと開閉範囲を見る | 設置向きや周囲の家具で使い勝手が変わる |

店頭体験は選ぶ材料になりますが、自宅の隣室や上下階での性能保証ではありません。

低音やペダルの振動、夜の周囲の静かさは、建物の条件も伝えて相談します。

動画は候補の寸法や操作を見る補助に使えます。

録音・再生時の音量調整で聞こえ方が変わるため、動画だけで遮音量を比較しないでください。

### エアコン・吸音材・遮音性能は上位ユニットと分けて考える

ミーナ町田店の公式説明では、12×12はエアコン取付不可、天井パネルを回して換気する方式です。

吸音材は別売で、簡易型のため密閉性はないと案内されています。

この仕様を全モデル共通と考えず、購入する型番で確認してください。

同ページの「Dr-15程度」は販売店の説明上の目安です。

ユニット型のDr-35・Dr-40と、同じ試験条件を確認せずに差し引き計算はできません。

私なら、長時間の配信に使う場合は、広さと同じくらい暑さ対策を先に確認します。

机が入っても、PCの排熱や換気音が使い方に合わなければ続けにくいからです。

低価格モデルの限界と排熱の考え方は、[格安防音室の夏の暑さと中古購入の注意点](/ja/soundproof-room/budget-soundproof-booth-comparison/)で確認できます。

## 来店前に図面を用意し、購入前に設置総額を確認

実物を見る前に、自宅の間取りと使い方をまとめておくと、見積もりの条件をそろえられます。

| 持参する情報 | 見積もりで確認する内容 |
| :--- | :--- |
| 楽器名、声量、使う時間帯 | 必要な遮音性能、振動対策 |
| 部屋・天井・梁の寸法、設置階 | 本体の寸法・重量、床の確認、作業空間 |
| 玄関・廊下・階段の寸法や写真 | 搬入経路、追加運搬費、組立費 |
| 机・椅子・PCの寸法と使い方 | 内寸、電源、配線、換気・冷房 |
| 賃貸契約・退去や引っ越しの予定 | 貸主等の許可、原状回復、撤去・移設 |

防音室内の換気と、部屋全体の冷房・温湿度管理は合わせて考えます。

換気口をふさがず、結露やカビが出ない使い方も相談してください。

設置の確認項目は、[防音室の寸法・重量・搬入チェックリスト](/ja/soundproof-room/bouon-setti-checkpoint/)を使えます。

キャンペーンや分割払いは、対象機種・期限・工事費の扱いを販売店に確認します。

割引や手数料だけで判断せず、工事を含む支払総額を書面で比較してください。

金融商品の条件は、販売店・信販会社にも確認が必要です。

## よくある質問

### 近所の島村楽器ならどこでも防音室を試せますか？

相談できる店舗と、実物の展示がある店舗は同じではありません。

展示店舗一覧で絞り、希望機種の展示・試奏条件を店舗に確認してください。

### 島村楽器ならヤマハとカワイを同じ日に比較できますか？

両方の希望機種が展示され、試奏の予約が取れる店舗なら比較できます。

全店で同じ比較ができるわけではないため、メーカー名だけでなく型番・Dr値まで伝えて確認します。

### 中古防音室も試せますか？

展示中か、倉庫保管中かで異なります。

個体の状態、付属品、組立・運送、保証範囲も含めて店舗に確認してください。
