カワイ防音室「ナサール」は、ライト0.8畳・Dr-30の本体標準価格が税込55万円で、組立・運送費は別です。

定型サイズで足りればライトなどのユニット、柱を避けたい場合はカスタム、部屋全体を使うなら自由設計が候補です。

<strong>ヤマハと比べるときは、同じDr値・近い内寸で、設置総額と室内の響きを確かめて選びます。</strong>

簡易ブースも含めた予算別の入口は、[防音室おすすめ比較と用途別の選び方](/ja/soundproof-room/bouon-osusume-hikaku/)で確認できます。

## カワイ防音室ナサールの価格は本体と設置費を分けて見る

「ナサール」はカワイ音響システムが案内する防音ルームです。

防音室を調べてきたさししとして、私が気になったのは「自由設計ができる」という説明で、どこまで価格を比較できるのかでした。

まず、金額が公表されているユニットから見ます。

## ナサールの構造とDr遮音性能はタイプごとに確認

カワイの公式FAQは、元の部屋の中に独立した防音空間を作る「ルームインルーム工法」を説明しています。

遮音に使う壁・天井と、室内の響きを整える吸音材は、役割が違います。

| タイプ | 公式に案内される遮音性能・構造 | 読み分ける点 |
| :--- | :--- | :--- |
| ライト・スタンダード・カスタム | Dr-30・Dr-35・Dr-40 | 音量・周囲の環境・使う時間帯で性能を選ぶ |
| 高遮音UWS | Dr-50、独立二重壁構造・木製二重防音ドア | 通常のユニットとは別シリーズ |
| オーダー・ルームプラン | OHX：単体Dr-35、OKX：単体Dr-40。遮音パネルと乾式浮床 | 建物と合わせた総合性能を、単体性能と混同しない |

出典：[カワイ公式FAQ](https://www.kawai-os.co.jp/faq/)、[高遮音UWS](https://www.kawai-os.co.jp/product/unit04/)、[ルームプラン](https://www.kawai-os.co.jp/product/order05/)。

Drは周波数ごとの遮音性能を評価する等級です。

「Dr-40ならすべての音が40dB下がる」「深夜でも必ず使える」とは言えません。

特に床を伝わる打撃・振動は、空気中の音と別に検討します。

UWSも、単体Dr-50を選べば自宅で生ドラムが問題なく使える、という意味ではありません。

カワイは重低音の対策について、設置場所の調査と専門家による音響設計が必要と案内しています。

室内の響きは、吸音パネルの種類・枚数・配置でも変わります。

「カワイは暖かい音、ヤマハはクリア」とメーカー名だけで音の好みを決めず、使う楽器と用途で確認してください。

## カワイ防音室の自由設計はどこまで対応し、値段はいくらか

### サイズ調整するユニットと自由設計は別の選択肢

| 選択肢 | 公式に確認できる範囲 | 向いている相談 |
| :--- | :--- | :--- |
| ライト | 0.8〜4.3畳の定型9サイズ | 小型ユニットが置けるか |
| スタンダード | 天井低音吸音パネル、高音域用・全帯域用の吸音パネルなど | 定型サイズで響きも整えたい |
| カスタム | 2.0〜10畳、110mm刻み。柱変形加工の最小寸法220mm | 柱を避け、部屋の余りを減らしたい |
| オーダー・ルームプラン | 部屋を生かす自由設計。音調内装板などを用途に合わせて提案 | 部屋全体を防音室にしたい |
| オーダー・フリープラン | 建築会社との分担、スタジオやサロンホールの設計にも対応 | 新築や大きな空間を建築段階から相談したい |

出典：[スタンダード](https://www.kawai-os.co.jp/product/unit02/)、[カスタム](https://www.kawai-os.co.jp/product/unit03/)、[フリープラン](https://www.kawai-os.co.jp/product/order07/)と各製品ページ。

カスタムは、どの寸法にも無制限に合わせられる製品ではありません。

引き違いサッシや防音引き戸のオプションは、MKCX（Dr-40）では対応しないなどの制限があります。

梁・柱を避けられるかは、位置と寸法を図面に入れて相談します。

## ヤマハとカワイの防音室比較は同じDr値・近い内寸で

同じ「1.5畳・Dr-35・標準高さ」を入り口に比較すると、次のようになります。

| 比較項目 | ヤマハ セフィーネNS | カワイ ナサール ライト |
| :--- | :--- | :--- |
| 型番 | AMDB15H | LHSX13-18 |
| 本体価格（税込） | 979,000円（希望小売価格） | 847,000円（本体標準価格） |
| 室内寸法／幅×奥行×高さ | 1,325×1,766×1,964mm | 1,262×1,702×1,973mm |
| 遮音性能 | Dr-35 | Dr-35 |
| 確認したい違い | 机や楽器を置いたあとの余裕、標準装備、響き | 同左。安い本体で必要条件を満たせるか |

出典：[ヤマハ セフィーネNSの公式仕様](https://jp.yamaha.com/musical-instruments/soundproofing/explore/ready-made-rooms/cefine-ns/index.html)・同ページのカタログ、[カワイ ライトタイプ](https://www.kawai-os.co.jp/product/unit01/)。

本体価格の差は132,000円ですが、内寸や装備は同一ではありません。

見積額の差や、響きの好みまでこの表からは決められません。

また、ヤマハにも[自由設計のAFEシリーズ](https://jp.yamaha.com/products/soundproofing/customized_rooms/afe_series/index.html)があります。

「自由設計ならカワイしかない」という比較にはしないでください。

私なら、価格差を確かめる前に、必要な楽器と家具を両方の内寸に置いて比べます。

安くても使いたい姿勢で収まらなければ、買い直しにつながるからです。

具体的な寸法の考え方は、[ユニット防音室のサイズと内寸の確認方法](/ja/soundproof-room/soundproof-room-size/)を参考にできます。

## 設置前は重量・天井・搬入・換気を確認する

| 確認項目 | 販売店へ渡す情報・聞くこと |
| :--- | :--- |
| 床 | 建物の図面、設置階、本体・楽器・人の重量。設置可否は専門家に確認 |
| 天井・梁 | 最低天井高、梁の位置、組立作業に必要な余白 |
| 搬入・扉 | 玄関、階段、廊下の幅と曲がり角、扉の開閉スペース |
| 空調・換気 | エアコンの可否と配管経路、換気扇の運転音、排気先 |
| 契約・撤去 | 賃貸の許可、原状回復、移設できる範囲 |

カワイのFAQでは、ナサールに機械換気設備を標準装備すると案内しています。

<strong>換気扇があっても、冷房の代わりにはなりません。</strong>

室温・湿度を確認し、結露やカビを防ぐ運用も相談します。

オーダータイプの室内天井高は、防振床・遮音天井によって元の部屋より20〜25cm低くなると公式FAQにあります。

仕上がりの内寸が必要な高さを満たすか、図面で確かめてください。

設置条件の整理には、[防音室導入前の寸法・重量・搬入チェック](/ja/soundproof-room/bouon-setti-checkpoint/)も使えます。

## カワイ防音室のローンは販売店と対象期間を確認

ナサールを対象とする分割払いの案内はあります。

たとえば[カワイ大宮ショップの公式案内](https://shop.kawai.jp/local/infoview.aspx?fid=21485&id=133006)には、ナサールを含む無金利キャンペーンが掲載されています（2026年11月6日確認）。

ただし、全国共通・常時利用可能な条件とは確認できません。

| 契約前に聞くこと | 比較する理由 |
| :--- | :--- |
| 対象店舗・型番・申込期限 | 別の店舗や注文日でも同条件とは限らない |
| 頭金・回数・手数料・審査 | 月額だけでなく支払総額を確認する |
| 工事・運送・空調費を含められるか | 本体だけの分割では別の現金支出が残る |
| 繰上返済・キャンセル条件 | 注文後の変更や返済方法を把握する |

金融商品の契約条件は、販売店・信販会社に確認してください。

比べる項目は、[防音室ローン・分割払いの確認ポイント](/ja/money/soundproof-room-loan-guide/)でも整理できます。
