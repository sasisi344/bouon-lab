## ヤマハ防音室の値段はサイズとDr値で決まる：楽器別にいくらから

Dr値は、防音室の遮音性能を表す等級です。

ヤマハの公式説明では、Dr-35はピアノが日常会話程度の音量まで下がる標準タイプ、Dr-40はトランペットやサックスなど大音量に対応する高遮音タイプです。

数値は当社実験値で、設置環境や建物構造により異なる場合があるとも書かれています。

Dr値の見方は、[遮音性能の基準「D値」とは？楽器・用途別の目安](/ja/soundproof-room/bouon-dchiseinou-meyasu/)で比べています。

## ヤマハ防音室の口コミ：価格に見合うか、良い点と悪い点

使った人の声は個人の感想で、防音性能や価格の保証ではありません。自分の部屋と使い方で足りるかを考える材料として、同じ話題の良い点と悪い点を並べます。

### 使った人の声（個人ブログ・note 6件）

確かめた個人ブログ・note 6件は、購入3件・レンタル3件で、掲載年が分かる5件は2019〜2026年です（2026年11月に確認）。使い方は配信と楽器の練習が中心です。

6件のうち、遮音を良い点に挙げたのは5件、夏の暑さ・換気・エアコンに触れたのは5件でした。

| 話題 | 良い点（声） | 気になる点（声） |
| :--- | :--- | :--- |
| 遮音 | 外にほとんど聞こえない、夜中に大声を出しても問題ないと感じる、と書く人がいる | 全くは漏れない、同居の家族には微かに聞こえる、低音は漏れてドラムは向かない、インターホンに気づきにくい、と書く人がいる |
| 響き | 調音パネルや反射パネルで響きがよく、マイクの声がクリアと書く人がいる | 内壁が硬く反響して吸音材を足した人、反響が多めで本格的な録音向きではないと書く人がいる |
| 暑さ・換気 | エアコン付きは早く冷える、と書く人がいる | エアコンなしの夏は熱がこもる、換気扇は空気を入れ替えるだけで涼しくならない、換気扇の音をマイクが拾う、と書く人がいる |
| 狭さ | 1.2畳は少し広く感じるほど、と書く人がいる | 1.5畳でモニター2枚は窮屈、0.8畳はクラリネットには窮屈、6畳の部屋に置くと圧迫感、と書く人がいる |
| 価格の納得感 | 買って良かった、長期で見るとスタジオ通いより安い、と書く人がいる | 「人生最大の買い物」と書く人や、新品・中古・レンタルを比べてレンタルを選んだ人がいる |
| 組立・移設 | 組立は約3時間、3人で床から組み立てた、と書く人がいる | 撤去や移設に費用がかかる、賃貸は許可と床の耐荷重の確認が難関、と書く人がいる |

苦情の例も1件あります。ある人は、3階に置いたあと下の階に入居者が入り、苦情が続いて使用禁止になり引っ越したと書いています。この1件から、苦情が出るか出ないかは言えません。

レンタルの利用者は、設置業者の手配を任せられた、早く返せて解体・廃棄の手間がない、と書いています。

## ヤマハ防音室の価格についてよくある質問

### ヤマハの防音室はいくらからですか？

本体は、税込770,000円（0.8畳・Dr-35・標準壁）からです。音場パネルが付かないカスタムベースモデルは726,000円（0.8畳）からで、どちらも組立費・運送費は別です。

### セフィーネNSのDr-35とDr-40は価格がいくら違いますか？

同じ畳数で、約31万〜52万円の差です。

0.8畳は、770,000円と1,078,000円で、差は308,000円です。

### ヤマハ防音室の価格に組立費・運送費は含まれますか？

含まれません。ヤマハミュージック直営店は、組立・運送料は本体価格に含まれないと案内しています。

札幌店の掲載例では、札幌市内1階で運搬費41,800円、組立費41,800〜84,700円です。

### ヤマハの防音室は値上がりしましたか？

2023年1月1日出荷分から約13〜15%の改定があり、0.8畳・Dr-35は671,000円から770,000円になりました。

### ヤマハの防音室は暑いですか？

確かめた個人ブログ6件のうち5件が、夏の暑さ・換気・エアコンに触れていました。

エアコンがない、または切った状態では熱がこもる、エアコン付きでも狭くて適温を保ちにくい、という声があります。換気扇は空気を入れ替えるだけで涼しくはならないと書く人もいます。

エアコンの取付費は本体と別で、付けられるかは型番と畳数を伝えて販売店に確かめます。

## ヤマハ防音室の価格のまとめと、次にやること

- <strong>本体の価格帯</strong> : 標準壁で770,000円（0.8畳・Dr-35）から2,684,000円（4.3畳・Dr-40）まで
- <strong>別にかかる費用</strong> : 組立費・運送費・工事費・エアコン・オプションは別
- <strong>古い価格表</strong> : 2023年1月1日出荷分から約13〜15%の改定があり、改定前の数字は今の価格ではない
- <strong>使った人の声</strong> : 遮音と響きを良い点に挙げる人がいる一方、暑さ・狭さ・撤去や移設の費用も書かれている

次にやることは1つ、用途から畳数とDr値を決め、同じ型番で、本体・組立・運送・エアコンなどの見積もりを取ることです。

私なら、同じ型番で2か所から、含まれる範囲をそろえた見積もりを取ります。
