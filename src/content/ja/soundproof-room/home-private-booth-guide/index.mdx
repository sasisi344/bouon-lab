個室ブースを自宅に置くなら、選択肢は<strong>デスクを囲むパーティション型（6万円台〜）</strong>、<strong>天井つきの1人用ブース（35万〜44万円前後）</strong>、<strong>月額レンタル（1万円台〜）</strong>の3つです（2026年10月時点の公式価格の例）。

どれも防げるのは<strong>会話の声と、家族の視線</strong>までで、楽器や歌の音を止める防音室とは別物です。

「Web会議のたびに、家族に『静かにして』と頼むのがつらい」。

「自分の声が筒抜けで、話す内容を選んでしまう」。

個室ブースを探す人の多くは、防音の数字よりも、<strong>気兼ねなく話せる自分だけの場所</strong>を求めています。

この記事では、自宅に置ける個室ブースの種類と価格、買ってから後悔しやすい防音・暑さ・設置の注意点を整理します。

## 個室ブースとは？防音室との違い

個室ブースは、1〜数人が入れる箱型の個室で、オフィスや駅でWeb会議や電話に使われているものです。

ワークブース、テレワークブース、集中ブースとも呼ばれます。

防音室と似ていますが、作られた目的が違います。

| 比べる点 | 個室ブース | 防音室 |
| :-- | :-- | :-- |
| 目的 | 会話の声と視線をさえぎる | 楽器・歌などの大きな音を外に漏らさない |
| 防音の表し方 | 「騒音軽減」「◯dBカット」など。条件がメーカーごとに違う | Dr値（Dr-30〜Dr-40など）の等級 |
| 見た目 | 窓やガラスのドアがあることが多い | 窓がないか小さく、密閉されている |
| 向いている音 | 話し声、キーボード、電話 | ピアノ、管楽器、歌、配信の大声 |
| 1人用の価格の例 | 6万円台〜40万円台（自宅向けの例） | 7万円台〜100万円超 |

<strong>話す声を家族に聞かれたくないなら個室ブース、楽器や歌の音を近所に漏らしたくないなら防音室</strong>、と考えると選び間違えません。

## 自宅に置ける個室ブースの種類と価格

自宅向けに選びやすいものを、メーカー・レンタル会社の公式ページで確認した価格の例とあわせてまとめました（2026年10月18日確認）。

| 種類 | 価格の例 | 防げるもの | 向いている人 |
| :-- | :-- | :-- | :-- |
| <strong>パーティション型</strong>（デスクを囲む。天井なし） | 66,000円（4枚）〜170,500円（6枚） | 視線、周りの話し声の反響 | まず安く集中できる場所を作りたい |
| <strong>天井つきの1人用ブース</strong> | 349,800円（Easy Booth、送料別）、437,800円（サンワサプライ SPT-PB009） | 視線、会話の声の一部 | 毎日Web会議がある在宅ワーカー |
| <strong>オフィス向けの高機能ブース</strong> | オープン価格が多い | 視線、会話の声。エアコン付きもある | 自宅の一室を業務用に使い込む人 |
| <strong>月額レンタル</strong> | 月14,900円〜（レントプラス CONBOX） | 製品による | 買う前に試したい、短期間だけ使う |

出典: [サンワサプライ ワークブース](https://www.sanwa.co.jp/product/desk_rack/workbooth/index.html)、[Easy Booth（CONOC）](https://workbooth.conoc-dx.co.jp/)、[レントプラス](https://www.rentplus.jp/boothlineup/)

### パーティション型

フェルトなどの吸音パネルで、デスクの周りを囲むタイプです。

サンワサプライのパーティションブースは、4枚入りで66,000円、6枚入りで170,500円（いずれも税込）です。

天井がないため、声は上から抜けます。

<strong>防音というより、視線を切って集中するための道具</strong>と考えてください。

### 天井つきの1人用ブース

四方と天井を囲み、ドアで出入りする、いわゆる「個室」のタイプです。

CONOCのEasy Boothは349,800円（税込・送料別）で、重さ約40kg、大人2〜3人で10分ほどで組み立てられます。

外寸は幅1,270mm×奥行900mm×高さ1,900mmで、換気ファン・照明・2口の電源タップが付いています。

サンワサプライのSPT-PB009は437,800円（税込）で、Web会議や個人作業向けの「セミクローズ型」と案内されています。

どちらも公式に遮音の数値はなく、Easy Boothは<strong>「完全防音の製品ではありません」</strong>と明記しています。

### オフィス向けの高機能ブース

駅やオフィスで見かけるテレキューブのような製品は、エアコンを備えたものもあります。

ただし、多くはオープン価格で、設置工事を前提にしています。

たとえばアイリスチトセのテレキューブAIRは、<strong>天井高2,400mm以上</strong>と段差のない床を設置の条件にしています（[アイリスチトセ](https://www.irischitose.co.jp/telecube/)）。

### 天井高2,400mmは「どの家にもある高さ」ではない

天井高2,400mmは、今の新築住宅でよく使われる高さですが、法律で決まった基準ではありません。

建築基準法（施行令第21条）が居室に求める天井高は、<strong>2.1m以上</strong>です。

ハウスメーカーの多くが標準仕様を2,400mmにしているため「普通の高さ」と思われがちですが、いつから一般的になったかを示す公的な基準はありません。

実際に、<strong>築年数の古いマンションでは天井高2.2〜2.3m程度の住戸も見られます</strong>（[野村不動産ソリューションズ ノムコム](https://www.nomu.com/mansion/library/trend/ai/ai27.html)）。

築年数の古い家ほど、天井高2,400mm以上を条件にしたブースは置けない可能性が高くなります。

新しい家でも、梁の下や下がり天井、勾配天井の部分は、ほかより低くなっています。

<strong>築年数で判断せず、置きたい場所の天井を実際にメジャーで測ってください</strong>。

なお、高さ1,900mm前後の組み立て式ブース（前述のEasy Boothやサンワサプライの製品）なら、天井高2.1〜2.3mの部屋にも収まります。

天井との間にどれだけ隙間が必要かは製品ごとに違うため、購入前に設置条件を確認しましょう。

### 月額レンタル

レントプラスでは、個室ブースを月額で借りられます。

公式ページの月額は、CONBOXが14,900円〜、Priwsが22,000円〜、One-Bo Plusが29,200円〜です。

配送・搬入設置の費用込みで初期費用はかからない一方、<strong>1年未満の契約は割高になる</strong>と案内されています。

個人で自宅に置く契約ができるかは、申し込み前に確認してください。

## 個室ブースの防音はどこまで？

個室ブースの防音性能は、<strong>「家族に会話の内容を聞き取られにくくする」程度</strong>と考えるのが現実的です。

オフィス向けのブースでは、メーカーが「約24〜42dBカット」などと表記していることがあります。

ただし、測る条件がメーカーごとに違うため、数字どうしを比べても意味がありません。

防音室のDr値とも別の物差しなので、「◯dBだからDr-◯◯相当」と換算することもできません。

自宅で使うときは、次のように考えると期待外れになりにくくなります。

| 音 | 個室ブースでの目安 |
| :-- | :-- |
| 自分の話し声（Web会議） | 内容は聞き取りにくくなるが、声がしていることは分かる |
| 家族の声・テレビの音 | 小さくなるが、消えはしない |
| 子どもの走る音・足音 | 床を伝わる音なので、ほとんど防げない |
| 楽器・歌 | 外に漏れる。防音室が必要 |

<strong>マイクに家族の声が入るのを防ぐなら、ヘッドセットとノイズ抑制機能の併用が効きます</strong>。

ブースは声と視線を減らし、マイクの工夫が残りの音を消す、という分担です。

家族の声やWeb会議の声漏れの対策を、手軽なものから順に知りたい場合は、次の記事で整理しています。

## 個室ブースは暑い？エアコンと換気の確認

自宅用の個室ブースで、いちばん後悔が多いのが<strong>暑さ</strong>です。

1人用ブースの中の空気は2㎥ほどしかありません。

そこに、人の体から出る熱（安静時でおよそ100W）と、パソコンやモニターの熱が加わります。

換気がないと、短い時間で中が暑く、息苦しくなります。

買う前に、次の3点を確認してください。

- <strong>換気ファンの有無</strong> : 付いていない製品もある。付いていれば、外の空気を入れ替えられる
- <strong>置く部屋のエアコン</strong> : ブースにエアコンがなければ、部屋を冷やして換気ファンで空気を入れる形になる。夏は部屋の温度を低めにしておく
- <strong>使う時間</strong> : 1時間を超える会議が多いなら、途中でドアを開けて空気を入れ替える前提で考える

エアコン付きのブースは、オフィス向けの高価格帯が中心です。

格安の防音室で起きる暑さの問題と対策は、[格安防音室は夏に地獄化する？だんぼっち・OTODASU排熱リスクと中古購入の注意点](/ja/soundproof-room/budget-soundproof-booth-comparison/)でも詳しく扱っています。

## 自宅に置く前に確認すること

個室ブースは「置くだけ」で使える一方、自宅ならではの確認点があります。

| 確認すること | 見るポイント |
| :-- | :-- |
| <strong>大きさ</strong> | 1人用でも幅・奥行1m前後、高さ1.9m前後。ドアを開ける場所も必要 |
| <strong>天井高</strong> | 照明・エアコン付きの製品は、天井高2,400mm以上を条件にしていることがある。築年数の古い住宅は2.2〜2.3mの部屋もあるため、実際に測る |
| <strong>搬入</strong> | 組み立て式か、完成品か。階段や廊下、玄関ドアを通るか |
| <strong>床</strong> | 重い製品は床の耐荷重とキズ。賃貸なら敷物で床を保護する |
| <strong>電源</strong> | パソコン・モニター・換気ファンを同じコンセントからとって、容量を超えないか |
| <strong>賃貸・マンション</strong> | 壁や床に固定しないか。管理規約や原状回復で問題にならないか |

### 消防法は気にする必要がある？

「個室ブース 消防法」と検索されるのは、主にオフィスに置く場合です。

天井と壁で囲われたブースは、オフィスや店舗に置くと、スプリンクラーや火災感知器の扱いが問題になります。

東京消防庁は「可動式ブース」の扱いを定めていて、床面積や材料などの条件を満たせば、ブース内の設備を免除できるとしています（[東京消防庁 可動式ブースに係る消防用設備等の取扱い](https://www.tfd.metro.tokyo.lg.jp/content/000060364.pdf)）。

一般の住宅は、オフィスビルとは消防設備の決まりが違います。

それでも、<strong>ブースの中で暖房器具など火を使わない</strong>、<strong>配線をタコ足にしない</strong>の2点は守ってください。

マンションの共用部に置く場合や、自宅を事務所として使う場合は、所轄の消防署に相談してください。

## 個室ブースを安く済ませる方法

予算を抑えたいときは、目的から逆算して選ぶと、無駄な出費を避けられます。

| 方法 | 費用の目安 | 向いている人 | 注意点 |
| :-- | :-- | :-- | :-- |
| <strong>パーティションで囲む</strong> | 6万円台〜 | 視線を切れれば十分な人 | 声はほとんど防げない |
| <strong>中古を買う</strong> | 新品より安いが個体差が大きい | オフィス撤去品を自分で運べる人 | 送料・組み立て・部品の欠品。換気ファンが動くか確認する |
| <strong>月額で借りる</strong> | 月14,900円〜 | 半年〜1年だけ使う人 | 1年未満は割高。個人契約の可否を確認する |
| <strong>時間貸しの個室を使う</strong> | 15分330円〜 | 大事な会議の日だけ個室がほしい人 | 自宅では使えない。移動が必要 |
| <strong>自作する</strong> | 材料費数万円〜 | 工作が苦にならない人 | 換気と重さの設計が難しい |

Web会議が週に1〜2回なら、駅の個室ブースやレンタルスペースを使うほうが安く済むことがあります。

時間貸しの選択肢は、[防音スペースのレンタルとは？5種類の料金の目安と用途別の選び方・探し方](/ja/soundproof-rental/soundproof-space-rental-guide/)で比較しています。

クローゼットなどを使って自作する方法は、[防音室を自作する方法｜クローゼットDIYで3万円から作れる録音ブース](/ja/diy/closet-diy-soundproof-room/)を参考にしてください。

## 個室ブースより防音室を選ぶべき人

次に当てはまるなら、個室ブースではなく防音室を検討してください。

- <strong>楽器を弾く</strong> : 個室ブースは楽器の音量を想定していない
- <strong>歌う・大きな声で配信する</strong> : 声が大きいと、ブースの外にはっきり聞こえる
- <strong>夜に音を出す</strong> : 近所への音漏れが問題になるなら、遮音の等級が示された防音室が必要

組み立て式の防音室の選び方と価格は、[組み立て式防音室おすすめ比較｜用途別（楽器・ゲーム・配信）と価格帯](/ja/soundproof-room/assembly-type-comparison/)で整理しています。

## よくある質問

### 自宅用の個室ブースはいくらで買える？

デスクを囲むパーティション型なら6万円台から、天井つきの1人用ブースなら35万〜44万円前後が公式価格の例です（2026年10月時点）。

月額レンタルなら月1万円台から借りられます。

### 個室ブースに入れば、Web会議の声は家族に聞こえない？

聞き取りにくくはなりますが、まったく聞こえなくなるわけではありません。

話す内容を絶対に聞かれたくない場合は、別の部屋を使うか、ブースとヘッドセットを組み合わせてください。

### 個室ブースにエアコンは必要？

夏に1時間以上こもるなら、換気ファン付きの製品を選び、置く部屋のエアコンで室温を下げておく必要があります。

## まとめ

- <strong>自宅に置ける個室ブース</strong> : パーティション型（6万円台〜）、天井つきの1人用（35万〜44万円前後）、月額レンタル（月1万円台〜）
- <strong>防げるもの</strong> : 会話の声と視線。楽器・歌・足音は防げない
- <strong>いちばんの注意点</strong> : 暑さ。換気ファンの有無と、置く部屋のエアコンを確認する
- <strong>置く前の確認</strong> : 大きさ、天井高、搬入、床、電源、賃貸の規約
- <strong>安く済ませるなら</strong> : 目的が視線ならパーティション、会議の日だけなら時間貸しの個室

まずは「誰の、どの音を、どこまで防ぎたいか」を決めてから、種類を選んでください。
