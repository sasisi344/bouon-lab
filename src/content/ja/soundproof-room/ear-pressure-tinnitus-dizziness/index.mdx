防音室で耳鳴りがするのは、多くの場合、周りの音がなくなって<strong>体の中の音が聞こえやすくなる</strong>ためです。

耳が詰まる感じはドアを閉める瞬間の気圧の変化や反響の少なさ、めまい・頭痛は換気不足やCO2の上昇が重なって起きることがあります。

本記事では、症状ごとの原因の切り分け表と、今日からできる対処、CO2濃度の目安、耳鼻科を受診する目安を順に示します。

<strong>本記事は一般的な情報で、診断の代わりにはなりません。</strong>

症状が続く・強くなる場合は、自己判断で使い続けず、医療機関を受診してください。

## 防音室で起きやすい症状と原因の切り分け表

| 症状 | 起きやすい場面 | 考えられる原因 | まず試すこと |
| :--- | :--- | :--- | :--- |
| 耳が詰まる・痛い | ドアを閉めた直後 | 閉める瞬間の気圧の変化 | ドアをゆっくり閉める。つばを飲み込む |
| 耳が詰まる感じが続く | 入ってしばらく | 反響と周りの音が少ない環境 | 小さな音でBGMを流す |
| 耳鳴り（キーン・ジー） | 静かにしているとき | 静けさで体の中の音が聞こえる | 小さな音を流す。外に出て消えるか確かめる |
| 頭痛・眠気・だるさ | 30分〜1時間以上いたとき | 換気不足によるCO2の上昇、熱 | 換気扇を確認し、ドアを開けて空気を入れ替える |
| めまい・息苦しさ・不安 | 入ってすぐ、またはドアを閉めたとき | 狭さ・閉じ込められる感覚 | ドアを少し開けて座る。広いサイズで試す |
| 防音室の外でも続く | 場所を問わない | 耳や体の病気の可能性 | 耳鼻科・内科を受診する |

大切なのは、<strong>防音室の外に出ると消えるかどうか</strong>です。

外に出て数分で消えるなら、防音室の環境が関係している可能性が高くなります。

外でも続くなら、防音室とは別の原因を疑い、受診を考えてください。

## 防音室で耳が詰まる｜ドアの開閉と気圧

防音室のドアは、四周のパッキンで隙間をふさぎます。

閉める最後の瞬間に、ドアが押し込んだ空気の逃げ場が少なくなり、室内の気圧がわずかに上がります。

### どのくらい気圧が変わるか

1.2畳のユニット防音室（内容積 約3.45㎥）で、閉める瞬間に押し込まれる空気の量を仮に置いて計算しました。

| 押し込まれる空気 | 気圧の上がり方（計算値） | 近い体験 |
| :--- | :--- | :--- |
| 1リットル | 約40Pa | エレベーターで約3m移動 |
| 5リットル | 約200Pa | エレベーターで約17m移動 |
| 10リットル | 約400Pa | エレベーターで約35m移動 |

計算は、空気が急に押し縮められるとして、気圧の上がり方を「押し込んだ量÷内容積×大気圧×1.4」とした単純化です（当サイトの試算）。

地上近くでは、高さが1m変わると気圧は約12Pa変わります。

実際は換気口や小さな隙間からすぐに空気が抜けるため、気圧の差は一瞬で小さくなります。

それでも、<strong>勢いよく閉めるほど一瞬の差は大きくなります</strong>。

鼻づまりや風邪で耳の空気の通り道（耳管）の調子が悪いときは、小さな気圧の差でも耳が詰まった感じや痛みが出やすくなります。

### 気圧が変わらなくても「詰まった感じ」がすることがある

防音室は、外の音が入らないうえ、吸音材で反響も少なくなっています。

反響がほとんどない部屋では、気圧が変わっていなくても耳が詰まったように感じる人がいます。

ふだん耳に入っている周りの音や反響がなくなり、その違いを「圧迫感」として受け取るためと考えられています。

この感覚は、少し音を流したり、ドアを開けたりすると軽くなるのが特徴です。

## 防音室で耳鳴りが気になる｜静けさで聞こえる体内音

防音室で「キーン」「ジー」という音が聞こえて、不安になる人は少なくありません。

1953年にHellerとBergmanが行った実験では、耳鳴りのない聴力が正常な若者を防音された部屋に数分入れたところ、<strong>約9割の人が何らかの音を聞いた</strong>と報告されています（Annals of Otology, Rhinology & Laryngology, 1953）。

ふだんは周りの音に紛れている、耳や体の中の音が、静けさで聞こえやすくなるためです。

防音室で耳鳴りが聞こえること自体は、珍しいことではありません。

### 気にしたほうがよい耳鳴り

- <strong>防音室の外でも聞こえる</strong> : 静かな場所に限らず続く
- <strong>片耳だけ</strong> : 片方の耳だけで、聞こえにくさを伴う
- <strong>急に始まった</strong> : 大きな音を聞いたあとや、ある日突然
- <strong>めまいを伴う</strong> : 耳鳴りと同時に、ぐるぐる回るめまいがある

このような場合は、防音室のせいと決めつけず、耳鼻科を受診してください。

静けさが体と心に与える影響は、[静寂の力｜防音室がメンタルケアになる理由](/ja/knowledge/mental-health-benefits-of-silence/)でも扱っています。

## 防音室でめまい・頭痛がする｜換気・温度・姿勢

めまい・頭痛・眠気は、防音室の<strong>空気と温度</strong>が関係していることが多い症状です。

### 酸欠より先にCO2が上がる

密閉された防音室で心配されるのは「酸欠」ですが、実際には酸素が減るより先に、吐く息のCO2が増えて症状が出ます。

人は酸素を吸った分に近い量のCO2を吐くため、酸素が21％から20％へ1％下がるころには、CO2は約1％（約10,000ppm）近くまで上がっています。

そのため、家庭の防音室で測るなら、<strong>酸素濃度計よりCO2モニター</strong>が役に立ちます。

| CO2濃度 | 目安 | 出典 |
| :--- | :--- | :--- |
| 約400〜420ppm | 外気 | — |
| 1,000ppm | ビルや事務所の空気の基準（これを超えたら換気不足のサイン） | 建築物衛生法の管理基準、事務所衛生基準規則5条 |
| 2,000〜5,000ppm | 換気の悪い室内。頭痛・眠気などが出ることがある | 東京消防庁などの解説 |
| 5,000ppm | 事務所の室内で超えてはいけない上限 | 事務所衛生基準規則3条 |
| 30,000ppm（3％）以上 | めまい・頭痛・呼吸の乱れなど中毒の症状が出始める | 高圧ガスの安全データシート、経済産業省の資料 |

酸素については、18％未満が「酸素欠乏」とされています（酸素欠乏症等防止規則）。

家庭の防音室で、換気扇を回していてそこまで下がることは考えにくい一方、CO2はもっと手前で上がります。

### 換気扇を止めるとどこまで上がるか

1.2畳（内容積 約3.45㎥）に1人で座って作業すると、吐く息のCO2は1時間に約0.02㎥です。

| 条件 | 1時間後のCO2濃度（計算値） |
| :--- | :--- |
| 換気扇（有効換気量23㎥/h）を回している | 約1,300ppmで頭打ち |
| 換気扇を止め、隙間からの出入りもないとした場合 | 約6,200ppm |

計算は、外気を約420ppm、空気が均一に混ざるとした単純化です（当サイトの試算）。

歌や管楽器では呼吸が増え、2人で入ればさらに上がります。

換気扇が回っていても1,000ppmを超える計算になるため、<strong>1時間に1回はドアを開けて空気を入れ替える</strong>のが安全です。

換気扇の能力とサイズ別の試算は、[防音室0.8畳で足りる？小型でギター・歌・配信はできるか](/ja/soundproof-room/compact-booth-under-1-5-tatami/)で扱っています。

### 一酸化炭素は「火を使わない」で防ぐ

一酸化炭素は、ものが燃えるときに出るガスで、人の呼吸からは出ません。

防音室の中で石油ストーブ・ガスストーブなど火を使う暖房器具を使わなければ、通常は問題になりません。

事務所の空気の基準では、一酸化炭素は50ppm以下とされています（事務所衛生基準規則3条）。

### CO2モニターの選び方

- <strong>測定方式</strong> : NDIR（非分散型赤外線）方式のセンサーを選ぶ。安価な製品には、CO2を直接測らない方式もある
- <strong>温度・湿度も表示</strong> : 熱がこもったか、乾燥しているかも同時に分かる
- <strong>警告の表示</strong> : 1,000ppmを超えたら色や音で知らせる機能があると気づきやすい

温度と湿度の管理は、[防音室の温湿度管理ガイド](/ja/soundproof-room/proofroom-humidity-airconditionlist/)で解説しています。

### 熱と姿勢

小さな防音室では、人とパソコンの熱がこもり、室温が上がりやすくなります。

暑さと脱水は、頭痛やめまいの原因になります。

低い椅子での前かがみや、モニターを見続ける姿勢も、首や肩のこりから頭痛につながります。

### 狭さ・閉じ込められる感覚

ドアを閉めた瞬間にめまいや息苦しさ、不安を感じる場合は、狭い空間が苦手なことが関係しているかもしれません。

ある配信者は、防音室に入ると落ち着かなくなり、長く使えなかったと話していました。

これは購入してから気づいても取り返しにくい問題です。

- <strong>展示品で座ってみる</strong> : 楽器店やショールームの展示品で、ドアを閉めて10分以上座ってみる
- <strong>広いサイズを選ぶ</strong> : 0.8畳より1.2畳、1.2畳より1.5畳以上のほうが圧迫感は小さくなる
- <strong>窓付きを選ぶ</strong> : 外が見える小窓があると、閉じ込められた感じが和らぐことがある
- <strong>レンタルで試す</strong> : 購入の前に、レンタルで一定期間使ってみる

サイズごとの内寸と圧迫感は、[防音室0.8畳で足りる？](/ja/soundproof-room/compact-booth-under-1-5-tatami/)で比べています。

## 今日からできる対処法

| 症状 | 対処 |
| :--- | :--- |
| 耳が詰まる・痛い | ドアを最後まで勢いよく閉めず、ゆっくり押し込む。つばを飲む・あくびをする |
| 詰まった感じ・耳鳴り | 雨音や環境音などのBGMを小さく流し、完全な無音を避ける |
| 頭痛・眠気 | 換気扇を回し、1時間に1回はドアを開けて空気を入れ替える。CO2モニターで確かめる |
| 熱 | 室温を確認し、エアコンのない防音室は使う時間を短くする |
| 息苦しさ・不安 | ドアを少し開けて使う時間をつくり、少しずつ慣らす。窓付き・広いサイズを検討する |

換気扇が止まっていないか、フィルターが詰まっていないかも、定期的に確認してください。

防音性能を落とさずに換気と空調を整える方法は、[防音室のエアコン選びと静音化の極意](/ja/soundproof-room/proofroom-aircondition-select/)にまとめています。

## 耳鼻科を受診する目安

次のような場合は、防音室の使い方の問題と決めつけず、早めに耳鼻科を受診してください。

- 防音室を出て、時間がたっても耳の詰まり・耳鳴りが消えない
- 片耳だけ聞こえにくい、または急に聞こえが悪くなった
- 耳鳴りと一緒に、ぐるぐる回るめまいや吐き気がある
- 耳の痛みが強い、耳だれが出る
- 頭痛がひどく、手足のしびれやろれつが回らないなどの症状を伴う（この場合は救急を含めて受診を急ぐ）

急に聞こえが悪くなった場合は、日にちがたつと治りにくくなる病気もあります。

様子を見すぎず、早めに相談してください。

## よくある質問

### 防音室で耳鳴りがするのは異常ですか？

静かな場所で耳鳴りに気づくこと自体は、聴力が正常な人にも起きます。

防音室を出て消えるなら、静けさで体の中の音が聞こえやすくなっている可能性が高いと考えられます。

外でも続く、片耳だけ、急に始まった場合は耳鼻科を受診してください。

### 防音室で耳が痛いときはどうすればいいですか？

ドアをゆっくり閉め、つばを飲み込んだりあくびをしたりして、耳の中と外の気圧をそろえます。

痛みが強い、または続く場合は受診してください。

### 防音室で頭痛がするのは酸欠ですか？

酸素が大きく減るより先に、CO2が上がって頭痛や眠気が出ることが多くなります。

CO2モニターで1,000ppmを超えていないか確かめ、1時間に1回は換気してください。

## まとめ｜まず「外に出ると消えるか」で切り分ける

- <strong>耳が詰まる・痛い</strong> : ドアを閉める瞬間の気圧と、反響の少なさ。ドアはゆっくり閉める
- <strong>耳鳴り</strong> : 静けさで体の中の音が聞こえる。小さなBGMで和らぐことが多い
- <strong>頭痛・眠気・めまい</strong> : CO2の上昇と熱を疑う。CO2モニターで確かめ、1時間に1回換気する
- <strong>狭さが苦手</strong> : 購入前に展示品で座る。広いサイズや窓付きを選ぶ
- <strong>外でも続く・片耳・急な変化</strong> : 防音室のせいと決めつけず、早めに受診する
