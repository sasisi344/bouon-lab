防音室の窓は「付けてはいけないもの」ではなく、ガラスの仕様と面積を管理すれば許容できます。

目安は、窓の遮音量が壁より10dB以内の差で、窓の面積が表面積の5％以下です。この条件なら、計算上の低下は約1.6dBにとどまります。

ドアは同じ等級でも隙間で台無しになりやすいため、窓なしの判断、引き戸の可否、ガラス張りの注意点まで、本記事で順に判定します。

## 防音室の窓・ドアが弱点になる理由｜面積と遮音量で決まる

防音室の壁は厚く重く作れますが、窓とドアは<strong>開閉できる重さと、光を通す透明さの制約</strong>の中で作られます。

壁と同じ重さにはできないため、遮音量が壁より低くなりやすい部分です。

### 合成した遮音量は、面積で重みづけされる

壁・ドア・窓がそれぞれ別の遮音量を持つとき、全体の遮音量は面積の重みづけで決まります。

音が通り抜ける割合（透過率）を面積で平均し、そこから遮音量に戻す考え方です。

遮音量が低い部分は、小さな面積でも全体を大きく引き下げます。

次の表は、外表面が約20㎡のブース（2畳前後の小型ブースを想定した仮の面積）で、壁の遮音量を40dBとして計算した例です。

| 条件 | 全体の遮音量（計算値） |
| :--- | :--- |
| 壁だけ（全面40dB） | 40.0dB |
| 壁40dB＋ドア1.8㎡（30dB） | 37.4dB |
| 上に窓0.5㎡（25dB）を追加 | 35.9dB |
| 上にドア周囲の隙間（幅1mm・長さ5.5m）を追加 | 32.7dB |
| ドアを35dB・窓を30dBに強化（隙間なし） | 38.5dB |
| ドアを35dB・窓を30dBに強化（隙間あり） | 33.8dB |
| ドアも窓も壁と同じ40dB（隙間だけあり） | 34.3dB |

この計算は、各部位の遮音量を1つの代表値で表し、隙間の遮音量を0dBと置いた単純化です。

実際は周波数ごとに値が変わり、建物の構造を伝わる音（フランキング）も加わります。

それでも、読み取れる傾向は実測と同じ向きです。

- <strong>ドア</strong> : 面積は表面積の約9％でも、音の通り道としては約半分を占める（壁40dB・ドア30dBの場合）
- <strong>隙間</strong> : 面積は0.03％でも、通る音の約半分を占める（表の4行目の条件）
- <strong>等級の強化</strong> : ドアと窓を強化しても、隙間が残れば約5dB分が打ち消される

つまり、弱点を探すときは「面積が大きい順」ではなく、<strong>遮音量が低い順</strong>に見ます。

隙間の影響は、[防音室の音漏れ対策ガイド](/ja/soundproof-room/proofroom-soudmore-manual/)でも診断の手順を解説しています。

### カタログの等級と、実際の部屋での性能は一致しない

ヤマハやカワイのカタログに載っているDr値は、壁・ドア・窓を含むユニット全体の等級です。

読み方は[遮音性能の基準「D値」とは？楽器・用途別の目安](/ja/soundproof-room/bouon-dchiseinou-meyasu/)にまとめています。

建物側の条件で、実際の遮音量はカタログ値と変わることがあります。

## 防音室のドアの種類と選び方｜開き戸・引き戸（スライドドア）・締付け式

ドアの種類は、閉めたときに<strong>隙間をどう消すか</strong>で性能が変わります。

| ドアの方式 | 閉めたときの隙間 | 向く場面 | 注意点 |
| :--- | :--- | :--- | :--- |
| 開き戸（パッキン圧着） | 四周のパッキンを枠に押し付けて塞ぐ | 配信・テレワークからピアノまで幅広く | 扉が振れるスペースが必要 |
| 締付け式の開き戸 | 閉めたあとハンドルで枠へ引き寄せ、さらに圧着する | 低音が強い楽器・高い等級 | 開閉にひと手間かかる |
| 引き戸（スライドドア） | 扉を走らせるための隙間が残りやすい | 狭い部屋でスペースを節約したいとき | 閉めたあとに圧着する機構があるかで性能差が大きい |

### 開き戸を基本に考える理由

開き戸は、閉めた扉を枠のパッキンに押し付けるだけで隙間が潰れます。

構造が単純なので、遮音性能が安定しやすい方式です。

高い等級のドアでは、ハンドルを回して扉を枠に引き寄せる締付け式が使われることが多くなります。

### 引き戸（スライドドア）は条件付きで使える

引き戸は、狭い部屋で扉の振れ幅を取れない場合に魅力的です。

ただし、扉を走らせるための隙間が構造上どうしても残ります。

次の3点がそろえば、引き戸も候補に入ります。

- <strong>圧着機構</strong> : 閉めたあとに、扉を枠へ押し付ける機構があるか
- <strong>下側の処理</strong> : レールや敷居まわりの隙間が、パッキンやシールで塞がれているか
- <strong>求める等級</strong> : 話し声や配信の音量なのか、ピアノやサックスなのか

話し声から配信までの音量であれば、引き戸でも成立する製品があります。

一方、低音の強い楽器では、遮音量を落とさない開き戸か締付け式を選ぶのが安全です。

製品によっては、等級によって引き戸を選べないモデルもあります。

引き戸を選ぶ場合は、希望の等級で選べるかをカタログで先に確認してください。

### ドアノブ・ハンドルまわりも弱点になる

ドアノブやハンドルのラッチ（かんぬき）部分は、扉に穴を開けて取り付けます。

そのため、扉の中でも遮音が途切れやすい場所になります。

一般の室内ドア用のレバーハンドルを、防音室のドアに後付けするのは避けてください。

ハンドルの交換は、扉の遮音性能と保証に影響します。

交換や追加の前に、メーカーか施工会社へ確認しましょう。

## 防音室の窓・ガラスの選び方｜ガラス厚・合わせガラス・二重窓

「窓がないと息が詰まりそう」と「窓から音が漏れたら本末転倒」の間で迷うのは、自然なことです。

答えは、ガラスの構成と面積で決まります。

### ガラスの厚みは質量則で効く

ガラスは1mmあたり約2.5kg/㎡の重さがあります。

5mmなら約12.5kg/㎡、10mmなら約25kg/㎡です。

面密度が2倍になると遮音量が約6dB向上する質量則は、ガラスにも当てはまります。

ただし、単板ガラスは特定の周波数で遮音量が谷のように落ちます。

人の声や中高音域に重なりやすいこの現象が、[コインシデンス効果](/ja/knowledge/coincidence-effect-soundproofing/)です。

### ガラスの構成別の特徴

| 構成 | 得意なこと | 弱点・注意点 |
| :--- | :--- | :--- |
| 単板ガラス | 構造が単純で安価 | コインシデンスの谷がはっきり出る |
| 合わせガラス（中間膜入り） | 谷が浅くなり、中高音の抜けを抑える | 中間膜は温度で硬さが変わり、性能も変わる |
| 複層ガラス（同じ厚み2枚） | 断熱に有利 | 同厚だと共鳴しやすく、遮音には不利 |
| 異厚複層ガラス | 厚みを変えて共鳴点をずらせる | 低音域は空気層の共鳴で質量則を下回ることがある |
| 二重窓（別々の枠・広い空気層） | 空気層を広く取れ、構造も分離できる | 厚みが増え、窓まわりの気密処理が増える |

同じ厚みのガラスを重ねるより、厚みや種類が違うガラスを組み合わせるほうが谷を浅くできます。

この考え方は壁と同じで、住宅の窓での使い分けは[賃貸と戸建てで変わる窓の防音対策](/ja/soundproof-room/shanon-vs-bouon-window/)で比較しています。

### 窓の遮音量は「サッシのT等級」で比べる

住宅用のサッシやドアセットには、遮音量を表すT等級（T-1〜T-4）があります。

日本建設業連合会の[用語解説](https://www.nikkenren.com/kenchiku/sound/pdf/glossary/en-0100.pdf)によると、JIS A 4702（ドアセット）とJIS A 4706（サッシ）で4等級が規定されています。

等級線は5dB間隔で、125Hz〜4kHzの1/3オクターブごとの音響透過損失が等級線以上かで判定します。

等級線を下回る値の合計が3dB以下であれば、その等級とされます。

T等級はガラス単体ではなく、<strong>枠を含めた窓全体</strong>の試験結果です。

造作の防音室や、既存の部屋の窓を比べるときは、ガラスの厚みよりT等級を見るほうが確実です。

### ユニット防音室の窓パネル

ユニット型の防音室では、窓はメーカーのオプション部品として用意されています。

ヤマハ「AVITECS（アビテックス）セフィーネNS」の公式サイトでは、Fix窓パネル（固定窓）が全サイズでオプション選択できます。

ガラスは、Dr-35用が複層ガラス、Dr-40用が真空ガラス（厚さ9.7mm）と、壁の等級に合わせて仕様が変わります。

つまり、ブースのメーカー自身が「窓の遮音量を壁に近づける」ことで、全体の等級を保っています。

<CtaBox slug="yamaha-avitex" />

カワイの[ナサール](/ja/soundproof-room/kawai-nasal-soundproof-room-guide/)も、Dr-30・Dr-35・Dr-40の3等級から選べ、窓や出入口はオプションで追加できます。

窓パネルの枚数や取り付け位置、等級ごとの選択条件は、サイズと等級で変わります。

購入前に、希望の等級で窓が選べるかを確認してください。

### 既存の部屋を防音室にする場合の窓

賃貸や戸建ての既存の窓を二重化する場合は、窓の内側にもう一つ窓を足す内窓が基本になります。

DIYとプロ施工の実測の差は、[内窓の防音効果を実測](/ja/diy/diy-internal-window-road-noise-reduction/)で比較しています。

内窓は断熱改修として補助金の対象になることがあります。

制度は年度ごとに変わるため、最新の条件は[防音窓リフォームで使える補助金制度まとめ](/ja/money/soundproof-window-subsidy-2025-guide/)で確認してください。

壁や床も含めた工事全体の比較は、[防音工事の種類と価格比較](/ja/soundproof-room/construction-types-cost-comparison/)にあります。

## 防音室は窓なしがよい？窓ありとの分かれ目

結論は条件付きです。

<strong>低音が強い楽器は窓なし、話し声から配信までの音量なら小さな窓あり</strong>が基本線です。

### 窓あり・窓なしの判断表

窓の面積が表面積の5％（1㎡／20㎡）のとき、窓の遮音量による全体の低下は次のとおりです。

| 窓の遮音量（壁は40dB） | 全体の遮音量 | 壁との差 |
| :--- | :--- | :--- |
| 20dB | 32.3dB | 低下 約7.7dB |
| 25dB | 36.0dB | 低下 約4.0dB |
| 30dB | 38.4dB | 低下 約1.6dB |
| 35dB | 39.6dB | 低下 約0.4dB |
| 40dB（壁と同じ） | 40.0dB | 低下なし |

窓の遮音量が壁より10dB低い程度なら、5％の面積でも低下は約1.6dBです。

壁との差が15dBに広がると、低下は約4dBに増えます。

なお、小さな窓ほど影響は小さくなり、窓0.3㎡で遮音量が30dBなら低下は約0.5dBです。

### 窓なしを選ぶ基準

次のどれかに当てはまる場合は、窓なしが無難です。

- <strong>低音の強い楽器</strong> : ドラム・ピアノ・ベースなど。複層ガラスは低音で質量則を下回ることがある
- <strong>夜間の演奏</strong> : 小さな遮音量の差が、近隣の聞こえ方に直結する
- <strong>ユニットの等級に余裕がない</strong> : 窓の分を等級で補う余地がない

### 窓なしのメリットとデメリット

窓なしのメリットは、遮音の弱点が1つ減ることです。

壁面を、吸音パネルや機材の設置に使えます。

デメリットは、閉塞感と外の様子の分からなさです。

閉塞感は、照明の色温度や明るさ、壁の色、換気で和らげられます。

換気の設計は、[防音室のエアコン選びと静音化の極意](/ja/soundproof-room/proofroom-aircondition-select/)も参考になります。

建築基準法や消防法での居室や避難の扱いは、建物と設置方法で変わります。

設置前に、管理会社・施工会社・消防への確認をおすすめします。

## パッキン・パテ・隙間処理の考え方

最初の計算のとおり、<strong>隙間は面積が小さくても全体の遮音量を大きく下げます</strong>。

ドアと窓の性能を上げる前に、隙間を先に塞ぎます。

### 場所別の隙間と処理

| 場所 | 起きやすい隙間 | 処理の例 |
| :--- | :--- | :--- |
| ドアの四周 | パッキンの劣化・変形 | メーカー純正パッキンへの交換 |
| ドアの下端 | 床との隙間 | 閉めると下がる気密部材、下端のシール |
| 窓枠まわり | 枠と壁の取り合い | 防音用パテ・気密材で埋める |
| 配線・配管の貫通部 | 穴まわりの隙間 | 防音用パテ、貫通部専用の部材 |

パッキンは、経年で劣化・変形します。

### 隙間の見つけ方

暗い部屋で内側から強いライトを当て、外側から光が漏れる場所を探す方法があります。

光が漏れる場所は、音も漏れやすい場所です。

一方、光が見えない隙間にも音は通ります。

最終的には、演奏や再生をしながら外で聞き、仮にテープで塞いで変化を確認すると確実です。

### パテを使うときの注意

防音用パテは、貫通部や枠まわりを埋めるための部材です。

ドアの可動部や、将来取り外す部分には向きません。

後から自己判断で穴を開けたり、部材を足したりすると、保証や性能に影響します。

工事の前に、メーカーか施工会社へ確認してください。

## 配信向けのガラス張り・透明パネルの注意点

ガラス張りの防音室は、配信映えと開放感が魅力です。

その一方で、ガラスは遮音量を下げる代表的な部位です。

壁40dBの20㎡で、窓の面積を広げたときの計算は次のとおりです。

| 窓の面積（遮音量30dB） | 全体の遮音量 |
| :--- | :--- |
| 0.3㎡ | 39.5dB |
| 1㎡ | 38.4dB |
| 2㎡ | 37.2dB |
| 4㎡（面積の20％） | 35.5dB |

4㎡の窓を30dBのガラスでつくると、壁の性能から約4.5dB落ちます。

同じ面積でも、窓の遮音量を35dBまで上げれば、全体は約38.4dBで約1.6dBの低下に収まります。

配信用途で「見せたい」場合は、<strong>小さめの窓＋高い遮音量のガラス</strong>の組み合わせが現実的です。

ガラスには、遮音以外の注意点もあります。

- <strong>音の反射</strong> : ガラス面は音を反射するため、収録ではこもりや響きが増える
- <strong>映り込み</strong> : 照明や機材がガラスに映り、映像に写り込みやすい
- <strong>熱</strong> : 日射が入る向きでは、夏の室温が上がりやすい

透明な個室ブースの遮音の限界は、[個室ブースを自宅に置くなら](/ja/soundproof-room/home-private-booth-guide/)で整理しています。

## 防音室のドア・窓の選び方チェックリスト

購入前や設計の打ち合わせで、次の項目を確認してください。

- [ ] 用途の音量と周波数（話し声・配信・ピアノ・ドラムなど）を決めた
- [ ] ドアは開き戸か締付け式か。引き戸なら、圧着機構と下側の処理を確認した
- [ ] 引き戸が、希望の等級で選べることをカタログで確認した
- [ ] 窓の遮音量が壁の等級から10dB以内か、メーカーの窓パネルの仕様を確認した
- [ ] 窓の面積が表面積の5％以下か、低音楽器なら窓なしを検討した
- [ ] ドアのパッキンが純正品で、交換できる部材か確認した
- [ ] 貫通部（配線・換気・エアコン）の処理方法を確認した
- [ ] ガラス張りにする場合は、窓の面積と遮音量から全体の低下を計算した

ユニット型防音室のメーカー別の比較は、[防音室おすすめ比較](/ja/soundproof-room/bouon-osusume-hikaku/)にまとめています。

## よくある質問

### 防音室に窓は付けられますか？

付けられます。

ユニット防音室では、メーカーが壁の等級に合わせた窓パネルをオプションで用意しています。

窓の遮音量が壁より10dB以内で、面積が表面積の5％以下なら、全体の低下は約1.6dBで収まります。

### 防音室のスライドドア（引き戸）は音漏れしますか？

構造上、開き戸より隙間が残りやすい方式です。

閉めたあとに扉を枠へ押し付ける機構があり、下側の処理が十分であれば、話し声から配信までの用途なら成立します。

低音が強い楽器では、開き戸か締付け式が安全です。

### 防音室のドアノブから音は漏れますか？

ラッチ部分は扉に穴を開けて取り付けるため、弱点になりえます。

一般の室内ドア用のハンドルへの交換は避け、メーカーや施工会社に相談してください。

## まとめ｜弱点は「遮音量が低い順」に潰す

- <strong>弱点の見方</strong> : 面積と遮音量の合成で決まり、遮音量が低い部分（隙間・窓・ドア）の順に影響する
- <strong>ドア</strong> : 開き戸か締付け式が基本。引き戸は圧着機構と等級の条件を確認する
- <strong>窓</strong> : 壁との差10dB以内・面積5％以下なら、低下は約1.6dB。低音の強い楽器は窓なしが無難
- <strong>隙間</strong> : ドア・窓の強化より先に塞ぐ。隙間が残ると約5dB分が打ち消される
- <strong>ガラス張り</strong> : 面積を抑え、遮音量の高いガラスを選ぶ

次の一手として、窓やドアを含めた全体の効果を数値で確かめたい方は、[防音室で音はどこまで消える？用途別の軽減率シミュレーション](/ja/soundproof-room/sound-reduction-simulation/)もご覧ください。

本記事の計算例は、各部位の遮音量を代表値で表した簡易計算です。

実際の遮音量は、周波数・施工・建物の構造で変わります。

最終的な判断は、メーカー・施工会社の公式仕様と、可能なら実機の体験で確認してください。
