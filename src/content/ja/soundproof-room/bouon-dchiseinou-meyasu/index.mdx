自宅に防音室を導入する際、カタログで必ず目にするのが <strong>「D値（またはDr値）」</strong> という指標です。これは「どれだけ音を遮ることができるか」を表す遮音性能の等級ですが、単に数字が大きいものを選べば良いというわけではありません。

2026年現在の住宅事情や最新の防音ユニットの性能を調べた結果をもとに、 <strong>「後悔しないD値の選び方」</strong> をまとめました。

本記事では、防音室（防音ユニット）のD値と、防音賃貸（物件）のD値を、別々に解説します。

同じ「D値」という言葉でも、<strong>何の遮音性能を指すかで、必要な数字が変わる</strong>ためです。

賃貸物件を探している方は、目次の「防音賃貸（物件）のD値」からお読みください。

## 防音性能の要「D値（Dr値）」の基礎知識

<strong>D値（遮音等級）</strong> とは、日本産業規格（JIS）で定められた、建物の部屋と部屋の間の遮音性能を表す基準です。一方、ヤマハやカワイなどの防音ユニット（組立型防音室）のカタログでは、日本建築学会の基準に基づいた <strong>「Dr値」</strong> という表記が一般的に使われます。

厳密には測定条件が異なりますが、一般ユーザーが防音性能を比較する上では <strong>「D値（Dr値）＝遮音の強力さ」</strong> と考えて差し支えありません。

### D値と音の減衰（聞こえ方）の目安
D値の数字は、遮断できる音の大きさ（デシベル数）と概ねリンクしています。

- <strong>D-30 :</strong> 普通の話し声（60dB）が約30dB、ホテルの客室くらいまで下がる。隣の部屋で「何か話しているな」と微かにわかる程度。
- <strong>D-35 :</strong> ピアノの音（正面1mで80〜90dB）が約45〜55dB、書店の店内くらいまで下がる。
- <strong>D-40 :</strong> ピアノの音が約40〜50dB、図書館の館内から書店の店内くらいまで下がる。夜の住宅地（40dB前後）では、曲が流れていることは分かる。
- <strong>D-50以上 :</strong> ピアノの音が約30〜40dB、ホテルの客室から図書館の館内くらいまで下がる。プロのスタジオで使われる水準。

身近な場所の例は[環境省「騒音の目安」](https://www.env.go.jp/air/ippan/meyasu.pdf)をもとにしています。

D値は低い音ほど下がりにくい等級のため、ピアノの低音やドラムはこの目安より大きく聞こえることがあります。

## 【2026年最新】用途・楽器別の「必要なD値」早見表

防音室選びで最も失敗が多いのは、<strong>「用途に対して性能が足りなかった」</strong> というケースです。以下の表を参考に、自身の活動に必要なスペックを確認してください。

実際にどこまで音が軽減されるかをシミュレーションした結果は、[【シミュレーション】防音室で音はどこまで消える？用途別の軽減率を徹底検証](/ja/soundproof-room/sound-reduction-simulation/)で確認できます。

| 用途・楽器 | 音源の音圧 (dB) | 目指すべきD値 | 防音後の聞こえ方 |
| :--- | :--- | :--- | :--- |
| <strong>テレワーク・事務</strong> | 60〜65 | <strong>D-30</strong> | 秘匿性が確保され、家族にも迷惑がかからない |
| <strong>ヴォーカル・ASMR配信</strong> | 70〜85 | <strong>D-35</strong> | 深夜でも隣人に気兼ねなく声を張れる |
| <strong>ピアノ（UP/GP）</strong> | 90〜100 | <strong>D-35〜40</strong> | マンション等で「常識的な時間内」に演奏可能 |
| <strong>サックス・トランペット</strong> | 100〜110 | <strong>D-40〜45</strong> | 近隣トラブルを防ぐための最低ライン |
| <strong>アコースティックドラム</strong> | 110〜120 | <strong>D-60以上</strong> | 専門の防音工事が必要（ユニット式は困難） |

## 楽器別・遮音等級の選び方詳細ガイド

### ピアノ（アップライト・グランド）演奏
ピアノは音が大きく、かつ低音から高音まで幅広い周波数を含んでいるため、最低でも <strong>D-35</strong>、深夜の練習も見据えるなら <strong>D-40</strong> が必須となります。また、ペダル操作による「床への振動」はD値では計れないため、別途 <strong>防振マット</strong> による対策が不可欠です。

### 動画配信・VTuber（ASMR含む）
YouTubeやTwitchでの配信者の場合、実は <strong>D-35</strong> 程度の遮音性能で十分なケースが多いです。それ以上に重要なのは「PCのファンノイズの遮断」や「マイクへの反響音の抑制」です。D値だけでなく、内部の <strong>吸音性能</strong> にも注目しましょう。

### テレワーク・Web会議
情報の秘匿性が求められるビジネス用途では、<strong>D-30</strong> があれば部屋の外に会話内容が漏れるのを効果的に防げます。最近では簡易的なダンボール防音室や、プラスチックボード製の <strong>軽量防音ブース</strong> でもこの数値を達成できるモデルが増えています。

## 防音賃貸（物件）のD値は、防音室ユニットと見方が違う

賃貸の募集図面にある「D-50」などの数字は、<strong>建物の壁や床そのもの</strong>の遮音性能を指します。

一方、ヤマハやカワイのカタログにあるDr値は、<strong>部屋に置く防音室ユニット</strong>の性能です。

両者は測定する対象も、前提となる建物条件も違います。

そのため、同じ楽器でも必要な数字が変わります。

| 楽器 | 防音室ユニットの目安 | 防音賃貸（物件）の目安 |
| :-- | :-- | :-- |
| サックス | D-40〜45 | D-55〜60 |
| ピアノ（アップライト） | D-35〜40 | D-50〜55 |

物件の目安は、物件の壁だけで隣戸に配慮するための数字です。

ユニットの目安は、居室の中にもう一つ防音の箱を置く前提の数字です。

一方の数字を、もう一方にそのまま当てはめないようにしてください。

### 建物タイプ別のD値と聞こえ方の目安

建物の種類による遮音性能の目安は、次のとおりです。

| 建物タイプ | D値の目安 | 音の聞こえ方 |
| :-- | :-- | :-- |
| 木造アパート | D-35程度 | 隣の話し声が聞こえる |
| 普通のマンション | D-40〜45 | 大きな音や生活音が聞こえる |
| 防音マンション | D-50〜60 | 楽器の音が大幅に軽減される |
| 高性能な防音賃貸 | D-65〜80 | ほぼ完全に遮断される |

これはあくまで一般的な目安で、築年数や施工、測定方法で変わります。

数字の意味と、木造アパートでできる対策は、[木造アパートの防音は無理？苦情ゼロまで音を減らす3つの現実的対策](/ja/diy/wooden-apartment-soundproof-guide/)で解説しています。

### 楽器別に、物件に求めたいD値の目安

防音賃貸を探すときの、楽器別の目安は次のとおりです。

| 用途・楽器 | 物件の目安 | 理由 |
| :-- | :-- | :-- |
| 電子ピアノ | D-40〜45 | 音量を調整できる |
| アップライトピアノ | D-50〜55 | 中音量の楽器 |
| グランドピアノ | D-60以上 | 大音量で低音も強い |
| フルート・クラリネット | D-45〜55 | 小〜中音量 |
| サックス・トランペット・トロンボーン | D-55〜60 | 大音量で指向性が強い |
| バイオリン・ビオラ | D-50〜55 | 高音域がよく響く |
| チェロ・コントラバス | D-55〜60 | 低音域と床への振動に注意 |
| アコースティックギター | D-45〜50 | 比較的小音量 |
| エレキギター（アンプ使用） | D-55〜60 | アンプの音量次第 |
| 電子ドラム | D-45〜50 | 空気音より振動対策が主 |
| アコースティックドラム | D-65〜70 | 大音量で振動も大きい |
| 歌・声楽・配信 | D-40〜55 | 声量と時間帯で変わる |

物件ごとに表記や基準が異なるため、「楽器可」と書かれていても、必ず条件を確認してください。

サックスの練習の工夫は、[サックスは賃貸で練習できる？アパートの現実解と防音室選び](/ja/soundproof-rental/saxophone-apartment-practice-guide/)で解説しています。

### 物件選びでD値以外に確認したいこと

D値だけを見ても、トラブルは防げません。

- <strong>振動対策</strong> : 浮き床構造か、防振ゴムが使われているか。ドラムやチェロは特に重要
- <strong>低音対策</strong> : 壁の厚み、二重壁、空気層の有無。D値が同じでも低音の漏れ方は変わる
- <strong>窓・ドア・換気口</strong> : 二重サッシ、防音ドア、消音ダクトの有無。ここが弱いと音が漏れる
- <strong>間取り</strong> : 角部屋、隣室との間に収納があるか、真下に寝室がないか

### 契約前と内見でのチェックリスト

契約前に確認すること:

- <strong>D値の数値が書面にあるか</strong> : 「防音仕様」とだけ書かれているのは不十分
- <strong>測定方法</strong> : 実験室の数値か、現場での実測値か。測定時期も確認する
- <strong>楽器の種類・時間帯の制限</strong> : 「楽器可」でも種類や音量、時間が決まっていることが多い

内見で確認すること:

- <strong>許可を得て、実際に音を出す</strong> : 隣室や廊下、可能なら外でも聞こえ方を確認する
- <strong>壁を軽く叩く</strong> : 軽い音なら壁が薄い可能性がある
- <strong>隣室や共用部の生活音</strong> : 隣の音が聞こえる部屋は、こちらの音も漏れやすい

内見時の調べ方は、[楽器可賃貸の正しい探し方](/ja/soundproof-rental/instrument-allowed-rental-research-method/)も参考にしてください。

### 物件のD値でよくある誤解

- <strong>「D-50なら絶対に漏れない」</strong> : D値は音を完全に遮断する指標ではありません。大音量なら隣室にわずかに聞こえます。低音と振動はD値だけでは判断できません
- <strong>「カタログ値がD-60だから安心」</strong> : 実験室のデータは、現場の実測より良い数字になる傾向があります。契約前に測定条件を確認してください
- <strong>「D値が高ければ音質も良い」</strong> : 遮音と、部屋の中の響き（音響）は別物です
- <strong>「防音賃貸ならドラムもOK」</strong> : D値が高くても、振動対策がなくドラムNGの物件は多くあります

## 失敗しないための「暗騒音（L50）」という考え方

「D-35の防音室を買ったのに、夜中にピアノを弾いたら文句を言われた」というケースがあります。これは <strong>「暗騒音（あんそうおん）」</strong> を考慮していないことが原因です。

<strong>暗騒音</strong> とは、周囲に何もない時に聞こえる微かな音（環境音）のことです。
- <strong>昼間 :</strong> 外が騒がしいため（暗騒音が大きいため）、多少の音漏れはかき消されます。
- <strong>深夜 :</strong> 外が非常に静かなため（暗騒音が小さいため）、漏れた音が非常に目立ちます。

深夜にしっかり活動したい場合は、カタログスペックに <strong>プラス5〜10</strong> の余裕を持った設計（例：D-45など）をおすすめします。

## 遮音性能だけで決めてはいけない「構造伝搬音」の罠

D値が指標としているのは「空気中を伝わる音（空気音）」です。しかし、集合住宅で最もトラブルになりやすいのは <strong>「構造伝搬音（振動）」</strong> です。

- <strong>例 :</strong> ドラムのキック、ピアノのペダル、ベースの重低音、椅子の移動音。

これらは壁の厚さ（D値）を上げても防ぎきれません。床に <strong>「浮き床構造」</strong> を採用したり、高硬度のゴムマットを敷くなどの <strong>「防振対策」</strong> をセットで行うことが、防音ライフ成功の鍵となります。

## 2026年最新：メーカー別・モデルの遮音性能

現在、市場で信頼されている主要メーカーのD値達成状況です。

- <strong>ヤマハ (Cefine NS) :</strong> <strong>Dr-35 / Dr-40 を中心に、音質の良さを両立。</strong>
- <strong>カワイ (ナサール) :</strong> <strong>Dr-30〜Dr-50 まで幅広く対応し、オーダーの自由度が高い。</strong>
- <strong>OTODASU / だんぼっち :</strong> <strong>D-15〜D-25 程度。楽器演奏には不向きだが、配信やテレワークには最適。</strong>

## まとめ：あなたの「ライフスタイル」に最適なD値を選ぼう

防音性能は「高ければ高いほど良い」ですが、性能に比例して価格も跳ね上がります（Dr-35からDr-40にするだけで、数十万円のコストアップも珍しくありません）。

1.  <strong>何を鳴らすか</strong> （ピアノか、声か、ベースか）
2.  <strong>いつ鳴らすか</strong> （昼間だけか、深夜もか）
3.  <strong>どこで鳴らすか</strong> （一軒家か、木造アパートか、RC造マンションか）

この3点を整理し、オーバースペックにならず、かつ不足のない <strong>「ちょうど良いD値」</strong> を見極めてください。不安な場合は、専門業者に「深夜にピアノを弾きたい。D値でいくつを目指せば良いか？」と具体的に相談することをおすすめします。
