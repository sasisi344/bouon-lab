苔の吸音効果は、<strong>部屋の響きを減らすには役立ちますが、隣や外への音漏れを止める「防音」にはなりません。</strong>

2026年に発表された音響管での試験では、厚く育つ苔で1kHzの吸音率が0.62ほどでした。

一般的な吸音パネル（0.7〜0.9程度）より少し低く、苔は「見た目の良い吸音の補助材」として使うのが現実的です。

この記事では、苔の吸音を測った研究、音を吸う仕組み、壁に取り入れるときの配置を順に説明します。

## 苔の吸音効果とは｜「吸音」と「防音」は別の話

苔の吸音効果という話で気になったのは、専用の吸音パネルとどこが違うのかでした。

最初に、言葉の違いを押さえておきます。

- <strong>吸音</strong> : 室内で跳ね返る音を吸い取り、響きやエコーを減らすこと
- <strong>遮音</strong> : 壁や窓で音を跳ね返し、反対側へ通さないこと
- <strong>防音</strong> : 遮音と吸音を組み合わせ、音漏れと響きの両方を抑えること

苔は、細かい茎や葉のすき間に音が入り込んで弱まる<strong>吸音の素材</strong>です。

軽く、すき間の多い素材なので、音を跳ね返す重さ（遮音）はほとんどありません。

そのため、苔を壁一面に貼っても、隣の部屋への話し声や楽器の音はほぼ同じように漏れます。

吸音と遮音のどちらが自分に必要かは、[吸音材か遮音材か迷う人へ｜あなたの環境で“必要なのはどっち？”徹底ガイド](/ja/knowledge/absorption-vs-soundproofing-materials/)で判定できます。

## 苔の吸音を測った研究｜吸音率はどのくらいか

吸音率は、当たった音のうち吸い取られた割合です。

0なら全部跳ね返し、1なら全部吸い取ります。

苔の吸音を数字で確かめた研究は、まだ多くありません。

その中で、条件と数値が公開されているのが次の研究です。

### ラトビアの研究（2026年）｜4種類の苔を音響管で測定

ラトビア生命科学技術大学の研究チームは、身近な4種類の苔を、音響管（ISO 10534-2）で測りました。

| 苔の種類（学名） | 厚さ | 500Hz | 1kHz | 1.6kHz |
| :--- | :--- | :--- | :--- | :--- |
| タチハイゴケ（Pleurozium schreberi）＋麻の下地 | 8.5cm | 0.31 | <strong>0.62</strong> | 0.54 |
| タチハイゴケ（下地なし） | 8.0cm | 0.31 | 0.49 | 0.48 |
| シッポゴケ属（Dicranum scoparium）＋麻の下地 | 5.0cm | 0.11 | 0.24 | 0.46 |
| ハイゴケ属（Hypnum cupressiforme）＋麻の下地 | 2.2cm | 0.09 | 0.19 | 0.38 |
| ハイゴケ属（下地なし） | 1.7cm | 0.07 | 0.12 | 0.23 |

出典: Karklina, J., Karklins, E. "Nature-based moss barriers for urban noise absorption: impedance tube assessment of boreal moss species." Engineering for Rural Development, 2026.（表は論文のTable 3から抜粋）

私がここで比べているのは、上の研究で測った苔の値と、同論文が集めた建材の値です。

比べるために、同じ論文が文献から集めた建材の値も載せます。

| 素材 | 500Hz | 1kHz | 2kHz |
| :--- | :--- | :--- | :--- |
| コンクリート | 約0.04 | 約0.06 | 約0.08 |
| れんが | 約0.03 | 約0.04 | 約0.05 |
| 吸音パネル | 約0.6〜0.9 | 約0.7〜0.9 | 約0.8〜1.0 |

この研究からわかることは、次の3つです。

- <strong>コンクリートの壁よりは、はるかに音を吸う</strong> : 薄い苔でも、むき出しの壁の数倍の値が出ている
- <strong>吸音パネルの代わりにはなりにくい</strong> : 一番よい苔でも、一般的な吸音パネルの下限あたり
- <strong>低い音はほとんど吸わない</strong> : 500Hzでは多くの苔が0.1前後で、足音や重低音には効かない

研究チーム自身も、試料の数が少ない探索的な結果だとしたうえで、<strong>苔だけを主な吸音材にするのは難しい</strong>と結論づけています。

### オランダ・デルフト工科大学の研究｜苔で覆ったコンクリート

同じ論文の中で紹介されているデルフト工科大学の研究では、6種類の苔をコンクリートの表面に育てて測っています。

苔で覆うと、特に1,000Hzより高い音で吸音が増え、最もよい種類で吸音率のピークが0.86、50〜6,400Hzの平均で0.48でした。

人の声の響きや、食器・キーボードの高い音には効きやすい、という傾向は2つの研究で共通しています。

### 製品の「吸音率0.95」は条件を確認する

苔パネルの販売資料には「吸音率0.95」といった高い数字が載っていることがあります。

ニュージーランドの販売会社の資料では、この値は<strong>5,000Hzという高い音の1点だけ</strong>の値でした。

声の中心（数百Hz〜2kHz程度）の値ではないため、数字が高くても、そのまま声の響きに効くとは限りません。

製品を比べるときは、何Hzの値か、どの試験方法（残響室法・音響管法）かを確認してください。

## なぜ苔は音を吸うのか｜吸音する構造

苔が音を吸う仕組みは、グラスウールやフェルトと同じ<strong>多孔質吸音</strong>です。

- <strong>すき間に入った音が弱まる</strong> : 細い茎や葉のすき間で空気が揺れ、こすれ合うことで音のエネルギーが熱に変わる
- <strong>厚いほど低い音まで吸う</strong> : ラトビアの研究では、8cmの厚さに育つタチハイゴケが最もよく、薄く広がる種類は低かった
- <strong>縦に立つ形が効く</strong> : 茎が縦に密集する種類ほど、音が入り込むすき間が多くなる
- <strong>下地を足すと上がる</strong> : 麻の下地を足すと、4種類すべてで吸音率が上がった

壁に取り入れるときは、苔の厚みに加えて、<strong>苔の裏にフェルトや空気層を足す</strong>と吸音の幅が広がります。

## 本物の苔・保存加工の苔パネル・フェイクの違い

室内の壁に使う「苔」には、3つの種類があります。

| 種類 | 手入れ | 吸音 | 室内の壁に向くか |
| :--- | :--- | :--- | :--- |
| 生きた苔 | 水やり・光・湿度管理が必要 | 厚く育てば効く | 向かない（湿気・カビの管理が難しい） |
| 保存加工の苔パネル（トナカイゴケなど） | 水やり・日光は不要 | 中〜高音の響きに効く | 向く |
| フェイクの苔（樹脂製） | 不要 | ほとんど期待できない | 見た目だけ |

室内の吸音で使われるのは、北欧のトナカイゴケ（Cladonia stellaris）を保存加工したパネルが中心です。

販売元の資料では、次の扱い方が案内されています。

- <strong>水をやらない</strong> : 水をかけると、空気中の湿気を吸ったり出したりする性質が損なわれる
- <strong>湿度を保つ</strong> : 相対湿度40〜80%程度で、乾燥しすぎると硬くなり、ぽろぽろ崩れやすい
- <strong>直射日光を避ける</strong> : 色あせの原因になる。屋外では使わない

触れると欠片が落ちることがあるため、人がよく通る場所や、手が当たる高さは避けたほうが無難です。

## 苔パネルの実用例｜壁のどこに貼れば効くか

苔パネルは、吸う面積が小さいと効果を感じにくい素材です。

響きを減らしたい場所に、まとめて置くのが基本です。

| 目的 | 貼る場所 | ポイント |
| :--- | :--- | :--- |
| Web会議・配信の声の響きを減らす | 机の正面の壁、顔の高さ | 声が最初に跳ね返る面を優先する |
| 楽器練習の響きを和らげる | 楽器と向き合う壁、左右の壁 | 低音は吸わないので、ベーストラップと併用する |
| リビング・寝室の反響を減らす | 平行に向き合う壁の片側 | 向き合う壁の間で音が往復する「鳴き」を抑える |

吸音材をどこに貼ると効くかの考え方は、[吸音材はどこに貼る？モニター裏・スピーカー裏など5つの正解ポイント](/ja/diy/gamer-acoustic-placement/)で場所ごとに解説しています。

苔だけで足りないと感じたら、見える面を苔、裏や見えない面を一般的な吸音パネルにして、見た目と吸音量を分担させる方法もあります。

## 音漏れを止めたいなら、苔の前にやること

苔を検討している理由が「隣や家族に音が聞こえるのを防ぎたい」なら、先に遮音と隙間対策が必要です。

- <strong>隙間をふさぐ</strong> : ドア下・窓のすき間からの漏れが一番大きい
- <strong>重さを足す</strong> : 遮音シートや石膏ボードなど、重い層で音を跳ね返す
- <strong>響きを整える</strong> : 苔や吸音パネルは、この後の仕上げとして使う

DIYで遮音と吸音を組み合わせるときの失敗例は、[防音パネルの罠｜DIY失敗例から学ぶ『遮音と吸音』の物理学的黄金比](/ja/diy/diy-soundproof-room-failures-solutions/)にまとめています。

楽器や配信で確実に音漏れを抑えたい場合は、遮音性能が公表されているユニット型防音室の中を、苔や木で仕上げるという考え方もあります。

防音室の性能と価格は、[防音室おすすめ比較｜失敗しない選び方とROI（投資対効果）を分析](/ja/soundproof-room/bouon-osusume-hikaku/)で比べています。

## よくある質問

### 苔で防音室は作れますか？

作れません。

苔は軽く、音を跳ね返す重さがないため、音漏れを止める遮音の役割は果たせません。

### 苔の吸音効果は、吸音ウレタンより高いですか？

研究で測られた値を見る限り、一般的な吸音パネルと同じか、それより低い程度です。

苔を選ぶ理由は、吸音量よりも見た目と、緑のある空間の心地よさにあります。

### 苔パネルは足音や重低音に効きますか？

ほとんど効きません。

500Hz以下の低い音の吸音率は小さく、床を伝わる足音は吸音ではなく防振の問題です。

## まとめ｜苔は「響きを整える、見た目の良い補助材」

- <strong>苔の吸音効果</strong> : 厚い種類で1kHzの吸音率0.62ほど。中〜高音の響きを減らす
- <strong>防音にはならない</strong> : 重さがないので、音漏れは止まらない
- <strong>選ぶなら保存加工のパネル</strong> : 水やり不要。湿度40〜80%を保ち、直射日光を避ける
- <strong>貼る場所</strong> : 声や音が最初に跳ね返る壁に、まとめて置く

緑と静けさが気持ちに与える効果については、[静寂の力：なぜ防音室はメンタルケアに役立つのか](/ja/knowledge/mental-health-benefits-of-silence/)で解説しています。

私なら、隣からの音が悩みなら先に遮音を考え、苔は響きと見た目の補助として選びます。

苔を増やしても、音漏れを止める重さは補えないからです。
