騒音計アプリは、同じ端末と条件で防音対策の前後を比べる目安になります。

スマホのマイクは機種で特性が違うため、表示値をそのまま正確な騒音レベルや遮音性能の証明には使えません。

無料のiPhone・Androidアプリの選び方と、比較するときにそろえる条件を整理します。

私が防音について調べていると、スマホで効果を測ったという話はよく見かけますが、その数字をどこまで信じてよいかは、あまり書かれていません。

## 騒音計アプリの「dB」はどこまで信用できるか

スマホの内蔵マイクは、本来は人の声を録るために最適化された設計で、騒音計のように<strong>全周波数で均一に反応するよう校正（キャリブレーション）されていません</strong>。

機種ごとにマイクの感度・指向性が異なるため、同じ音を測っても端末によって表示される数値がずれることがあります。

そのため、「このアプリで防音室の遮音等級を確認できた」というような<strong>絶対値の証明には使えません</strong>。

一方で、同じ端末・同じ場所で「対策前と対策後」のように<strong>変化量を比較する</strong>使い方であれば、機種を変えるより条件をそろえやすくなります。

ただし、誤差がなくなるわけではありません。

## 無料アプリで十分なケース・足りないケース

- <strong>十分なケース</strong> : DIY防音（マスク・パネル・ベーストラップ等）の対策前後の変化を大まかに確認したい場合
- <strong>十分なケース</strong> : 配信・宅録で「マイクに入る環境音がどの程度減ったか」を感覚ではなく数字で記録したい場合
- <strong>不十分なケース</strong> : 防音室の遮音等級（D値・Dr値）を正式に証明したい場合（専門業者の実測が必要）
- <strong>不十分なケース</strong> : 低音域を正確に評価したい場合（スマホマイクは低音の感度が低く出やすい）

## 【iOS/Android】無料で使える騒音測定アプリ比較

| アプリ名 | 対応OS | できること | 限界 |
| :--- | :--- | :--- | :--- |
| <strong>デシベル計</strong>系アプリ（複数の無料アプリが該当） | iOS/Android | 現在の音量をdB表示でリアルタイム確認 | 機種間誤差が大きく、絶対値の証明には不向き |
| <strong>Sound Meter</strong>系アプリ | Android | 最大値・平均値の記録、簡易グラフ化 | 低音域の感度がスマホ機種によって大きく異なる |
| <strong>NIOSH Sound Level Meter</strong> | iOS | 米国労働安全衛生研究所が開発、比較的信頼性の高い校正ロジック | 英語表記、日本の生活騒音の文脈には設計されていない |

無料アプリは頻繁に仕様変更・配信終了が起きるため、ストアで<strong>「校正（キャリブレーション）」「外部マイク対応」の有無</strong>を確認してから選ぶことをおすすめします。

## 周波数まで見たい人向け：スペクトラムアナライザー系アプリ

dBの一点表示だけでなく、<strong>どの周波数帯が問題なのか</strong>を知りたい場合は、リアルタイムでスペクトラム（周波数ごとの音量分布）を表示するアプリが有効です。

低音のこもり・定在波が疑われる場合は、低音域にピークが出ていないかを確認します。ベーストラップの設置効果を測定する手順は[ベーストラップ自作・設置ガイド](/ja/diy/bass-trap-installation-guide/)で詳しく解説しています。

## もう一段正確に測りたい場合：外部マイク＋PCソフトという選択肢

本格的に効果を検証したい場合は、スマホ単体ではなく<strong>USB接続の測定用マイクとPC用の無料音響測定ソフト</strong>を組み合わせる方法があります。

測定用マイクは指向性・周波数特性が公開されているため、スマホ内蔵マイクより再現性の高いデータが得られます。具体的な測定手順・必要な機材は[ベーストラップ自作・設置ガイド](/ja/diy/bass-trap-installation-guide/)の「効果測定の方法」セクションを参照してください。

正式な遮音等級（D値）の考え方そのものを知りたい場合は、[D値の嘘と本当](/ja/knowledge/d-value-truth-and-myths/)、用途別にどこまで音が軽減されるかの目安は[防音室で音はどこまで消える？用途別の軽減率を徹底検証](/ja/soundproof-room/sound-reduction-simulation/)も参考になります。

アプリで測った「対策前後の何dB減ったか」という数値を、楽器・交通音・配信音などの身近なシーンに置き換えてイメージしたい場合は、[防音室の-dB軽減効果とは？楽器・交通音・空港・配信音で分かる体感早見表](/ja/knowledge/db-reduction-familiar-sound-scale/)も参考になります。

## 何dB減れば「効果があった」と言えるか

一定の差が出れば効果あり、と一律には決められません。

音の種類や測定条件で差が変わるため、同じ条件で繰り返し測り、聞こえ方とあわせて傾向を見ます。

アプリの表示値だけで、違法かどうかや音源を判断しないようにします。

生活への影響を記録して相談する場合は、[上の階の足音の記録方法と管理会社への伝え方](/ja/soundproof-rental/upstairs-footsteps-noise/)を参考にしてください。

## 測定のコツ：設定と持ち方

- <strong>A特性（dB(A)）を選ぶ</strong> : 人の聴感に近い重みづけ。多くのアプリで選べます
- <strong>最大値と平均値を分けて見る</strong> : 突発的な音は最大値、継続する音は平均値で比べます
- <strong>端末の位置を固定する</strong> : 三脚やスタンドで、高さと向きをそろえます
- <strong>マイクをふさがない</strong> : ケースや手でマイク穴を覆うと値がずれます
- <strong>測る前に環境音を記録する</strong> : 対策前後とも、暗騒音（何も鳴らしていない状態）を測っておきます

## 測定するタイミングと記録のコツ

- <strong>対策前に必ず基準値を取る</strong> : 対策後だけ測っても比較ができません。施工・設置の前に同条件で測定しておきます
- <strong>同じ時間帯・同じ場所で測る</strong> : 交通量や生活音は時間帯で変動するため、できるだけ同じ条件（曜日・時間・窓の開閉状態）で測定します
- <strong>複数回測って平均を見る</strong> : 一度だけで決めず、繰り返して傾向を確認します

## よくある質問

### 騒音計アプリの誤差は、どのくらいですか？

端末とアプリで異なり、表示値がずれることがあります。

絶対値の正確さを保証するものではないため、同じ端末で対策前後を比べる使い方が向いています。

### iPhoneとAndroidでは、どちらが正確ですか？

一概には言えません。

マイクの特性は機種ごとに違うため、OSではなく、校正機能や外部マイク対応の有無で選ぶのが現実的です。

### 防音室の遮音性能（D値）を、アプリで測れますか？

正式な測定はできません。

D値の測定には、規格に沿った方法と機材が必要です。アプリは、対策の前後を比べる目安として使ってください。

### 低い音（ベースや足音）は測れますか？

苦手です。

スマホのマイクは、低音域の感度が低く出やすいためです。低音を評価したい場合は、外部マイクと測定ソフトを検討してください。

## まとめ：目的別おすすめの選び方

| 目的 | おすすめの方法 |
| :--- | :--- |
| <strong>DIY対策の効果を手早く確認したい</strong> | 無料の騒音計アプリで対策前後を比較 |
| <strong>低音のこもり・定在波を診断したい</strong> | スペクトラムアナライザー系アプリ |
| <strong>本格的に検証したい・記録を残したい</strong> | 外部マイク＋PC用音響測定ソフト |
| <strong>正式な遮音等級を証明したい</strong> | 専門業者による実測を依頼 |

スマホアプリは「無音にできたかどうか」を証明する道具ではなく、「対策が効いている方向に進んでいるか」を確認するための道具と捉えるのが、過度な期待をせずに使いこなすコツです。

私なら、同じスマホ・同じ場所・同じ音で、対策の前と後を何回か測って比べます。1回だけだと、たまたま入った物音で数字がぶれるからです。
