「石膏ボードを2枚重ねて壁を厚くしたのに、人の話し声だけ思ったより聞こえる」——このような相談を受けることがあります。

<strong>遮音の基本原則である「質量則」は、壁が重いほど遮音性能が上がるという考え方</strong>ですが、実際にはすべての周波数で単純に比例するわけではありません。特定の周波数帯で遮音性能が谷のように落ち込む現象があり、これを<strong>「コインシデンス効果」</strong>と呼びます。

この記事では、質量則のおさらいから、コインシデンス効果が起きる仕組み、実務での対策までを解説します。

## 質量則とは｜遮音の基本原則

質量則（マスの法則）とは、<strong>「壁の面密度（重さ）が2倍になると、遮音性能は約6dB向上する」</strong>という遮音設計の基本原則です。

<strong>質量則の考え方</strong>

- <strong>重い壁ほど遮音性能が高い</strong> : コンクリートや鉛のように密度の高い材料は遮音に有利
- <strong>面密度が2倍→遮音性能+6dB</strong> : 石膏ボードを2枚から4枚に増やすと理論上6dB向上する
- <strong>単一材質の壁を前提とした理論</strong> : 複合構造や中空層がある壁には別の考え方が必要

質量則は防音設計の出発点として重要ですが、<strong>「重ければ重いほど、すべての周波数で必ず遮音性能が上がる」わけではない</strong>点に注意が必要です。

## コインシデンス効果とは｜質量則が崩れる現象

コインシデンス効果とは、<strong>壁材の中を伝わる「曲げ波」の伝わる速さと、空気中を伝わる音波の速さが特定の角度・周波数で一致（コインシデンス＝一致）することで、遮音性能が局所的に大きく低下する現象</strong>です。

<strong>なぜ性能が落ちるのか</strong>

- <strong>壁は音を受けると微妙に振動（曲げ波）する</strong> : 硬い材料でも音のエネルギーを受けて板全体がわずかにたわむ
- <strong>特定の周波数で共振的にエネルギーが伝わる</strong> : 曲げ波の速度と入射音波の速度が一致する「コインシデンス周波数」付近では、壁が音のエネルギーを効率よく反対側へ伝えてしまう
- <strong>この現象は材料の厚み・硬さ・密度で決まる</strong> : 材質や厚みが変わればコインシデンス周波数も変わる

<strong>単一材質・単一厚みの壁ほど、この谷（ディップ）がはっきり出やすい</strong>のが特徴です。石膏ボード1枚だけの壁は、特定の周波数帯（人の声や中高音域に重なりやすい帯域）で遮音性能が想定より落ち込むことがあります。

## なぜ「壁を厚くしただけ」では解決しないのか

石膏ボードを同じ材質のまま重ねて厚くする対策は、質量則の観点では有効ですが、<strong>同じ材質を重ねただけではコインシデンス周波数がほぼ変わらない</strong>ため、特定の音域の抜けが解消しないことがあります。

<strong>よくある誤解</strong>

- <strong>「厚くすれば厚くするほど比例して静かになる」という誤解</strong> : 質量則は目安であり、コインシデンス効果による落ち込みは別途考慮が必要
- <strong>同一材質を重ねるだけの対策の限界</strong> : 石膏ボードを2枚、3枚と同じ厚みのまま重ねても、コインシデンス周波数は大きく動かない

## 実務での対策

コインシデンス効果による性能の落ち込みを緩和するには、以下のような設計上の工夫が使われます。

- <strong>異なる厚み・材質を組み合わせる</strong> : 石膏ボードとケイ酸カルシウム板など、厚みや密度が異なる材料を組み合わせることで、それぞれのコインシデンス周波数をずらし、谷を埋め合う
- <strong>制振材（防振ゴム・制振シート）を挟む</strong> : 壁の振動そのものを減衰させることで、コインシデンス効果による共振的なエネルギー伝達を抑える
- <strong>中空層・空気層を設ける</strong> : 二重壁構造にして空気層を挟むことで、単一壁のコインシデンス効果とは異なる遮音特性を持たせる
- <strong>施工業者に周波数特性のデータを確認する</strong> : カタログのD値・Rw値は単一の数値にまとめられているため、可能であれば周波数帯ごとの遮音性能グラフを確認し、極端な落ち込みがないかを見る

## まとめ：厚みだけでなく「組み合わせ」で設計する

コインシデンス効果は、質量則だけでは説明できない遮音性能の落ち込みを引き起こす現象です。

<strong>覚えておきたいポイント</strong>

- <strong>質量則は「重いほど遮音性能が上がる」という基本原則だが、すべての周波数で一様に当てはまるわけではない</strong>
- <strong>コインシデンス効果は、材料の曲げ波と音波の速度が一致する周波数で遮音性能が落ち込む現象</strong>
- <strong>同一材質を重ねるだけでなく、異なる材質・制振材の組み合わせで谷を埋める設計が有効</strong>

「壁を厚くしたのに特定の音だけ漏れる」と感じたら、質量則だけでなくコインシデンス効果の観点から壁の構成を見直してみることをおすすめします。
