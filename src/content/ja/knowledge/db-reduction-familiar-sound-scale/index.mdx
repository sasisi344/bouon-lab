「D-40で20dB軽減」と言われても、実際にどれくらい静かになるのかピンとこない方が多いのではないでしょうか。

防音室のカタログには「-dB」という数字が並びますが、この数字だけでは音の軽減効果を実感しにくいものです。本記事では、<strong>楽器演奏・睡眠を妨げる交通騒音・空港騒音・配信者の声漏れ</strong>という4つの身近なシーンを例に、防音室がどれくらい静かになるかを目安として解説します。

## なぜ「-dB」だけでは伝わりにくいのか

デシベル（dB）は<strong>対数で表される単位</strong>で、数字が直線的に増減する感覚とは異なります。10dB下がると人の耳には「音の大きさが半分になった」と感じられるのが目安です。

しかし「D-40で20dB軽減」と言われても、その20dBが日常のどの音に相当するのかが分からなければ、実際の静けさをイメージできません。<strong>数値そのものより、身近な音との比較で捉える方が体感に近づきます</strong>。

## 身近な音のdB早見表

まずは、身近な場所の音の大きさを目安として確認しましょう。

| dB | 身近な空間 | 体感の言い方 |
| :--- | :--- | :--- |
| <strong>30dB</strong> | ホテルの客室 | とても静か。小さな物音も目立つ |
| <strong>40dB</strong> | 図書館の館内、住宅地の夜 | 静か。ただし音楽が鳴っていれば分かる |
| <strong>50dB</strong> | 書店の店内、マンションが多い地域の昼 | 静かだが、人の気配や物音がある |
| <strong>60dB</strong> | 銀行の窓口、博物館の館内 | ふつうに話す声の大きさ |
| <strong>70dB</strong> | バスの車内、コーヒーショップ | 少し声を張らないと話しにくい |
| <strong>80dB</strong> | 地下鉄の車内、飛行機の機内 | 大きな声でないと話せない |
| <strong>90dB</strong> | パチンコ店の店内 | 長くいるとつらい |

出典: [環境省「騒音の目安」](https://www.env.go.jp/air/ippan/meyasu.pdf)（全国環境研協議会 騒音小委員会）をもとに10dB刻みで整理

<strong>これらの数値はあくまで目安であり、場所や時間帯によって変動します。</strong>防音室のD値がこの早見表のどのあたりまで音を落とし込めるのか、という感覚で以降を読み進めてください。

## 対象別に見る防音室の軽減効果

「防音室が必要な人」の悩みは一様ではありません。ここでは代表的な4つのシーン別に、必要な軽減量の考え方を整理します。

- <strong>楽器演奏</strong> : 発生源そのものが80〜110dBと大きく、外へ漏らさないための遮音が目的
- <strong>睡眠を妨げる交通騒音</strong> : 外から侵入する70〜90dBの騒音を、就寝に適したレベルまで下げるのが目的
- <strong>空港騒音</strong> : 突発的かつ広帯域の音圧を、生活時間帯全体で軽減する必要がある
- <strong>配信者の声漏れ防止</strong> : 自分の声（60〜80dB）を外部に漏らさない、内向きの遮音が目的

### 楽器演奏の場合｜発生源の大きな音を外に出さない

ピアノは正面1mで<strong>80〜90dB</strong>、管楽器やドラムは<strong>100dBを超える</strong>こともあります。

100dBは、電車が通るときのガード下に近い大きさです。

D-40の防音室であれば、理論上は<strong>40dB前後の軽減</strong>が見込めます。

ピアノなら外では40〜50dB、図書館の館内から書店の店内くらいの大きさまで下がる計算です。

ただし夜の住宅地も40dB前後と静かなため、この大きさでも曲が流れていることは分かります。

110dBのドラムなら、外でも70dB前後、バスの車内くらいの大きさが残ります。ただし低音域は減衰しにくいため、<strong>ドラムやベースなど低音楽器はカタログ値より軽減幅が小さく感じられる</strong>点に注意が必要です。楽器・用途別の推奨D値は[遮音性能の基準「D値」とは？楽器・用途別の目安](/ja/soundproof-room/bouon-dchiseinou-meyasu/)で詳しく確認できます。

### 睡眠を妨げる交通騒音の場合｜高速道路・線路・貨物列車

高速道路沿いの走行音は<strong>約70〜80dB</strong>、線路沿いで夜間に通過する貨物列車の通過音は<strong>瞬間的に80dB前後</strong>に達することがあります。

これらは地下鉄の車内に近い大きさの音が、就寝中の部屋に侵入している状態です。窓の防音強化や防音室相当の遮音性能を持たせることで、<strong>侵入音をホテルの客室くらいの30dB台まで抑えられれば、入眠を妨げにくい環境</strong>に近づきます。ただし低周波の振動成分は壁の遮音だけでは防ぎきれないため、防振対策を併用するのが現実的です。

### 空港が近い場合｜突発的な音圧への対策

空港周辺では、離着陸時に<strong>瞬間的に80〜90dB</strong>の航空機騒音が発生することがあります。持続時間は短いものの、頻度が高く生活時間帯を通じて繰り返されるのが特徴です。

このケースでは、瞬間的なピーク音を抑えると同時に、<strong>窓・壁・換気口といった音の侵入経路をまんべんなく遮音する</strong>ことが重要になります。一部分だけ性能を上げても、隙間から音が回り込んでしまうためです。

### 配信者・VTuberの場合｜自分の声を外に漏らさない

配信者やVTuberが求める防音は、外の音を遮断するというより<strong>自分の声（約60〜80dB）を外に漏らさない</strong>という、他の3つのケースとは逆方向の遮音です。

深夜のボイスチャットや叫び声を伴う実況配信では、瞬間的に80dB近くまで声量が上がることもあります。D-30〜35程度の遮音性能があれば、隣室では「何か話しているらしい」と分かる程度まで軽減できる目安です。深夜帯まで見据える場合は、暗騒音が小さくなる分だけ余裕を持ったD値を選ぶと安心です。

## ケース別に見る軽減効果の考え方

4つのケースを、目的別に整理すると以下のようになります。

| ケース | 音源の目安 | 遮音の方向 | 目安となるD値 |
| :--- | :--- | :--- | :--- |
| 楽器演奏 | 80〜110dB | 内から外へ | D-40〜60 |
| 交通騒音対策（睡眠） | 70〜80dB | 外から内へ | D-35〜45 |
| 空港騒音対策 | 80〜90dB（瞬間） | 外から内へ（全方位） | D-40〜50 |
| 配信者の声漏れ防止 | 60〜80dB | 内から外へ | D-30〜35 |

<strong>D値の数字は同じでも、対策すべき音の方向（内から外か、外から内か）が異なる</strong>ため、自分の悩みがどちらに近いかを整理してから防音室や防音リフォームを検討すると、必要な性能を見誤りにくくなります。カタログのD値が実際の設置環境でどこまで再現されるかという注意点は、[D値の嘘と本当｜カタログスペックだけで選ぶと失敗する理由](/ja/knowledge/d-value-truth-and-myths/)で解説しています。

自宅の音環境を実際に数値で確認したい場合は、簡易的な騒音計で測定してみるのもおすすめです。

## まとめ｜数字より「身近な音」で軽減効果をイメージする

防音室の「-dB」という数字は、単体では実感しにくい指標です。しかしホテルの客室・図書館・書店・銀行の窓口・バス・地下鉄といった<strong>身近な場所の音の大きさに置き換えることで、どれくらい静かになるかを具体的にイメージできます</strong>。

- <strong>楽器演奏</strong> : 発生源の80〜110dBを外に漏らさない対策
- <strong>睡眠を妨げる交通騒音</strong> : 侵入する70〜80dBを就寝レベルまで下げる対策
- <strong>空港騒音</strong> : 瞬間的な80〜90dBを全方位から抑える対策
- <strong>配信者の声漏れ防止</strong> : 自分の声60〜80dBを外に出さない対策

自分の悩みがどのケースに近いかを見極めたうえで、必要なD値の目安を確認してください。海外製の防音建材を検討している場合は、日本のD値と単純比較できない点にも注意が必要です。詳しくは[D値とRw値は換算できない｜日本と海外の遮音等級を混同すると失敗する理由](/ja/knowledge/d-value-vs-rw-value-confusion/)をご覧ください。
