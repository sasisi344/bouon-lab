防音工事の坪単価は、ピアノ・声楽向けに部屋まるごとを防音室にする場合で<strong>約50万〜155万円/坪</strong>、ドラム向けで<strong>約105万〜230万円/坪</strong>が目安です。

これは注文住宅の建物本体の坪単価（2025年度の全国平均で約119万円/坪）とは<strong>別に</strong>かかる費用なので、2つを分けて試算すると予算が読みやすくなります。

本記事では、公的統計と施工会社の公表価格をもとに、地域差の正体、新築で組み込む場合と後付けの差、ローコスト住宅で防音室を作るときの考え方までを表で整理します。

<strong>本記事の数値はすべて公的統計・公表価格をもとにした目安です。実際の金額は土地条件・仕様・依頼先で大きく変わるため、必ず複数のハウスメーカー・工務店から個別に見積もりを取ってください。</strong>

## 防音工事の坪単価の目安（用途別）

防音工事の費用は、部屋の広さよりも<strong>どの音をどこまで下げるか</strong>で決まります。

下の表は、防音工事の専門会社が公式サイトで公表している「〜万円から」の価格を、1坪あたりに換算したものです。

| 用途 | 6畳の公表価格 | 8畳の公表価格 | 1坪あたりに換算 |
| :--- | :--- | :--- | :--- |
| <strong>ピアノ・声楽・シアター</strong> | 約160万〜460万円（6社） | 約200万〜490万円（4社） | <strong>約50万〜155万円/坪</strong> |
| <strong>管楽器・エレキギター</strong> | 約420万〜455万円（1社） | 約460万〜515万円（1社） | 約115万〜155万円/坪（各1社のみ） |
| <strong>ドラム・打楽器</strong> | 約380万〜680万円（2社） | 約420万〜760万円（4社） | <strong>約105万〜230万円/坪</strong> |

6畳は約2.9坪、8畳は約3.9坪として換算しました。

各社の価格と出典は、[防音室リフォームの費用相場｜6畳・8畳・10畳の総額とユニットとの分かれ目](/ja/money/soundproof-reform-cost-by-tatami/)にまとめています。

### この坪単価の読み方

- <strong>部屋の中にもう一つ部屋を作る費用である</strong> : 壁・天井・床・ドア・窓・換気を一体で作る「部屋まるごと」の価格です
- <strong>リフォームの公表価格がもとになっている</strong> : 新築で組み込む場合の上乗せ額を公表している会社は少ないため、リフォームの価格を上限の目安として使っています
- <strong>広いほど1坪あたりは安くなる</strong> : ドア・窓・換気・設計の費用は広さにかかわらずほぼ一定のため、8畳のほうが1坪あたりは割安です
- <strong>性能が1段上がるごとに階段状に上がる</strong> : ある会社の6畳の参考価格では、D-40で150万円〜、D-60で250万円〜と、等級ごとに約50万〜100万円ずつ上がっています

### 部屋まるごとでなく、部分的な防音で足りる場合

テレワークの通話や寝室の静けさが目的なら、部屋まるごとの防音室は要らないこともあります。

その場合は、部位ごとの工事を組み合わせます。

| 工事 | 6畳程度での目安 |
| :--- | :--- |
| <strong>壁の増し打ち</strong> | 約15万〜40万円 |
| <strong>床の浮き床化</strong> | 約30万〜60万円 |
| <strong>ドア・窓の交換</strong> | 1か所あたり約8万〜25万円 |

部位ごとの工事の目安は、[防音工事の業者の選び方](/ja/money/soundproof-contractor-selection-guide/)のよくある質問で紹介しているものです。

音は一番弱いところから漏れるため、窓だけ・壁だけの工事は、どの経路から音が来ているかを確かめてから選んでください。

## 注文住宅の建物坪単価の目安（地域別・2025年度）

次に、防音工事を足す前の「家そのもの」の坪単価です。

住宅金融支援機構の「2025年度フラット35利用者調査」（2026年7月24日公表）から、土地をすでに持っている人の注文住宅の建設費と住宅面積を使い、坪単価を計算しました。

| 地域 | 建設費の平均 | 住宅面積の平均 | 坪単価（計算値） |
| :--- | :--- | :--- | :--- |
| <strong>首都圏</strong> | 4,761.5万円 | 121.6㎡（約36.8坪） | <strong>約129万円/坪</strong> |
| <strong>近畿圏</strong> | 4,269.8万円 | 117.5㎡（約35.5坪） | 約120万円/坪 |
| <strong>東海圏</strong> | 4,348.8万円 | 121.0㎡（約36.6坪） | 約119万円/坪 |
| <strong>その他地域</strong> | 4,012.6万円 | 116.5㎡（約35.2坪） | 約114万円/坪 |
| <strong>全国</strong> | 4,259.8万円 | 118.4㎡（約35.8坪） | <strong>約119万円/坪</strong> |

坪単価は「建設費÷住宅面積」で計算した値で、調査が公表している数字ではありません。

フラット35を使った人だけの集計なので、全体の相場とずれる可能性もあります。

全国の建設費は前年度（3,932.1万円）から8.3%上がっており、見積もりは最新の金額で取り直すことをおすすめします。

## 地域差の正体は、建物より土地代

「東京の注文住宅は高い」という印象の多くは、<strong>建物ではなく土地代の差</strong>から来ています。

同じ調査で、土地も一緒に買った人（土地付注文住宅）の数字を比べると、差がはっきりします。

| 地域 | 建設費 | 土地取得費 |
| :--- | :--- | :--- |
| <strong>首都圏</strong> | 3,814.3万円 | <strong>2,590.0万円</strong> |
| <strong>近畿圏</strong> | 3,601.7万円 | 1,884.3万円 |
| <strong>東海圏</strong> | 3,871.1万円 | 1,453.5万円 |
| <strong>その他地域</strong> | 3,734.3万円 | <strong>1,016.5万円</strong> |

首都圏とその他地域の差は、建設費が約80万円なのに対し、土地取得費は<strong>約1,570万円</strong>です。

つまり、首都圏だから防音室が作れないのではなく、<strong>土地にかかるお金が防音室の予算を圧迫しやすい</strong>というのが実態に近い見方です。

すでに土地を持っている人は、上の建物坪単価の表に防音工事の費用を足せば、ほぼ総額になります。

これから土地を買う人は、希望エリアの地価を先に確認し、建物・土地・防音を別枠で予算を組んでください。

## 防音室を足すと総額はいくらになるか（試算）

全国平均の注文住宅（約35.8坪・4,259.8万円）に、ピアノ向けの6畳の防音室を足す場合を試算します。

| 項目 | 金額の目安 |
| :--- | :--- |
| 建物本体（全国平均） | 4,259.8万円 |
| ピアノ向け6畳の防音工事 | 約160万〜460万円 |
| <strong>合計</strong> | <strong>約4,420万〜4,720万円</strong> |
| 建物本体に対する割合 | 約4〜11% |

新築では、その部屋の普通の内装費がもともと建設費に入っているため、実際の上乗せはこの試算より小さくなることがあります。

逆に、ドラム向けの6畳なら約380万〜680万円で、建物本体の約9〜16%になります。

防音室の広さは、延床面積の全国平均（約36坪）を目安に、防音室分を足して考えると具体的になります。

| 延床面積の目安 | 部屋数のイメージ |
| :--- | :--- |
| <strong>25〜30坪</strong> | 3LDK前後。防音室1室を含めるとやや手狭 |
| <strong>35坪前後</strong>（全国平均に近い） | 4LDK＋防音室1室を組み込みやすい |
| <strong>40坪以上</strong> | 防音室・書斎など個室を複数確保しやすい |

部屋の位置や広さの決め方は、[注文住宅で防音室を作る間取りのポイント](/ja/soundproof-room/custom-home-soundproof-room-layout/)で解説しています。

## 新築で組み込む場合と、リフォームで後付けする場合の費用差

同じ広さの防音室でも、新築で組み込むか、住んでから後付けするかで費用の構造が変わります。

| 比較軸 | 新築時に組み込む | リフォームで後付け |
| :--- | :--- | :--- |
| <strong>費用</strong> | 上の坪単価が上限の目安。既存の内装を壊す費用がかからない | 上の坪単価に、解体費（6畳で約15万〜20万円と公表する会社あり）が加わる |
| <strong>構造の自由度</strong> | 床の防振・壁の厚み・天井高を設計の段階から一体で決められる | 既存の柱・梁・床の位置に制約される。木造では構造補強が別途必要な場合がある |
| <strong>広さ</strong> | 防音の厚みを見込んで部屋の寸法を決められる | 部屋の内側に作るため、6畳が約5.2畳になる例がある |
| <strong>向いている人</strong> | これから新築を計画し、防音の必要がほぼ決まっている人 | 入居後に必要になった人、部分的な防音で足りる人 |

<strong>新築で組み込むほうが、同じ仕様でも総費用を抑えやすい</strong>のが一般的な傾向です。

将来、防音室を作るかもしれない段階なら、間取りが決まる前に「防音がほしい部屋がある」と伝えておくだけでも、床の下地など後から対応しやすい準備をしてもらえる場合があります。

## ローコスト住宅で防音室は作れるか

ローコスト住宅でも、防音室を作ること自体は可能です。

ただし、次の2点で<strong>防音にかかる費用の割合が大きくなりやすい</strong>ことを前提にしてください。

- <strong>防音工事の費用は、建物の坪単価に比例して下がらない</strong> : 防音室の壁・ドア・窓・換気の費用は、本体が安くても同じようにかかります
- <strong>仕様の変更が標準外になりやすい</strong> : 間取りや部材を規格化してコストを下げている場合、壁の構成や窓の仕様の変更がオプション扱いになりやすいため、対応できる範囲を最初に確認します

予算が限られる場合は、防音の要望を3段階に分けて考えると、削る順番を決めやすくなります。

| 段階 | 内容 | 費用の目安 |
| :--- | :--- | :--- |
| <strong>間取りでの配慮</strong> | 音を出す部屋と寝室を離す、隣家側に窓を作らない | 設計の工夫が中心で、追加費用は小さい |
| <strong>部屋ごとの防音強化</strong> | 1室だけ壁・窓・ドアを強化する | 部位ごとに数十万円〜 |
| <strong>専用の防音室</strong> | 部屋まるごとを防音室にする | 6畳で約160万円〜（ピアノ向け） |

3つの道の比べ方は、[音の悩みの解決策は3つ｜防音賃貸への引っ越し・後付け・注文住宅の設計段階で伝える道](/ja/soundproof-room/noise-solutions-relocate-retrofit-custom-home/)で整理しています。

## 新築戸建て・住宅購入のどの段階で、防音の予算を決めるか

| あなたの状況 | 先に決めること |
| :--- | :--- |
| <strong>これから土地探しから始める</strong> | 土地代の地域差が総額を左右します。建物の比較より先に、希望エリアの地価を確認し、防音に回せる額を残せるかを見ます |
| <strong>土地をすでに持っている</strong> | 建物坪単価＋防音工事の費用がほぼ総予算です。依頼先の実績坪単価と照らし合わせます |
| <strong>防音室が必要か、まだ決まっていない</strong> | 「防音がほしい部屋がある」とだけ設計者に伝え、将来対応できる下地を相談します |
| <strong>建売住宅・中古住宅の購入も考えている</strong> | 後付けになるため、解体費・構造補強を含めて比べます |

依頼先によって、防音室の実績や見積もりの出し方が違います。

ハウスメーカー・工務店・設計事務所の違いと、資料請求から契約までの流れは、[注文住宅で防音室を作る依頼先｜選び方と流れ](/ja/soundproof-room/custom-home-soundproof-builder-selection/)で解説しています。

大手ハウスメーカーの防音の公式表記は、[防音室が作れるハウスメーカーおすすめ4社｜注文住宅の公式防音仕様を比較](/ja/soundproof-rental/housing-builder-soundproof-comparison/)で比べています。

## 資金計画を具体化する3ステップ

1. <strong>希望エリアの地価を確認する</strong> : 自治体の公示地価・基準地価や不動産ポータルで、土地代の目安を把握します
2. <strong>複数の依頼先に「防音室を含める前提」で概算見積もりを依頼する</strong> : 建物本体と防音工事を分けて書いてもらい、壁・床・天井・ドア・窓・換気の項目に漏れがないか確認します
3. <strong>住宅ローンの事前審査を、防音室を含めた総額で申し込む</strong> : 契約後に防音室だけ別のローンにすると、金利の条件が不利になりやすいためです

防音室の費用を住宅ローンに含める手順は、[ピアノと住宅ローン｜防音室・ピアノ室は組み込める、ピアノ本体は別が基本](/ja/money/piano-soundproof-mortgage-tax-guide/)で解説しています。

防音室だけをローン・分割払いで買う場合の月々の目安は、[防音室ローン・分割払い完全ガイド2026](/ja/money/soundproof-room-loan-guide/)で確認できます。

## よくある質問

<strong>Q. 防音工事の坪単価だけで、防音室付き住宅の総額は計算できますか？</strong>

A. 計算できません。建物本体の坪単価、土地代、防音工事の費用を別々に積み上げる必要があります。坪単価はあくまで目安で、最終的には個別の見積もりで確認してください。

<strong>Q. 防音室は新築時に組み込まないと作れませんか？</strong>

A. リフォームで後付けもできます。ただし、既存の内装を壊す費用や構造補強がかかることがあり、部屋も狭くなるため、新築で組み込むほうが総費用を抑えやすい傾向があります。

<strong>Q. 東京で家を建てると、防音室の費用も高くなりますか？</strong>

A. 総額が高くなる主な理由は土地代です。2025年度の調査では、土地付注文住宅の建設費は首都圏とその他地域で約80万円の差でしたが、土地取得費は約1,570万円の差がありました。

<strong>Q. 固定資産税への影響はどう考えればよいですか？</strong>

A. 防音室で床面積や内装の仕様が上がると、評価額に影響する可能性はありますが、金額は自治体の個別評価によります。詳しくは[防音室・ピアノ室は住宅ローンに組み込める](/ja/money/piano-soundproof-mortgage-tax-guide/)を参照し、自治体の窓口や税理士に確認してください。

## まとめ

防音工事の坪単価は、ピアノ向けの部屋まるごとで約50万〜155万円/坪、ドラム向けで約105万〜230万円/坪が目安です。

注文住宅の予算は、<strong>建物本体の坪単価・土地代・防音工事の費用を分けて積み上げる</strong>と精度が上がります。

地域による総額の差の多くは土地代で、建物本体の差はそれほど大きくありません。

防音室は新築で組み込むほうが費用を抑えやすいため、間取りが決まる前に、依頼先へ防音の希望を伝えることから始めてください。
