「防音室 予算10万円」と検索する人は少なくありません。

新品のユニット防音室は0.8畳クラスでも70万円台からで、10万円では届きません。

そこで「中古なら半額で買えるのでは」と考えるのは自然な発想です。

ただし、<strong>予算10万円で中古を探すなら、最初に決めるのは「どの製品を探すか」です。</strong>

結論は次のとおりです。

- <strong>中古で狙うなら</strong> : だんぼっち・OTODASUのような、1畳前後の組み立て式。元値が8万〜16万円程度で、送料・設置費も小さく済みます
- <strong>セフィーネなど100万円クラス</strong> : 中古でも運搬・解体・再組立費が乗ります。中古を探すくらいなら、公式のレンタル・サブスクを使うほうが現実的です

この記事では、元の製品の価格から逆算した総額で、中古に向く製品と向かない製品を整理します。

## 予算10万円は『元の製品の価格』で決まる

中古の価格は、元の新品価格の半額前後になることが多いです。

そのため、中古の本体価格より先に、<strong>元の製品がいくらだったか</strong>を確認します。

下の表は、新品価格の目安と、中古が「新品の半額」だった場合の本体価格を並べたものです（半額は試算用の仮定です）。

| 製品クラス | 新品価格の目安 | 中古が半額なら | 運搬・設置の負担 |
| :--- | :--- | :--- | :--- |
| だんぼっち | 8万〜9万円台 | 4万円台 | 小さい（組み立て式で軽量） |
| OTODASU II | 15万〜16万円程度 | 7万円台 | 小さい（OTODASUは約30kgとされる） |
| ユニット型 0.8畳（セフィーネNS等） | 77万円（希望小売価格） | 約38万円 | 大きい（解体・運搬・再組立が別途） |
| ユニット型 1.5畳（セフィーネNS等） | 97万9千円（希望小売価格） | 約49万円 | 大きい（同上） |

※新品価格は時期・モデル・販売店で変わります。だんぼっちは公式サイト8万3,500円〜（送料別）・Amazon 9万6,100円〜、OTODASU IIは公式サイト14万4,400円（税抜）・楽天市場の島村楽器で15万400円（送料込み）です（2026年10月時点）。購入前に最新の販売価格を確認してください。ユニット型は[ヤマハ公式の仕様](https://jp.yamaha.com/products/soundproofing/ready-made_rooms/size_08-15/amdb08h/specs.html)の希望小売価格（税込・Dr-35標準壁）です。

予算10万円に収まるのは、上2行の組み立て式だけです（だんぼっちは新品でも、OTODASU IIは中古なら収まります）。

ユニット型は、半額でも本体だけで予算の3〜5倍になります。

## セフィーネ等の100万円クラスを中古で探さない理由

ユニット型の中古は、本体が半額でも<strong>運搬・解体・再組立の費用が別に乗ります</strong>。

数百キロ単位の重量物のため、運搬は専門業者への依頼が事実上必須です。

0.8畳を半額で買った場合の総額は、次のように試算できます。

| 費用項目 | 目安 |
| :--- | :--- |
| 本体（新品77万円の半額） | 約38万円 |
| 解体費 | 5万〜15万円 |
| 運搬費 | 3万〜10万円 |
| 再組立費 | 5万〜20万円 |
| <strong>合計</strong> | <strong>約51万〜83万円</strong> |

※解体・運搬・再組立の金額は、距離・搬入経路・業者で大きく変わる目安です。メーカー系リユースでは、これらが見積もりに最初から含まれることがあります。

運搬費だけでも数万円は上乗せされ、ほとんどの場合、予算10万円どころか50万円を超えます。

しかも中古は、保証がなかったり、パッキンの劣化で遮音性能が落ちていたりするリスクがあります。

だったら、<strong>公式のレンタル・サブスクで新品の状態のものを借りる</strong>ほうが安心です。

ヤマハ「音レント」の最短15ヶ月の総額（登録料・レンタル料・返却時費用を含む、0.8畳）は、次のとおりです。

- <strong>通常プランの新品</strong> : 約32万円
- <strong>MCプランの新品</strong> : 約27万円
- <strong>MCプランのUSED</strong> : 約23万円（在庫分のみ）

搬入・設置の基本料金はレンタル料に含まれ、中古のように業者を自分で手配する必要がありません。

ただし最短15ヶ月の契約で、途中で返却しても残りのレンタル料を払います。

料金の詳細と購入との損益分岐点は、[防音室レンタルの初期費用と月額相場｜2026年最新・購入との損益分岐点](/ja/money/soundproof-room-rental-cost/)で計算しています。

レンタルとリースの違いと、個人・法人の借り方は[防音室はレンタル・リース可能？個人と法人の「一番賢い借り方」と料金比較](/ja/money/soundproof-room-rental-lease/)で解説しています。

## 中古で狙うなら『だんぼっち・OTODASU』

予算10万円で中古を探すなら、狙いは1畳前後の組み立て式です。

- <strong>元値が低い</strong> : 新品が8万〜16万円程度（2026年10月時点）なので、中古の本体価格は数万円で収まりやすくなります
- <strong>送料・設置費が小さい</strong> : パネルを分解して送れ、工具なしで組み立てられる製品が多いため、解体・再組立の業者手配がほぼ不要です
- <strong>失敗しても傷が浅い</strong> : 性能が合わなくても、数万円の損失で済みます

一方、できることには限界があります。

だんぼっち・OTODASUの遮音性能は、D-15〜D-25程度の目安です。

話し声・タイピング・通常のボイスチャット・配信には向きますが、楽器演奏や大声には向きません。

ピアノや管楽器の防音を目的にするなら、組み立て式の中古は選択肢から外し、上記のレンタルを検討してください。

話し声や配信が目的で、中古が見つからない・状態が不安なときは、新品も候補になります。

だんぼっちはAmazonで買えます。

## どこで買える？購入ルート比較

組み立て式の中古は、次のルートで見つかります。

| ルート | 価格水準 | 保証 | 向いている人 |
| :--- | :--- | :--- | :--- |
| リサイクルショップ | 中間〜安め | なしが多い | 現物を見て即決したい人 |
| 個人売買（メルカリ・ジモティー等） | 最安 | なし | リスクを許容でき、状態を写真で見極められる人 |
| メーカー系リユース・中古専門業者 | やや高め | 業者による | 保証や状態確認を重視する人（主にユニット型） |

だんぼっち・OTODASUは軽量で、個人売買でも<strong>送料が数千円〜1万円台で済むことが多い</strong>製品です。

ユニット型を個人売買で買う場合は、「本体5万円」の出品でも、業者手配の解体・運搬・再組立で20万円以上かかることがあります。

組み立て式でも、梱包サイズが大きい製品は送料が高くなります。

出品者に、梱包サイズと送料の見込みを事前に確認してください。

## 現物確認チェックリスト7項目

写真だけで判断すると、届いてから後悔することがあります。

可能な限り現物を確認し、次の項目を見てください。

- <strong>扉のパッキン</strong> : ゴムが硬化・剥離していないか。扉を閉めた際の密閉感を確認する
- <strong>型番・製造年</strong> : 本体の型番シールで世代を確認する
- <strong>臭い</strong> : タバコ・ペット・カビの臭いが染み付いていないか
- <strong>パネル接合部のゆがみ</strong> : 設置と解体を繰り返した個体は、接合部に隙間ができやすい
- <strong>換気ファンの動作</strong> : 異音がないか、実際に動かして確認する
- <strong>付属品の有無</strong> : 照明・換気扇・窓パネルが標準仕様どおり揃っているか
- <strong>搬入経路の実測</strong> : 自宅の玄関・廊下・エレベーターのサイズと、パネルの最大寸法を照合する

<strong>目安として、製造から3〜5年以内・パッキン交換歴のある個体を優先すると、性能劣化のリスクを抑えられます。</strong>

現物確認ができない遠方からの購入は、これらのチェックができないまま契約することになるため、慎重に判断してください。

## ユニット型を中古で買うなら（予算に余裕がある人向け）

予算を50万円以上確保できる場合は、ユニット型の中古も選択肢に入ります。

中古市場で多く出回るのは、ヤマハ「アビテックス（セフィーネ）」とカワイ「ナサール」です。

どちらも数年おきにモデルチェンジしており、<strong>世代によって遮音性能・扉のパッキン構造が異なります</strong>。

- <strong>アビテックス（セフィーネ NS以降）</strong> : 現行世代は遮音性能・気密性が改善されています。型番に「NS」が付くかどうかが世代の目印になります
- <strong>ナサール（LHSX・LKSXシリーズ等）</strong> : モデルチェンジのたびに扉の気密構造が更新されています。型番シールは本体内部に貼られていることが多いので、出品者に確認を依頼しましょう

両モデルの特徴と価格帯は、[防音室おすすめ比較｜失敗しない選び方と5年後の売却価格（ROI）を分析](/ja/soundproof-room/bouon-osusume-hikaku/)、[カワイ防音室ナサール（Nasal）完全ガイド](/ja/soundproof-room/kawai-nasal-soundproof-room-guide/)で比べています。

各メーカーの新製品・モデルチェンジの最新動向は[防音室メーカー最新ニュース｜新製品・モデルチェンジ](/ja/knowledge/proofroom-maker-2025productcheck/)も参考にしてください。

ユニット型は本体だけで数百キロあり、2畳クラス以上では1トンに迫ることもあります。

木造アパートや古いマンションでは、床の耐荷重の確認が必要です。

床補強が必要になれば、追加で10万円以上かかります。

計算方法は[築20年のマンションに重さ500kgの防音室を置ける？床補強なしで設置するための安全基準と計算術](/ja/soundproof-rental/apartment-weight-limit-500kg/)を参照してください。

## 中古 vs 新品 vs レンタルの選び方

予算と用途で、選ぶ製品は次のように分かれます。

| 予算・用途 | 向いている選択 |
| :--- | :--- |
| 予算10万円・話し声や配信が中心 | 組み立て式（だんぼっち・OTODASU）の中古 |
| 予算10万円・楽器を演奏したい | 組み立て式では不足しやすい。レンタルや貯金してのユニット型を検討 |
| 予算50万円以上・本格的な防音が必要 | ユニット型の中古（運搬・組立費込みの総額で判断） |
| 数年で使い終える見込み・まず試したい | 公式レンタル・サブスク |

将来的に手放す可能性も踏まえるなら、[防音室の資産価値分析｜リセールバリューと不動産投資的視点でのROI](/ja/money/bouon-asset-value-analysis/)も合わせて確認してください。

## まとめ

- 予算10万円なら、中古で探すのは<strong>元値が8万〜16万円程度の組み立て式（だんぼっち・OTODASU）</strong>
- セフィーネなど100万円クラスは、半額でも運搬・解体・再組立費が乗り、総額が50万円を超えやすい
- 100万円クラスを使いたいなら、中古より<strong>公式のレンタル・サブスク</strong>（0.8畳は最短15ヶ月で約23万〜32万円）が現実的
- 組み立て式でも、現物確認7項目と、梱包サイズ・送料の事前確認は必須
- 判断は本体価格ではなく、運搬・設置を含めた<strong>総額</strong>で行う
