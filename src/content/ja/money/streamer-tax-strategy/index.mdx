防音室を経費にできるのは、収入を得る業務に必要な部分で、趣味や私生活のための部分は含められません。

購入費は原則として減価償却で各年に分けますが、取得価額や青色申告などの条件を満たせば一括計上できる場合があります。

<strong>毎年の経費額は、資産区分・耐用年数・使い始めた月・業務使用割合を確認して計算します。</strong>

防音室を調べてきたさししです。

私が気になったのは、同じ購入額でも「その年の経費」と「実際に減る税金」が違うという点でした。

以下は2026年11月6日に確認した公的資料による、個人の所得税を中心とした一般的な整理です。

<strong>個別の税務判断や申告を代行するものではありません。購入・申告前に、税理士・税務署へ実態と見積書を示して確認してください。</strong>

購入候補と本体・設置費を整理する段階では、[防音室の用途・予算別比較](/ja/soundproof-room/bouon-osusume-hikaku/)も確認できます。

## 防音室を経費にできるかは職業名より業務との関係で決まる

国税庁の[「必要経費の知識」](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2210.htm)は、収入を得るために直接要した費用や業務上の費用を説明しています。

配信者という肩書きや、収益が一度発生したことだけで、購入額すべてが経費になるわけではありません。

| 使い方 | 確認する考え方 | 残しておきたい資料 |
| :--- | :--- | :--- |
| 有料配信、広告収入のある動画・音声制作に使用 | 収入を得る業務と防音室の必要性を説明できるか | 売上記録、制作物、使用記録 |
| 演奏、作曲、ナレーション、レッスンなどに使用 | 具体的な仕事に必要な設備か | 契約、依頼内容、収録・レッスン記録 |
| 仕事と私的なゲーム・楽器練習を兼用 | 業務部分を合理的に区分できるか | 用途別の使用時間、按分の根拠 |
| 趣味だけに使用 | 家事上の支出は必要経費にならない | 業務用とする根拠の有無を確認 |
| 給与所得者の在宅勤務用に購入 | 個人事業の必要経費と同じ方法では扱えない | 勤務先の費用負担や、該当制度を別に確認 |

### 配信者の防音室は副業でも経費にできますか？

業務との関係と使用実態によって、必要経費になり得ます。

事業所得か、業務に係る雑所得かも確認が必要です。

雑所得で必要経費を計算できる場合でも、青色申告者向けの少額資産特例を同じように使えるわけではありません。

趣味から業務へ転用した場合や、まだ収益化前の場合も、購入額をそのまま申告せず税理士・税務署に確認してください。

## 防音室の減価償却はいくらずつ経費になるか

国税庁の[「減価償却のあらまし」](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2100.htm)は、取得費を原則として各年に配分すると説明しています。

購入代金だけでなく、取得・使用開始に直接必要な運送や据付などの費用も取得価額の確認対象です。

[国税庁「定額法と定率法による減価償却」](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2106.htm)に、取得価額と計算方法が示されています。

### 取得価額100万円・耐用年数8年と仮定した計算例

次は、資産区分を確認した結果、仮に耐用年数8年・定額法を適用する場合の例です。

<strong>防音室なら8年と決まっている、という意味ではありません。</strong>

計算は「取得価額×償却率×使用月数÷12×業務使用割合」です。

| 条件 | 計算 | その年の必要経費の例 |
| :--- | :--- | :--- |
| 取得価額100万円、償却率0.125、1月から12月まで、業務100％ | 1,000,000円×0.125 | 125,000円 |
| 同じ資産・通年使用、業務60％ | 1,000,000円×0.125×60％ | 75,000円 |
| 同じ資産を7月に使い始め、業務60％ | 1,000,000円×0.125×6÷12×60％ | 37,500円 |

取得価額・耐用年数・業務割合は説明用の仮定です。

最終年は帳簿価額1円を残す調整などが必要となり、毎年まったく同じ額とは限りません。

減価償却は、購入代金が戻る制度でも、経費額そのものを税額から引く制度でもありません。

税金への影響は所得額などによって変わり、購入時の支出は別に発生します。

ローンの月々の元本返済額と減価償却費も別です。

支払計画を立てる場合は、[防音室ローン・分割払いで確認する項目](/ja/money/soundproof-room-loan-guide/)も参考にしてください。

## 防音室の耐用年数はユニット・工事の実態から確認する

確認した国税庁の主な耐用年数表には、「防音室」という独立した名称の欄はありません。

製品名や材質だけで一律に「木製8年」「金属製15年」「工事15年」と決めるのは避けてください。

| 設置の実態 | 税理士・税務署に確認する内容 |
| :--- | :--- |
| 解体・移設できる独立したユニット | 器具備品等のどの区分・細目に該当するか |
| 建物と一体になる壁・床・天井の工事 | 建物への資本的支出等としての処理と耐用年数 |
| エアコン、換気、電気工事などを同時に導入 | 本体と一体か、別の資産として扱うか |
| 既存防音室の修理・改良 | 修繕費か、取得価額に加える資本的支出か |

出典：[国税庁・主な耐用年数表](https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/037.pdf)、[減価償却資産の耐用年数等に関する省令](https://laws.e-gov.go.jp/law/340M50000040015/)。

見積書の内訳、製品仕様、設置図面、建物への固定方法をそろえると、実態を確認してもらいやすくなります。

年数を短くすることを先に目的にせず、該当する区分を確かめてください。

## 「30万円の壁」は取得時期で変わる少額減価償却資産の特例

<strong>2026年4月1日以後の取得分は、取得価額の基準が30万円未満から40万円未満に変わっています。</strong>

個人の所得税については、国税庁No.2100と租税特別措置法第28条の2で確認できます。

### 金額別に選択肢を整理する

| 取得価額などの条件 | 必要経費への計上方法の候補 |
| :--- | :--- |
| 使用可能期間1年未満、または10万円未満 | 業務に使い始めた年に計上 |
| 10万円以上20万円未満 | 通常の減価償却、または一定条件で3年間の一括償却 |
| 10万円以上40万円未満／2026年4月1日以後の取得分 | 要件を満たす青色申告者なら少額資産特例も候補 |
| 2026年3月31日までの取得分 | 上の特例の取得価額基準は10万円以上30万円未満 |
| 特例に該当しない資産 | 原則として通常の減価償却 |

10万円・20万円・40万円ちょうどは、それぞれ「未満」には含みません。

貸付用資産などには除外条件があるため、金額だけでは決まりません。

### 個人が特例を使う主な要件

| 確認項目 | 2026年11月6日時点の整理 |
| :--- | :--- |
| 対象者 | 青色申告書を提出する中小事業者。常時使用する従業員400人以下などの要件 |
| 対象業務 | 不動産所得・事業所得・山林所得を生む業務。雑所得の配信にはそのまま適用しない |
| 対象金額 | 2026年4月1日以後取得は1資産の取得価額40万円未満。10万円未満等は別規定 |
| 年間限度 | 特例対象資産の取得価額の合計300万円まで。防音室以外の対象資産も合算 |
| 開業・廃業の年 | 年300万円の枠は業務を営んだ月数で調整 |
| 適用期限 | 2029年3月31日までの取得等・業務供用。契約・注文だけで判断しない |
| 除外・重複 | 主要業務以外の貸付用資産などは対象外。他制度との重複適用にも制限 |
| 申告 | 青色申告決算書の減価償却費の計算・摘要に「措法28の2」等、必要な記載・明細を確認 |

出典：[国税庁No.2100](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2100.htm)、[租税特別措置法第28条の2](https://laws.e-gov.go.jp/law/332AC0000000026/)、[同施行令第18条の5](https://laws.e-gov.go.jp/law/332CO0000000043/)、[中小企業庁の特例案内](https://www.chusho.meti.go.jp/zaimu/zeisei/pamphlet/syougaku_shisan.pdf)。

消費税を含めて判定するかは、税込・税抜経理で異なります。免税事業者は税込経理です。

取得価額は本体だけで判定せず、運送・設置等を含む範囲を確認します。

また、一つの防音室を請求書上でパネル等に分けても、それぞれが別資産になるとは限りません。

段階的な拡張も、資産の単位や資本的支出の確認が必要です。

資産の判定単位は、[国税庁の措置法28条の2関係通達](https://www.nta.go.jp/law/tsutatsu/kobetsu/shotoku/sochiho/801226/sinkoku/57/28/02.htm)で確認できます。

## 自宅の防音室を兼用する場合は家事按分する

仕事と私生活の両方で使う場合、業務に必要な部分を区分します。

国税庁No.2210は、取引記録などに基づき、業務に直接必要な部分を明らかに区分できることを求めています。

| 費用・資産 | 按分を考える材料 | 気をつける点 |
| :--- | :--- | :--- |
| 防音室の減価償却費 | 業務・私用それぞれの使用時間や使用実態 | 設置した部屋の面積だけで決めない |
| 自宅家賃の一部 | 業務専用面積、兼用の時間・利用状況など | 防音室本体と家賃で同じ割合になるとは限らない |
| 電気代等 | 機器の使用時間、消費電力、計測記録など | 家族の生活分まで含めない |

たとえば前の計算例で用いた業務60％も、任意に選んでよい数字ではありません。

収録・編集・私的な練習などの記録から、説明できる割合にします。

少額資産特例の金額判定も、按分後の業務負担額だけを見て基準未満と判断しないでください。

私なら、購入前の見積書と、使い始めたあとの用途別記録を同じ場所に保存します。

税務上の説明に必要なのは、製品名だけでなく、どう仕事に使ったかの根拠だからです。

## 中古防音室の耐用年数は条件付きで計算する

中古だから一律2年で償却できるわけではありません。

耐用年数省令第3条では、取得後の使用可能期間を見積もる方法と、それが難しい場合の簡便法を定めています。

| 状態 | 簡便法の算式 |
| :--- | :--- |
| 法定耐用年数を全部経過 | 法定耐用年数×20％ |
| 法定耐用年数の一部を経過 | 法定耐用年数－経過年数＋経過年数×20％ |
| 算出した年数に端数がある | 1年未満の端数を切捨て。2年未満なら2年 |

出典：[耐用年数省令第3条](https://laws.e-gov.go.jp/law/340M50000040015/)、[国税庁No.5404・中古資産の耐用年数](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5404.htm)（後者は法人税向けの計算解説）。

仮に法定耐用年数8年の資産で、8年を全部経過し、簡便法を使えるなら、8年×20％＝1.6年から2年となります。

<strong>防音室の資産区分・製造時期・経過年数を確認できることが前提です。</strong>

使用開始のための資本的支出が中古資産の取得価額の50％を超える場合、簡便法は使えません。

新品での再取得価額の50％を超える場合には法定耐用年数によるなど、改良額でも扱いが変わります。

個人の場合も、仕様・購入履歴・改良費を税理士・税務署に示して確認してください。

安く買えても移設や補修が必要な場合があります。

中古を探す段階では、[中古防音室の予算と購入時の確認点](/ja/money/used-soundproof-room-buying-guide/)を参考にしてください。
