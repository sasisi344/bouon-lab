防音室付きの注文住宅で失敗しないハウスメーカー選びは、「どの会社が一番静かか」を探すことではありません。

<strong>自分が出す音に必要な性能を、根拠のある数値で説明してくれる会社かどうか</strong>で決まります。

各社の公式サイトを確認すると、防音の表記は会社ごとに指標が違い、数値を横並びにして優劣をつけることはできません。

この記事では、大手4社が公式に公表している防音の内容を整理し、数値の読み方と、商談で担当者に聞くべき質問をまとめます。

## 大手4社の防音は公式にどう書かれているか

次の表は、2026年10月6日時点で確認した各社公式サイトの記載をまとめたものです。

公式に数値が書かれていない項目は「記載なし」としています。

| ハウスメーカー | 防音に関する公式の商品名・表記 | 公式に書かれている数値 |
| :--- | :--- | :--- |
| <strong>大和ハウス</strong> | 防音室「奏でる家＋」「奏でる家」、静音室「やすらぐ家」（総称は「音の自由区」） | 減音目安：奏でる家＋は70dBA、奏でる家は55dBA、やすらぐ家は45dBA |
| <strong>積水ハウス</strong> | 「音と家」ページで「遮音」「吸音」「インテリアプラン」の3つを基本性能として説明 | 記載なし |
| <strong>ヘーベルハウス</strong> | 外壁材のALCコンクリート・ヘーベル（内部の独立気泡が音を吸収） | 75mmの壁で70dB(A)の外の騒音を30dB(A)まで抑える |
| <strong>三井ホーム</strong> | 上下階の音を抑える「MOCX MUTE」、外の騒音を抑える「BSウォール」、制振バーを設けた遮音床構造 | 記載なし |

大和ハウスの数値は<strong>防音室そのもの</strong>の減音の目安です。

一方、ヘーベルハウスの数値は<strong>外壁材</strong>が外の騒音を抑える性能で、防音室の性能ではありません。

積水ハウスと三井ホームは、確認したページに数値の記載がありませんでした。

つまり4社の数値は、測っているものがそれぞれ違います。

## 数値を横並びにできない理由

比較サイトでは「A社はdB、B社はDr値」のように同じ表に並べることがありますが、読み方には注意が必要です。

- <strong>減音目安（dBA）</strong> : 室内で出した音を、室外でどれだけ小さくできるかの目安です。大和ハウスは「性能値として保証するものではなく、使用状況や周辺の環境、間取りなどにより異なる場合があります」と注記しています
- <strong>外壁材の遮音性</strong> : 外の騒音が室内に入る量の目安で、家の外壁全体の話です。部屋の中の演奏音が外に漏れる量とは別の指標です
- <strong>等級（D値・Dr値）</strong> : 建物や部位ごとの遮音等級です。カタログの値が壁単体の試験値なのか、部屋全体を測った値なのかで意味が変わります

壁がいくら高性能でも、実際の部屋ではドア・窓・換気口・コンセントの周りから音が抜けます。

数値を見るときは、<strong>「何を」「どの条件で」測った数値か</strong>を確認してください。

## 用途別に確認すること

必要な性能は、出す音の種類で大きく変わります。

### ピアノ・管楽器・歌

中高音域が中心で、時間帯と近隣との距離が判断の軸になります。

ピアノの具体的な必要性能とマンションとの違いは、[ピアノ防音室ガイド](/ja/soundproof-room/piano-room-guide/)で整理しています。

大和ハウスの公式では、ピアノ・ホームシアター・カラオケ向けの防音室が「奏でる家」（55dBAの減音目安）とされています。

### ドラム・バンド・ベース

低音は壁や床を振動として伝わりやすく、遮るのに質量と構造が必要になります。

大和ハウスの公式では、ドラム・バンド演奏向けが「奏でる家＋」（70dBAの減音目安）です。

ドラムを演奏する場合は、<strong>「ドラム演奏を想定した実績と測定結果があるか」</strong>を各社に確認してください。

### ホームシアター・カラオケ

映画の低音と歌声を同時に扱うため、遮音と音響（残響の調整）の両方が必要です。

設計の考え方は、[自宅映画と自宅カラオケを両立する防音設計ガイド](/ja/soundproof-rental/home-theater-karaoke-soundproof-design/)にまとめています。

## 大手以外の選択肢：工務店・設計事務所・防音専門業者

大手ハウスメーカーの防音は、商品として仕様が決まっているため、打ち合わせが進めやすい利点があります。

一方、防音性能そのものを最優先にするなら、次の依頼先も選択肢です。

- <strong>工務店・建築設計事務所</strong> : 部屋ごとに構造を設計できる反面、防音の実績は会社によって大きく違います
- <strong>防音工事の専門業者</strong> : 既存の住宅への後付けに強く、施工事例を公開している会社が多くあります

依頼先を比べるときの流れは、[防音リフォーム業者の選び方](/ja/money/soundproof-contractor-selection-guide/)と[防音工事の種類と価格比較](/ja/soundproof-room/construction-types-cost-comparison/)も参考になります。

## 商談で担当者に聞く質問

数値の違う各社を比べるには、同じ質問を全社にするのが最も確実です。

- 「想定する音（楽器・音量）を、室外でどのくらいまで下げる設計ですか」
- 「その数値は、壁単体の試験値ですか。部屋全体を測った値ですか」
- 「ドラムなど低音の演奏を想定した施工実績と、測定結果はありますか」
- 「ドア・窓・換気口・コンセントは、壁と同じ水準の仕様ですか」
- 「引き渡し時に、防音性能を測定してもらえますか。保証はどうなっていますか」
- 「実際に音を体感できる実例や、見学できる事例はありますか」

回答が具体的で、根拠となる測定条件まで説明してくれるかが、その会社の防音への取り組み方を見る目安になります。

雨音や雷のような不定期の大きな音は、カタログに数値が出ないことが多いため、<strong>「大雨や雷の日の室内の聞こえ方」</strong>を実例のオーナーに聞けないかも相談してみてください。
