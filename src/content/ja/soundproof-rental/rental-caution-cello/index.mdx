チェロのエンドピンの振動は、<strong>床にじかに刺さず、ストッパーの下に「重い板」と「柔らかい層」を重ねる</strong>ことで減らせます。

防振マットを1枚敷くだけでは、チェロのいちばん低い音（約65Hz）の振動は残りやすいためです。

この記事では、重ね方の順番、効いているかの確かめ方、楽器可の賃貸で先に確認しておく点を整理します。

## チェロのエンドピンから床に振動が伝わる仕組み

チェロの音は、弦から駒、駒から胴へと伝わって鳴ります。

胴の振動はエンドピンを通り、<strong>床との接点1か所に集中して</strong>伝わります。

音量そのものは、島村楽器の解説で「100dB前後」とされています（[島村楽器 イオンモール長久手店、2021年10月28日公開](https://www.shimamura.co.jp/update/?p=58742)）。

問題は、空気を伝わる音より、床を伝わる振動のほうです。

床に入った振動はコンクリートや梁を伝わり、真下や斜め下の部屋で「ブーン」という低い音として聞こえます。

これを「固体伝搬音」と呼びます。

弾いている本人の耳には届きにくいので、苦情が来て初めて気づくことが多い音です。

固体伝搬音が伝わる仕組みは、[叩く音・押す音が下の階に響くのはなぜ？ヘッドホンでも消えない振動の止め方](/ja/knowledge/structure-borne-noise-tapping-striking/)で詳しく解説しています。

### 低い音ほど止めにくい

チェロの開放弦のいちばん低い音（C線）は、約65Hzです。

振動は周波数が低いほど、薄く柔らかいマットを素通りしやすくなります。

ヨガマットやジョイントマットで「高い雑音は減ったのに、低い響きは残る」となるのはこのためです。

## エンドピンの振動を減らす重ね方の順番

床から上に向かって、次の順に重ねます。

| 層（床から上へ） | 例 | 役割 |
| :-- | :-- | :-- |
| 床 | フローリング・カーペット | — |
| 柔らかい層 | 防振ゴム、防振マット、ゲル状のインシュレーター | 振動を受け止めて、床へ伝わる量を減らす |
| 重い層 | 合板（コンパネ）や厚手の板、重さのあるゴムマット | 上に乗る重さを増やし、柔らかい層を効きやすくする |
| ストッパー | ゴム付きのエンドピンストッパー | 先端を受け止め、滑りと床の傷を防ぐ |
| エンドピン | — | 振動の出口 |

ポイントは、<strong>柔らかい層の上に重い層を乗せる</strong>ことです。

柔らかい層は「ばね」、上に乗る板やチェロは「おもり」として働きます。

おもりが重いほど、ばねが揺れやすい周波数（固有振動数）は下がり、低い振動を通しにくくなります。

この考え方は、[低周波・振動対策の基礎｜防振床・浮き床構造の仕組みと選び方](/ja/knowledge/vibration-isolation-technology-trend/)で解説しています。

### 椅子も同じ板に乗せる

板は、エンドピンだけでなく<strong>椅子ごと乗る大きさ</strong>にするのが理想です。

体の重さが加わると板が重くなり、柔らかい層がよく効くようになります。

演奏中に体を揺らしたり足でリズムを取ったりする振動も、同じ板で受けられます。

目安は、椅子とエンドピンの位置が両方収まる、90cm角前後の板です。

### やってはいけない重ね方

- <strong>柔らかい層だけを厚くする</strong> : 上に乗る重さが軽いままだと、低い振動はあまり減らない。演奏中にチェロが沈んで不安定にもなる
- <strong>ストッパーの真下にだけ小さなゴムを置く</strong> : 先端1点の重さしか乗らず、ばねとして働きにくい
- <strong>重い板を床にじかに置く</strong> : 板の下に柔らかい層がないと、振動は板を通ってそのまま床へ伝わる

## チェロの防振マットの選び方

防振マットは単体で完結させず、「重ね方の中の柔らかい層」として選びます。

| 確認する点 | 選び方 |
| :-- | :-- |
| 素材 | 防振ゴム・ゲル・高密度のゴムマット。発泡スチロールやウレタンだけのものは低い振動に弱い |
| 厚さ | 1cm以上を目安にする。厚すぎると演奏中にぐらつく |
| 大きさ | 単体で使うなら椅子ごと乗る大きさ。板の下に敷くなら四隅と中央に置く方法でもよい |
| 上の層 | 板を乗せるか、重さのあるマットを重ねる前提で選ぶ |
| 滑り | エンドピンが滑らない表面か、ストッパーと組み合わせて使えるか |

電子ドラムや電子ピアノ、ランニングマシン用の防振マットも、仕組みは同じです。

楽器専用品にこだわらず、上の表の条件に合うものを選べば使えます。

素材の重ね方の具体例は、[マンションのランニングマシン防音対策｜階下の振動を減らす「重ね敷き」と置き方](/ja/diy/treadmill-apartment-soundproofing-layering/)の予算別セットが参考になります。

### エンドピンストッパーは「振動対策」の主役ではない

エンドピンストッパーは、サウンドハウスで1,380〜2,640円（税込、2026年10月確認）で手に入ります。

主な役割は、<strong>滑り止めと、床に穴や傷を付けないこと</strong>です。

ゴムの付いたものなら振動もいくらか和らぎますが、商品説明の多くは滑りにくさを打ち出しています。

ストッパーだけで階下への振動が収まると考えず、下に重ねる層とセットで使ってください。

なお賃貸では、床にエンドピンの穴を開けると、退去時の原状回復で費用を求められることがあります。

振動対策とは別に、ストッパーは入居初日から使ってください。

## 振動が減ったかを確かめる方法

対策の効果は、弾いている本人には分かりにくいものです。

次の方法で確かめます。

1. <strong>C線の開放弦を強めに弾く</strong> : いちばん低い音が、いちばん床に伝わりやすい
2. <strong>家族に別の部屋で聞いてもらう</strong> : 床や壁に耳を近づけ、対策前と後で「ブーン」の大きさを比べる
3. <strong>床に手のひらを当てる</strong> : 楽器から1〜2m離れた床で、振動が手に伝わるか比べる
4. <strong>同じ曲・同じ強さで比べる</strong> : 条件をそろえないと、違いが分からない

一人暮らしで聞いてくれる人がいない場合は、スマホで別の部屋の音を録音して聞き比べる方法もあります。

自分の音が下の階に届いているかの確かめ方は、[叩く音・押す音が下の階に響くのはなぜ？ヘッドホンでも消えない振動の止め方](/ja/knowledge/structure-borne-noise-tapping-striking/)でも解説しています。

### 対策の限界

床の重ね敷きで減らせるのは、床に伝わる振動の一部です。

防振マットや板による低減量を、チェロの条件で測った第三者のデータは見つかりませんでした。

そのため、この記事では「何dB下がる」とは書きません。

建物の床が薄い・軽い場合は、重ね敷きをしても低い響きが残ることがあります。

その場合は、時間帯の工夫や、防音室・練習スタジオとの併用を考えます。

## チェロを楽器可の賃貸で弾くときの注意点

チェロは、音量だけを見ればピアノと同じくらいの楽器です。

それでも賃貸で警戒されやすいのは、ここまで見てきた<strong>床への振動</strong>があるためです。

### 「楽器可」の中身を確認する

募集図面の「楽器可」「楽器相談」は、細則でさらに条件が付いていることがあります。

- <strong>ピアノのみ可</strong> : アップライトピアノは可、ほかの楽器は要相談
- <strong>管楽器不可</strong> : 弦楽器は可でも、サックスやトランペットは不可
- <strong>低音の弦楽器に制限</strong> : バイオリンは可でも、チェロ・コントラバスは不可、または時間の制限あり

仲介会社には「チェロです」とはっきり伝え、管理会社に可否と演奏できる時間帯を確認してもらいます。

口頭で済ませず、特約として契約書に書いてもらうと、あとで揉めにくくなります。

「楽器可」の表記を裏取りする手順は、[楽器可賃貸の正しい探し方｜通勤1時間以内で相場を見誤らない手順](/ja/soundproof-rental/instrument-allowed-rental-research-method/)で解説しています。

### 部屋選びで有利になる条件

| 条件 | 理由 |
| :-- | :-- |
| 1階、または真下が共用部・店舗 | 床の振動が届く先の住戸がない、または少ない |
| 角部屋 | 隣接する住戸が少ない |
| RC造（鉄筋コンクリート造） | 床が重く、振動が伝わりにくい。木造・軽量鉄骨は振動が伝わりやすい |
| 床が厚いと分かる物件 | コンクリートの床（スラブ）が厚いほど有利。厚さは図面や管理会社で確認する |

募集図面にある「L-45」などの防音フローリングの表示は、主にスプーンを落としたような<strong>軽い衝撃音</strong>の指標です（[日本建築総合試験所の解説](https://www.gbrc.or.jp/assets/documents/gbrc/GBRC186_899.pdf)）。

チェロの低い振動を止める性能を示すものではないので、この表示だけで判断しないでください。

### 入居時のあいさつ

入居時に上下と両隣へ「チェロを弾きます。気になったらすぐ教えてください」と伝えておきます。

先に知らせておくと、気になったときに管理会社を通さず直接言ってもらえることが多く、早めに直せます。

演奏する時間帯の目安は、[マンションで楽器を演奏できる時間帯は何時まで？](/ja/knowledge/mansion-instrument-practice-time-rules/)にまとめています。

## マットで足りないときは防音室・練習場所を検討する

床の対策をしても苦情が続く場合や、夜に練習したい場合は、ユニット型の防音室も選択肢になります。

島村楽器の解説では、チェロを座って弾くには<strong>最低1.5畳</strong>が必要とされ、1.5畳でDr-40の製品が例に挙がっています（[島村楽器 イオンモール長久手店](https://www.shimamura.co.jp/update/?p=58742)）。

ただし、防音室の中でも<strong>エンドピンの防振は必要</strong>です。

防音室の床がそのまま建物の床に載っているため、エンドピンの振動は防音室の床を通って外に伝わります。

楽器ごとの遮音性能の目安は、[遮音性能の基準「D値」とは？楽器・用途別の目安](/ja/soundproof-room/bouon-dchiseinou-meyasu/)で解説しています。

音大生など、毎日長時間弾く人の物件探しは、[音大生の防音物件の探し方](/ja/soundproof-rental/music-student-property-search-guide/)も参考になります。

## よくある質問

### ヨガマットやカーペットだけで足りますか？

高い雑音や床の傷は減りますが、低い振動は残りやすいです。

上に板を乗せて「柔らかい層＋重い層」にすると、効きやすくなります。

### 弱音器（ミュート）は床の振動にも効きますか？

ある程度は効きます。

練習用の弱音器は駒の振動を抑えるため、胴の鳴りが小さくなり、エンドピンに伝わる振動も一緒に小さくなります。

ただし音色が変わるので、床の対策と組み合わせ、弱音器は夜など時間を限って使うのがおすすめです。

### 防振マットは厚いほど効きますか？

厚さより、上に乗る重さとの組み合わせで決まります。

軽いまま厚くすると、演奏中にぐらつくわりに低い振動は減りにくくなります。

### 戸建てなら気にしなくてよいですか？

2階で弾くと、1階の家族の部屋に振動が伝わります。

家族が寝ている時間に弾くなら、戸建てでも同じ対策をしておくと安心です。

## まとめ

- チェロの振動は、エンドピンから床の1か所に集中して伝わる
- いちばん低い音は約65Hzで、薄いマットだけでは止めにくい
- 床から「柔らかい層 → 重い板 → ストッパー」の順に重ね、椅子ごと板に乗せる
- エンドピンストッパーは滑り止めと床の保護が主な役割で、振動対策は下の層で行う
- 効果は、C線の開放弦を弾いて別の部屋で聞いてもらって確かめる
- 賃貸では、チェロが可か・時間帯を管理会社に確認し、特約として残す

まずは手持ちのマットの上に板を1枚乗せて、別の部屋で聞き比べるところから始めてみてください。
