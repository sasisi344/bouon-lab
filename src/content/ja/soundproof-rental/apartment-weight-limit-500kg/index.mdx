築20年のマンションに500kgの防音室を置けるかは、築年数と総重量だけでは判断できません。

ここでの築年数と重さは検討する条件の例で、特定製品の仕様や設置可能な上限ではありません。

本体・機材・人の重さと、床に接する位置を整理し、管理会社や設置業者に確認する順番をまとめます。

## マンションの床荷重は、部屋の平均だけで判断しない

部屋全体に重さが広がる場合と、防音室の脚などに集中する場合を分けて考えます。

部屋の面積で総重量を割るだけでは、脚の下の床材や下地にかかる負担は分かりません。

契約書や管理側の案内に床荷重の数値がある場合も、それだけで設置できるとは判断しません。

その数値が何を対象にした条件か、設置業者と管理会社に確認してください。

## 防音室の荷重を整理する方法

製品の重さと寸法は、設置する型番の説明書で確かめます。

| 確認するもの | 相談時に渡す内容 |
| :-- | :-- |
| 総重量 | 本体に空調・楽器・家具・人などを含めた重さ |
| 支え方 | 底面全体で支えるか、脚や台座で支えるか |
| 設置面 | 外寸だけでなく、実際に床へ接する部分の位置 |
| 床の状態 | 仕上げ材、下地、沈み込みや傷の有無 |

荷重分散板や専用ベースパネルは、接する部分の負担を広げるための候補です。

ただし、板を敷くだけで床の耐力が増すわけではありません。

必要な厚みや広さ、設置方法は、床と防音室の組み合わせによるため、業者に確認します。

## 設置場所は図面と床の状態を確認して選ぶ

梁や壁の位置を手がかりにしても、見た目だけで床の強い場所とは決められません。

管理会社に設計図面や床の仕様を確認できるか尋ね、候補の位置を設置業者へ伝えます。

沈み込みやきしみが気になる場所は、材料を重ねる前に点検を相談してください。

## 住宅構造別に見る荷重分散の考え方：RC造・木造・軽量鉄骨の違い

RC造でも、表面の床材や下地まで一体のコンクリートとは限りません。

構造名だけで局所的な沈み込みが起こらないとは判断せず、床の構成を確かめます。

軽量鉄骨造では、床を支える梁の位置や間隔も確認する材料になります。

![軽量鉄骨造の床のたわみ比較図解。梁スパンが広いと荷重点のたわみが大きく、梁スパンが狭いとたわみが小さいことを示す断面イメージ](./floor-deflection-diagram.png)

図は支える間隔とたわみの関係を考えるイメージで、特定の住宅への設置可否を示すものではありません。

木造では、床下の根太や梁の位置・状態も含めて点検を相談します。

図面が残っていなければ、工務店やリフォーム会社に確認できる範囲を聞いてください。

賃貸では設置前の床を写真で記録し、傷や沈み込みが生じた場合の原状回復も管理会社と確認します。

## 軽い組み立て式防音室（だんぼっち等）でも床の対策は要る？

軽い組み立て式でも、本体の重さだけで床の対策を省けるとは限りません。

だんぼっち等を候補にする場合も、底面や脚のどこが床に触れるかを確認します。

購入前に、説明書の設置条件も確認してください。

軽くても、接する部分が狭ければ、その下に負担が集中するためです。

重量ユニットとの違いは、耐力の相談に加え、日常の床の傷や手入れも先に考えておきたい点です。

コンパネなどの合板は、床に接する負担を分散する候補になります。

ただし、一律の厚みや価格で安全を保証できるものではありません。

使う板はブースの支え方に合わせて業者へ確認し、敷く前に床の砂やごみを取り除きます。

板と床の間に保護材を使う場合も、床材との相性を確かめてください。

床の保護と振動への対策は、別に確認します。

防振ゴムやマットを追加すれば階下への音が止まるとは考えず、ブースの安定を保てる構成か相談します。

また、板やマットの下を点検できるようにし、湿気やカビの有無を確かめます。

除湿シートを挟むだけで、退去時の修繕を避けられる保証はありません。

設置前には、次の点を管理会社・設置業者と確認してください。

- <strong>床の状態</strong> : 既存の傷や沈み込みを記録し、設置する範囲を伝える
- <strong>板とブースの配置</strong> : 板の端やブースがドアの開閉・通行を妨げないかを見る
- <strong>設置後の手入れ</strong> : 床の清掃や湿気の点検を、どのように行うか決める

軽量ブースでも、賃貸の設置許可と原状回復の扱いを先に確かめると、材料選びの条件がはっきりします。

## 長く置く場合も、床の状態を点検する

設置時に問題が見えなくても、長く重さがかかる場所は継続して状態を確認します。

沈み込みや扉の開閉の変化があれば、放置せず管理会社や施工業者へ相談してください。

構造と設置可否の判断は、建築・施工の専門家に確認します。

搬入経路や空調まで含めた設置条件の全体像は、[賃貸にユニット型防音室を置くときの許可と大家さんへの相談](/ja/soundproof-rental/rental-unit-soundproof-room/)で確認できます。

グランドピアノとユニット型防音室を合わせて設置する場合の床荷重の考え方は、[ピアノ防音室ガイド｜アップライト・グランド別の費用とマンション設置の条件](/ja/soundproof-room/piano-room-guide/)でも解説しています。

賃貸オーナーが「24時間演奏可」物件としてグランドピアノ対応をアピールする場合も、同様の床荷重計算が欠かせません。
