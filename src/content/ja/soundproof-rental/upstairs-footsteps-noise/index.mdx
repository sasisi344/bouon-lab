上の階の足音がドスドス響くのは、かかとなどの衝撃が床を揺らし、低い音や振動として体にも伝わるからです。

研究機関や住宅の解説資料では、この音は床の構造に左右され、下の階の天井に材料を貼るだけでは対策しにくいと分かります。

下の階でできることの限界を整理し、音を記録して、上の階の人に責めずに協力を頼む順番をまとめます。

## 上の階の足音がドスドス響くのは、低い音が体に伝わるから

夜11時、天井から「ドス、ドス」と歩く音がして、テレビの音量を上げても体に響くように聞こえる。

こうした場面では、音量だけでなく、床の揺れが伝わる道も考えます。

ライブやフェスなら、ボーカルは耳で聞き、バスドラムやベースは体で感じる、という違いを思い浮かべてください。

足音の低い響きも、体で感じるために目立つ、というイメージです。

かかとが床を押すと、床が揺れ、その揺れが下の階の天井から音になって伝わります。

歩行や飛び跳ねで床に加わった力が伝わる音を、建築では「重量床衝撃音」と呼びます。

用語の根拠は[日本建設業連合会の解説](https://www.nikkenren.com/kenchiku/sound/pdf/glossary/ya-0100.pdf)です（2026年11月14日確認）。

スプーンを落とすような軽い衝撃音とは対策が違い、カーペットなどは主に軽い衝撃音に向きます。

[住宅の音の解説](https://allabout.co.jp/gm/gc/26901/2/)では、重い衝撃音には床の重さや硬さを上げることが有効とされています（同日確認）。

私は住まいで足音に困ったことはありませんが、ホテルの廊下を歩く人のスリッパや、かかとのドスドス音が気になったことはあります。

その場ではどうしようもないと思いましたが、住まいで続くなら、記録して伝える準備が必要になります。

床の音を表すL値は遮断性能の等級で、重い音はLH、軽い音はLLで区別します。

等級の読み方は、[床の防音等級とL値・LHの違い](/ja/knowledge/floor-soundproof-rating/)へ進んでください。

## 木造・鉄骨・鉄筋コンクリートで響き方が違う

[北海道立総合研究機構の資料](https://www.hro.or.jp/upload/10140/26107004001.pdf)では、木造住宅の床衝撃音の遮断性能は、鉄筋コンクリート造より劣ると説明されています（2026年11月14日確認）。

木造では床の軽さや揺れを考えますが、鉄骨・鉄筋コンクリートでも構造名だけで静かさは決められません。

物件ごとの床の仕様が違うため、「木造なら何dB、鉄筋コンクリートなら何dB」とは示せません。

契約書で構造を確認したら、床の遮音に関する資料があるかを管理会社に聞きます。

## 夜中・子供の足音は「仕方ない」の範囲か

子供の足音だから、または生活音だからという理由だけで、全部を我慢するかどうかは決まりません。

受忍限度は、共同生活で一般に受け入れる音の範囲という考え方で、音量だけの線引きではありません。

既存の相談先記事が扱う[公害等調整委員会の決定](https://www.soumu.go.jp/main_content/000961985.pdf)には、一般地域の屋内指針が登場します。

昼間の6〜22時は45dB以下、夜間の22〜翌6時は35dB以下ですが、比較は時間区分全体の等価騒音レベルによります。

瞬間的な足音やアプリの表示だけで違法と決める値ではなく、時間帯・続き方・暮らしへの影響も含めて相談します。

条件と出典の詳細は、[騒音の苦情の相談先と受忍限度の考え方](/ja/soundproof-rental/noise-complaint-landlord-negotiation-guide/)にまとめています。

## 下の階でできる対策と、その限界

<strong>下の階から、上の床を揺らす衝撃そのものを止めるのは難しいです。</strong>

こちらで眠る場所や耳元を調整したら、材料を買い足し続けず、上の階の人に協力してもらう方向へ進みます。

### 1. 寝る場所を変える

同じ部屋の中でも、寝る位置を移して響き方が変わるかを確かめます。

別の部屋を使えるなら、音が続く時間に比較し、上の階で歩く場所と重ならない位置を候補にします。

間取りが分からなければ、相手の生活を推測するより、自室で聞こえ方を比べます。

### 2. 耳栓・ホワイトノイズで眠りを守る

耳栓は耳に届く音を減らす手ですが、体に響く振動や低い音は残ります。

ホワイトノイズも音を目立ちにくくする方法で、振動を止めるものではありません。

形や注意点は、[睡眠用耳栓の選び方とデメリットへの対策](/ja/soundproof-rental/earplugs-for-sleep/)で確認してください。

### 3. 天井の対策はほぼ効かない

天井に吸音材を貼るだけでは、上の床の重さや硬さは変わりません。

床から伝わるドスドスへの対策として、吸音材を買う順番は下げます。

天井の工事まで考える場合は、期待できる効果と工事の範囲を、管理会社や施工業者に確認してください。

### 4. 引っ越しを考えるときの見方

構造名だけで選ばず、上階の有無や床の仕様も確認します。

最上階は上の住戸からの足音を避ける候補ですが、建物のすべての音がなくなる条件ではありません。

住み替えの確認項目は、[防音賃貸の選び方](/ja/soundproof-rental/bouon-rental-market-guide/)を参考にしてください。

## 音を記録する（日時・時間・音の種類・スマホのアプリでの測定）

音がしたときに、次の欄を埋めてみてください。

| 記録すること | 自分の部屋で書く内容 |
| :-- | :-- |
| 日付・時刻 | いつ始まり、いつ止まったか |
| 聞こえた場所 | 寝室・居間など、どちら側から聞こえたか |
| 音の種類 | 歩くような音、走るような音、物を落とすような音 |
| 暮らしへの影響 | 目が覚めた、寝つけなかったなど |
| 測定・相談の条件 | アプリや機器、置いた場所、管理会社への連絡日と返答 |

スマホのアプリで測るなら、同じ端末・場所で記録し、表示値だけで原因や法的な判断を決めないようにします。

音源を確認できていなければ、「上の部屋が出した」と断定せず、聞こえた方向を書きます。

## 上の階の人に協力してもらう：責めずに伝える

相手が下の階での響き方を知らない可能性もあります。

[千葉県の資料](https://www.pref.chiba.lg.jp/kansei/kankyouhakusho/documents/28-4-08.pdf)も、近隣騒音には心理的・感情的な要因が含まれ、解決を難しくすると指摘しています（2026年11月14日確認）。

悪い人と決めつけず、記録した時刻と音を添え、心当たりを尋ねる形にします。

> いつもこの時間に、こういう音が聞こえるのですが、何か心当たりはありますか？
>
> 寝室で目が覚めることがあるため、夜の歩き方などで調整できることがないか、ご相談したいです。

スリッパやラグを使えるか、夜はかかとから強く着地する歩き方を避けられるか、といった頼み方を考えます。

ラグだけで重い衝撃音が止まるとは約束せず、相手ができることから相談します。

私も、関係が悪くならないか、気にしすぎか、どこに言うか、言っても変わらないかという点で迷います。

| 迷うこと | 伝えるときの進め方 |
| :-- | :-- |
| 関係が悪くなりそう | 直接話すのが不安なら管理会社を通す |
| 気にしすぎかもしれない | 性格の話にせず、時刻と生活への影響を伝える |
| どこに言えばよいか | 入居案内の管理会社、なければオーナーへ相談する |
| 言っても変わらなそう | 何を確認し、いつ返答できるかを管理側に聞く |

## 伝える順番：管理会社・オーナー → 手紙 → 話し合いで解決しないとき

まず管理会社・オーナーへ記録を渡し、建物内での確認と注意喚起を頼みます。

個人名や部屋番号を相手に伝える範囲も、先に相談しておきます。

手紙が必要な場合も、先に管理側と出し方を相談してください。

文面は、[騒音苦情の手紙の例文](/ja/soundproof-rental/noise-complaint-letter-template/)を使い、相手を決めつける表現を避けます。

[札幌市の生活騒音の案内](https://www.city.sapporo.jp/kankyo/souon/sonota/seikatsu.html)では、一般家庭の生活騒音は法律などの規制対象ではなく、話し合いや大家・管理組合への相談が基本です（2026年11月14日確認）。

解決しない場合は、相談経過もまとめて自治体の相談窓口や法律相談へ進み、民事でできる対応を確認します。

足音だけで警察を呼ぶことは勧めません。

身の危険など、緊急対応が必要な状況は、普段の生活音の相談と分けて考えます。

## 仕返しはしない

天井を叩いたり音を返したりすると、別の騒音や対立につながります。

相手を困らせる方法を探すより、記録と相談の返答を残して、第三者を通して進めます。

## よくある質問（FAQ）

### 上の階の足音は、相手が気をつければ止まりますか？

歩き方を調整してもらう余地はありますが、床の構造で響く部分までなくなるとは限りません。

スリッパやマットだけで解決すると決めず、試したあとにどう変わったかを共有します。

### 子供の足音への苦情は言ってもいいですか？

相談前に、違法かどうかを自分で証明する必要はありません。

子供や保護者を責めず、困っている時間帯と生活への影響を管理側へ伝えます。

### 木造アパートで、足音で部屋が揺れるのは普通ですか？

木造では衝撃が伝わりやすいものの、「普通だから問題ない」とは判断できません。

揺れ方が気になる場合は、建物の状態も含めて管理会社に確認してください。

## まとめと次にやること

上の階のドスドスは床の揺れで伝わるため、下の階だけの対策には限界があります。

眠る場所を調整しながら、相手を責めず、管理会社・オーナーを通して協力を相談します。

次にやることは、<strong>今夜、音がした時刻と音の種類をメモすること</strong>です。

法的な判断は、弁護士などの専門家や自治体の相談窓口に確認してください。
