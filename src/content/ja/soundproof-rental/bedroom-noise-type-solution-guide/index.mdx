寝室の騒音で眠れないときは、聞こえる音を分け、届く経路に合う対策を選びます。

空気を伝わる話し声と、建物を伝わる足音では、効く対策が違います。

手軽な対処、賃貸でできる配置換えや隙間対策、相談する順番を音の種類ごとに整理します。

## 寝室の騒音は、聞こえている音の種類を分ける

最初に、寝室で聞こえている音がどれに近いかを確認します。

音の種類によって、伝わり方と効きやすい対策が違うからです。

| 聞こえる音 | 主な伝わり方 | 手軽な対処の効き方 |
| :--- | :--- | :--- |
| 外の交通音（車・バイク・電車） | 空気を伝わる音。低い音が多い | ノイズキャンセリングが得意。窓まわりの対策も効きやすい |
| 隣室の話し声・テレビ | 空気を伝わる音。高い音から中くらいの音が多い | 耳栓が効きやすい |
| 上の階の足音・ドスンという音 | 建物を伝わる音（固体伝搬音）。低い音が体に響く | 耳栓だけでは減りにくい。窓やカーテンでは変わらない |
| 家族の生活音（ドアの開閉・水回り・足音） | 空気と建物の両方を伝わる | 音の種類によって分かれる |

耳栓をしても体に響く足音が残るなら、耳元の対策だけで足りるかを見直します。

この違いを知らないと、「自分が神経質なだけでは」と考えてしまいがちです。

しかし、聞こえ方も効く対策も音の種類で決まるので、自分を責める必要はありません。

## 手軽な対処がどこまで効くか

次の2つは、すでに多くの方が試している対処です。

- <strong>耳栓とノイズキャンセリングの併用</strong> : 耳栓は高い音、ノイズキャンセリングは持続する低い音が得意です。両方を使って補い合います
- <strong>防音（遮音）カーテン</strong> : 窓から入る高い音を和らげます。低い音は残り、音をゼロにすることはできません

使い方と選び方は、それぞれの記事にまとめています。

[睡眠用耳栓の選び方とノイキャン・寝ホンの注意点](/ja/soundproof-rental/earplugs-for-sleep/)

[防音（遮音）カーテンの選び方と限界](/ja/soundproof-room/hsp-soundproof-curtain-guide/)

上の階の足音が主な悩みなら、耳栓やカーテンを買い足す前に、寝る位置の変更と音の記録を考えます。

響く仕組みと相談の手順は、[上の階の足音の原因と自分でできる対策](/ja/soundproof-rental/upstairs-footsteps-noise/)にまとめています。

## 部分的な対策｜手軽な対処と工事のあいだ

耳栓やカーテンで足りず、工事や引っ越しまでは大げさだと感じる場合に、間に入る対策があります。

### 寝る位置を音源から離す

音が壁の向こうから聞こえるなら、頭の位置を<strong>音源側の壁から離す</strong>だけで、聞こえ方が変わることがあります。

ベッドを反対側の壁に寄せる、頭と足の向きを入れ替える、といった方法です。

お金がかからず、元に戻せるので、最初に試す価値があります。

壁沿いに本棚やタンスを置いて壁を厚くする考え方もあります。

家具配置や隙間の考え方は、[木造アパートの防音は無理？苦情ゼロまで音を減らす3つの現実的対策](/ja/diy/wooden-apartment-soundproof-guide/)で整理しています。

### 窓と隙間を見直す（外の音向け）

外の交通音が主な悩みなら、音の入口は窓です。

窓まわりの隙間をテープで埋め、防音カーテンを併用すると、高い音は和らぎます。

さらに、既存の窓の内側にもう1枚窓を足す内窓があります。

減る量は窓の仕様と取り付け方で変わるため、DIYと既製品に一律の実測値は示せません。

[窓の防音DIYと内窓・隙間テープの確認手順](/ja/diy/diy-internal-window-road-noise-reduction/)で、音の入口から見直します。

ただし、内窓は上の階の足音のような建物を伝わる音には効きません。

賃貸での内窓の選び方は、[賃貸と戸建てで変わる窓の防音対策](/ja/soundproof-room/shanon-vs-bouon-window/)にまとめています。

外の機械音が続く場合は、窓から入る音と建物を伝わる振動を分けて相談します。

[室外機の騒音対策と隣の人への頼み方](/ja/knowledge/outdoor-ac-unit-noise/)で、自分でできることと所有者に頼むことを確認してください。

### 家族の生活音とドアを見直す

家族の声が廊下から入るなら、就寝中の部屋の使い方を相談し、ドアの隙間を確認します。

開閉時の衝撃音と、隙間を通る声を分けて考えます。

[ドアの防音対策と隙間をふさぐ順番](/ja/diy/door-soundproof/)で、閉まり方や換気も確かめてください。

### 音で覆う（マスキング）

気になる音を、別の穏やかな音で覆い、意識を向きにくくする方法があります。

ホワイトノイズや環境音を、小さな音量で流す方法です。

音量を上げすぎると、それ自体が新しい刺激になります。

控えめな音量から試してください。

考え方と注意点は、[音に過敏でつらい人の環境調整ガイド](/ja/knowledge/sound-sensitivity-misophonia-environment-guide/)で解説しています。

### 賃貸で試すときの注意

賃貸では、効果と同じくらい<strong>退去時に元に戻せるか</strong>が大切です。

「大げさに見られるのでは」と迷うのも自然ですが、次の点を守れば失敗を減らせます。

- <strong>壁に直接貼らない</strong> : 強い両面テープは、剥がすときにクロスを傷めて、退去費用につながることがあります
- <strong>内窓は大家や管理会社に確認する</strong> : ネジ止めする製品は、事前に許可を取っておくと安心です
- <strong>換気口はふさがない</strong> : 換気が足りないと、湿気がこもります
- <strong>結露とカビに気をつける</strong> : 窓まわりを密閉すると、結露やカビの原因になることがあります。換気と湿度に気を配ってください

## 音の種類別｜効く順の早見表

ここまでの内容を、1枚の表にまとめます。

| 音の種類 | まず試す | 次に試す | それでも足りないとき |
| :--- | :--- | :--- | :--- |
| 外の交通音 | ノイズキャンセリング、耳栓 | 防音カーテン、窓の隙間、内窓 | 窓の本格対策、引っ越し |
| 隣室の話し声・テレビ | 耳栓、寝る位置を壁から離す | 壁沿いの家具配置、隙間 | 管理会社に相談 |
| 上の階の足音 | 寝る位置を変える | 音の記録、耳栓で残る音を確認 | 管理会社に相談、引っ越し |
| 家族の生活音 | 耳栓、寝る時間帯と部屋の使い方の相談 | ドアの隙間対策 | 部屋の配置変更、工事 |

上から順に試して、足りなければ次の段階に進みます。

最初から全部を揃える必要はありません。

## それでも足りないときは

手軽な対処と部分的な対策を試しても眠れないなら、次の2つの道があります。

### 管理会社に相談する

隣室や上の階の音は、自分の側の対策だけでは限界があります。

根本の対策は、音を出している側にあるからです。

とはいえ、「苦情を言えば、関係が悪くなるのでは」と感じる方は多いでしょう。

直接言いに行くのは避け、<strong>管理会社を通して</strong>伝えるのが基本です。

日時と音の種類を記録して、メールで相談すると、感情的な対立を避けられます。

相談先の選び方と記録の付け方は、[騒音の苦情の相談先と記録方法](/ja/soundproof-rental/noise-complaint-landlord-negotiation-guide/)にまとめています。

### 引っ越し・後付け・新しく建てる

相談しても改善しない場合や、外の音が大きい立地の場合は、住まいそのものを見直す選択肢があります。

防音賃貸への引っ越し、今の家への後付け、注文住宅の設計段階で防音を伝える道の3つです。

費用と快適性のどちらを優先するかで、選ぶ道が変わります。

[音の悩みの解決策は3つ｜引っ越し・後付け・注文住宅の設計段階で伝える道](/ja/soundproof-room/noise-solutions-relocate-retrofit-custom-home/)で、3つの道を比べています。

防音室で眠る場合の注意点は、[防音室で眠ると睡眠の質が変わる理由](/ja/soundproof-room/sleep-quality-soundproof-room/)で確認できます。

## まとめ：音の種類を見分けて、順番に試す

眠れない原因の音を、種類ごとに分けて考えると、試すべき対策が見えてきます。

- <strong>外の交通音</strong> : ノイズキャンセリングと窓まわりの対策が中心です
- <strong>隣室の話し声</strong> : 耳栓と寝る位置の工夫から始めます
- <strong>上の階の足音</strong> : 自分側の対策は和らげるまでで、管理会社への相談が本筋です
- <strong>家族の生活音</strong> : 時間帯や部屋の使い方の相談と、隙間対策を組み合わせます

手軽な対処、部分的な対策、相談や引っ越しの順に進めれば、無駄な出費を減らせます。
