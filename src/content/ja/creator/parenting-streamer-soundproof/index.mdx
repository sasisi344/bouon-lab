同居人がいる家で配信する人の悩みは、2方向あります。

「<strong>同居人の音が配信に入る</strong>」と、「<strong>自分の配信音が同居人を起こす</strong>」の2つです。

「配信のために家族を我慢させているのでは」「迷惑をかけているのでは」——そんな罪悪感を抱えながら続けている人も多いはずです。

どちらも完全には解決できませんが、環境と習慣の組み合わせで、多くのケースは改善できます。

この記事では、<strong>子育て・実家暮らし・ルームシェア</strong>のそれぞれで、何から手をつけるかを整理します。

## 同居人によって、悩みの中心は変わる

| 同居人 | 起きやすい悩み | まず見直すこと |
| :-- | :-- | :-- |
| 子ども | 泣き声・笑い声が配信に入る。夜の配信で起こしてしまう | 部屋の分離、時間帯、ヘッドホン |
| 親（実家） | 夜の声やキーボード音で親を起こす。注意されて気まずい | 寝室との位置関係、声量、話し合い |
| パートナー・ルームシェア | 家事や電話の音が入る。お互いの生活リズムがぶつかる | 配信スペースの位置、時間の取り決め |

## まず、配信部屋と寝室の位置関係を確認する

対策の優先順位は、<strong>配信する部屋が、寝る人の部屋からどれだけ近いか</strong>で大きく変わります。

### 寝室が隣接している場合

声だけでなく、キーボードの打鍵音やイスのきしみなど、あらゆる音が伝わります。

壁側にベッドや棚を置き、<strong>音源と壁の間に緩衝物をつくる</strong>ことから始めます。

### 部屋が離れている、または階が違う場合

空気を伝わる音より、ドアの開閉音や廊下を歩く音のほうが響きやすい傾向があります。

配信中はドアをしっかり閉め、深夜の移動もできるだけ静かに行います。

### 壁を軽く叩いて、おおまかな傾向をつかむ

専門の機器がなくても、壁を手のひらや指の関節で軽く叩くと、おおまかな傾向がつかめます。

- <strong>コンコンと乾いた高い音</strong> : 壁の中が空洞に近く、音が響きやすい壁です。優先して対策します。
- <strong>ゴツゴツとこもった低い音</strong> : 中身が詰まっており、比較的音が伝わりにくい壁です。

これは簡易的な体感診断で、遮音等級を示すものではありません。

同じ部屋でも壁ごとに違うため、複数の箇所で比べてください。

## 子どもの声が配信に入る問題

子どもの泣き声や笑い声は、高音成分が多く、マイクに入りやすい音です。

ノイズゲート（一定音量以下の音をカットする処理）でも、消しきれないことがあります。

<strong>部屋の分離</strong>が最も根本的な対策です。

- <strong>配信部屋を別室にする</strong> : 子どもがいるリビングや子ども部屋から離れた部屋にします。
- <strong>ドアの隙間テープ・防音カーテン</strong> : ドア下端と枠の隙間をふさぎ、廊下からの音を減らします。
- <strong>リフレクションフィルター・吸音パネル</strong> : マイク周辺の吸音を高めて、遠くからの音の回り込みを軽減します。
- <strong>ノイズゲート・AIノイズ除去</strong> : 子どもの声が入る場面を、ソフトウェアで軽減します（NVIDIA Broadcast、Krispなど）。

子どもが寝ている時間帯に、収録や配信を集中させるのも現実的です。

昼寝の時間や、夜に就寝した後のまとめ撮りなど、生活リズムに合わせたスケジュールを組みます。

## 配信の音が家族を起こす問題

### 声量以外の音も見落とさない

音漏れ対策は声量ばかりに意識が向きがちですが、<strong>生活音も家族を起こす原因</strong>になります。

- <strong>キーボードの打鍵音</strong> : 特にメカニカルキーボードは響きやすいです。
- <strong>机や手を叩く音</strong> : 興奮した瞬間に、無意識に出やすい音です。
- <strong>イスのきしみ</strong> : 体を大きく動かすたびに鳴り続けます。

これらは声より小さくても、静かな深夜には意外と響きます。

### 今日からできる対策

- <strong>ゲーム音はヘッドホンで聴く</strong> : スピーカー出力をやめます。
- <strong>声量を抑える</strong> : 夜は驚き声や笑い声を意識して抑えます。ヘッドセットのマイクを口元に近づけると、小さな声でも十分に収音できます。
- <strong>ドアを閉め、隙間テープでふさぐ</strong> : 数百円のテープでも、音漏れのルートを減らせます。
- <strong>配信スペースの向きを見直す</strong> : デスクを、寝室から一番遠い壁側に寄せます。
- <strong>吸音パネルで反響を下げる</strong> : 反響があると、声が広がりやすくなります。

より詳しい音漏れ対策の手順は、[ワンルーム配信の防音ハック](/ja/creator/one-room-streaming-soundproof/)で紹介しています。

乳幼児は音に敏感で、少しの音で起きることがあります。

子どもが寝た後の配信は、特に声量とドアの対策を優先してください。

### 時間帯そのものを見直す

対策を尽くしても不安が残るなら、配信の時間帯を変えるのも現実的です。

深夜0時以降を避けて、夕方から22時台に切り替えるだけでも、家族の睡眠への影響は大きく減ります。

視聴者が固定されている場合は、事前に時間変更を告知しておくと混乱を防げます。

## 家族と、どんな音かを話してみる

注意されて気まずくなり、距離を置いてしまう人は多いです。

ですが、それでは同じことが繰り返されます。

<strong>まず、「具体的にどんな音が気になった？」と聞き返してみてください。</strong>

足音なのか、声なのか、キーボードの音なのか、時間帯そのものなのかで、必要な対策は変わります。

相手が「うるさい」としか言わないことも多いため、原因の特定は自分から歩み寄って引き出します。

原因が分かれば、「23時以降は声を出さない」「マイクの位置を変える」など、お互いが譲れる着地点を一緒に決められます。

一方的な我慢でも、一方的な要求でもなく、<strong>譲り合いの条件を言葉にして共有すること</strong>が、同じ注意をされないための近道です。

パートナーとは、配信する時間帯・曜日・音量ルールを、事前に決めておくことが重要です。

「週何日・何時まで」というルールがあると、深夜に突発で長時間になることによるトラブルを防げます。

大がかりな防音リフォームを親に相談したい場合は、[実家暮らし配信者の防音リフォーム交渉](/ja/creator/family-home-soundproof-reno-negotiation/)も参考にしてください。

## ルームシェア・同居人がいる場合の調整

ルームシェアは、子育てや実家と違い、<strong>同居人もそれぞれ生活リズムを持つ対等な当事者</strong>です。

「自分ばかり我慢している」と感じるなら、対等な話し合いができていないサインかもしれません。

一方的に配慮するのではなく、双方の生活音をどう調整するかが課題になります。

### 同居人の生活音が配信に入る

家事の音、テレビの音、電話の声などが、配信中のマイクに入ることがあります。

- <strong>配信スペースを生活の通路から離す</strong> : キッチンやリビングに近い部屋は、生活音が入りやすいです。
- <strong>同居人の在宅時間を把握する</strong> : 家事や在宅勤務の電話が多い時間帯を避けるだけで、ノイズが減ります。
- <strong>吸音パネルで収音範囲を絞る</strong> : 貼る位置は、[吸音材はどこに貼る？](/ja/diy/gamer-acoustic-placement/)を参照してください。

### 部屋割りと防音コストの分担

ルームシェアを始める段階で、<strong>配信用の個室を確保できるか</strong>が最初の分かれ道になります。

- 個室がある場合は、ドアの隙間対策と吸音パネルで、自室を簡易ブース化します。
- 個室が確保できない場合は、収録時間を分担するなど、運用でカバーします。
- 防音性能を重視した物件選びは、[配信者向け賃貸の選び方](/ja/creator/streamer-rental-selection-guide/)も参考にしてください。

共有部分に関わる対策は、導入前に同居人と相談します。

- 自室だけで完結する対策（吸音パネル、防振マットなど）は、個人負担で進めやすいです。
- 玄関や廊下の隙間テープなどは、費用や設置範囲を話し合います。

## 機材選びのポイント

- <strong>単一指向性マイク</strong> : 口元の声を中心に拾うため、周囲の声の回り込みを抑えます。
- <strong>閉鎖型ヘッドホン</strong> : 開放型より音漏れが少なく、家族が近くにいる環境でも使いやすいです。
- <strong>ノイズ除去機能つきのマイクやソフト</strong> : 背後の環境音を軽減できます。

## まとめ

同居人がいる家で配信を続けるためのポイントは、次のとおりです。

- 配信部屋と寝室の位置関係を確認し、優先する壁を把握する
- <strong>同居人の音が入る問題</strong>は、部屋の分離、ドアと隙間の対策、時間帯の調整で減らす
- <strong>配信の音が家族を起こす問題</strong>は、ヘッドホン、声量、ドア、配置の見直しで減らす
- 注意されたら距離を置かず、具体的な原因を聞いて譲り合う
- 時間帯・音量・費用の取り決めを、同居人と言葉にして共有する

完全に音を消すことよりも、家族との関係を保ちながら続けられる工夫を積み重ねることが、長続きのコツです。
