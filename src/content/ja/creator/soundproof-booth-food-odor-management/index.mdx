防音室の匂いが気になるときは、発生源を片付け、換気を確かめてから内装の手入れを考えます。

ダイキンの換気案内では、閉めきった部屋は空気が外へ出にくいと説明されています。

ブース内の飲食や片付け、外まで空気を入れ替える経路、吸音材に触る前の確認手順を整理しました。

配信環境全体の選び方は、[配信者・VTuber向けの防音環境ガイド](/ja/creator/streamer-soundproof-room-comprehensive-guide/)にまとめています。

## 防音室の匂い対策は発生源・換気・手入れの順に進める

<strong>最初に確かめるのは、食べ残しや容器、こぼした場所など、匂いの元が残っていないかです。</strong>

防音室だから一律に匂いが残ると決めず、発生源と換気の状態を分けて見ます。

| 確かめる順番 | 見るところ | 次にすること |
| :--- | :--- | :--- |
| 発生源 | 食べ残し・空き容器・ゴミ・こぼした跡 | 持ち出せるものを片付ける |
| 換気 | 換気設備の運転と給排気口の周り | 取扱説明に沿って運転し、荷物でふさいでいないか見る |
| 手入れ | 机・床・椅子・内装のどこが汚れたか | 素材ごとに許可された方法を確かめる |
| 原因が分からない場合 | 新品の素材の匂い、内部の汚れなど | ブースのメーカーへ状況を伝える |

ダイキンの[「上手な換気の方法」](https://www.daikin.co.jp/air/life/ventilation)は、閉めきった部屋では空気が外へ出にくいと説明しています。

これは住宅の換気に関する一般的な説明で、特定のブースの消臭効果を示すものではありません。

布やウレタンを含む内装は、水拭きや洗濯ができるとは限らず、手入れの方法が制限される場合があります。

匂いが吸音材の奥まで染みたと決めつけず、まずは外せるカバーや床の汚れを確認します。

## 防音室の換気はブースの外まで空気の通り道を確かめる

ブースの換気では、<strong>空気が入る口と出る口、それにつながるブース外の部屋</strong>を順に見ます。

ブースの扉を開けるだけで済ませず、設置している部屋の換気も確かめます。

1. ブースの取扱説明を開き、換気設備の運転方法を確認します。
2. 給気口と排気口が、荷物や追加した吸音材でふさがれていないかを見ます。
3. 設置している部屋の換気口や換気設備も、取扱説明に沿って確認します。
4. 扉を開ける場合は、収録や発声を止めた休憩中に行います。

扉を開けたまま話せば、閉めているときと同じ防音条件では使えません。

換気音が録音に入る場合も、換気を止めて使い続けず、収録の区切り方や設備を見直します。

換気時間やCO2の考え方は、[防音室のCO2濃度の計算と換気の工夫](/ja/soundproof-room/ear-pressure-tinnitus-dizziness/)で確認できます。

設備を選び直す場合は、[防音室の空調・換気設備の選び方](/ja/soundproof-room/proofroom-aircondition-select/)を参照してください。

「配信後に何分開ければ匂いが消える」という共通の時間は、ここでは設けません。

ブースや設置場所の条件が違うため、メーカーの案内に従い、匂いが続く場合は発生源と手入れを再確認します。

## 防音ブースの臭いを増やさない飲食と片付け

匂いが気になる人は、食事を休憩に合わせてブースの外で済ませる方法から考えます。

飲食が必要な場合の段取りは、次のように分けられます。

| 場面 | 当サイトからの運用案 | 確かめること |
| :--- | :--- | :--- |
| 食事を取る | 食べ物を持ち込まず、外で食べる | ブース内での飲食が許可されているか |
| 飲み物を置く | ふた付き容器を使う | 倒しても機材や内装にかかりにくい置き場所か |
| 配信を終える | 容器・食べ残し・ゴミを持ち出す | 机の下や椅子の周りに残っていないか |
| こぼしてしまう | 使用を止め、取扱説明を確認する | 濡れた素材と、その素材に使える手入れ方法 |

たとえばカップ麺をブースの外で食べても、食べ終えた容器を中に置けば発生源が残ります。

食べる場所と、容器を片付けるところまでを一緒に決めておきます。

ふた付き容器も、転倒や液漏れを防ぐ保証にはならないので、配線や電源から離して置きます。

これらは、持ち込みと片付けの段取りを決めるための運用案です。

## 吸音材の手入れと消臭剤は取扱説明を確かめる

<strong>吸音材に水や消臭スプレーをかけてよいかは、当サイトでは個別製品を確認していません。</strong>

各ブースの取扱説明で、内装の素材と清掃方法を先に調べてください。

説明が見つからない場合は、ブースのメーカーへ問い合わせてから手入れします。

- <strong>机・床・椅子</strong> : それぞれの素材に使える清掃方法を確認する
- <strong>吸音材・布の内装</strong> : 水拭き・薬剤・取り外し・洗濯の可否を確認する
- <strong>消臭剤</strong> : メーカーの説明で、使える場所・素材・使用方法を確認する
- <strong>空気清浄機</strong> : メーカーの説明で、使用できる場所・設置条件・対象となる匂いを確認する

サーキュレーターを置く場合も、室内の空気を回すことと、外の空気へ入れ替えることを分けて考えます。

空気清浄機や消臭剤を追加したことだけで、ブースの換気設備が不要になるとは判断しません。

片付けと、許可された方法での清掃をしても匂いが続く場合は、発生場所や使った清掃用品をメーカーへ伝えます。

吸音材の交換が必要か、自分で取り外せるかも、その段階で相談します。

## 来客・コラボ前に匂いを確かめる

人を招く予定があるなら、使用直後だけでなく、片付けと換気をした後にも状態を見ます。

相手に確認を頼む場合は、気になる匂いや香りがないかを聞き、無理に中へ入ってもらわないようにします。

来客前だけ消臭剤を増やすより、ゴミ・換気口・汚れた場所の確認を先に済ませます。

2人で使う予定なら、[コラボ配信・2人収録の防音部屋と広さの選び方](/ja/creator/collab-streaming-soundproof-space/)も確認できます。

まずは次の配信を終えたときに、容器やゴミをブース内に残していないか確かめてください。
