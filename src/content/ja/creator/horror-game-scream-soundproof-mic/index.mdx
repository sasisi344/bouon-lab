ホラーゲーム実況・対戦ゲームの絶叫は視聴者を惹きつける大事なリアクションです。
一方で「声量を下げてください」というアドバイスは、<strong>配信のクオリティを犠牲にする対症療法</strong>でしかありません。
本記事は音の種類別対策を網羅した[ゲーム実況者の防音環境｜打鍵音・マウス音・叫び声ごとの対策](/ja/creator/game-streamer-sound-types/)からさらに踏み込み、<strong>「絶叫の声量は落とさず、マイクにはしっかり乗せつつ、部屋の外への音漏れだけを抑える」</strong>という配置・機材の工夫に絞って解説します。

## 発想の転換：「声を小さくする」のではなく「音の向きを制御する」

叫び声は空気伝播音のため、声量を落とせば当然マイクに入る音も小さくなります。しかし<strong>絶叫のインパクトはリアクション動画の価値そのもの</strong>なので、単純な声量ダウンは配信内容を薄くしてしまいます。

そこで有効なのが「指向性」という考え方です。<strong>マイクは近距離の声を高感度で拾い、部屋の壁・窓に向かう音のエネルギーだけを吸音・遮音で減衰させる</strong>という役割分担にすると、声量を落とさずに音漏れだけを抑えられます。

## マイクの指向性と距離を最適化する

- <strong>単一指向性（カーディオイド）マイクを選ぶ</strong> : 正面からの声には高感度、背面・側面からの音は拾いにくい特性があります。無指向性マイクより絶叫時の音量差が付けやすくなります
- <strong>マイクを口元10〜15cm程度に近づける</strong> : 近接効果でマイクの感度が上がるため、<strong>実際の発声音量を上げなくても大きく収録できます</strong>。マイクゲインを上げるより先に距離を詰めるのが基本です
- <strong>マイクの背面を窓・隣室側の壁に向けない</strong> : 単一指向性マイクは背面の感度が低いため、背面方向にある壁・窓へ音が抜けやすい配置は避け、背面を吸音パネル側に向けます

## 「音の逃げ道」を吸音パネルでふさぐ

叫び声が窓・壁に届く前に、発生源の周辺で吸音してしまうのが最も効果的です。

- <strong>デスク背面・側面にL字型の吸音パネルを設置する</strong> : 口元から放射状に広がる音のうち、部屋の壁に向かう分をパネルで先に吸収します。マイクに向かう分はパネルの内側（発声者側）を通るため影響を受けません
- <strong>窓側には厚手の防音カーテンを設置する</strong> : 窓は壁より遮音性能が低いため、絶叫のような瞬間的な大音量が最も抜けやすい弱点です
- <strong>反響を抑えることで結果的にマイクの音質も向上する</strong> : 吸音パネルは音漏れ対策であると同時に、声の輪郭がはっきりした収録にもつながります

## タイミング面の運用ルール

配置を工夫しても、深夜帯の絶叫は近隣配慮が必要です。

- <strong>ホラーゲーム・対戦ゲームなど絶叫が出やすいタイトルは、可能な限り21時までに配信を終える</strong>
- <strong>深夜にどうしても配信する場合は、事前に近隣へ一言伝えておく</strong>と苦情に発展しにくくなります。詳しくは[深夜配信を続けるための「近隣トラブル回避術」賃貸編](/ja/creator/night-streaming-neighbor-tips/)を参照してください
- <strong>すでに苦情が来ている場合</strong>は、配置の工夫だけでは間に合わないケースもあるため、[配信中に「苦情が来た」ときの対処フロー](/ja/creator/streamer-noise-complaint-response/)を確認してください

## この方法の限界

指向性マイクと吸音パネルの組み合わせは、<strong>「壁が薄い賃貸物件で絶叫がダイレクトに響く」ような重度のケース</strong>までは救えません。
その場合は防音マスクや簡易防音ブースなど、遮音そのものを底上げする対策に切り替える必要があります。詳しくは[ゲーム配信×防音マスク自作 声漏れを500円で抑える3つの作り方](/ja/diy/diy-vocal-soundproof-mask/)を参考にしてください。

## まとめ

| 目的 | 対策 |
| :--- | :--- |
| <strong>声量を落とさず収録品質を保つ</strong> | 単一指向性マイクを口元10〜15cmに配置 |
| <strong>音漏れだけを抑える</strong> | デスク周辺・窓側に吸音パネル、マイク背面は吸音側へ |
| <strong>近隣配慮</strong> | 21時までの配信終了、深夜配信時の事前一言 |

「叫び声を我慢する配信」ではなく、<strong>「叫び声はそのまま、音の向きだけ制御する配信」</strong>を目指すことで、コンテンツの魅力と近隣配慮を両立できます。
