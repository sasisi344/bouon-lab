ゲーム実況の騒音対策は、<strong>どの音が、どこへ届いているかで、やることがまったく変わります。</strong>

叫び声のように空気を伝わる音は隙間と壁で、打鍵音や台パンのように床へ響く音は防振で、マイクに入る音はマイクの置き方で減らします。

この記事では、ゲーム実況で出る6つの音を早見表で振り分け、最初にやる対策と、詳しく解説した記事を案内します。

## まず音を振り分ける｜ゲーム実況の騒音早見表

「うるさい」と言われた音、または配信に入ってしまう音を、下の表で探してください。

| 音 | 主に届く先 | 伝わり方 | 最初の対策 |
| :--- | :--- | :--- | :--- |
| 打鍵音 | マイク・下の階 | 机から床へ響く振動＋空気 | キーボードの下にマット、マイクを机から離す |
| マウスのクリック音 | マイク | 空気＋机の振動 | 静音マウス、厚手のマウスパッド |
| 台パン・足の踏み鳴らし | 下の階 | 床へ響く振動 | 机の脚と床の間に防振材 |
| 叫び声・笑い声 | 隣の部屋・家族 | 空気 | 窓・ドアの隙間をふさぐ、深夜の声量を下げる |
| ゲーム音（スピーカー） | 隣の部屋・家族 | 空気＋スピーカーの振動 | ヘッドホンに切り替える |
| PCのファン音 | マイク | 空気 | PCをマイクから離す、マイクの向きを変える |

大きく分けると、次の3つの行き先になります。

- <strong>下の階に響く音（打鍵音・台パン）</strong> : 壁を厚くしても止まりにくい。床へ渡る振動を減らす
- <strong>隣や家族に漏れる音（叫び声・ゲーム音）</strong> : 空気を伝わる。隙間をふさぎ、重さのある壁や防音室で閉じ込める
- <strong>マイクに入る音（打鍵音・クリック音・ファン音）</strong> : 近所への迷惑ではなく、配信の音質の問題。マイクの置き方で減らす

叩く音・押す音が床へ響く仕組みは、[叩く音・押す音が下の階に響くのはなぜ？ヘッドホンでも消えない振動の止め方](/ja/knowledge/structure-borne-noise-tapping-striking/)で、共通の通り道からまとめています。

## 打鍵音｜マイクに入る音と、下の階に響く振動

キーボードの打鍵音は、配信のマイクに入る音と、机から床へ伝わる振動の2つに分かれます。

- <strong>マイクを机から離す</strong> : 机に置いたマイクスタンドは、打鍵の振動を拾います。アームやショックマウントで机から離すと、打鍵音が入りにくくなります
- <strong>静音スイッチ・Oリング</strong> : マイクに入る「カチャカチャ」を抑えます
- <strong>キーボードの下のマットと、机の脚の防振</strong> : 下の階に届く「コトコト」という振動を抑えます

ストロークの長さと振動の関係や、対策を効く順に並べた費用の比較は、[キーボードの打鍵音対策｜下の階に響く振動を止める順番と静音化](/ja/diy/keyboard-typing-noise-vibration/)で解説しています。

## マウス音｜クリック音は静音化で減らす

マウスのクリック音は、主にマイクに入る音です。

- <strong>静音マウスに替える</strong> : クリックの「カチッ」という音を抑えたスイッチの製品があります。ゲーム用でも静音タイプを選べます
- <strong>厚手のマウスパッドを使う</strong> : 机に直接当たる音と、机に伝わる振動を和らげます
- <strong>マイクの向きを変える</strong> : 単一指向性のマイクなら、マウスのある方向をマイクの背中側に向けます

## 台パン・足の踏み鳴らし｜下の階への苦情が多い音

対戦中に机を叩く、足を踏み鳴らす音は、<strong>床へ直接響く振動</strong>です。

吸音パネルや防音カーテンでは止まりません。

- <strong>机の脚の下に防振材を入れる</strong> : 机から床へ渡る振動を減らす
- <strong>足元にマットを重ねる</strong> : 柔らかい層と重い層を重ねて、着地の衝撃を和らげる
- <strong>叩く癖そのものを減らす</strong> : 叩く場所にクッションを置く、配信中の癖を意識する

費用別の対策と、効かない対策の見分け方は、[台パンの衝撃吸収・防振対策｜下の階に響く仕組みと2,000円で防ぐ方法](/ja/creator/gaming-floor-impact-noise-fix/)で解説しています。

## 叫び声・笑い声｜隣や家族に漏れる音

ゲーム実況での叫び声・笑い声・驚き声は、<strong>空気を伝わる音で、窓・ドア・壁から漏れます。</strong>

対策は、効く順に次のとおりです。

1. <strong>窓・ドアの隙間をふさぐ</strong> : 隙間テープ・ドア下のすき間ふさぎ
2. <strong>深夜帯の声量を意識して下げる</strong> : 叫びの多いジャンルは、遅い時間を避ける
3. <strong>マイクを口元に近づける</strong> : 小さな声でも拾えるため、声量を落とせる
4. <strong>吸音パネルで反響を減らす</strong> : 漏れは止まらないが、マイクに入る響きが減る

声量を落とさずに音漏れだけを抑えたい場合は、[ホラーゲーム実況の絶叫、近所には漏らさずマイクにはしっかり乗せる配置術](/ja/creator/horror-game-scream-soundproof-mic/)でマイクの指向性と吸音パネルの配置を解説しています。

ワンルームで隣人への声漏れを1万円以下で抑える方法は、[ワンルーム配信の防音ハック｜1万円以下で夜の声漏れと隣人の壁ドンを防ぐ](/ja/creator/one-room-streaming-soundproof/)にまとめています。

## ゲーム音（スピーカー）｜ヘッドホンが一番確実

ゲーム音をスピーカーで鳴らしている場合、音量によっては深夜に問題になります。

- <strong>ヘッドホン・ヘッドセットに切り替える</strong> : スピーカーからの音漏れをなくせる、最も確実な対策です
- <strong>スピーカーを隣の部屋側の壁に向けない</strong> : 壁に向けると、その壁を揺らす音が増えます
- <strong>スピーカーの下にインシュレーターを置く</strong> : 低音の振動が机から床へ伝わるのを減らします

## PCのファン音｜マイクに入る「サー」という音

PCのファン音は、近所への迷惑より、<strong>配信に入るノイズ</strong>として問題になります。

- <strong>PCをマイクから離す</strong> : 机の下に置く、マイクとの間に距離をとる
- <strong>マイクの向きを変える</strong> : PCをマイクの背中側にする
- <strong>ファンの回転を見直す</strong> : ほこりの掃除やファンの設定で、回転数そのものを下げる

ファン音・部屋の反響・外の音のどれがノイズの原因かの切り分け方は、[配信のマイクノイズはPC本体が原因？ファン音・反響・外音の切り分けと直し方](/ja/creator/streaming-pc-fan-noise-mic/)で解説しています。

## どこから手を付けるか

苦情が来ているなら、<strong>苦情の来た方向</strong>から手を付けます。

| 苦情・悩み | 優先する音 | 優先する対策 |
| :--- | :--- | :--- |
| 下の階から苦情 | 台パン・打鍵音 | 机の脚と足元の防振 |
| 隣の部屋から苦情 | 叫び声・ゲーム音 | 隙間対策、ヘッドホン、声量 |
| 家族から「うるさい」 | 叫び声 | ドアの隙間、深夜の声量 |
| 視聴者から「ノイズが入る」 | 打鍵音・クリック音・ファン音 | マイクの位置と向き |

苦情を受けた直後の謝り方や、改善の伝え方は、[配信中に「苦情が来た」ときの対処フロー｜謝罪・改善・再発防止まで](/ja/creator/streamer-noise-complaint-response/)にまとめています。

防音より先にマイク側でできる対策は、[ゲーム配信者が防音より先にやるべき騒音対策｜マイク音質改善が最優先](/ja/creator/streamer-noise-quick-fix/)を参照してください。

低コストの対策を使い切っても叫び声が漏れる場合は、防音室を検討する段階です。

活動規模別の選び方は、[【2026完全版】配信者・VTuberのための防音環境完全ガイド｜ワンルームから防音室まで全解説](/ja/creator/streamer-soundproof-room-comprehensive-guide/)で整理しています。

## まとめ｜音を振り分けてから対策を選ぶ

- <strong>下の階に響く音（打鍵音・台パン）</strong> : 防振。吸音パネルやカーテンでは止まらない
- <strong>隣や家族に漏れる音（叫び声・ゲーム音）</strong> : 隙間対策、ヘッドホン、声量。足りなければ防音室
- <strong>マイクに入る音（打鍵音・クリック音・ファン音）</strong> : マイクの位置と向き、静音化

防音室を買う前に、まず早見表で自分の音を振り分け、その音に合った低コストの対策から始めてください。
