ASMR配信者にとって、外音は最大の敵です。

<strong>一般的な配信者が「まあいいか」と流せる外音も、ASMRでは録音クオリティを大きく下げます。</strong>

だからこそ、収録時間を深夜2時に合わせたり、機材にお金をかけ続けたりして、少しずつ生活が削られていませんか。

ただし、「外音を完全にゼロにする」のは現実的に非常に困難です。

この記事では、ASMRの収録で外音を下げる順番と、防音ブースを選ぶときの確認点を解説します。

青天井にならない範囲で、「どこまでやれば十分か」が分かるようにまとめました。

## ASMR収録で外音が問題になる理由

ASMR収録では、感度の高いコンデンサーマイクを使うことが多いです。

このマイクは<strong>遠くの微細な音まで拾うため、一般の配信では聞こえない環境ノイズが録音に乗りやすい</strong>です。

問題になりやすい外音は次のとおりです。

- <strong>交通音</strong> : 窓越しの車・バイク・電車の音。低い音は壁を透過しやすいです。
- <strong>空調・換気扇の音</strong> : 収録中は切りますが、夏場は熱対策との兼ね合いが難しくなります。
- <strong>隣人の生活音</strong> : 足音・会話・テレビの音が、壁や床を通じて伝わります。
- <strong>PCのファン音</strong> : 機材側のノイズです。部屋ではなく、機材側で対策します。

## 「完全な無音」は現実的でない理由

一般的な賃貸マンションに住みながら、外音を完全にゼロにすることはできません。

プロのレコーディングスタジオでも、無響室に近い状態を作るには大規模な施工が必要です。

<strong>現実的な目標は、「気にならないレベルまで外音を下げること」</strong>です。

具体的には、編集時のノイズリダクションで除去できる程度に、外音を抑えることを目指します。

## 外音対策の優先順位

### まず録音時間帯を選ぶ（コスト：0円）

最も費用がかからない対策は、<strong>外音が少ない時間帯に録音すること</strong>です。

- 交通音は、深夜から早朝にかけて小さくなります
- 近隣の生活音は、平日の早朝や深夜が少ない傾向があります
- 工事や作業の音は、平日の昼間に多くなります

収録のタイミングを選ぶだけで、録音の質は大きく変わります。

### 窓の対策

外音の主要な侵入経路は窓です。<strong>窓の対策が、外音の軽減に最も効きやすい</strong>部分です。

- <strong>防音カーテン（重ね掛け）</strong> : 既存のカーテンの内側に追加します。二重にするとさらに効果が高まります。
- <strong>窓の隙間テープ</strong> : サッシの隙間をふさぎます。最も安く試せる対策です。
- <strong>内窓（二重窓）の設置</strong> : 最も効果が高い窓対策です。賃貸での施工には、大家の許可が必要です。費用は工事内容で変わるため、見積もりで確認してください。

### 部屋の吸音を高める

外音をふさぎきれない場合でも、<strong>部屋の吸音を高めると、マイクに入る外音の影響を軽減できます</strong>。

外音が部屋の中で反響して、大きく聞こえる現象を防げるためです。

- 吸音パネルを、壁の広い範囲に設置します
- 厚手のラグやカーペットで、床を覆います
- 本棚やソファを、反射しやすい壁側に置きます

マイクの周りだけを響きの少ない環境にするなら、デスク型のリフレクションフィルターと吸音パネルの組み合わせから始められます。

## それでも残るなら、防音ブースを検討する

ここまでの対策を積み重ねても、気になる外音が残る場合に、防音ブースを検討します。

「趣味にここまで出費していいのか」と迷う場面です。

収録品質はチャンネルの評価に関わるため、趣味の延長ではなく、<strong>制作環境への投資</strong>と捉えるのが妥当です。

### ブースのクラスと、できること

| クラス | 遮音の目安 | 向いている用途 |
| :-- | :-- | :-- |
| 簡易ブース | 低い。音質の向上が主目的で、近隣への遮音は限定的 | 昼間の雑談、歌ってみた、入門 |
| ユニット型（標準） | 公表されたDr値で選ぶ | VTuber、集合住宅での配信 |
| ユニット型（高遮音） | 高いDr値と、浮き床などの構造 | ASMR、深夜の収録 |

機種ごとの価格とDr値は、時期とサイズで変わります。

購入前に、メーカーや代理店の最新の仕様と見積もりで確認してください。

価格の目安は[防音室サイズ別価格相場](/ja/money/soundproof-room-price-market/)、機種の比較は[防音室のおすすめ比較](/ja/soundproof-room/bouon-osusume-hikaku/)で整理しています。

エントリークラスの選び方は、[格安防音室の比較（だんぼっち・OTODASU・自作）](/ja/soundproof-room/budget-soundproof-booth-comparison/)も参考になります。

### ASMRで見るべき「ブース自身の騒音」

ASMRでは、外音だけでなく、<strong>防音ブース自身が出す音</strong>が最大の敵になることがあります。

- <strong>換気扇の静音性</strong> : 静かなファンか、ファンを外部に置けるモデルかを確認します。
- <strong>床の安定性</strong> : 高感度マイクは、わずかな床の振動も拾います。浮き床構造のモデルが理想です。
- <strong>熱と配線</strong> : 高性能PCを入れると熱がこもります。排気ルートと、ケーブルの通し口があるかを見ます。

ケーブルの通し方は[防音室のケーブル配線術](/ja/creator/soundproof-booth-cable-management/)、空調の選び方は[防音室のエアコン選びと静音化](/ja/soundproof-room/proofroom-aircondition-select/)で解説しています。

VTuberとして体を動かす配信をするなら、広さにも余裕が必要です。

1畳前後では、腕を振ったときに壁へ当たることがあります。

### ブースの外にある「接続経路」のノイズも消す

ASMRの高感度マイクは、部屋の暗騒音だけでなく、<strong>機材の接続方法が出すノイズ</strong>まで拾います。

- <strong>オーディオインターフェースを経由する</strong> : PCに直接つなぐマイクは、USBバスのノイズを拾いやすくなります。
- <strong>XLRのバランス接続にする</strong> : 家庭用のアンバランスなケーブルはノイズを拾いやすく、ASMRでは致命的です。マイクからインターフェースまでは、XLRのバランスケーブルにします。
- <strong>ゲインを整える</strong> : マイクプリで適正な音量まで上げてから、ミキサー側で微調整します。プリアンプでゲインを上げすぎると、ノイズも一緒に増えます。

<strong>簡易ブースでも、接続経路を整えると、体感の音質が大きく変わります。</strong>

逆に、高価なブースでも、アンバランス接続のままでは性能を活かせません。

どこまで暗騒音を抑えるべきかの技術的な基準は、[暗騒音の目安はNC値で決める｜ASMR・歌枠・ゲーム実況の録音に必要な静けさ](/ja/knowledge/report-japan-asmr-vtuber-streaming-studio-standard/)で解説しています。

## ソフトウェアとの組み合わせ

部屋の対策と並行して、ノイズリダクションのソフトを使うと、後処理の負担を減らせます。

- <strong>Adobe Audition・iZotope RX</strong> : 編集用。ノイズ除去の精度が高いソフトです。
- <strong>Krisp・NVIDIA Broadcast</strong> : リアルタイム処理。収録後の編集工数を減らせます。

ただし、ソフトウェア処理は音質に影響する場合があります。

ASMRでは、収録の段階で外音を下げることを優先してください。

## 導入方法：購入か、レンタルか

- <strong>購入</strong> : 長く（目安として3年以上）活動する予定があるなら、購入のほうが総額を抑えやすいです。中古市場もあり、売却も考慮できます。
- <strong>レンタル・サブスク</strong> : 「まず半年試したい」「引っ越しが多い」という場合に向いています。料金はサービスごとに違うため、公式で確認してください。

レンタルの費用の考え方は、[防音室レンタルの費用ガイド](/ja/money/soundproof-room-rental-cost/)にまとめています。

防音室の設置全体の流れや買う判断は、[配信者・VTuberのための防音環境完全ガイド](/ja/creator/streamer-soundproof-room-comprehensive-guide/)を参照してください。

## まとめ

ASMR収録の外音対策は、現実的な目標設定から始まります。

1. <strong>時間帯を選ぶ</strong>（コスト0円）
2. <strong>窓の隙間テープ・防音カーテン</strong>
3. <strong>部屋全体の吸音を高める</strong>
4. <strong>防音ブース・内窓</strong>（ブース自身の騒音と、接続経路も確認する）

完全な無音を目指すより、「ノイズリダクションで処理できる程度に外音を下げる」という目標で、対策を積み上げてください。
