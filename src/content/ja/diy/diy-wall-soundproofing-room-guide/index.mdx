「部屋ごと防音室にしたい」という希望は自然ですが、賃貸DIYには物理的な上限があります。  
重要なのは、目標性能とコストとリスクを同時に見積もることです。

結論から言うと、<strong>賃貸で壁をDIYして狙えるのは「話し声やテレビ音を和らげる」レベルまで</strong>です。
楽器や大音量の配信を隣室に聞こえない水準まで抑えたい場合は、ユニット防音室か専門工事が現実的な選択肢になります。

## 目的別に見る、DIYで届く範囲の目安

先に「自分の目的はDIYで届くのか」を確認しておくと、無駄な出費を防げます。

| 防ぎたい音 | 壁DIY（突っ張り二重壁など） | 現実的な選択 |
| :-- | :-- | :-- |
| 隣室の話し声・テレビ音 | 軽減が期待できる | DIYで試す価値あり |
| 在宅ワークのオンライン会議の声 | 軽減が期待できる | DIY＋隙間処理 |
| 夜間の配信・ボイチャ | 窓・ドアの処理を併用して軽減を狙う | DIY＋窓・ドア対策、または小型ブース |
| 楽器・ドラムなどの大音量 | 不足しやすい | ユニット防音室、専門工事 |
| 足音・物を落とす音 | 壁では減らせない（床の振動が原因） | 床の防振対策 |

壁の構成と狙える性能（Dr値）の対応は、[防音材スペック早見表](/ja/knowledge/soundproof-material-spec-chart/)で確認できます。
石膏ボード片面1枚のDr-20〜25から、独立柱＋二重張りのDr-45〜50まで幅があり、<strong>賃貸の突っ張り壁は気密や荷重の制約から、上位の構成には届きにくい</strong>と考えておくのが安全です。

## まず知っておきたい前提

- <strong>吸音材だけでは遮音にならない</strong> : 室内の反響を抑えても、壁を透過する音量はほとんど変わりません
- <strong>壁だけ対策しても回り込みが残る</strong> : 窓・ドア・換気口など、壁より弱い経路から音が回り込みます
- <strong>重量増による床負荷に注意が必要</strong> : 二重壁や遮音材の追加は、想像以上に総重量を増やします

## 工法別の比較

部屋全体を防音室化する方法は、大きく4つに分かれます。それぞれ費用・効果・工期・原状回復リスクが大きく異なるため、目的に応じて選ぶことが重要です。

| 工法 | 予算目安 | 効果（dB減衰の目安） | 工期 | 賃貸原状回復リスク |
| :-- | :-- | :-- | :-- | :-- |
| 吸音材直貼り | 低（数千円〜数万円） | 室内反響の軽減が中心、透過音の減衰はわずか | 数時間〜1日 | 低（剥がせる施工なら原状回復しやすい） |
| 突っ張り式二重壁 | 中（数万円〜十数万円） | 中音域中心に数dB〜10dB程度の軽減目安 | 1〜3日 | 低〜中（ラブリコ等は壁・床に穴を開けず撤去可能） |
| ユニット防音室 | 高（数十万円〜） | 20dB前後以上の高遮音が期待できる | 設置工事で数日 | 中（床荷重・搬入経路の制約あり、撤去は可能） |
| 専門工事（壁・床・天井の本格防音改修） | 最高（百万円規模になることも） | 最も高い遮音性能を狙える | 工事内容により数週間 | 高（賃貸では原則不可、持ち家向き） |

### 各工法の特徴

- <strong>吸音材直貼り</strong> : コストは低いが、遮音目的では効果が限定的です。室内の音の響きを整えたい用途（楽器練習時の聞こえやすさ改善など）には向きます
- <strong>突っ張り式二重壁</strong> : ラブリコなどの突っ張り柱を使い、既存の壁から離れた位置に新しい壁を作る工法です。賃貸でも壁や床に穴を開けずに施工・撤去できる点が大きな利点です
- <strong>ユニット防音室</strong> : 工場で組み立てられた防音性能の高い箱を室内に設置する方法です。性能は安定していますが、設置場所の床荷重と搬入経路の確認が必須です
- <strong>専門工事</strong> : 壁内に遮音シートや遮音ボードを仕込み、躯体ごと防音化する方法です。最も高い性能を狙えますが、賃貸では原状回復が難しく、持ち家での本格改修向きです。工法別の価格帯・業者の選び方は[防音工事の種類と価格比較｜壁・床・開口部、業者の選び方まで](/ja/soundproof-room/construction-types-cost-comparison/)で詳しく解説しています

工事不要で壁際に立てかけるだけの製品を検討している場合は、[ワンタッチ防音壁は効果ある？評判と自作代用の可否を検証](/ja/soundproof-room/onetouch-soundproof-wall-review/)で効果の限界を確認しておくと失敗を防げます。

工法ごとの壁構成で狙えるD値（Dr値）の目安は、[防音材スペック早見表｜面密度・TL値・D値の対応を一覧で比較できる資料](/ja/knowledge/soundproof-material-spec-chart/)で数値を確認できます。

## 突っ張り式二重壁工法の具体的な手順

二重壁工法は、既存の壁との間に空気層を設けることで遮音性能を高める仕組みです。

1. <strong>下地の確認</strong> : 突っ張り柱を設置する床・天井の位置に、強度のある下地（コンクリートスラブや梁の位置）があるかを確認します
2. <strong>空気層の確保</strong> : 既存の壁から最低でも数cm、できれば10cm前後の空気層を空けて柱を立てます。空気層は音の振動が新しい壁へ直接伝わることを防ぎ、また空気層自体が低音域の吸収にも寄与します。それでも部屋の隅にこもる低音の膨らみが残る場合は、[ベーストラップ設置ガイド](/ja/diy/bass-trap-installation-guide/)でコーナー処理を追加すると効果的です
3. <strong>柱の設置</strong> : 突っ張り柱を床と天井の間で固定し、水平方向に等間隔（目安として40〜60cm程度）で複数本立てます
4. <strong>面材の取り付け</strong> : 柱に石膏ボードや遮音ボードをビス留めし、新しい壁面を作ります
5. <strong>気密処理</strong> : 新しい壁と床・天井・既存壁との接合部にできる隙間を、気密テープやコーキングで処理します。空気層を設けても隙間から音が抜けると効果が大きく損なわれます

## 床荷重180kg/㎡のリスクの根拠

二重壁やユニット防音室を導入する際、最も見落とされやすいのが床荷重です。

- <strong>建築基準法上の目安</strong> : 住宅の居室における床の構造計算で一般に用いられる基準的な荷重の目安は、180kg/㎡程度とされています（実際の設計荷重は建物ごとに異なるため、正確な数値は建物の構造図面や管理会社への確認が必要です）
- <strong>防音室導入時の荷重増</strong> : ユニット防音室や遮音材を多用した二重壁は、本体重量・遮音材の質量則に基づく重さが加わり、設置面積あたりの荷重がこの目安に近づく、あるいは超えるケースがあります
- <strong>リスクの内容</strong> : 床の構造的な許容範囲を超える荷重がかかると、床のたわみや、最悪の場合は構造的な損傷につながる可能性があります
- <strong>確認方法</strong> : 重量物を導入する前に、製品の総重量（梱包重量ではなく設置時重量）と設置面積から1㎡あたりの荷重を計算し、必要であれば管理会社や建築士に確認することが推奨されます

### 6畳の二重壁を作った場合の重さの試算

石膏ボード12.5mmの面密度を約10.5kg/㎡として、6畳（3.6m×2.7m、天井高2.4m）の壁4面に2枚重ねで張る場合を試算します。

| 項目 | 計算 | 結果 |
| :-- | :-- | :-- |
| 壁の総面積 | 周長12.6m × 高さ2.4m | 約30.2㎡ |
| 面材の総重量 | 30.2㎡ × 10.5kg/㎡ × 2枚 | 約635kg |
| 床面積あたりの増加荷重 | 635kg ÷ 9.72㎡ | 約65kg/㎡ |

この試算では、面材だけで床面積あたり約65kg/㎡、上の目安（180kg/㎡）の3分の1強が埋まります。
柱材、家具、人の重さ、荷重が壁の足元に集中する点は含まれていないため、実際の余裕はさらに小さくなります。

壁1面（幅3m）だけの二重張りでも約150kgになります。
<strong>重量は「壁を足した分だけ確実に増える」ため、全面ではなく、音が問題になる面に絞る</strong>ほうが安全です。

数値は目安の試算です。実際の安全性は、建物の構造や管理規約によって変わるため、導入前に管理会社や建築士へ確認してください。

## 弱点となる窓・ドア・換気口の個別対策

壁面の対策をどれだけ強化しても、開口部が弱点として残ると音響短絡（隙間からの音漏れ）が起きます。

### 窓の対策

- <strong>内窓（二重窓）の設置</strong> : 既存窓の内側にもう1枚窓を追加し、窓全体を二重構造にする方法です。空気層により遮音性能が向上します
- <strong>防音カーテンの併用</strong> : 内窓ほどの効果は期待できませんが、すきま風や反響の軽減には一定の効果があります

### ドアの対策

- <strong>ドア下の隙間処理</strong> : ドア下に専用のドアボトムシールを取り付け、隙間からの音漏れを減らします
- <strong>気密パッキンの追加</strong> : ドア枠とドア本体の間に気密パッキンを追加し、密閉性を高めます

### 換気口の対策

- <strong>防音換気口への交換</strong> : 内部にサイレンサー構造を持つ防音タイプの換気口に交換すると、換気経路を保ったまま音の透過を抑えられます
- <strong>気密と換気の両立</strong> : 気密性を上げる施工をしても、換気経路を完全に塞いではいけません。結露やカビの原因になるため、防音換気口や換気ダクトの確保が前提になります

## まとめ

部屋全体DIYは「可能か」より「どこまで許容するか」が判断軸です。

1. 目的騒音を明確にする
2. 到達性能を決める
3. 施工リスク（床荷重・気密・原状回復）を先に潰す

この順で設計すると、過剰投資と施工トラブルを減らせます。遮音・吸音それぞれの具体的なテクニックは、[DIY防音のコツ｜安価で効果的な遮音・吸音テクニック](/ja/diy/diy-soundproofing-tips/) で詳しく解説しています。木造アパート特有の制約は[木造アパートの防音DIYガイド](/ja/diy/wooden-apartment-soundproof-guide/)、クローゼットを活用した省スペース施工は[クローゼットDIY防音室](/ja/diy/closet-diy-soundproof-room/)も参考にしてください。

材料費の内訳を先に確認したい場合は、[自作防音室の費用内訳｜材料費だけでいくらかかる？](/ja/diy/soundproof-room-diy-cost/)で1.5畳の試算を紹介しています。
