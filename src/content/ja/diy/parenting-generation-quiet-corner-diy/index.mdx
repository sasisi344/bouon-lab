夜泣きを夫婦で交代しているのに、<strong>非番の人まで泣き声で目が覚めてしまう</strong>なら、寝る場所と音の通り道を変えるのが先です。

赤ちゃんから一番遠い部屋を非番の寝室にし、ドアの隙間をふさぎ、耳栓と環境音で残りを隠せば、1万円台からでも眠れる場所は作れます。

この記事では、交代制が続く家の中に「ぐっすり眠れる一人の場所」を後付けする手順を、費用の段階ごとに紹介します。

## 夜泣きの交代制がうまくいかない理由

子育てで一番つらい時期は、夜泣きで何度も起こされる時期です。

夫婦で交代すれば半分は眠れるはずですが、実際には次の理由でうまくいきません。

- <strong>非番の人にも泣き声が聞こえる</strong> : 同じ部屋や隣の部屋で寝ていると、当番でなくても目が覚める
- <strong>「聞こえているのに寝ている」気まずさ</strong> : 泣き声で起きたのに手を出さないと、休めた気がしない
- <strong>当番の時間があいまい</strong> : 何時から何時までが担当か決まっていないと、2人とも浅い眠りになる

交代制で大事なのは、<strong>当番は確実に気づき、非番は確実に聞こえない</strong>状態を分けて作ることです。

## まず決めること｜当番の時間と、非番の寝る場所

防音の道具を買う前に、時間と場所を決めます。

| 決めること | 例 | ポイント |
| :--- | :--- | :--- |
| 当番の時間 | 21時〜2時はAさん、2時〜7時はBさん | まとまった4〜5時間の睡眠を、それぞれに確保する |
| 非番の寝る場所 | 赤ちゃんから一番遠い部屋 | 間に部屋や廊下を挟むほど、泣き声は小さくなる |
| 当番の気づき方 | 赤ちゃんの近くで寝る、ベビーモニターを使う | 非番を静かにする分、当番の聞こえ方は確実にする |
| 交代の合図 | 時間になったら起こす、スマホのアラーム | 非番が耳栓をしていても起きられる方法にする |

### 非番の寝る場所の選び方

非番の寝室は、音の通り道が長い部屋を選びます。

- <strong>赤ちゃんのいる部屋と壁1枚で接していない</strong> : 間にクローゼットや廊下がある部屋がよい
- <strong>ドアを2枚以上はさめる</strong> : 寝室のドアと廊下のドアの両方を閉められると、聞こえ方がかなり変わる
- <strong>戸建てなら別の階</strong> : 1階と2階に分かれると、ドア越しより聞こえにくくなる
- <strong>ベッドを共有の壁から離す</strong> : 同じ部屋の中でも、赤ちゃん側の壁から遠い位置に寝る

部屋を入れ替えるだけなら0円で、この段階で効果を感じる家庭も少なくありません。

## 0円〜5千円でできること｜隙間と耳栓とマスキング

部屋が決まったら、一番安くて効く順に手を入れます。

泣き声は、壁よりも<strong>ドアの下や周りの隙間</strong>から多く入ってきます。

| 対策 | 費用の目安 | 効果 |
| :--- | :--- | :--- |
| ドアを閉め切る・廊下のドアも閉める | 0円 | 通り道が長くなり、泣き声が弱まる |
| ドアの周りに隙間テープを貼る | 数百円〜2,000円程度 | 隙間から入る高い音を減らす |
| ドア下にすき間ふさぎ（ドラフトストッパー）を置く | 1,000〜3,000円程度 | ドア下からの漏れを減らす |
| フォーム耳栓 | 数百円〜1,000円程度 | 耳に届く音を全体に下げる |
| 扇風機・ホワイトノイズの環境音 | 0円〜3,000円程度 | 残った泣き声を一定の音で目立たなくする |

隙間テープは、ドア枠の当たり面に貼ると、閉めたときに隙間がつぶれてふさがります。

賃貸では、はがせるタイプを選び、ドアの開け閉めが重くなりすぎない厚さにしてください。

### 耳栓と環境音の組み合わせ方

耳栓だけでは、泣き声の高い音がうっすら残ることがあります。

そこで、扇風機やホワイトノイズのような<strong>一定の音を小さく流して、残った泣き声を目立たなくする</strong>のがマスキングです。

- <strong>音量は小さめに</strong> : 寝ている人の耳元で、会話より明らかに小さい音にとどめる
- <strong>音源は非番の人の近くに置く</strong> : 赤ちゃんの部屋には流さない
- <strong>警報が聞こえるか確かめる</strong> : 火災警報器やスマホのアラームが聞こえる状態を保つ

## 1〜3万円でできること｜寝室の入口を固める

0円〜5千円の対策で足りないときは、寝室の入口と、赤ちゃん側の壁に手を入れます。

| 対策 | 費用の目安 | 向いている家 |
| :--- | :--- | :--- |
| ドアに貼る遮音シート＋吸音材 | 1〜2万円程度 | 室内ドアが軽く、ドア越しの声がよく聞こえる |
| 赤ちゃん側の壁に家具・本棚を寄せる | 0円〜（手持ちの家具） | 壁1枚で接している部屋しかない |
| 窓の内側に吸音カーテン・防音カーテン | 1〜3万円程度 | 外の音（車・早朝の物音）でも起きてしまう |

軽い室内ドアは、壁よりも音を通しやすい部分です。

ドアに重さを足し、隙間をふさぐと、寝室全体の中で一番弱い所が補強されます。

吸音パネルを壁に貼るだけでは、部屋の響きは減っても、隣から入ってくる泣き声はほとんど変わりません。

遮音と吸音の役割の違いは、[吸音材か遮音材か迷う人へ｜あなたの環境で“必要なのはどっち？”徹底ガイド](/ja/knowledge/absorption-vs-soundproofing-materials/)で確認できます。

賃貸で壁を傷つけずにできる方法は、[賃貸の防音対策は壁を傷つけずにできる？原状回復を守る5つの方法【実家・親バレ対策も】](/ja/diy/renter-parent-house-soundproofing/)にまとめています。

## 当番の安全を守るルール

非番の静けさを優先するほど、当番が一人で対応する時間の安全が大事になります。

- <strong>当番は必ず聞こえる場所にいる</strong> : 当番が耳栓や環境音を使わない
- <strong>当番が体調を崩したときの起こし方を決める</strong> : ノック、スマホの通話など、耳栓をしていても気づける方法にする
- <strong>非番も警報が聞こえる状態にする</strong> : 火災警報器・地震の通知が聞こえない寝室にはしない
- <strong>授乳など交代できない時間は無理に分けない</strong> : 母乳の時期は、当番の時間を短くするなど夫婦で調整する

防音室の中で赤ちゃんの声や警報に気づくための仕組みは、[防音室でインターホンが聞こえない時の対策｜赤ちゃんや警報に気づく仕組み](/ja/soundproof-room/notice-outside-sounds-in-booth/)で解説しています。

## 夜泣きが終わったあとも「一人になれる場所」として使う

非番の寝室として整えた部屋は、夜泣きの時期が終わったあとも役に立ちます。

子育て中は、昼も夜も一人になれる時間がほとんどありません。

隙間をふさぎ、ドアを固めた部屋は、そのまま次の使い方に切り替えられます。

- <strong>昼寝・仮眠の部屋</strong> : 休日に交代で1時間ずつ眠る
- <strong>在宅ワークの部屋</strong> : 子供の声が入りにくい部屋で、Web会議をする
- <strong>趣味の部屋</strong> : 子供が寝たあとの1時間を、自分の時間にする

家族には、「少し眠れると、機嫌よく育児に戻れる」と、家族全体のための場所として伝えると理解を得やすくなります。

部屋がない、もっと本格的に静かな場所がほしい場合の選択肢は、[自宅に防音室がなくても「一人になれる空間」を作る4つの方法｜40〜60代の予算別ガイド](/ja/money/quiet-space-budget-decision-guide/)で予算別に比べています。

子供の足音や声が下の階や隣に響く悩みまで含めて対策したい場合は、[【子育て×防音リノベ】マンションの騒音トラブルを「構造」から解決する完全ガイド](/ja/soundproof-rental/child-rearing-soundproof-pillar/)を参考にしてください。

## まとめ｜交代制は「聞こえる人」と「聞こえない人」を分ける

- <strong>先に決める</strong> : 当番の時間と、赤ちゃんから一番遠い非番の寝室
- <strong>0円〜5千円</strong> : ドアを閉め切る、隙間テープ、耳栓、環境音
- <strong>1〜3万円</strong> : 寝室のドアに重さを足し、赤ちゃん側の壁に家具を寄せる
- <strong>安全</strong> : 当番は必ず聞こえる場所に。非番も警報が聞こえる状態を保つ

夜泣きの時期は、いつか終わります。

それまでの間、2人が交代で確実に眠れる場所を、家の中に1つ作ってみてください。
