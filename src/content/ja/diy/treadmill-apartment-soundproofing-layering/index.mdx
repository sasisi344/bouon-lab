家族がランニングマシンを買った、自分で買ったけれど階下が気になる——そんなとき、まず心配になるのが「ドスンドスン」という振動の苦情ではないでしょうか。

結論から言うと、<strong>階下に響くのはモーター音ではなく、着地の衝撃が床を揺らす振動です</strong>。
そのため、静音設計の機種を選んでも、階下への影響は大きく変わらないことがあります。

対策の基本は、<strong>柔らかい層と重い層を重ね、置き場所と使い方も合わせて見直す</strong>ことです。
ただし、重ね敷きで振動を完全に消すことはできません。限界も含めて整理します。

## 階下に響くのは音ではなく「床を伝わる振動」

階下に聞こえているのは、機械の音ではありません。
走るときの<strong>着地の衝撃が床や梁を揺らし、天井から音として放射される</strong>ものです。

これは固体伝搬音（重量床衝撃音）と呼ばれ、空気を伝わる普通の音とは性質が異なります。
走行時の着地の衝撃は、体重のおおむね2〜3倍にもなると言われています。

薄いヨガマットやジョイントマット1枚では、この衝撃を受け止めきれません。
衝撃が薄い層を突き抜けて床に当たるため、振動は階下に伝わり続けます。

なぜジョイントマットでは防げないのか、その仕組みは[なぜジョイントマットでは防げないのか？「重量床衝撃音」を遮蔽するプロの防音構造の正体](/ja/knowledge/vibration-reduction-science/)で詳しく解説しています。

## 対策の基本は「柔らかい層」と「重い層」を重ねること

効果を出すには、役割の違う素材を組み合わせます。

- <strong>柔らかい層</strong> : 着地の衝撃をやわらげるクッション役
- <strong>重い層</strong> : 床が揺れるのを抑える重石役

高価な専用マットを1枚買うより、手頃な素材を重ねるほうが効果的なケースもあります。
なぜ「ふわふわ」だけでは振動が止まらないのか、重ね敷きの考え方の違いは[北米の80%ラグルールが失敗する理由｜日本の積層物理学で振動を止める](/ja/knowledge/why-your-80-percent-rug-rule-fails/)で解説しています。

## 予算と使い方で選ぶ、重ね敷きセット

使い方に合わせて、3つの組み合わせから選べます。

| セット | 構成 | 予算の目安 | 向いている使い方 |
| :-- | :-- | :-- | :-- |
| 梅（まずここから） | 洗濯機用の防振ゴム＋厚手カーペット | 3,000〜6,000円 | ウォーキング中心、昼間のみ |
| 竹（標準） | 高密度ゴムマット（厚さ1cm以上）＋トレーニングマット（厚さ2cm以上） | 8,000〜15,000円 | ジョギング程度の速度で使う |
| 松（しっかり） | コンパネ＋ゴムマット＋トレーニングマット | 1万5,000円〜 | 賃貸で床の凹みも防ぎたい、頻繁に使う |

価格は一般的なホームセンター・通販での目安です。
効果の大きさは、マシンの重さ、走る速度、建物の床構造によって大きく変わります。

### 梅：洗濯機用ゴム＋厚手カーペット

最も手軽で、すぐに試せる組み合わせです。

1. カーペットを床に敷く
2. その上に洗濯機用の防振ゴム4つを、マシンの脚の位置に置く
3. マシンを設置する

洗濯機用の防振ゴムは、マシン本体が床を揺らす振動を和らげます。
本格的に走る使い方では、これだけでは不十分です。

### 竹：ゴムマット＋トレーニングマット

もう少ししっかり対策したい方向けの組み合わせです。

1. 一番下に高密度のゴムマット（重い層）を敷く
2. その上にトレーニングマット（柔らかい層）を重ねる
3. マシンを設置する

選ぶときのポイントは次のとおりです。

- <strong>ゴムマット</strong> : 「高密度」と書かれた、重みのあるものを選ぶ
- <strong>トレーニングマット</strong> : EVA素材など、クッション性のあるものを選ぶ
- <strong>サイズ</strong> : マシンより一回り大きいものを選ぶ

### 松：コンパネを下に敷く

重いマシン（30〜50kg以上）は、畳やフローリングを凹ませることがあります。
ホームセンターで売っているコンパネ（合板）を一番下に敷くと、荷重を面で受けられます。

設置の順番は、下から次のとおりです。

1. コンパネ（木の板）
2. ゴムマットまたは防振ゴム
3. トレーニングマット
4. マシン

床の凹みを防げるうえ、賃貸でも原状回復がしやすい構成です。

### 安全面の注意点

柔らかい層を厚く重ねると、マシンが不安定になり、転倒やベルトのずれにつながるおそれがあります。

- 設置前にマシンの取扱説明書を読み、推奨される敷物の有無を確認する
- 設置後に、水平が取れているか、揺れがないかを必ず確認する
- 不安な場合はメーカーに問い合わせる

マシンの保証や安全に関わるため、重ね敷きは自己責任で慎重に行ってください。

## 置き場所の工夫でも、響き方は変わる

素材の重ね敷きだけでなく、「どこに置くか」も効果に影響します。

- <strong>壁から拳ひとつ分離す</strong> : 壁に密着させると、壁を伝って隣室へ響きやすくなります
- <strong>窓から30cm以上離す</strong> : 窓や壁からの反響を抑えます
- <strong>部屋の隅や梁の近くに置く</strong> : 床がたわみにくい場所を選びます

床の中央は、たわみが大きくなりやすい場所です。
上階や下階の間取り、梁の位置は建物ごとに異なるため、可能であれば管理会社に確認してください。

## 走り方と時間帯でも、階下への響きは減らせる

道具だけでなく、使い方の工夫も効果があります。

### かかと着地を減らす

「ドスン」という大きな音の原因は、かかとから強く着地する走り方です。
つま先寄り（足の中ほど）で着地するよう意識すると、着地の衝撃が小さくなります。

マシンの傾斜を2〜3%に上げると、自然と着地位置が前になりやすくなります。

### 夜はウォーキングに切り替える

夜は周囲が静かで、同じ振動でも響きやすくなります。
家族で使う場合は、「20時以降はウォーキングにする」といったルールを決めておくと、トラブルを防ぎやすくなります。

- ウォーキングは着地の衝撃が小さく、振動も小さい
- 傾斜をつければ、歩きでも運動量を確保しやすい
- 夜遅い運動は睡眠に影響するため、健康面でも合理的

## 対策の限界：どうしても響く場合に

重ね敷きや置き方の工夫でも、次のような状況では限界があります。

| 状況 | 起こりやすいこと | 次の選択肢 |
| :-- | :-- | :-- |
| 木造・軽量鉄骨造のアパート | 床が軽く、振動が広く伝わる | ウォーキング中心にする、屋外・ジムで走る |
| 階下に人が在宅している時間帯 | 小さな振動でも気づかれやすい | 使用時間帯を昼間に限定する |
| すでに苦情が来ている | 感情的な対立に発展しやすい | 管理会社を通じて、対策内容を伝える |

苦情への対応は、[騒音クレームを直接言うのは危険？マンションの騒音トラブルを解決する『3フェーズ式』対策マニュアル](/ja/soundproof-rental/noise-complaint-landlord-negotiation-guide/)のような、段階的な進め方が参考になります。

「対策している」という姿勢を示しておくと、万が一音が気になったときも、階下の方に理解してもらいやすくなります。

## ダンス・フィットネス配信、フィットネスゲームの足音も同じ対策が有効

ランニングマシンがなくても、ダンスやフィットネスの配信、リングフィットアドベンチャーなどで足踏みやジャンプをすると、階下が気になることがあります。
「ジョイントマットを敷いているのに、階下から足音を指摘された」という声も少なくありません。

原因は、ランニングマシンと同じ重量床衝撃音です。

| 種類 | 主な原因 | マットの効果 |
| :-- | :-- | :-- |
| 軽量床衝撃音 | 物を落とす・椅子を引くなど、軽くて硬い衝撃 | ジョイントマットやカーペットで軽減しやすい |
| 重量床衝撃音 | 走る・飛び跳ねるなど、低い周波数を含む大きな衝撃 | 表面のマットだけでは、ほとんど軽減できない |

重量床衝撃音は、床のスラブそのものがたわむことで発生します。表面に数センチのマットを敷いても、たわみは抑えられません。
「マットを敷いているから大丈夫」という安心感が、対策不足のまま続ける原因になります。仕組みは[階下から足音の苦情が来たら？ジョイントマットで防げない理由と正しい対策](/ja/knowledge/vibration-reduction-science/)で解説しています。

### 重ね敷きで、衝撃をやわらげる

ランニングマシンほどの重量物ではないため、次の2層でも一定の効果が見込めます。

- <strong>下</strong> : 防振ゴムマット（厚さ1cm以上の高密度タイプ）
- <strong>上</strong> : ヨガマットまたは厚手のジョイントマット（クッション性重視）

ポイントは、次のとおりです。

- <strong>動く範囲全体に敷く</strong> : 一部だけだと、動きがマットの外に出た瞬間に対策が無効になる
- <strong>過度な期待をしない</strong> : 重量床衝撃音を、マットだけで完全に遮るのは構造的に難しい

### 動き方と時間帯を工夫する

- <strong>つま先重心を意識する</strong> : かかとから着地するより、着地音がやわらぐ
- <strong>クッション性のある室内シューズを履く</strong> : 靴下や素足より、足裏への衝撃を分散できる
- <strong>強く踏み込む動きを把握する</strong> : 振り付けの中で衝撃が大きい動作を知っておき、その部分だけ動きを小さくする
- <strong>連続したジャンプを避ける</strong> : 休憩を挟んで動作を分散させる
- <strong>近隣の在宅時間を避ける</strong> : 早朝・深夜は避け、日中を中心にスケジュールする
- <strong>夜はジャンプ・足踏み系を避ける</strong> : 上半身中心のメニューに切り替える

### 部屋を変えるという選択

対策を一通り試しても不安が残る場合は、物件そのものの見直しが選択肢になります。

- <strong>1階の部屋</strong> : 階下に住戸がないため、重量床衝撃音の影響を大きく減らせる
- <strong>最上階の部屋</strong> : 上階がないので、上からの足音に悩まされにくい。ただし、自分の足音が階下へ響く点は変わらないため、階下への対策の代わりにはならない
- <strong>二重床・防振構造を採用した物件</strong> : 表面のマットに頼らずに活動しやすい

内見時に確認する項目は、[配信者向け賃貸の選び方｜静かに配信できる部屋の探し方と内見チェックリスト](/ja/creator/streamer-rental-selection-guide/)にまとめています。

ゲーム配信の「台パン」のように、机・椅子側の衝撃を吸収する方法は、[台パンの衝撃吸収・防振対策｜下の階に響く仕組みと2,000円で防ぐ方法](/ja/creator/gaming-floor-impact-noise-fix/)で解説しています。

## まとめ：重ね敷き・置き場所・使い方の3点セットで見直す

ランニングマシンの階下対策は、1つの方法に頼らず、組み合わせて進めるのが基本です。

今日からできることは、次の4つです。

1. 洗濯機用の防振ゴムと厚手のカーペットを試す（梅セット）
2. 壁から離し、部屋の隅に置き直す
3. かかと着地を減らし、傾斜を2〜3%にする
4. 夜はウォーキングに切り替える

それでも響く場合は、使用時間帯を限定する、屋外やジムで走るなど、環境を変える選択肢も検討してください。

床の構造や管理規約によって、必要な対策は変わります。
苦情が続く場合や不安が大きい場合は、管理会社や専門業者に相談しましょう。
