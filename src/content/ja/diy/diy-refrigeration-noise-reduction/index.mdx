冷蔵庫の「ブーン」という振動音は、<strong>まず水平と、壁や周りの物との接触を直し、それでも床に響くなら防振マットを足す</strong>順番で減らします。

コンプレッサーの振動は脚から床へ伝わり、隣の部屋や下の階、在宅ワークのマイクにまで届くことがあります。

この記事では、冷蔵庫の振動音の原因の見分け方から、防振マットの選び方、換気扇の音の対策まで、効く順に解説します。

## 冷蔵庫の振動音の原因｜3つに分けて確かめる

冷蔵庫の音は、原因によって対策が変わります。

| 原因 | よくある症状 | 最初の対策 |
| :--- | :--- | :--- |
| 水平の狂い・脚の浮き | 運転が始まると「ガタガタ」「ブーン」と大きくなる | 調整脚で前の脚をしっかり床に付ける |
| 壁・棚・周りの物との接触 | 「ビリビリ」「カタカタ」という共鳴音 | 壁や棚から離す。上に置いた物をどける |
| 床への振動の伝わり | 離れた部屋や下の階で「ブーン」と低く響く | 防振マット・防振ゴムを脚の下に入れる |

買ったばかりのときや、食品をたくさん入れた直後は、冷やすためにコンプレッサーが強く回り、音が大きくなるのは正常とされています。

数日たっても大きいままなら、上の表の順に確かめてください。

## 調整脚で水平をとる

冷蔵庫の前の下側には、高さを変えられる調整脚があります。

この脚が床から浮いていると、コンプレッサーが動いたときに本体が揺れ、床とぶつかって音が出ます。

- <strong>前の脚を床に付ける</strong> : 回して下げ、床にしっかり当たるようにする
- <strong>少し後ろに傾ける</strong> : 扉が自然に閉まる程度にする。取扱説明書の指示に従う
- <strong>本体を押して確かめる</strong> : 角を押してガタつかなければよい

## 壁や周りの物から離す

冷蔵庫の側面や背面が壁や棚に触れていると、振動がそこへ移って「ビリビリ」と鳴ります。

壁との隙間は、放熱のためにも必要です。

隙間が足りないと熱がこもり、コンプレッサーの運転時間が長くなって、音が出る時間も増えます。

必要な隙間はメーカーと機種で違うため、取扱説明書で確かめてください。

海外メーカーの例では、側面と背面に5cm以上、上に2.5cm以上を求めているものがあります。

冷蔵庫の上に電子レンジや物を置いている場合は、それが共鳴していないかも確かめます。

## 防振マット・防振ゴムの選び方

水平と隙間を直しても、離れた部屋や下の階で低い音が響くなら、床へ伝わる振動の問題です。

脚の下に防振材を入れて、床へ渡る振動を減らします。

| 種類 | 向いている場合 | 注意点 |
| :--- | :--- | :--- |
| 防振ゴム（脚ごとに置くタイプ） | 床に響く低い振動を減らしたい | 冷蔵庫の重さに合う耐荷重のものを選ぶ |
| 防振マット（本体の下に敷くタイプ） | 脚ごとに置けない、床の傷も防ぎたい | 薄い傷防止マットには防振の効果はほとんどない |
| 硬い板＋防振ゴム | 床がたわみやすい木造の2階など | 板で重さを広げてから、防振ゴムを入れる |

選ぶときに一番大事なのは、<strong>冷蔵庫の重さに合っているか</strong>です。

冷蔵庫は、中身を入れると数十kgから100kg前後になります。

柔らかすぎる防振材は、重さでつぶれきって効かなくなり、硬すぎると振動をそのまま通します。

製品の耐荷重を、冷蔵庫の重さ（中身を含む）を脚の数で割った値と比べてください。

防振材を入れると、本体が少し高くなり、傾きや揺れが出ることがあります。

入れた後は、もう一度水平を確かめ、地震に備えて転倒防止も見直してください。

防振材の硬さと重さの組み合わせで、かえって揺れが増える仕組みは、[低周波・振動対策の基礎｜防振床・浮き床構造の仕組みと選び方](/ja/knowledge/vibration-isolation-technology-trend/)で解説しています。

## 寝室・隣の部屋・下の階に響かせない置き方

冷蔵庫の場所を変えられるなら、置き方でも響き方は変わります。

- <strong>寝室と接する壁に付けない</strong> : 壁の向こうが寝室なら、別の壁に移すか、壁から十分離す
- <strong>床の真ん中より壁際・柱の近く</strong> : 床の真ん中はたわみやすく、振動が大きくなりやすい
- <strong>木造の2階は板で重さを広げる</strong> : 床の一点に重さが集中しないようにする

夜に冷蔵庫の音や上の階の音で眠れない場合の、音の種類別の対策は、[上の階の足音・隣の話し声で眠れない｜音の種類で変わる寝室の騒音対策の選び方](/ja/soundproof-rental/bedroom-noise-type-solution-guide/)で整理しています。

## 在宅ワーク・配信のマイクに入れない

冷蔵庫の唸りは、Web会議や配信のマイクにも入ります。

床を伝った振動がマイクスタンドや机から入ることもあるため、空気と振動の両方で対策します。

- <strong>マイクの背中側に冷蔵庫を置く</strong> : 単一指向性のマイクは、背中側の音を拾いにくい
- <strong>マイクを口元に近づけ、入力の音量を下げる</strong> : 声に対して冷蔵庫の音が相対的に小さくなる
- <strong>マイクスタンドの足元を防振する</strong> : 床からスタンドへ渡る振動を減らす
- <strong>ノイズ除去ソフトは最後に使う</strong> : 背景の音が大きいほど強くかける必要があり、声までこもりやすくなる

録音や配信で部屋をどこまで静かにすべきかの目安は、[暗騒音の目安はNC値で決める｜ASMR・歌枠・ゲーム実況の録音に必要な静けさ](/ja/knowledge/report-japan-asmr-vtuber-streaming-studio-standard/)で解説しています。

## 換気扇の音の対策

換気扇の音は、振動ではなく、羽根が空気を押し出すときの<strong>気流の音</strong>が中心です。

- <strong>距離をとる</strong> : 音は音源からの距離が2倍になるごとに約6dB下がるため、離すだけでも効く
- <strong>吹き出し口の正面を避ける</strong> : 気流がマイクや寝る位置に直接当たらないようにする
- <strong>羽根とフィルターを掃除する</strong> : 汚れで回転のバランスが崩れると、音や振動が増える
- <strong>異音が続くなら交換を検討する</strong> : 軸の摩耗による「キーン」「カラカラ」は、掃除では直らない

## それでも音が大きいときは

水平・隙間・防振を試しても音が変わらない、または以前より明らかに大きくなった場合は、故障の可能性があります。

「ガガガ」という金属音や、運転が止まらない状態が続くときは、メーカーのサポートに相談してください。

## まとめ｜冷蔵庫の振動音は「水平→隙間→防振」の順で

- <strong>水平</strong> : 調整脚で前の脚を床に付け、ガタつきをなくす
- <strong>隙間</strong> : 壁・棚・上の物との接触をなくし、放熱の隙間をとる
- <strong>防振</strong> : 床に響くなら、冷蔵庫の重さに合う防振ゴム・防振マットを脚の下に入れる
- <strong>置き方</strong> : 寝室と接する壁を避け、木造の2階は板で重さを広げる
