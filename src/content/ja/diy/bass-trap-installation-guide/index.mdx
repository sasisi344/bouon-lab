防音室を作ったのに「低音がこもる」「ベースが濁る」「ミックスがうまく決まらない」。

せっかく防音室まで用意したのに、また新しい機材が必要なのかとうんざりする気持ちもよく分かります。

この症状の犯人は、<strong>低音域（20〜200Hz）の定在波</strong>です。

通常の吸音パネルでは対処できず、専用の「ベーストラップ」が必要になります。

<strong>ベーストラップ</strong>とは、部屋の角に置いて低音のエネルギーを吸い取る、厚みのある吸音材のことです。

本記事では選び方・配置・自作（DIY）・測定まで一気通貫で解説します。

市販品を買わずに<strong>ベーストラップを自作</strong>したい方向けに、材料費3,000円台から作れる方法も詳しく紹介します。

防音室を調べていくと、外への音漏れとは別に、室内の「こもり」に悩む声が多いことに気づきます。

## なぜ低音は「コーナー」に溜まるのか

低音の波長は中高音より桁違いに長く、60Hzで約5.7m、100Hzで約3.4mあります。
この長い波が壁に反射し、進行波と反射波が重なって<strong>「定在波（部屋の特定周波数が異常に大きくなる現象）」</strong>を起こします。

定在波は部屋の角（コーナー）に特に集中します。
縦・横・高さの3方向の壁が交わるコーナーには3種類の定在波が同時に存在するため、エネルギーが凝縮されやすいのです。

そのため、<strong>ベーストラップはコーナーから設置する</strong>のが基本とされています。

## ベーストラップの種類と選び方

### ① コーナー設置型（推奨・最もコスパが良い）

三角柱や円柱形で、壁のコーナーに密着して置くタイプです。

- <strong>吸音帯域</strong>：50〜500Hz（製品による）
- <strong>費用目安</strong>：1個 15,000〜60,000円
- <strong>向いている用途</strong>：DTM・宅録・ポッドキャスト・ゲーム配信

コーナーに設置するだけで、壁面型の2〜3倍の吸音効果が得られます。
初めてベーストラップを導入するなら、私ならまずこのタイプから試します。

置くだけで済み、効果が薄ければ位置を変えて試し直せるからです。

### ② 壁面設置型（見た目重視・追加対策向け）

フラットなパネル型で、壁面に貼るように設置します。

- <strong>吸音帯域</strong>：100〜500Hz（深い低域は苦手）
- <strong>費用目安</strong>：1㎡あたり 10,000〜30,000円
- <strong>向いている用途</strong>：コーナー型の補完・部屋の見た目を整えたい場合

コーナー型では対処しきれない中域の反響を調整するのに有効です。

### ③ 共鳴器型（DIY上級者向け・特定周波数のピンポイント対策）

ヘルムホルツ共鳴器や板状共鳴器と呼ばれる構造で、特定の周波数だけを選択的に吸音します。

- <strong>費用目安</strong>：材料費 3,000〜15,000円
- <strong>注意点</strong>：寸法が吸音周波数を決めるため、計算と製作精度が必要

## ベーストラップを自作する（グラスウール充填型DIY）

市販品を買う前に、<strong>ベーストラップを自作</strong>して費用対効果の高さを試す方法です。

1個あたり材料費 3,000〜8,000円で、コーナー型相当の効果が得られます。

<strong>自作する場合も、密度と設置高さの2点を守れば市販品に近い吸音性能が出せます。</strong>

### 必要な材料（1個分）

| 材料 | 規格目安 | 費用目安 |
| :--- | :--- | :--- |
| <strong>グラスウール 32kg/m³</strong> | 50mm厚 × 600mm × 900mm | 1,500〜3,000円 |
| <strong>木材（角材）</strong> | 30×40mm 程度 | 500〜1,000円 |
| <strong>布（通気性のある素材）</strong> | 不織布またはサラシ | 300〜800円 |
| <strong>タッカー・ビス</strong> | — | 500円程度 |

### 製作手順

1. <strong>フレームを作る</strong>：木材を三角柱状（底辺200〜300mm×高さ1,000〜1,200mm）に組みます。コーナーに収まるサイズに合わせます。
2. <strong>グラスウールを詰める</strong>：フレーム内にグラスウールを隙間なく詰めます。グラスウールは必ずゴム手袋と防塵マスクを着用して扱います。
3. <strong>布で包む</strong>：通気性のある布（不織布・サラシ）で全体を包み、タッカーで固定します。
4. <strong>コーナーに設置する</strong>：床から天井まで高さをそろえて配置すると効果が高くなります。

<strong>グラスウールの密度は重要</strong>です。密度が低い（16kg/m³以下）製品は低音への効果が薄いため、<strong>32〜48kg/m³</strong>を選んでください。

## 配置の基本と部屋面積別の目安

### 基本原則：床・壁・天井コーナーを優先する

| 優先順位 | 設置場所 | 効果 |
| :--- | :--- | :--- |
| <strong>1位</strong> | 縦コーナー（壁と壁の角）床から天井まで | 定在波の根本対策 |
| <strong>2位</strong> | 天井コーナー（壁と天井の角） | 高さ方向の定在波対策 |
| <strong>3位</strong> | 壁面（スピーカー背面・リスニングポイント後方） | 反射・残響の調整 |

### 部屋面積別の必要個数目安

| 部屋の広さ | コーナー型（最低限） | 目標 |
| :--- | :--- | :--- |
| <strong>4畳以下</strong> | 4個（四隅） | 6〜8個 |
| <strong>4〜8畳</strong> | 4〜6個 | 8〜10個 |
| <strong>8〜12畳</strong> | 6〜8個 | 10〜12個 |
| <strong>12畳以上</strong> | 8個〜 | 12個以上 |

まず四隅に1本ずつ設置し、測定しながら追加するのが効率的です。

## 効果測定の方法（スマホの簡易確認からREWまで）

設置の効果は「聴感」だけに頼らず、測定で確認するのが確実です。

スマホだけでも設置前後の比較はできますが、低音の数値を正しく読むなら、PCの測定ソフトと測定マイクを使います。

### 測定手段の比較

| 手段 | 必要なもの | 分かること | 向いている人 |
| :--- | :--- | :--- | :--- |
| <strong>スマホアプリ</strong> | スマホ（Androidは「Spectroid」、iPhoneはApp Storeのスペクトラムアナライザー系アプリ） | どの帯域が盛り上がっているかの目安 | まず傾向を見たい人 |
| <strong>REW＋USB測定マイク</strong> | PC、REW（無料）、校正ファイル付きのUSB測定マイク | 周波数特性、低音の残り方（ウォーターフォール）、残響時間（RT60） | 配置を詰めたい人・宅録やミックスをする人 |
| <strong>REW＋XLR測定マイク</strong> | PC、REW、オーディオインターフェース、XLR接続の測定マイク | REW＋USBマイクと同じ | すでにオーディオインターフェースを持っている人 |

スマホの内蔵マイクは、低音域の感度が機種ごとに違い、校正もされていません。

数値そのものは信用せず、<strong>同じ位置・同じ音量での設置前後の比較</strong>にだけ使います。

### REWと測定マイクの選び方

<strong>Room EQ Wizard（REW）</strong>は、Windows・macOS・Linuxで動く無料の音響測定ソフトです。

テスト信号を再生してマイクで拾い、周波数特性・ウォーターフォール・残響時間（RT60）などを表示します。

マイクは、<strong>個体ごとの校正ファイルが付く測定用マイク</strong>を選びます。

例として、miniDSPのUMIK-1はUSBで直接PCにつながり、シリアル番号ごとの校正ファイルをREWに読み込んで使えます。

ボーカル用のマイクは低音の特性が平らではないため、測定には向きません。

### 測定の手順

1. <strong>設置前に基準測定</strong>：リスニングポジション（スピーカーと自分の中間点）にマイクを置き、REWのスイープ信号を再生して測定します。
2. <strong>ベーストラップ設置後に再測定</strong>：マイクの位置・高さ・音量を変えずに測定し、問題の帯域がどれだけ下がったかを見ます。
3. <strong>判断の目安</strong>：問題の周波数のピークが 5dB 程度以上下がれば、効果が出ていると見てよいでしょう。変化が小さい場合は、配置を変えて再測定します。

### REWで見る3つのグラフ

- <strong>周波数特性</strong> : 200Hz以下で、特定の周波数だけ突き出たピークや、深い谷がないかを見ます
- <strong>ウォーターフォール</strong> : 音を止めた後に、どの周波数がいつまで鳴り残るかを立体的に表示します。低音のこもりは「一部の周波数だけ尾を引く」形で見えます
- <strong>残響時間（RT60）</strong> : 音が60dB減衰するまでの時間です。低音域の値が設置前より短くなっていれば、低音の「ため込み」が減っています

## よくある失敗と対策

- <strong>「コーナーに設置したのに効果が薄い」</strong>：グラスウールの密度不足か、高さが足りないケースが多いです。床から天井まで連続して配置し直してください。
- <strong>「高音域まで吸収されすぎてデッドになった」</strong>：ベーストラップの数が多すぎる or 壁面全体に貼った場合に起きます。吸音パネルの面積を減らし、バランスを取ります。
- <strong>「特定の音程のみ改善されない」</strong>：その周波数に対応する共鳴器型を追加するか、スピーカーの位置・向きを調整します。

## よくある質問

### ベーストラップの効果を測るのに最適なツールは？

小さなスタジオで、残響の減衰やモード（定在波）の出方まで見たいなら、<strong>REWと校正済みの測定マイク</strong>の組み合わせが基本です。

モードの出方は周波数特性とウォーターフォール、減衰の速さは残響時間（RT60）で確認します。

### スマホだけで測定できる？

設置前後の比較なら可能です。

ただし、内蔵マイクは低音の感度が正確ではないため、「何dB下がったか」の絶対値は参考程度にとどめます。

### ベーストラップは何個から効果が出る？

まず部屋の四隅に1本ずつ置き、測定してから追加を判断します。

部屋の広さ別の目安は、上の「部屋面積別の必要個数目安」の表を参照してください。
