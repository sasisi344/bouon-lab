防音室を作ったのに「低音がこもる」「ベースが濁る」「ミックスがうまく決まらない」。
この症状の犯人は、<strong>低音域（20〜200Hz）の定在波</strong>です。
通常の吸音パネルでは対処できず、専用の「ベーストラップ」が必要になります。
本記事では選び方・配置・自作（DIY）・測定まで一気通貫で解説します。市販品を買わずに<strong>ベーストラップを自作</strong>したい方向けに、材料費3,000円台から作れる方法も詳しく紹介します。

## なぜ低音は「コーナー」に溜まるのか

低音の波長は中高音より桁違いに長く、60Hzで約5.7m、100Hzで約3.4mあります。
この長い波が壁に反射し、進行波と反射波が重なって<strong>「定在波（部屋の特定周波数が異常に大きくなる現象）」</strong>を起こします。

定在波は部屋の角（コーナー）に特に集中します。
縦・横・高さの3方向の壁が交わるコーナーには3種類の定在波が同時に存在するため、エネルギーが凝縮されやすいのです。

<strong>だからベーストラップはコーナーから設置する</strong>のが鉄則です。

## ベーストラップの種類と選び方

### ① コーナー設置型（推奨・最もコスパが良い）

三角柱や円柱形で、壁のコーナーに密着して置くタイプです。

- <strong>吸音帯域</strong>：50〜500Hz（製品による）
- <strong>費用目安</strong>：1個 15,000〜60,000円
- <strong>向いている用途</strong>：DTM・宅録・ポッドキャスト・ゲーム配信

コーナーに設置するだけで、壁面型の2〜3倍の吸音効果が得られます。
初めてベーストラップを導入するなら、まずこのタイプから試すのが正解です。

### ② 壁面設置型（見た目重視・追加対策向け）

フラットなパネル型で、壁面に貼るように設置します。

- <strong>吸音帯域</strong>：100〜500Hz（深い低域は苦手）
- <strong>費用目安</strong>：1㎡あたり 10,000〜30,000円
- <strong>向いている用途</strong>：コーナー型の補完・部屋の見た目を整えたい場合

コーナー型では対処しきれない中域の反響を調整するのに有効です。

### ③ 共鳴器型（DIY上級者向け・特定周波数のピンポイント対策）

ヘルムホルツ共鳴器や板状共鳴器と呼ばれる構造で、特定の周波数だけを選択的に吸音します。

- <strong>費用目安</strong>：材料費 3,000〜15,000円
- <strong>注意点</strong>：寸法が吸音周波数を決めるため、計算と製作精度が必要

## ベーストラップを自作する（グラスウール充填型DIY）

市販品を買う前に、<strong>ベーストラップを自作</strong>して費用対効果の高さを試す方法です。
1個あたり材料費 3,000〜8,000円で、コーナー型相当の効果が得られます。<strong>自作する場合も、密度と設置高さの2点を守れば市販品に近い吸音性能が出せます。</strong>

### 必要な材料（1個分）

| 材料 | 規格目安 | 費用目安 |
| :--- | :--- | :--- |
| <strong>グラスウール 32kg/m³</strong> | 50mm厚 × 600mm × 900mm | 1,500〜3,000円 |
| <strong>木材（角材）</strong> | 30×40mm 程度 | 500〜1,000円 |
| <strong>布（通気性のある素材）</strong> | 不織布またはサラシ | 300〜800円 |
| <strong>タッカー・ビス</strong> | — | 500円程度 |

### 製作手順

1. <strong>フレームを作る</strong>：木材を三角柱状（底辺200〜300mm×高さ1,000〜1,200mm）に組みます。コーナーに収まるサイズに合わせます。
2. <strong>グラスウールを詰める</strong>：フレーム内にグラスウールを隙間なく詰めます。グラスウールは必ずゴム手袋と防塵マスクを着用して扱います。
3. <strong>布で包む</strong>：通気性のある布（不織布・サラシ）で全体を包み、タッカーで固定します。
4. <strong>コーナーに設置する</strong>：床から天井まで高さをそろえて配置すると効果が高くなります。

<strong>グラスウールの密度は重要</strong>です。密度が低い（16kg/m³以下）製品は低音への効果が薄いため、<strong>32〜48kg/m³</strong>を選んでください。

## 配置の基本と部屋面積別の目安

### 基本原則：床・壁・天井コーナーを優先する

| 優先順位 | 設置場所 | 効果 |
| :--- | :--- | :--- |
| <strong>1位</strong> | 縦コーナー（壁と壁の角）床から天井まで | 定在波の根本対策 |
| <strong>2位</strong> | 天井コーナー（壁と天井の角） | 高さ方向の定在波対策 |
| <strong>3位</strong> | 壁面（スピーカー背面・リスニングポイント後方） | 反射・残響の調整 |

### 部屋面積別の必要個数目安

| 部屋の広さ | コーナー型（最低限） | 目標 |
| :--- | :--- | :--- |
| <strong>4畳以下</strong> | 4個（四隅） | 6〜8個 |
| <strong>4〜8畳</strong> | 4〜6個 | 8〜10個 |
| <strong>8〜12畳</strong> | 6〜8個 | 10〜12個 |
| <strong>12畳以上</strong> | 8個〜 | 12個以上 |

まず四隅に1本ずつ設置し、測定しながら追加するのが効率的です。

## 効果測定の方法（スマホ完結）

設置効果は「聴感」だけに頼らず、測定で確認するのが確実です。
スマホアプリと安価なマイクで測定できます。

### 推奨ツール

- <strong>Room EQ Wizard（REW）</strong>：Windows/Mac対応の無料音響測定ソフト。USB接続の測定マイク（1,500〜5,000円）と組み合わせて使います。
- <strong>Spectroid（iPhone/Android）</strong>：スマホアプリのリアルタイムスペクトラムアナライザー。簡易確認に使えます。

### 測定の手順

1. <strong>設置前に基準測定</strong>：リスニングポジション（スピーカーと自分の中間点）でスイープ信号を再生し、測定します。
2. <strong>ベーストラップ設置後に再測定</strong>：同条件で測定し、問題帯域の改善量を確認します。
3. <strong>判断基準</strong>：問題周波数で 5dB 以上の改善が出れば有効と判断します。改善が見られない場合は配置を変えて再測定します。

残響時間（RT60）が設置前後で短縮していれば、低音の「ため込み」が改善されています。

## よくある失敗と対策

- <strong>「コーナーに設置したのに効果が薄い」</strong>：グラスウールの密度不足か、高さが足りないケースが多いです。床から天井まで連続して配置し直してください。
- <strong>「高音域まで吸収されすぎてデッドになった」</strong>：ベーストラップの数が多すぎる or 壁面全体に貼った場合に起きます。吸音パネルの面積を減らし、バランスを取ります。
- <strong>「特定の音程のみ改善されない」</strong>：その周波数に対応する共鳴器型を追加するか、スピーカーの位置・向きを調整します。
