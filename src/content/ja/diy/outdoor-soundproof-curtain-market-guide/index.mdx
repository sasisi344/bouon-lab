屋外用防音カーテンは、工事現場で<strong>音を出す場所を囲い、周りに届く音を減らす</strong>ための防音シートです。

実測では、囲いの外で10〜15dBほど音が下がった例があり、通販で個人も買えるため、ガレージ作業の囲いや室内の間仕切りにも使えます。

ただし重さは1m²あたり1.5kgほどと軽く、家の壁や窓の代わりに音漏れを止めるものではありません。

この記事では、工事用防音シートの効果と限界を数字で確かめたうえで、家庭での使い方を紹介します。

## 屋外用防音カーテン（防音シート）とは

足場や解体現場の周りを覆っている、灰色や白の厚手のシートが屋外用防音カーテンです。

業界では「防音シート」と呼ばれることが多く、工事関係者には身近な資材です。

| 項目 | 一般的な仕様の例 |
| :--- | :--- |
| 素材 | 塩化ビニール、またはポリオレフィンの膜に、補強の布を重ねたもの |
| 大きさ | 幅1.8m・1.5m・1.2m・0.9m・0.6m × 高さ3.4mなど |
| 重さ | 1.8m×3.4mで約9kg（軽量品で約5.8kg） |
| 取り付け | 周りのハトメ（金属や樹脂の穴）に、結束ひもを通して足場に固定 |

重さの例は、日建リース工業の軽量防音シートの紹介で示された従来品と軽量品の値です。

1.8m×3.4mで9kgなら、1m²あたり約1.5kgになります。

## 屋外用防音カーテンの効果｜囲うとどのくらい下がるか

防音シートの効果を、実際の現場で測った報告があります。

大阪の都心部で、ボーリング調査の作業場を天井まで防音シートで囲い、騒音を約30日間測った例です。

| 測った場所 | 騒音レベル | 読み取れること |
| :--- | :--- | :--- |
| 囲いの中、エンジンの横 | 約87〜93dB（金属音の時は約95dB） | 音源そのものの大きさ |
| 囲いの外、閉じた面から3.5m | 約71〜75dB（金属音の時は77〜79dB） | <strong>中と外で10〜15dBほどの差</strong> |
| 囲いの外、出入口の前 | 約74〜76dB | 開いている所では効果が落ちる |
| 囲いから7m以上 | 約65〜70dB | 周りの街の音と同じくらいまで下がる |

出典: 小川貴好ほか「ボーリング時の防音シートを用いた騒音対策効果と新たな課題への解決策」全地連 技術フォーラム2023

この結果から、家庭で使うときにも大事な点が3つわかります。

- <strong>囲うと効く</strong> : 音源を四方と上から囲えば、10dB以上下がることがある
- <strong>開いている所から漏れる</strong> : 出入口の前では、閉じた面より効果が小さい
- <strong>中は暑く、暗くなる</strong> : 同じ報告では、換気と照明の確保が課題に挙がっている

## 重さで見る限界｜家の壁や窓の代わりにはならない

音を跳ね返す力（遮音）は、素材の重さでおおよそ決まります。

| 素材 | 1m²あたりの重さの目安 |
| :--- | :--- |
| 工事用防音シート | 約1〜1.5kg |
| 石膏ボード（厚さ12.5mm） | 約8〜9kg |

防音シートは、石膏ボード1枚の数分の1の重さしかありません。

そのため、<strong>部屋の壁に貼っても、隣への音漏れはほとんど変わりません。</strong>

防音シートが効くのは、軽さを「囲う」ことで補える使い方、つまり音を出す物のすぐ近くを覆うときです。

遮音と吸音の違いから確かめたい場合は、[吸音材か遮音材か迷う人へ｜あなたの環境で“必要なのはどっち？”徹底ガイド](/ja/knowledge/absorption-vs-soundproofing-materials/)を参考にしてください。

## 家庭での使い道｜向いていること・向いていないこと

工事用の防音シートは、通販や資材店で1枚から買えます。

家庭で使うなら、次のように向き不向きがあります。

| 使い方 | 向き不向き | 理由 |
| :--- | :--- | :--- |
| ガレージ・庭での電動工具や木工作業を囲う | <strong>向いている</strong> | 音源の近くを囲う、本来の使い方に近い |
| 室内の間仕切り（パーティション） | 向いている | 視線を切り、話し声や物音を少し和らげる |
| 作業部屋の一角を区切る | 向いている | 音より「区切られた場所」を作る効果が大きい |
| エアコンの室外機・給湯器を囲う | <strong>向いていない</strong> | 排気や放熱がこもり、故障や事故の原因になる |
| マンションのベランダや窓の外に張る | 向いていない | 管理規約・強風での落下・避難経路の問題がある |
| 隣の部屋との壁に貼って音漏れを止める | 向いていない | 重さが足りず、効果がほとんど出ない |

### 室内の間仕切りとして使う

防音シートは、部屋を区切るカーテンとしても使えます。

市販の防音カーテンより大きく、天井近くから床まで1枚で覆えるのが利点です。

- <strong>できること</strong> : 視線を切る、テレビや話し声の響きを少し和らげる、作業スペースを区切る
- <strong>できないこと</strong> : 隣の部屋への音漏れを止める、上下の隙間から回り込む音を防ぐ

在宅ワークの場所づくりや、夜泣きの交代で別々に眠るための部屋の区切り方は、[夜泣きの交代制で眠れない？非番の人が寝る部屋を1万円台から静かにする方法](/ja/diy/parenting-generation-quiet-corner-diy/)で紹介しています。

## 防音シートで間仕切りを作る手順

賃貸でも壁に穴を開けずに作れる方法です。

1. <strong>突っ張りポールを2本立てる</strong> : 天井と床で突っ張るタイプを、区切りたい幅の両端に立てる
2. <strong>横に棒を渡す</strong> : 2本のポールの上部に、シートを吊るす横棒を固定する
3. <strong>ハトメで吊るす</strong> : シートのハトメに結束バンドやS字フックを通して、横棒に掛ける
4. <strong>床まで垂らす</strong> : 下に隙間があると音が回り込むので、床に少し付く長さにする
5. <strong>端を重ねる</strong> : 2枚使うときは、継ぎ目を10cm以上重ねて隙間をなくす

1枚で約9kgあるため、突っ張りポールと横棒の<strong>耐荷重</strong>を必ず確かめてください。

軽量品（同じ大きさで約5.8kg）を選ぶと、室内では扱いやすくなります。

## 買う前に確認すること

| 確認すること | 理由 |
| :--- | :--- |
| 防炎の表示 | 室内で使うなら、燃えにくい防炎品を選ぶ |
| 大きさと重さ | 吊るす棒やポールの耐荷重に収まるか |
| 色 | 灰色は暗く、白は光を通して明るい |
| においと素材 | 塩化ビニール製は、開封直後ににおいが出ることがある |
| ハトメの間隔 | 吊るすときの留め具の数と、たわみ方が変わる |
| 屋外での固定方法 | 風を受けると大きな力がかかる。強風時は外す |

防音を「音漏れを止めたい」という目的で考えている場合は、防音シートより、隙間対策と重さのある遮音材の組み合わせを先に検討してください。

DIYで遮音と吸音を組み合わせるときの失敗例と立て直し方は、[防音パネルの罠｜DIY失敗例から学ぶ『遮音と吸音』の物理学的黄金比](/ja/diy/diy-soundproof-room-failures-solutions/)にまとめています。

## 工事・設備で選ぶときのポイント

現場の騒音対策として選ぶ場合は、シート単体の数値より、囲い方と運用で効果が決まります。

- <strong>開口部を減らす</strong> : 出入口や継ぎ目から音が漏れる。重ねしろと裾の処理を決めておく
- <strong>上も覆う</strong> : 高い建物が近い現場では、上に抜ける音が問題になる
- <strong>暑さと換気を計画する</strong> : 全面を囲うと中が高温多湿になり、作業者の負担が増える
- <strong>防炎・耐候の書類をそろえる</strong> : 防炎ラベルや試験成績書を、発注の条件に入れる
- <strong>測る場所を決めておく</strong> : 設置前後に同じ場所・同じ時間帯で測り、効果を確かめる

## よくある質問

### 屋外用防音カーテンは、個人でも買えますか？

買えます。

工事用の防音シートは、通販や資材店で1枚から販売されています。

### 防音シートを部屋の壁に貼れば、防音室になりますか？

なりません。

1m²あたり1.5kgほどと軽く、壁に貼っても隣への音漏れはほとんど減りません。

確実に音を閉じ込めたい場合は、遮音性能が公表されている組み立て式の防音室を比べてください。

格安の防音室の選び方と、夏の暑さの注意点は、[格安防音室は夏に地獄化する？だんぼっち・OTODASU排熱リスクと中古購入の注意点](/ja/soundproof-room/budget-soundproof-booth-comparison/)で解説しています。

### 室内用の防音カーテンとは何が違いますか？

室内用の防音カーテンは、窓に掛けて外の音や響きを和らげるためのもので、見た目や開け閉めのしやすさも考えて作られています。

窓に使うカーテンの選び方と限界は、[HSP気質の方へ。生活音のストレスを劇的に減らす「防音（遮音）カーテン」の正しい選び方と限界](/ja/soundproof-room/hsp-soundproof-curtain-guide/)で解説しています。

## まとめ｜防音シートは「囲う」と効き、「貼る」だけでは効かない

- <strong>屋外用防音カーテン</strong> : 工事で音源を囲う防音シート。囲いの外で10〜15dB下がった実測例がある
- <strong>限界</strong> : 1m²あたり約1.5kgと軽く、壁や窓の代わりにはならない
- <strong>家庭での使い道</strong> : ガレージ作業の囲い、室内の間仕切り、作業スペースの区切り
- <strong>避けたい使い方</strong> : 室外機を囲う、ベランダや窓の外に張る
