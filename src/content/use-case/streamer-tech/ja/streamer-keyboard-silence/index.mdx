深夜のボイスチャットで「キーボードの音がうるさい」と言われたことはありませんか？
高価な静音キーボードに買い替えなくても、数百円から数千円で打鍵音は激減します。

## キーボードの打鍵音（カチャカチャ音）を消す重要性と防音の仕組み

キーボードの音には「スイッチそのものの音」と「机に伝わる振動音」の2種類があります。

### 配信でキーボードの音が嫌われる物理的な理由

マイクは高域の尖った音（クリック音）を拾いやすく、視聴者にとってストレスになります。
特に「底打ち音」と呼ばれる、キーを最後まで押し込んだ時の衝撃音を抑えるのがカギです。

### デスクマットが果たす「防振」の役割

キーボードを机に直置きすると、打鍵の衝撃が机全体をスピーカーのように鳴らしてしまいます。
厚手のデスクマットは、この振動を吸収する「防振材」として機能します。

## スイッチ種類で打鍵音はどれくらい変わるか

キーボードの静音化は、  
まずスイッチ特性を理解すると失敗しにくいです。

### 代表的な3タイプ

- <strong>赤軸（リニア）</strong> : クリック音は少ないですが、底打ち音は出ます。
- <strong>茶軸（タクタイル）</strong> : 押下感があり、やや高域ノイズが乗ります。
- <strong>静音軸</strong> : 軸側の緩衝で衝撃音を抑えやすく、配信向きです。

### 交換前に見るべきポイント

- <strong>配信時間帯</strong> : 深夜中心なら静音軸が有利です。
- <strong>ゲーム種類</strong> : FPSの連打が多いなら底打ち抑制が最優先です。
- <strong>作業難易度</strong> : はんだ不要のホットスワップ機を選ぶと安全です。

## 4つの静音化手法をコスト・効果で比較

買い替え前に、段階的に試すのがおすすめです。

| 対策 | 目安コスト | 効果 | 難易度 | 向いている人 |
| :-- | :-- | :-- | :-- | :-- |
| 静音リング | 500〜1,500円 | 底打ち音を中程度低減 | 低 | まず試したい人 |
| 厚手デスクマット | 1,500〜4,000円 | 机鳴りを低減 | 低 | 机振動が大きい人 |
| スイッチ交換 | 4,000〜12,000円 | 打鍵音全体を大きく低減 | 中 | 既存キーボードを活かしたい人 |
| 静音キーボード買い替え | 8,000〜25,000円 | 全体最適しやすい | 低〜中 | 最短で結果が欲しい人 |

### FPS配信者向けの優先順

1回目の改善では、  
<strong>静音リング + デスクマット + マイク近接化</strong> を推奨します。  
これで不足する場合に、軸交換か買い替えへ進む流れが効率的です。

## ソフト対策を組み合わせて完成度を上げる

物理対策だけでは、  
強打時の瞬間ノイズが残ることがあります。  
そこでAIノイズ抑制を併用します。

- <strong>ノイズ抑制（NVIDIA Broadcast等）</strong> : 打鍵帯域を自動で減衰します。
- <strong>ノイズゲート</strong> : 無発話時のキーボード音を遮断します。
- <strong>コンプレッサー</strong> : 声の音量を均し、ゲート誤作動を減らします。

### マイク位置の最終調整

- <strong>口元10cm前後</strong> : 小声でも十分な入力になります。
- <strong>キーボードから離す</strong> : 物理距離で打鍵音比率を下げます。
- <strong>指向性を口側へ</strong> : 机方向の音を拾いにくくします。
