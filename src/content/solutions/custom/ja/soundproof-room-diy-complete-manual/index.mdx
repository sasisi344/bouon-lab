## 最初に知る：「遮音」と「吸音」は完全に別物

DIYで最も多い失敗の原因がこの混同です。

| 性質                   | 遮音                                         | 吸音                                 |
| :--------------------- | :------------------------------------------- | :----------------------------------- |
| <strong>役割</strong>  | 音を外に漏らさない（反射・阻止）             | 室内の反響音・残響を減らす           |
| <strong>素材</strong>  | 石膏ボード・遮音シート（重い素材）           | ウレタンフォーム・ロックウール（軽い素材） |
| <strong>効果</strong>  | 隣人・近隣への音漏れを防ぐ                   | 録音のクオリティを上げる             |
| <strong>誤解例</strong> | 吸音材を貼ると「遮音できる」と思ってしまう  | 「静かになった気がする」は室内の反響が減っただけ |

<strong>外への音漏れを防ぎたいなら遮音、録音品質を上げたいなら吸音</strong> — この区別なしにDIYを始めると全額無駄になります。

## 「卵パック神話」を科学で否定する：質量則とは

「卵パックを壁に貼ると防音になる」——この都市伝説は <strong>物理学的に完全に誤り</strong> です。

### 質量則（Mass Law）の法則

音の透過損失（TL）は壁材の面密度（kg/m²）で決まります。

- <strong>面密度が2倍</strong> になると、透過損失は <strong>約6dB向上</strong>
- 卵パックの面密度：約0.1〜0.2kg/m²（ほぼゼロ）
- 石膏ボード12.5mm の面密度：約10kg/m²

6dBの遮音効果を得るだけで「石膏ボード2枚重ね」が必要です。卵パックでは <strong>理論上、何枚重ねても遮音は不可能</strong> です（吸音効果は若干あり）。

## 施工の3大鉄則

### 鉄則①：気密性は「光」で確認する

音は空気と同じ経路で漏れます。施工中は強力なLEDライトを外から当て、 <strong>「光が漏れる場所＝音が漏れる場所」</strong> を徹底的にコーキングで塞いでください。1mmの隙間が防音性能を30%低下させます。

### 鉄則②：重量分散で「床抜け」を防ぐ

1畳の本格DIY防音室は、人・機材・材料を含めると <strong>300〜500kg</strong> を超えることがあります。日本の住宅の床耐荷重は <strong>180kg/㎡</strong> が一般的な基準です。

**浮き床（フローティングフロア）構造が必須：**

- 防振ゴム → 合板 → ロックウール → 合板のサンドイッチ構造
- 「タイヤふにゃふにゃシステム」：廃タイヤを床下に敷く低コスト防振法
- プラ木靴（ぷらもっくく）：床面への荷重を分散する専用資材

### 鉄則③：換気・熱対策は生命線

2026年の夏、密閉された防音室は <strong>室温40℃超</strong> になります。換気なしは生命の危険です。

- <strong>エアコン設置可能なら</strong>：貫通スリーブを施工し防音ダクトで引き込む
- <strong>エアコン不可なら（0.5畳〜1畳の小型ブース）</strong>：スポットクーラー＋DIY換気ファン
- <strong>ASMR・宅録向け最高品質</strong>：ロスナイ（熱交換型換気）で空調ノイズなし換気

## スモールスタート：クローゼット改造（3万円〜）

「本格DIYに挑戦する前に試してみたい」という方に最適なのが <strong>クローゼット改造</strong> です。

- <strong>コスト</strong> : 3万円〜（既存のクローゼットを活用するため材料費のみ）
- <strong>賃貸対応</strong> : 壁に穴を開けない「板囲い方式」なら管理会社の許可不要
- <strong>用途</strong> : 歌ってみた・ゲーム実況・ナレーション収録

クローゼットはもともと密閉空間なので、遮音シートと吸音材を貼るだけで劇的に音質が向上します。ただし <strong>換気対策は必須</strong> です。

## よくある失敗例と対策

| 失敗例                      | 原因                          | 対策                             |
| :-------------------------- | :---------------------------- | :------------------------------- |
| <strong>「静かになった気がする」が外には漏れてる</strong> | 吸音材のみで遮音材なし | 遮音シート＋石膏ボードを追加 |
| <strong>夏場にサウナ状態</strong>        | 換気設計を省略した             | ロスナイ・スポットクーラーの先行設置 |
| <strong>フレームが歪んだ・壁が崩れた</strong>   | 遮音シートの重量を計算していない | 木枠は2×4材、垂木補強必須 |
| <strong>低音だけ抜けてくる</strong>     | 質量不足（薄い材料）           | 石膏ボード3重以上＋浮き床 |
| <strong>コーナーから音が漏れる</strong> | 接合部のコーキング不足         | L字金具＋コーキング二重塗り |

## まとめ：DIY防音室の正しい出発点

1. <strong>「遮音」と「吸音」を混同しない</strong>（最重要）
2. <strong>卵パック・段ボールは遮音不可</strong>（質量則を知る）
3. <strong>換気と重量分散は設計の第1工程</strong>（後付け不可）
4. <strong>20万円超なら中古ユニット型とROIを比較する</strong>
5. <strong>スタートはクローゼット改造（3万円〜）で検証する</strong>

防音室を自作することは、物理現象を味方につけるプロセスです。「光が漏れる場所に音が漏れる」というシンプルな法則を武器に、誰にも邪魔されない自分だけの音空間を手に入れてください。
