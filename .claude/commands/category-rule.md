# /category-rule — カテゴリ判定ルール

**使い方**:
```
/category-rule                          ← 対話形式でテーマを入力
/category-rule 防音室のローンの組み方    ← テーマ直接指定
/category-rule _draft/記事タイトル.md   ← ドラフトファイルから判定
```

---

## カテゴリ体系（2026-06-01 改定）

BouonLab は以下の **8トップカテゴリ** で構成される。サブカテゴリ（`diy` / `knowledge` / `solution` / `others`）は**廃止**。新規記事はすべて3階層URLに配置する。

```
/ja/{category}/{slug}/
```

| # | カテゴリ名 | URL第2セグメント | 優先度 |
|---|-----------|----------------|--------|
| 1 | 防音室 | `soundproof-room` | ★★★ |
| 2 | 防音賃貸 | `soundproof-rental` | ★★★ |
| 3 | DIY防音 | `diy` | ★★ |
| 4 | お金・補助金 | `money` | ★★ |
| 5 | 配信・クリエイター | `creator` | ★★ |
| 6 | 防音の基礎知識 | `knowledge` | ★ |
| 7 | 地域ガイド | `local` | ★ |
| 8 | 企業・法人向け | `business` | ☆ |

## 判定ルール（カテゴリ定義）

### 1. `soundproof-room` — 防音室

**記事の中心が「防音室という製品・空間」であるもの。**

含まれる記事タイプ:
- ユニット防音室（アビテックス・ナサール・OTODASU等）の選び方・比較・レビュー
- 防音室の導入・設置・搬入・撤去
- 防音性能（D値・DR値）の実測・スペック解説
- 防音室メーカー別ガイド
- サイズ・内寸の選び方
- 防音室の維持管理・メンテナンス
- 音漏れ対策・隙間処理

**判定ポイント**: 「防音室を選ぶ/使う/管理する」という行動が主題か？

除外: 費用・ローン中心 → `money` / DIY製作 → `diy` / 賃貸物件探し → `soundproof-rental`

---

### 2. `soundproof-rental` — 防音賃貸

**記事の中心が「賃貸住宅と防音の関係」であるもの。**

含まれる記事タイプ:
- 防音賃貸・楽器可物件の探し方
- 賃貸契約における防音条件・交渉・確認事項
- 賃貸での防音工事の可否・原状回復
- 管理組合・管理会社との交渉
- 防音賃貸市場動向・相場
- 楽器演奏OKの賃貸注意事項（チェロ・バイオリン・ピアノ等）
- 地域別防音賃貸ガイド（`local` と重複する場合は本カテゴリ優先）
- オーナー向け防音リノベーション投資

**判定ポイント**: 「賃貸物件を借りる・貸す立場での防音」が主題か？

除外: DIY改造がメイン → `diy` / 防音室製品がメイン → `soundproof-room`

---

### 3. `diy` — DIY防音

**記事の中心が「自分で防音を作る・改造する」手順・素材・コストであるもの。**

含まれる記事タイプ:
- 自作防音ブース・防音室の作り方
- 吸音パネル・バストラップ自作
- 防音素材（遮音シート・吸音材・防振マット）の選び方と施工
- DIYコスト内訳・材料費シミュレーション
- 失敗例・やってはいけないDIY
- 段ボール・布団などのゼロコスト簡易防音
- 賃貸でできるDIY防音（穴あけ不要系）

**判定ポイント**: 「自分でやる・自分で作る」HOW-TOが主な価値か？

タグで親カテゴリを明示: `tags: ["soundproof-room"]` or `tags: ["soundproof-rental"]`

---

### 4. `money` — お金・補助金

**記事の中心が「防音にかかるお金・もらえるお金・賢い使い方」であるもの。**

含まれる記事タイプ:
- 防音室の購入費用・価格相場
- ローン・分割払い・住宅ローン組み込み
- 補助金・助成金（空港/道路/自衛隊/省エネ窓）
- 節税・経費計上（個人事業主・フリーランス）
- ROI・資産価値シミュレーション
- 買取・中古売却
- 防音室のレンタル/リース費用比較
- 損益分岐計算（賃貸vs購入等）

**判定ポイント**: 「費用・お金・補助金・節税」が主題の中心か？

---

### 5. `creator` — 配信・クリエイター

**記事の中心が「配信者・VTuber・宅録アーティスト等の活動環境」であるもの。**

含まれる記事タイプ:
- ゲーム実況・ボイスチャット環境の防音
- VTuber向け防音室・ブース設定
- ASMR録音環境
- 配信部屋の吸音・音響設計
- 声優・宅録の録音ブース
- 配信者の熱管理・排熱・空調対策
- 配信者向け税務・経費（`money` との重複はペルソナで判断）

**判定ポイント**: 「配信/録音/VTuber活動」というペルソナの問題解決が主題か？

---

### 6. `knowledge` — 防音の基礎知識

**記事の中心が「防音の仕組み・科学・制度の純粋な解説」であるもの。**

含まれる記事タイプ:
- D値・DR値・STC値の仕組みと読み方
- 吸音と遮音の違い
- 残響時間（RT60）の概念・測定方法
- 固体伝搬音・空気伝搬音の違い
- 騒音規制・法令・受忍限度の基礎
- 防音素材の物理的特性
- 季節・統計データの解説
- 音の問題に関する科学的な誤解の訂正

**判定ポイント**: 「これを読むと仕組みが分かる」という純粋な知識記事か？

除外: 製品選びがメイン → `soundproof-room` / DIY手順がメイン → `diy`

---

### 7. `local` — 地域ガイド

**記事の中心が「特定の都市・地域における防音事情」であるもの。**

含まれる記事タイプ:
- 〇〇市の防音賃貸物件ガイド（仙台・大阪・福岡など）
- 地域別の補助金情報（道路沿い・空港周辺）
- 都市別の防音工事業者情報

**判定ポイント**: 地名が主要キーワードに入っており、地域特有の情報が価値の中心か？

---

### 8. `business` — 企業・法人向け

**記事の中心が「企業・法人ニーズの防音」であるもの。**

含まれる記事タイプ:
- オフィス・会議室・電話ブースの防音
- 音楽スタジオ・録音スタジオの設計・運営
- データセンター・工場の騒音対策
- シェア防音スタジオのビジネスモデル
- 防音業界の市場動向・企業分析
- 学校・医療施設の音響設計

**判定ポイント**: 「法人・企業の業務文脈」での防音が主題か？

## 判定フローチャート

```
記事テーマを確認
  │
  ├─ 地名が主役？ ──────────────────────────── → local
  │
  ├─ 企業・オフィス・スタジオ運営・市場分析？ → business
  │
  ├─ 配信者/VTuber/宅録の活動環境？ ─────── → creator
  │
  ├─ 費用・ローン・補助金・節税・ROI？ ───── → money
  │
  ├─ 自分で作る・素材を選ぶ・DIY手順？ ───── → diy
  │
  ├─ 仕組み・法令・科学的解説？ ─────────── → knowledge
  │
  ├─ 賃貸物件・契約・管理会社・大家？ ────── → soundproof-rental
  │
  └─ 防音室製品・設置・性能・選び方？ ────── → soundproof-room
```

## ファイルパスと frontmatter

### 配置パス
```
src/content/ja/{category}/{slug}/index.mdx
```

### frontmatter テンプレート（新規記事）
```yaml
---
title: "主要KWを左側に | 35-42文字"
description: "SEO用サマリー | 80-120文字"
slug: "unique-slug"
date: "YYYY-MM-DD"
lastmod: "YYYY-MM-DD"
draft: false
lang: "ja"
category: "{上記8カテゴリのいずれか}"
tags: ["タグ1", "タグ2"]
image: ./cover.png
---
```

> **`subcategory` フィールドは新規記事では不要。** 旧構造（diy/knowledge/solution/others）の記事を移行するときのみ、移行前の値を参考情報として残してもよいが、URLには影響しない。

### タグによるクロスリンク
カテゴリを跨ぐ関連性はタグで表現する。

| 状況 | 例 |
|------|----|
| DIY記事が防音室に関係する | `tags: ["防音室", "diy"]` |
| creator記事が賃貸前提 | `tags: ["配信者", "防音賃貸"]` |
| money記事が楽器向け | `tags: ["補助金", "楽器", "防音室"]` |

## 曖昧ケースの判定基準

| 状況 | 判定 | 理由 |
|------|------|------|
| 「防音室の費用まとめ」 | `money` | 費用が主題 |
| 「防音室の選び方（予算別）」 | `soundproof-room` | 製品選定が主題。費用は補助情報 |
| 「賃貸でDIY防音する方法」 | `diy` | HOW-TOが主題。タグに `soundproof-rental` |
| 「配信者向け防音室ガイド」 | `creator` | ペルソナが主題。タグに `soundproof-room` |
| 「VTuberの防音補助金活用」 | `money` | 補助金取得手順が主題。タグに `creator` |
| 「仙台の防音賃貸ガイド」 | `local` | 地名が主役 |
| 「大阪の防音工事費用」 | `local` | 地名 + 費用。地名が主役ならlocal |
| 「D値と防音室の選び方」 | `soundproof-room` | 選び方が目的。D値は説明手段 |
| 「D値の仕組みと読み方」 | `knowledge` | 純粋な解説が目的 |
