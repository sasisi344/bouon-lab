# /draft-plan — ドラフト記事ブレストコマンド

**引数**: ファイル名（省略時は \_draft/ 内の記事ドラフトを一覧して選択を促す）
例: `/draft-plan 防音賃貸の入居待ち期間にやるべき代替策.md`
例: `/draft-plan` （一覧から対話で選択）

## このコマンドの役割

ファイルを書き出す前に「どんな記事にするか」を対話で固める。**ファイルの書き込みは行わない**。提案 → フィードバック → 修正のループを繰り返し、方向性が固まったら `/publish-draft {ファイル名}` への引き渡しを提案する。

## Step 0. 事前ロード（毎回必ず実行）

1. `bouon-persona-thinking` skill — 本音と建前シンキングルール
2. `.agents/persona/01_Consumer-Personas.md` — ペルソナA〜H
3. `.agents/persona/00_Persona-Omega.md` — 編集長フィルター
4. `bouon-category` skill — カテゴリ定義

## Step 1. ドラフト一覧と選択

`$ARGUMENTS` が空の場合、`_draft/` 内の `.md` ファイルをスキャンし（`strategy-`/`cluster-ideas`/`owner-renovation-cluster`始まり・構想メモのみは除外）、番号付きで表示して選択を促す。`$ARGUMENTS` がある場合は指定ファイルのみ処理する。

## Step 2. ドラフト分析と提案カード生成

選択されたファイルを読み込み、以下の「提案カード」を1記事ずつ出力する。

`> [!forAI]` ブロックがある場合は、方向性・カテゴリ・読者・主張の前提をそこから最優先で取り込み、提案カードと矛盾させない（ブロックは企画用であり本番記事には載せない）。

### 提案カードのフォーマット

```
📄 {ファイル名}

## 現状分析
（骨格のみ / 一部本文あり / ほぼ完成、欠けている要素を1〜3行）

## 🎯 方向性の提案
**メインアングル**: なぜ今これを読むべきかを1文で
**差別化ポイント**: 既存記事（Globで確認）との違い
**記事の結論**: 読者が持ち帰る「1つの答え」

## 👤 ターゲットペルソナ
**主ペルソナ**: A〜Hから選び理由を1行で
**検索意図**: キーワード3〜5個
**読者の状態**: 記事を読む前の心理状態

## 📏 推奨ボリューム
**推奨**: Small / Medium / Large、**目標文字数**: {数値}〜{数値}字
理由: テーマの深さ・内部リンク充実度・アフィリエイト訴求の有無

## 🎭 トーン & マナー
**ペルソナボイス**: 下記「トーン選択の早見表」のどのセグメントか
**文体スタイル**: PREP/QUEST/PASONA、専門度
**避けるべき表現**: Persona Ωで引っかかりそうな箇所

## 🗂️ 提案見出し構成
[リード文]（結論先出し・100〜200字）
## {H2-1}
### {H3}（必要な場合）
## まとめ
## 次のステップ（内部リンク）
（想定文字数を各H2単位で括弧内に示す）

## 💰 マネタイズ提案（任意）
高単価記事（防音室・防音賃貸）ではPASONA/QUESTを起動する

---
フィードバックをどうぞ。「OK」で次の記事へ、「確定」でブレスト完了→/publish-draftへの引き渡し案内。
```

## Step 3. 対話ループ

| ユーザー発言 | 対応 |
| --- | --- |
| `OK` / `次` | 次のドラフトの提案カードを出力 |
| `確定` / `これでいく` | Step 4へ進む |
| `もっと短く` / `もっと詳しく` | ボリュームを変えた構成案を提示 |
| `アングルを変えて` | 別の切り口2〜3案を提示 |
| `ペルソナを変えて` | 別ペルソナ向けに調整して再提示 |
| `全部見直して` | 提案カードを丸ごと再生成 |

変更点のみを差分で示し、理由を1行添える。

## Step 4. ブレスト完了 → 引き渡し

「確定」が出たら、確定した方向性サマリー（アングル・ペルソナ・ボリューム・トーン・見出し数）と、次のアクション `/publish-draft {ファイル名}` を出力する。複数ファイルを処理した場合はまとめて出力する。

## 分析の観点（内部参照）

### ボリューム判断の基準

| 判定 | 条件 |
| --- | --- |
| **Small** | チェックリスト型・FAQ型・ハブ補助線・内部リンク先が充実 |
| **Medium** | 一般解説・比較記事・シナリオガイド |
| **Large** | ピラー記事・高単価商材・意思決定サポート・QUEST/PASONAが有効 |

### アングル発見の手順

1. ドラフトの「タイトル案」と「本文の主張」を読む
2. `src/content/` 内の近接記事をGlobで確認し、被りを避けた切り口を探す
3. ペルソナの「検索意図」に最も刺さるBefore/Afterを設定する
4. Persona Ωフィルター: 誇大広告・物理的根拠なし・二次リスク忘れがないか確認
