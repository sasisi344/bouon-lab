# BouonLab Growth Ops

## 収益導線

- 高単価記事では QUEST / PASONA / BEAF を用途に応じて使い分ける
- 防音賃貸は PASONA 寄り、防音室は QUEST 寄りで構成する
- 誇大表現を避け、根拠値・注意点・代替案をセットで提示する

## ビジュアル設計

- 装飾画像より「理解を短縮する図」を優先する
- 比較は表だけに依存せず、図解（マトリクス/フロー）化を検討する
- 画像生成プロンプトは英語、画像内テキストは必要に応じて日本語を使う（詳細は `bouon-writing` skillの`references/cover-image-fallback.md`）
- 生成画像は原則 `.png`、`image: ./cover.png` を標準運用とする

## SNS運用

Threads（@bouonlab）を運用中。投稿タイプの使い分け・文字数・リンクの置き方・作業フォルダは `bouon-threads-ops` skillを参照。
