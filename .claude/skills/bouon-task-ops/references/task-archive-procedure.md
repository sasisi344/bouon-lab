# task-list アーカイブファイルの書き方

`bouon-task-ops` SKILL.md の補助資料。

チェックリストの丸写しは不要。実行したこと・結果・参照先だけ残す。

```markdown
# task-list-NN

- **完了日**: YYYY-MM-DD
- **概要**: 1行

## 実施内容

- 何をしたか（箇条書き、各1行程度）
- 主要な成果・数値があれば1行

## 参照

- 詳細チェックリスト・分析本体のパス（あれば）
```

**索引**: 通し番号と概要一覧は `archive/task-list-index.md` を正とする。1回のアーカイブ操作＝1ファイルが基本だが、複数セクションを同時に片付ける場合（同日・同テーマの完了まとめ）は1ファイルにまとめてよい。
