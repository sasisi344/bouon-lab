# BouonLab Threads運用ルール

作業フォルダは `.workspace/_sns-post/` を使用する。**週間運用（週2ポスト×約3スレッド、`w{NN}-threads-post.md`、投稿後の`archive/`移動、ネタ台帳による重複防止）は `.workspace/_sns-post/CLAUDE.md` が正本**で、本skillと食い違う場合は週の本数・構成・文量・記録先は同ファイルを優先する。旧作業フォルダ `.agents/threads-ops/` は移行済み。
運用の基本方針（収益導線・ビジュアル設計）は `bouon-growth-ops` skillを参照。本ファイルは投稿の**中身の作り方**を定義する。

投稿は目的の異なる2種類に大別し、混同しない。

## 投稿タイプ①: 小ネタ型（定期投稿・低コスト）

- **目的**: 更新頻度の確保・フォロワーの離脱防止。エンゲージメント最大化は狙わない
- **ソース**: 既存の公開記事（`src/content/ja/**/index.mdx`）から「へえ、と思わせる事実・数値・比較」を**1つだけ**抜き出す。記事の要約ではなく、1トピックに絞る
- **選定基準**（数値・比較・意外性を優先）:
  - dB換算の身近な例（洗濯機・電車・クラクション等）
  - 価格帯・補助額の対比（例: 100万円クラスと簡易ブースの差）
  - 制度・規約の意外な条件（例: 使用細則の実際の文言）
- **文字数**: 週間ポストでは約3スレッドで合計350〜600字（`_sns-post/CLAUDE.md`）。単発で出す場合は100〜200字で単体完結させる
- **頻度**: 週間ポストの本数は `_sns-post/CLAUDE.md` に従う（標準は週2ポストのうち1本）
- **リンク**: 元記事へのリンクは任意。なくても内容として成立させる
- 直近で使用した記事・トピックは`_sns-post/archive/topic-index.md`で重複を避ける

## 投稿タイプ②: クエリ疑問オープナー型（長文・エンゲージメント重視）

- **目的**: リプライ・いいね・リポストなどのリアクション最大化。Threadsの長文投稿枠（最大500字）を活かし、他プラットフォームより深く書く
- **開始のフック**: 防音室・防音賃貸に関わる**実際の検索クエリ**（`weekly-task.md`の実データ、GSCエクスポート、`bouon-persona-thinking` skillの本音と建前分析）に基づいた疑問形で書き出す。検索者の言葉をそのまま、または近い表現で再現し、「これは自分のことだ」と数秒で認識させる（`bouon-persona-thinking` skillの「指名検索・個別クエリ記事における導入フックの厳格化」と同じ考え方をThreadsにも適用する）
- **架空のクエリを作らない**。必ず実データに基づくクエリ・悩みを起点にする
- **本文構成**:
  1. 疑問形の導入（検索者の言葉に近い表現）
  2. 本音の言語化（なぜその疑問を持つのか、不安の中身）
  3. 結論・具体的な答え（記事を読まなくても一定の価値が完結するボリュームで書く。要約ではなく実質的な回答にする）
  4. リアクションを誘発する一文で締める（例:「あなたの物件はどうでしたか？」といった問いかけ、または軽い意見表明で賛否を引き出す）
- **リンク**: 本文（1/3）には入れず、連投の最後（3/3）または1件目のリプライで元記事へ誘導する（本文内リンクはリーチが抑制される傾向があるため）
- **頻度**: 週間ポストの本数は `_sns-post/CLAUDE.md` に従う（標準は週2ポストのうち1本）。量産せず、クオリティを優先する

## 共通ルール

- **連投（3スレッド）の1/3と2/3の末尾には続き誘導を入れる**（`（1/3）👇`、次スレッドの予告1行など）。手法と禁止事項は `.workspace/_sns-post/CLAUDE.md` §2.1

- テンプレ化を避ける（フック・語順は投稿ごとに変える）
- 誇大表現・断定しすぎない書き方を守る（`.agents/persona/00_Persona-Omega.md`の検閲フィルターに準拠）
- 投稿後は必ず`.workspace/_sns-post/archive/topic-index.md`に記録する（投稿タイプ・ソース記事またはクエリ・切り口・投稿日・投稿URL）
- 使用済みの記事・クエリ・切り口は同台帳で管理し、次回選定時に重複チェックする（ルールは`_sns-post/CLAUDE.md` §5）
