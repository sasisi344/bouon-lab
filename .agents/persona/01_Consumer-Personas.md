## 【ペルソナA】30-40代・趣味の楽器演奏層（市場最大・購買意欲高）

- **年齢**: 30-40代
- **性別**: 男女半々（ピアノは女性比率高め、ギター・ドラムは男性比率高め）
- **居住形態**: 都市部の分譲マンション、または賃貸マンション
- **悩み・動機**:
  - 仕事終わりの夜間（20時以降）に練習したいが、近隣トラブルが怖くて音が出せない。
  - 本格的な防音室の購入や、防音賃貸への引っ越しを検討しはじめている。
  - 「音質（吸音しすぎないか）」にもこだわりがある。

## 【ペルソナB】20-30代・配信＆クリエイター（FPS・歌い手など）対象

- **悩み・動機**: 親や同居人フラグ、深夜のボイスチャットや打鍵音、安価な防音ブースの実用性。

### カテゴリ1：対「親・家族」防衛戦（交渉・ルール・資金）

- [x] 「うるさい！」と親に怒鳴られた夜に読む。深夜ゲーマーが家族と結ぶべき『騒音協定』のテンプレート
- [x] 親をスポンサーにせよ。「配信で稼ぐから防音室を買って」というプレゼンが失敗する理由と成功の鍵（→済：persuading-parents-soundproof-strategy）
- [ ] 実家防音の最終手段。親に「月3万円の家賃」を払ってでも防音リフォームを頼むべきか？
- [ ] 【親フラ防止】配信中に親が入ってこない環境作り。ドアの鍵＋「配信中ランプ」の効果検証
- [ ] 「勉強部屋」という名目で防音室をねだる。受験生×防音ブースの意外な相性の良さを親に説く
- [ ] 壁ドンは親からの警告音。家族のストレス限界ラインを見極める「深夜の騒音チェック」法

### カテゴリ2：FPS・格ゲー・配信特化（プレイスタイル別）

- [x] 【動作検証】トラッキングが飛ぶ？狭い防音室でモーションキャプチャーを快適に動かす空間設計の裏技

- [x] 家賃4万のアパートに「防音室」をぶち込む。引っ越しvs購入、どっちが「最安で静寂」を手に入れられるか比較
- [x] 中古の簡易防音室を買う時の注意点。「タバコ臭」と「パーツ欠品」で詰まないためのチェックリスト

### カテゴリ4：生活環境・快適性（狭い・暑い・暗い）

- [x] 【ゲーム実況】汗だく配信を卒業。エアコンなしの簡易防音室で夏を乗り切る「スポットクーラー」設置ガイド

- [x] 隣人からの「壁ドン」が止まらない。防音室を買う前にまずやるべき「謝罪」と「配置換え」

## 【ペルソナC】40代後半〜・テレワーク＆書斎（高所得・合理的判断・持家/高級賃貸）

この層は「防音室＝資産価値・生産性向上・QOL（生活の質）」という視点で見る。タイトル付けは信頼性と専門性の高さを追求すること。

### カテゴリ1：仕事・生産性・セキュリティ（「投資対効果」）

- [x] 機密情報の漏洩を防ぐ。経営者・役員のための自宅内「完全個室」セキュリティ構築ガイド（→済：executive-home-office-security）
- [x] Web会議の「音質」は信頼に直結する。相手にストレスを与えない防音室の残響調整とマイク選定
- [x] リビングの一角を社長室に。1.5畳で実現する「没入型」テレワークブースの最適解
- [x] 家族の生活音をシャットアウト。集中力を「買う」ための防音室導入とROI（投資対効果）試算（→済：telework-family-stress-solution）
- [x] 「パパの声がうるさい」とは言わせない。在宅ワークと家庭円満を両立する遮音設計の重要性
- [x] 深夜の海外カンファレンスも安心。寝室の隣でもパートナーを起こさないDr-40の静寂性能（→済：executive-home-office-security）
- [x] 【節税対策】防音室は「経費」で落とせるか？経営者が知るべき減価償却の期間と固定資産税の判定基準

### カテゴリ2：資産価値・不動産・リフォーム（「資産防衛」）

- [x] マンション売却時に「防音室」は武器になるか？プラス査定を狙うリフォーム戦略と市場価値（→済：soundproof-room-asset-value）
- [ ] 【資産価値】組み立て式ユニットvs造作工事。将来のライフスタイル変更に強いのはどっち？
- [ ] タワーマンションの「梁」や「柱」に合わせる。オーダーメイド防音室の施工事例と費用感
- [ ] 高級賃貸でも諦めない。原状回復可能な「浮き床構造」ハイスペック防音室の選び方
- [ ] 「リセールバリュー」で選ぶ防音室メーカー。ヤマハ・カワイ・専門業者の5年後再販価格比較
- [ ] マンション管理規約の「L値（床衝撃音）」をクリアする。階下トラブルゼロの防音床構造解説
- [ ] リノベーション防音の落とし穴。スケルトン工事で「やっていいこと」と「構造上無理なこと」

### カテゴリ3：居住性・健康・環境（「QOLの追求」）

- [x] 【生産性維持】脳を飽和させない！1.5畳防音室の「二酸化炭素濃度」とロスナイ同時換気の技術論
- [x] 【空調設計】静寂を壊さない。1.2畳以下の狭小防音室にエアコン・冷房を「スマートに」導入する方法
- [ ] 「無響室」は逆に疲れる？仕事が捗る「適度な雑音」と「吸音」の黄金比率
- [ ] シックハウス症候群を防ぐ。F☆☆☆☆（フォースター）建材だけを使った安全な防音室選び
- [x] 照明で圧迫感を消す。演色性の高いLEDと「ガラス扉」で演出する広がりある書斎空間
- [ ] 老後の趣味を見据えて。バリアフリー対応の防音ドアと床段差の解消法

### カテゴリ4：オーディオ・シアター・趣味（「大人の隠れ家」）

- [ ] 深夜のホームシアター。重低音（サブウーファー）を近隣に響かせない防振・遮音の極意
- [ ] ピュアオーディオの性能を解放する。電源ノイズ対策と「部屋鳴り」を抑える音響工事
- [ ] 書斎兼オーディオルーム。仕事と趣味をスイッチする「大人の隠れ家」レイアウト術
- [ ] 妻も納得するデザイン性。リビングの景観を損なわない「家具調」防音室の可能性
- [x] グランドピアノをマンションに。床の耐荷重制限をクリアする補強工事と配置計画
- [ ] アナログレコードを大音量で。針飛びを防ぐ床の剛性と「制振」の科学

### カテゴリ5：スペック比較・技術検証（「合理的判断」＆「防御の真実」）

- [x] 【実測の重要性】カタログスペック「Dr-35」の罠。施工誤差と現地実測値の乖離が生む「期待外れ」を防ぐ方法
- [x] 【ブランド比較】ヤマハ・カワイ・専門工務店。1.5畳超の「居住性」と「音響特性」から選ぶハイエンド防音室の正解
- [ ] 失敗しない業者選び。見積もり段階で「素人工務店」を見抜く5つの質問リスト
- [x] 【物理的根拠】窓の防音は「二重サッシ」だけでは限界あり。ガラス厚と空気層（エアギャップ）が導く遮音の方程式
- [ ] Dr-35とDr-40の決定的違い。対数グラフで読み解く「5dB」が聴感上の騒音を半減させる物理的根拠
- [ ] 【実測検証】カタログ値「Dr-40」は現場で再現できるか？施工誤差とフランキング伝搬（側路伝搬）の現実
- [ ] 「D値」と「Rw値」の混同に注意。ISO基準とJIS基準の違いから見る、輸入防音室の性能評価
- [ ] 低周波騒音（125Hz以下）はなぜ止まらないのか？「質量則」の限界と重低音対策の物理的アプローチ
- [ ] 防音ドアの気密性能「T値」とは何か？グレモンハンドルとマグネットパッキンの遮音性比較
- [ ] グラスウール密度「32k」と「96k」の吸音率比較。壁内充填において高密度＝高性能とは限らない理由
- [ ] 「コインシデンス効果」による遮音欠損の恐怖。石膏ボードの厚みを変える（12.5mm+9.5mm）異厚貼りの重要性
- [ ] 遮音シート（面密度）vs 石膏ボード（剛性）。コスト対効果で見る、壁の重量増と遮音性能の相関関係
- [ ] 乾式浮き床（フリーフロア）の固有振動数計算。ピアノの打鍵音が階下に伝わる「共振」メカニズムの解説
- [ ] 制振材（ゴム・アスファルト系）の正しい使い方。振動エネルギーを熱エネルギーに変換する「損失係数」の科学
- [ ] 三菱電機「ロスナイ」の熱交換効率と遮音性能。給排気同時換気が防音室に必須である技術的理由

- [x] 「デッド」すぎると脳が疲れる？防音室内の最適残響時間（RT60）と吸音・拡散の黄金比率（→済：rt60-reverberation-guide）

## 【ペルソナD】20-30代・睡眠重視/音過敏の単身者（騒音被害・環境改善層）

自ら音を出すのではなく、「隣人の生活音」や「外の騒音」に悩まされており、静かなパーソナルスペースを確保したい層。

- **ターゲット**: 幹線道路沿いや線路沿い、または壁の薄い賃貸アパート・マンションに住む会社員や交代勤務者。HSP気質など音に敏感な人。
- **悩み**: 外の車の走行音（低周波音）や隣人の生活音（足音、テレビ、いびき等）による睡眠障害やストレス。賃貸のため大規模な防音工事ができない。
- **ニーズ**: 賃貸でも可能な原状回復できるDIY防音（隙間テープ、吸音ボード、突っ張り棒を使った簡易内窓など）。防音効果に加えて「遮光・遮熱」も兼ね備えた高機能防音カーテン。睡眠の質向上に向けた具体的なノウハウ。

## 【ペルソナE】30-40代・子育て奮闘中のファミリー（生活音配慮層）

楽器などは弾かないものの、小さな子供の出す音で近隣トラブルになることを恐れている層。

- **ターゲット**: 集合住宅に住む、未就学児〜小学生の子供がいる家庭。
- **悩み**: 子供の走り回る足音（床衝撃音）や泣き声による階下・隣室からの苦情。100均のジョイントマットだけでは効果が薄いことへの不安。防音対策とインテリア性の両立。
- **ニーズ**: 重量音（ドスンドスンという音）を防ぐための高密度な防振マットや防音カーペット。子供が転んでも安全なクッション性。部分的な敷き詰めや、掃除・手入れのしやすさ。

## 【ペルソナF】30-50代・ペット愛好家（多頭飼い・ペット共生層）

- **ターゲット**: ペット可の集合住宅で、犬や猫を飼育している人。
- **悩み**: 留守中の犬の無駄吠えや、夜間のケージ内での物音、猫が走り回る足音。ペットが防音材を引っ掻いてボロボロにする、または粗相をしてしまうリスク。
- **ニーズ**: 洗える・消臭機能付きの防音タイルカーペット。引っ掻きに強い壁用防音パネル。ペットの誤飲や健康に影響のない安全な素材。

## 【ペルソナG】60代以上・リタイア後の趣味人（オーディオ・シアター・DIY層）

時間と資金に余裕ができ、持ち家で趣味を極めたいシニア層。

- **ターゲット**: 退職後、持ち家（戸建て）でホームシアターや高級オーディオ鑑賞を楽しむ層。
- **悩み**: 大音量や重低音による同居家族（配偶者）や近隣への迷惑。加齢によりテレビなどの音量が大きくなりがち。本格的な防音室を作りたいが、後の処分やメンテナンスが面倒。
- **ニーズ**: 単なる音の遮断だけでなく、室内の響きを最適化する「調音パネル」などの音響設計。二重窓リフォーム等で利用できる国や自治体の補助金（先進的窓リノベ事業など）の活用。

## 【ペルソナH】40〜60代・子育て世代の「一人になれる空間」希求層（2026-07-05追加）

子育てに追われる中で、自宅に防音室・遮音性の高い部屋がなく、趣味や一人の時間に没頭できるプライベート空間を欲しがっている層。ペルソナGと異なり、退職後の余裕層ではなく、まだ子育て・仕事の渦中にいる現役世代である点が特徴。

- **ターゲット**: 40〜60代、子どもと同居中（未成年〜同居の成人子どもまで幅広い）。持ち家・賃貸を問わず、自宅に防音室や遮音性の高い個室がない。
- **悩み**: 「今は自宅に静かな空間がないが、欲しい」という漠然とした願望はあるが、何から手をつければいいか分からない。引っ越し・DIY・業者依頼・防音室購入のどれが自分の予算感に合うか判断材料がない。子育て中で時間的・心理的余裕も限られ、大掛かりな決断への腰が重い。
- **ニーズ**: 予算・年収に応じた現実的な選択肢の比較（引っ越し／DIY／専門業者への防音リフォーム依頼／防音室購入）。大掛かりな決断をする前に踏める小さな一歩の提示。原状回復や家族の同意など、実行に移す際の障壁への配慮。
