## 本文（1投稿目・長文）

```
「マンションでピアノ、何時まで弾いていいの？」

これ、検索してもスッキリ答えが出てこない質問です。

理由は単純で、「何時何分までならセーフ」という全国共通の法律が存在しないから。

判断材料になるのは3つだけ。

・管理規約（物件ごとにバラバラ）
・自治体の条例（実は時刻ではなく音量の基準がほとんど）
・受忍限度（音量・時間帯・頻度から総合判断される考え方）

使用細則でよく見かける文言はこれです。

「午前9時から午後8時までの間に、十分な防音措置を講じたうえで行うこと」

でも規約に何も書いていない物件も普通にあります。その場合、自治体の生活騒音の目安（昼間55dB・夜間45dB）と、受忍限度の考え方を組み合わせて自分なりの基準を作るしかありません。

一般的なマナーの目安は平日9〜20時・休日10〜19時あたり。でもこれは法的な保証じゃなく、あくまで「トラブルになりにくい範囲」の話。

みなさんの物件の規約、何時までって書いてありますか？
```
