# 防音シートの規格サイズと中古・使用済品の流通に関する調査

## 記事ドラフト案（公開用）

### 想定タイトル
防音シートの規格サイズ完全ガイド | 工事用は家庭で使える？費用と効果を理論で解説

### 想定読者
- 配信・テレワークで「簡易的に音漏れを減らしたい」人
- 工事現場向け防音シートをDIY転用したい人
- 中古防音シートの相場とリスクを先に知りたい人

### この記事で結論からわかること
- 工事用防音シートは一般流通しており、個人でも購入は可能です。
- ただし、室内での「防音対策」としては単体性能に限界があります。
- カーテンで区画する簡易ワークスペースは、主に高音域で体感改善します。
- 会話音の完全遮断は難しく、目的を「軽減」に設定するのが現実的です。

---

## 導入

工事現場で使う防音シートは、家庭でも買えるのでしょうか。  
結論は「買えるが、使い方にコツが必要」です。  

理由は、工事用シートが本来「屋外の仮設用途」で設計されているためです。  
屋内の生活音対策では、重量・隙間・設置方法が効果を大きく左右します。  

本記事では、まず規格サイズを整理します。  
次に、中古流通と価格を確認します。  
最後に、防音カーテンで区画した簡易ワークスペースがどこまで効くかを理論的に説明します。  

---

## 工事用防音シートの規格サイズ

工事現場向け防音シートは、足場のモジュールに合わせた寸法で作られています。  
最も流通量が多いのは、幅1.8mクラスです。  

### 1枚物の代表サイズ

| 規格サイズ（幅×高さ） | 主な用途 | コメント |
| :--- | :--- | :--- |
| 1.8m × 3.4m | 標準足場の主面 | 最も一般的。家庭DIYでは大きめ。 |
| 1.5m × 3.4m | 調整部位 | ベランダや狭小面で使いやすい。 |
| 1.2m × 3.4m | 端部調整 | カット前提で扱いやすい。 |
| 0.9m × 3.4m | 隙間・コーナー | 室内パーティション用途に転用しやすい。 |
| 0.6m × 3.4m | 細部補助 | 補修・二重張りの追加材向け。 |
| 1.8m × 5.1m | 高さ確保が必要な面 | 室内では余りが出やすい。 |

### ロール物の代表サイズ

| 規格サイズ | 特徴 | 室内利用の注意点 |
| :--- | :--- | :--- |
| 幅1.8m × 長さ50m | 現場での連続施工向け | 重量が大きく搬入が大変。 |
| 幅0.9m × 長さ50m | 小回り重視 | 端部処理と固定が必要。 |

- ハトメ間隔はおおむね300〜450mmです。  
- 厚みは0.4〜1.0mm超まであります。  
- ロール原反はハトメ無しの場合があり、固定パーツが別途必要です。

## 工事用防音シートは一般流通するか

結論として、一般流通しています。  
ただし「新品」「中古」「リースアップ」で品質差が大きい市場です。  

### 主な入手ルート

1. 仮設資材専門店（新品・中古）  
2. ECモール（新品中心、一部リユース）  
3. オークション・フリマ（中古中心）  
4. 地域掲示板・引き取り取引（中古中心）  

### 中古・使用済品が多い理由

- 現場単位で入れ替えが発生する  
- 破れが軽微なら再利用できる  
- 新品より単価が下がり、需要がある

## 価格帯の目安（新品・中古）

相場は、厚み・防炎性能・状態で上下します。  
以下は個人購入時の目安です。  

| 区分 | 1.8m×3.4m相当の目安 | 備考 |
| :--- | :--- | :--- |
| 新品（標準グレード） | 4,000〜8,000円/枚 | 防炎・厚手で上振れ。 |
| 新品（高遮音・高耐久） | 8,000〜15,000円/枚 | 仕様書確認が必須。 |
| 中古（軽度使用） | 2,000〜5,000円/枚 | ハトメ・破れ確認が重要。 |
| 中古（使用感強い） | 500〜2,000円/枚 | 補修前提。臭い注意。 |

### 送料の落とし穴

- 1枚で5〜10kg前後になりやすい  
- 枚数が増えると、送料が商品代を超えることがある  
- 近隣引き取りが総額最安になるケースが多い

## 部屋の防音対策に使えるか

「使えるが、単体では不十分」が実務的な答えです。  
防音シートは、音を止める素材というより「透過を少し下げる補助材」と考えると失敗しにくいです。  

### 室内利用で効きやすいケース

- 窓面・開口部の一次遮蔽  
- 既存カーテンの裏打ち  
- パーティション面の追加質量としての利用  

### 効きにくいケース

- 低音（重低音、キック、サブベース）の抑制  
- ドア下や壁コンセント周辺の隙間が多い環境  
- シートを「1枚吊るすだけ」の設置  

### 安全面・実用面の注意

- 屋内利用では換気と臭気対策を優先  
- 防炎ラベルの有無を確認  
- 重量物の吊り下げは転倒・落下対策を実施

## 防音カーテンで区画した簡易ワークスペースの遮音を理論で見る

ここでは、部屋の一角をカーテンで囲ったケースを想定します。  
理論上、効果は「素材の透過損失」と「隙間率」でほぼ決まります。  

### 基本モデル

- カーテン単体の透過損失を 8〜15dB（中高音中心）と仮定  
- 天井・床・側面の隙間から回り込む音を考慮  
- 実効遮音は、単体性能より大幅に低下  

### 簡易計算イメージ

区画面積のうち、実際にシートで塞げている割合を `C` とします。  
体感上の実効値は、おおまかに次の関係になります。  

`実効遮音量 ≒ 素材遮音量 + 10log10(C)`  

例として、素材遮音量を12dB、被覆率を70%とすると、  
`10log10(0.7) ≒ -1.55dB` なので、理論値は約10.5dBです。  

さらに実空間では、床・天井・隙間共振・構造伝搬があるため、  
最終的な体感改善は3〜8dB程度に収まることが多いです。  

### 3〜8dBの意味

- 3dB低下: わずかに小さく感じる  
- 6dB低下: はっきり小さく感じる  
- 10dB低下: かなり小さく感じる（ただし完全遮断ではない）  

つまり、カーテン区画は「迷惑低減」には有効です。  
一方で、深夜配信や楽器の強音を無音化する手段ではありません。

## 実践しやすい構成例（低コスト順）

### 構成A: 既存カーテン + 防音シート裏打ち

- 目安費用: 1.5万〜4万円  
- 期待効果: 会話帯域中心に軽減  
- 向く用途: テレワーク、軽い配信  

### 構成B: カーテン2重 + 床ラグ + 隙間処理

- 目安費用: 3万〜8万円  
- 期待効果: 反射抑制と漏れ低減のバランス  
- 向く用途: 長時間配信、ボイス収録  

### 構成C: カーテン区画 + 吸音材 + マイク近接運用

- 目安費用: 5万〜12万円  
- 期待効果: 録音品質改善と近隣配慮の両立  
- 向く用途: 配信・ナレーションを継続運用

## 購入前チェックリスト

- サイズは搬入経路に通るか  
- 臭いと汚れ許容度を家族合意できるか  
- 防炎・材質情報を確認したか  
- 送料込み総額で比較したか  
- 目的を「無音化」ではなく「軽減」に設定したか  

---

## まとめ

工事用防音シートは、一般流通しており個人でも入手可能です。  
ただし室内防音では、シート単体に過度な期待は禁物です。  

効果を出す鍵は、被覆率・隙間処理・二重化です。  
カーテン区画は中高音の軽減には有効ですが、低音対策は別設計が必要です。  

「どこまで静かにしたいか」を先に定義し、予算と施工難易度を合わせると失敗しにくくなります。
